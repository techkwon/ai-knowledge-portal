ComfyUI-PhotoDeblur: 원본 크기를 유지하는 타일 사진 흔들림 보정

HI-Diff와 MISCFilter로 흔들림·움직임에 의한 흐림을 줄이는 ComfyUI 노드. 타일·겹침 처리로 입력 크기를 유지하지만 잃어버린 사실이나 익명화된 얼굴의 정확한 복원을 보장하지 않는다.

#사진 보정#HI-Diff#MISCFilter#타일 처리

무엇을 할 수 있나요?

HI-Diff·MISCFilter 각각 RealBlur_J·RealBlur_R·GoPro 체크포인트를 지원한다. R은 모델 변형 이름이지 RAW 사진 입력 모드가 아니다. RAW는 먼저 현상하고 sRGB TIFF·PNG로 넣도록 안내한다.

원본 해상도를 유지하면서 타일을 나눠 추론하고 겹치는 경계를 블렌딩한다. 시작값은 RealBlur_J, tile 768, overlap 96, TTA 끔이며 VRAM이 부족하면 512·64로 낮춰 비교하도록 제작자가 권한다.

ComfyUI의 Python 환경에 의존성을 설치하고 예제 워크플로에서 로더와 다운로드 노드의 모델·변형을 맞춘다. MISCFilter의 안내 환경은 NVIDIA CUDA 12·CuPy이며 별도 요구사항 설치가 필요하다.

다운로더는 제작자가 지정한 공식 원본 아카이브를 받아 SHA256을 확인하는 설계다. HI-Diff는 각 변형별 세 파일, MISCFilter는 변형별 단일 가중치 파일이 필요하다. 직접 다운로드·해시검증은 수행하지 않았다.

살펴볼 점
  • 설치·추론·품질·속도는 시험하지 않았다. 제작자의 예시와 소수 사진 관찰 결과이며 심한 초점 이탈·작고 크게 흐려진 얼굴·하이라이트 손실은 개선이 제한될 수 있다.
  • 생성·추정된 디테일을 실제 인물 식별이나 증거로 사용하지 않는다. 블러로 익명화한 사진의 원래 신원을 정확히 되찾는 도구로 안내하지 않는다.
  • TTA는 8방향 예측을 평균하여 모델 연산량이 대략 8배가 된다. 타일을 크게 하거나 TTA를 켜면 자원·시간을 추가로 고려한다.
  • 새 통합 코드는 MIT, 포함 HI-Diff 코드는 Apache-2.0, MISCFilter 코드는 MIT로 안내된다. 가중치는 별도 다운로드이며 코드 라이선스가 체크포인트·데이터의 모든 사용을 자동 허가한다고 보지 않는다.
  • 기본 Save Image는 8-bit PNG를 쓴다. 추가 색보정용 16-bit 저장은 지원되는 고급 저장 노드와 색공간 설정을 확인한다.
