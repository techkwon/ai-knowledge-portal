K-EXAONE 2.5 API: 무료 이용과 비상업·제3자 호출 제한

LG AI연구원의 OpenAI 호환 텍스트 API. 무료 공개와 별개로 비상업 이용·제3자 호출 제한을 확인하고 개인 에이전트 연결을 검토합니다.

#EXAONE#API#추론#이용약관

무엇을 할 수 있나요?

K-EXAONE 2.5는 LG AI연구원이 EXAONE API Platform에서 제공하는 텍스트 전용 모델입니다. 공식 발표는 현재 무료 API 이용을 안내합니다. API는 OpenAI 호환 형식이며 모델 식별자는 k-exaone_v2.5, 호출 경로는 POST /v1/chat/completions입니다.

최대 문맥 길이 524,288토큰은 입력과 max_tokens의 합에 적용됩니다. max_tokens에는 추론 토큰도 포함됩니다. reasoning_effort는 low·high·max를 지정할 수 있으며 기본값은 max입니다. 짧은 답변을 원하더라도 추론 예산을 함께 고려해야 합니다.

이용 전에는 발표문보다 플랫폼 약관의 허용 범위를 먼저 확인해야 합니다. 검토한 2026년 11월 9일 시행 한국어 약관은 비상업적 이용 권한만 부여하고, 모델이나 결과물의 영리 목적 이용 및 제품·서비스 통합을 통한 제3자 호출·입력 제출을 금지합니다. 무료 API를 누구나 이용하는 앱의 백엔드로 바로 배포할 수 있다고 안내하지 않습니다.

비밀이 없는 자체 평가 입력을 준비하고, 허용 범위를 검토한 뒤 API 키를 안전한 서버 측에 보관하는 순서가 적절합니다. 키는 발급 후 30일 유효합니다. 429가 발생하면 응답의 잔여 한도와 retry-after 계열 헤더를 확인합니다. 공식 문서의 예시 숫자를 계정별 보장 한도로 받아들이지 않습니다.

공식 Agent 연결 문서는 Hermes와 OpenCode를 안내합니다. 허용되는 개인 실험이라면 키를 환경변수 EXAONE_API_KEY에 두고 기존 Hermes 설정에 exaone provider를 병합하는 흐름을 참고할 수 있습니다. 기존 설정 전체를 덮어쓰지 않고, 비민감한 작은 작업에서 도구 호출·결과 반환·다음 턴까지 이어지는지 각각 확인하는 것이 좋습니다. 문서별 추론 강도 예제가 일치하지 않아 이 카드에는 검증되지 않은 고정 설정값을 제시하지 않습니다.

발표의 성능 수치는 제작자 자체 평가이며 실사용 속도나 다른 모델 대비 우열을 보장하지 않습니다. API 호출·가입·설치·성능 테스트는 직접 하지 않았습니다.

살펴볼 점
  • 무료 API 접근과 오픈 웨이트 라이선스는 다릅니다. 플랫폼은 가중치·파라미터·소스코드 제공을 약속하지 않습니다. 기존 K-EXAONE 2.0 카드의 가중치 조건을 2.5 API에 전용하면 안 됩니다.
  • 검토한 한국어 약관은 만 19세 이상, 타인 개인정보 입력 금지, 회사의 입력·결과물 이용 권한과 모델 학습 거부의 사후 적용을 명시합니다. 학습 거부와 이용 기록 분석 선택동의에 따른 한도 확대를 같은 설정으로 추정하지 말고 각각 확인해야 합니다.
  • 본 글은 공식 공개 문서의 독립 요약이며 출력물이나 모델을 재배포하지 않습니다. 직접 테스트하지 않았습니다.
  • API 키는 발급일부터 30일 유효하며 약관은 향후 유료 전환 가능성을 둡니다. 현재 무료 안내를 영구 무료·무제한 보장이나 가중치 재배포 허가로 해석하지 않습니다. 실제 사용 전 최신 한국어 약관과 적용되는 공통약관을 다시 확인하세요.
