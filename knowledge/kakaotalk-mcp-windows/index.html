KakaoTalk MCP: Windows PC 자동화

Windows의 카카오톡 PC를 Win32 API로 제어해 MCP 클라이언트에서 메시지 읽기·전송과 키워드 모니터링을 연결하는 커뮤니티 도구

#MCP#Windows#메신저

무엇을 할 수 있나요?

Windows 10/11, 로그인된 카카오톡 PC, Python 3.10 이상이 필요합니다. macOS와 Linux에서는 동작하지 않습니다.

uvx kakaotalk-mcp로 실행하거나 Claude Code에서 claude mcp add kakao -- uvx kakaotalk-mcp로 등록할 수 있습니다. 먼저 상태 확인과 열린 방 목록 확인부터 시작하세요.

읽기·URL 추출·이미지 전송·키워드 모니터링 도구를 제공하며, 서버 내부 자동 응답은 README의 예정 기능으로 구분되어 있습니다.

살펴볼 점
  • 카카오의 공식 API나 Aside의 macOS 읽기 전용 연결과 다른 커뮤니티 프로젝트입니다. 다른 연결의 지원 기능으로 혼동하지 마세요.
  • 일부 동작은 창을 최전면으로 가져오고 클립보드를 변경합니다. 이미지 캐시는 방별로 구분되지 않으므로 다른 대화의 자료가 섞일 수 있습니다.
  • 메시지·이미지·일괄 전송은 실제 외부 행동입니다. 수신 대상과 내용을 사람이 확인한 뒤 승인하고, 사적 대화를 모델에 보내기 전에 동의와 처리 범위를 점검하세요.
