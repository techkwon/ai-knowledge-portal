ThreeRT: three.js 스타일 장면을 광선 추적 런타임으로

three.js와 유사한 장면 API로 조명·반사·물리·게임 로직을 구성하는 공개 렌더링 엔진. 브라우저 three.js 실행과 전용 클라이언트의 광선 추적은 구분해야 합니다.

#Three.js#3D#광선 추적#로컬 렌더링

무엇을 할 수 있나요?

ThreeRT는 Rust·wgpu 기반의 패스 트레이서와 임베디드 JavaScript 런타임이다. @threert/scene으로 장면·카메라·재질·광원을 구성하고 @threert/gameplay로 상태와 입력을 추가한다. three.js와 독립된 프로젝트이며 제휴된 공식 three.js 기능은 아니다.

공식 문서는 Mac 클라이언트에 포함된 CLI로 프로젝트 생성, 개발 서버, 타입·기초 실행 검사, 이미지 캡처와 정적 패키지를 만드는 흐름을 안내한다. 같은 주소를 일반 브라우저로 열면 three.js로 실행되며, 전용 클라이언트의 광선 추적 경로와 같다고 단정할 수 없다.

문서의 개발 경로는 Apple Silicon·macOS 14 이상이다. iPhone·iPad는 iOS 17 이상이며 최신 문서는 Linux x86_64·Steam Deck과 Android arm64·Android 10 이상 재생 클라이언트도 안내한다. README의 클라이언트 목록보다 문서가 넓으므로 실제 배포와 기기별 호환을 사용 전에 확인해야 한다.

소스 빌드는 Rust·Node 24·Bun을 요구한다. GPU가 지원하면 Metal·Vulkan 하드웨어 ray query를, 미지원 환경에서는 소프트웨어 BVH를 사용한다고 README가 설명한다. GPU 지원과 실제 장면의 속도는 별도다.

살펴볼 점
  • 직접 설치·빌드·렌더·성능 측정은 하지 않았다. 제작자의 특정 장면 프레임 수·품질 수치를 일반 기기 성능 보장으로 옮기지 않았다.
  • 엔진 코드는 MIT이며 저작권·허가문 보존과 무보증 조건이 있다. README가 무료·폐쇄 소스로 안내하는 macOS·iOS 클라이언트와 엔진 소스의 권리를 혼동하지 말아야 한다.
  • 모델 가중치 배포 도구가 아니다. 외부 3D 에셋은 엔진의 MIT와 별개로 CC BY·CC0·ODbL 등 각 권리가 적용되며 장면별 표기·배포 조건을 따로 확인해야 한다.
  • 장면 작성 자체에 LLM API·개인 AI 구독을 요구한다고 읽은 문서는 말하지 않는다. 코딩 에이전트를 붙일 때의 모델 요금·계정 사용 조건은 별도이며, threert.app 공개에는 GitHub 로그인이 필요하다고 문서가 안내한다. 호스팅의 전체 요금·한도와 연령 조건은 이번 확인 범위에서 검증하지 않았다.
