Stitch CLI: 터미널과 코딩 에이전트에서 Google Stitch 화면 만들기

npm으로 설치하는 Google Stitch 공식 CLI로, Google 로그인 뒤 /stitch 스킬을 코딩 에이전트에 추가해 화면 생성·DESIGN.md 동기화·앱 UI 점검을 대화나 명령어로 실행합니다.

#Google Stitch#CLI#DESIGN.md#에이전트 스킬#UI 디자인

무엇을 할 수 있나요?

Stitch 공식 문서(베타)의 CLI 빠른 시작은 Node.js 20 이상에서 `npm install -g @google/stitch`로 설치하거나 `npx @google/stitch`로 바로 실행하는 방법을 안내합니다. `stitch login`은 브라우저 Google OAuth로 로그인하며, 헤드리스·CI 환경은 `STITCH_API_KEY` 환경 변수나 전역 설정의 API 키를 쓰고 `stitch status`로 상태를 확인합니다.

Claude Code·Cursor·Gemini CLI·Antigravity 같은 코딩 에이전트를 쓴다면 `stitch agent-skills add --user`로 /stitch 스킬을 설치합니다. 이후 에이전트 대화에서 /stitch로 화면 생성, DESIGN.md 추출·동기화, 실행 중인 앱 점검을 요청할 수 있습니다.

터미널만으로도 `stitch create project` → `stitch config set project <id>`로 현재 폴더에 프로젝트를 고정하고, `stitch generate screen`에 제목·기기·프롬프트를 넣어 화면을 만든 뒤 `stitch serve` 또는 `stitch open project`로 결과를 봅니다. 문서는 다음 단계로 로컬 개발 서버 화면 캡처, DESIGN.md 기준 UI 감사, 기존 저장소 분석 워크플로를 안내합니다.

살펴볼 점
  • 문서에 베타로 표시되어 있어 명령어와 지원 범위가 바뀔 수 있습니다. 설치 전 공식 CLI 명령어 문서를 다시 확인하세요.
  • API 키를 전역 설정에 저장하면 같은 계정의 다른 도구도 접근할 수 있으니, 공용 PC나 공개 저장소에 키가 남지 않게 관리하세요.
