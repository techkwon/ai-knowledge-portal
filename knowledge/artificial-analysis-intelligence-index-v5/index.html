Artificial Analysis Intelligence Index v5: 모델 성능을 비교하는 독립 복합 벤치마크

수학·과학·코딩·추론 등 9개 평가를 종합한 독립 기관(Artificial Analysis)의 복합 벤치마크로, 모델별 점수·비용·속도를 공개 웹에서 비교할 수 있는 객관적 참고 자료

#벤치마크#모델 비교#Artificial Analysis#LLM 평가

무엇을 할 수 있나요?

핵심 내용: Frontier Code 2.0, Terminal-Bench-Science, GPQA Diamond, Humanity's Last Exam 등 9개의 어려운 평가를 가중 합산해 하나의 지능 지수 점수로 제공하는 독립 3자 벤치마크입니다. 모델별 점수뿐 아니라 '점수 대비 비용', '작업당 토큰 사용량', '작업당 처리 시간' 등을 같은 페이지에서 비교할 수 있습니다.

활용: 커뮤니티에서 종종 벌어지는 '어느 모델이 더 낫다'는 주관적 인상 비교 대신, 공개된 독립 기관의 복합 점수·비용·속도 그래프를 참고 지표로 제시할 수 있습니다. 같은 사이트에 법률·의료·에이전트형 업무 등 특화 벤치마크(Harvey LAB, MLCR 등)도 함께 제공됩니다.

예시 활용법: 여러 모델을 두고 어떤 것을 쓸지 고민될 때, 커뮤니티의 개인적 느낌만 참고하기보다 이 지수의 '점수 대비 비용' 사분면에서 자신의 용도(저비용 우선/고성능 우선)에 맞는 모델을 먼저 추려보고, 실제 자기 업무로 소규모 테스트를 해보는 순서를 권장할 수 있습니다.

살펴볼 점
  • 벤치마크 점수는 실제 업무 성능과 반드시 일치하지 않으며, 특정 평가셋에 최적화된 모델이 실제 사용 사례에서는 다르게 느껴질 수 있습니다.
  • 일부 모델은 '공개 API 없음'으로 표시되어 비용/속도 데이터가 제공되지 않습니다.
  • 직접 벤치마크를 재현·실행하지 않았으며 Artificial Analysis가 공개한 점수를 그대로 인용한 것입니다.
