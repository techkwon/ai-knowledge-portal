Artificial Analysis Intelligence Index v5: 모델 성능을 비교하는 독립 복합 벤치마크

Artificial Analysis가 자체 방법론으로 9개 평가를 합산하는 제3자 복합 지수. 모델별 점수·작업당 비용·생성 시간을 비교할 수 있지만 모든 업무의 보편적 성능 순위를 뜻하지는 않음

#벤치마크#모델 비교#Artificial Analysis#LLM 평가

무엇을 할 수 있나요?

구성: 공식 v5.0 방법론은 AA-Briefcase v1.1, AutomationBench-AA, GDP.pdf, FrontierCode 2.0, Terminal-Bench 4.0, AA-Omniscience v1.1, HLE-Diamond, CritPt v2(Hard Subset), Terminal-Bench-Science 0.1.0의 9개 평가를 사용합니다. 지식 업무·코딩·과학·일반의 네 범주에 각각 25%를 배정하고 범주 안의 평가별 가중치로 종합 점수를 계산합니다. GPQA Diamond나 일반 HLE를 그대로 포함하는 구성으로 혼동하지 말아야 합니다.

비교 화면: 점수, 지수 작업당 가중 평균 비용, 추론·답변 출력 토큰 수, 작업당 가중 평균 디코딩 시간을 볼 수 있습니다. 속도 그래프는 첫 토큰 대기(TTFT)와 부가 처리 시간을 제외하므로 실제 업무의 전체 완료 시간과는 다릅니다. 다른 업무용 별도 평가도 제공되지만 지능 지수에 포함된 평가와 구분해야 합니다.

활용: 같은 지수 버전과 모델·추론 설정에서 점수와 비용을 참고해 후보를 좁힌 뒤 실제 자기 업무로 소규모 검증을 하는 순서가 유용합니다. 가격·추론 예산·평가 하네스가 달라지면 결과도 달라질 수 있으며, 공개 그래프의 평가 비용을 개인 구독료나 자기 업무의 실제 비용으로 곧바로 환산하지 마세요.

살펴볼 점
  • 주로 텍스트 기반 영어 평가이며 이미지·음성·다국어 평가는 별도로 이뤄집니다. 자체 설계·가중치와 일부 비공개 평가를 포함하므로 제3자 측정이라는 사실이 무편향성이나 모든 사용 사례의 우수성을 보증하지는 않습니다.
  • 일부 모델은 '공개 API 없음'으로 표시되어 비용/속도 데이터가 제공되지 않습니다.
  • 직접 벤치마크를 재현·실행하지 않았으며 Artificial Analysis가 공개한 점수를 그대로 인용한 것입니다.
