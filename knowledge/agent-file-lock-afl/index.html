agent-file-lock (afl)

OS 수준 불변(immutable) 플래그로 코딩 에이전트가 특정 파일을 수정·삭제·이름변경하지 못하도록 잠그는 CLI 도구

#에이전트 안전#파일 잠금#CLI#Linux

무엇을 할 수 있나요?

합의되어 더 이상 바뀌지 않아야 하는 문서·설정 파일을 코딩 에이전트의 실수나 자동 수정으로부터 보호하기 위해 만들어진 CLI 도구입니다.

OS 수준의 불변(immutable) 플래그로 파일을 잠그고, 상위 디렉터리에는 추가 전용(append-only) 플래그를 걸어 '삭제 후 재생성' 우회 시도도 차단합니다.

Linux 및 WSL2의 Linux 파일시스템을 지원하며, 네이티브 Windows/DrvFs에서는 지원이 제한적입니다.

살펴볼 점
  • OS 파일시스템 플래그를 직접 조작하므로 잠금 해제 방법과 권한 요구사항을 사용 전에 숙지해야 합니다.
  • 네이티브 Windows 환경에서는 완전히 동작하지 않을 수 있어 사전에 지원 범위를 확인해야 합니다.
