ComfyUI의 HeyGen 음성 생성

Instant Clone과 Turbo·Standard TTS 노드를 연결하는 클라우드 음성 워크플로. 복제 무료와 TTS 요금은 별개입니다.

#ComfyUI#HeyGen#음성 동의

무엇을 할 수 있나요?

ComfyUI 공식 게시물은 HeyGen Instant Clone, Turbo·Standard를 선택하는 Text to Speech 노드와 HeyGen Voice 1 템플릿을 소개합니다. 이는 파트너 클라우드 API 연결이며 로컬에서 무료 오픈 가중치를 실행하는 방식이 아닙니다.

HeyGen 문서는 Instant Clone의 미리보기 기간 생성을 무료로 안내합니다. ComfyUI TTS 노드의 음성 생성은 복제 무료와 별개인 모델별 크레딧·요금 확인 대상입니다. 별도의 heygen-voice-1-turbo-free API 모델은 2026년 11월 30일까지 무료라고 안내되나 API 키 또는 OAuth와 공유 용량 제한이 있고, ComfyUI 노드에 해당 무료 모델이 적용되는지는 확인되지 않았습니다.

초보자 시작점: 권리를 보유한 본인 음성 또는 공개 음성과 짧은 비민감 대본을 사용하고, 생성 전에 노드의 선택 모델·예상 크레딧과 서비스 조건을 확인하세요.

살펴볼 점
  • 타인 음성 복제·사칭은 동의 없이 하지 마세요. 입력 녹음과 대본은 클라우드 제공자에게 전송되므로 민감 자료와 식별정보를 제외하고 보관 정책을 확인해야 합니다.
  • 무료 복제 미리보기, 유료 TTS, 별도 Turbo Free API 혜택을 혼동하지 마세요. 할인·무료 기한과 용량 제한은 사용 전에 공식 요금 정보를 다시 확인하세요.
  • 공식 발표와 문서만 확인했으며 계정 연결·설치·생성·요금 청구 또는 음질을 독립 시험하지 않았습니다.
