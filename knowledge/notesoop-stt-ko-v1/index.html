Notesoop-STT-Ko-v1: Apple Silicon 가속 한국어 온디바이스 음성인식 모델

Google EmbeddingGemma-2 오디오 인코더 기반의 한국어 ASR 모델. 제작자는 Apple Silicon MPS의 빠른 비자기회귀 전사를 자체 보고하며, 모델카드에 가중치·코드를 Apache-2.0으로 공개한다고 안내한다.

#Notesoop#한국어 STT#EmbeddingGemma#Apple Silicon#온디바이스

무엇을 할 수 있나요?

모델카드에 따르면 Google embeddinggemma-2 오디오 인코더에 경량 한국어 음향 리더와 KenLM 3-gram 언어모델을 결합했다. 비자기회귀 단일 패스 구조를 사용하며, GPU 메모리가 약 1.2~1.5GB대라고 소개한다. 실측표의 Host RAM 1,076MB와 GPU 메모리 1,537MB는 별도 항목이므로, 1.5GB를 앱 전체 메모리 요구량으로 단정하지 않는다.

학습 데이터는 AI Hub의 한국어 강의 음성 약 300GB이며, 25,000개 형태소/음절 혼합 어휘를 사용한다. 지원 백엔드는 PyTorch MPS(bfloat16)·CUDA·CPU.

제작자의 Apple M1 Pro(16GB) 실측 보고: Zeroth-Korean 테스트 분할(457문장, 약 1시간11분)을 150.7초(RTF 0.0352, CER 16.21%)에 처리했다. 별도의 41분43초 전공강의 녹음에서는 62.7초(RTF 0.0251, CER 22.46%)로, 같은 표의 Whisper-large-v3(704.9초, CER 25.55%)보다 빠르고 CER가 낮았다고 보고한다. 표준 분할 결과와 단일 강의 비교를 서로 다른 평가로 구분한다.

모델카드는 체크포인트·어휘·언어모델·추론 코드를 Apache-2.0으로 공개한다고 안내하며, CLI(transcribe.py)와 Python API(EmbeddingGemmaSTT)를 제공한다. 이는 제작자의 권리 표시이며, 여기서 기반 모델·학습 자료까지 권리 감사를 완료한 것은 아니다.

살펴볼 점
  • 위 벤치마크 수치는 모델 제작사(Notesoop/Phsoft-ai)가 자체 환경(M1 Pro)에서 측정해 모델카드에 올린 것으로, 제3자 독립 재현이 아니다. 다른 하드웨어·오디오 조건에서는 속도·오차율이 달라질 수 있다.
  • WER(단어 오차율)은 CER보다 상당히 높게 보고돼(예: Zeroth 테스트 45.40%), 형태소 단위 평가와 어절 단위 평가의 차이를 혼동하지 않아야 한다.
  • 모델은 'Notesoop' 앱에 추후 탑재될 예정이라고 명시돼 있어, 현재 공개된 것은 연구/온디바이스 실험용 가중치이며 상용 앱 품질과 동일하다고 가정해서는 안 된다.
  • 직접 설치·추론 테스트는 하지 않았다. 본 카드는 공식 모델카드 내용을 정리한 것이다.
  • Google 기반 모델, AI Hub 학습 자료와 의존성의 조건은 별도 확인이 필요하다. 온디바이스라는 소개만으로 실제 배포의 외부 전송 부재를 검증한 것은 아니며, 학생·타인의 음성은 동의·보관 정책을 먼저 확인한다.
