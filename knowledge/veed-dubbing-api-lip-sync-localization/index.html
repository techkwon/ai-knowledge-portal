VEED Dubbing API: 목소리 복제와 립싱크를 함께 하는 영상 더빙 API

영상 하나와 목표 언어만 보내면 화자 목소리를 복제해 번역된 대사를 입히고 입모양까지 맞춰주는 VEED의 신규 API. Standard(100개 언어)·Pro(94개 언어+14개 억양, 다화자 지원) 두 버전을 초당 과금으로 제공

#VEED#더빙#립싱크#현지화#API

무엇을 할 수 있나요?

VEED가 2026년 10월 28일 공식 출시한 Dubbing API는 영상 속 발화를 번역하고, 화자별 목소리를 복제해 번역된 대사로 재생하며, 입 모양을 새 오디오에 맞춰 립싱크까지 처리합니다. 영상과 목표 언어 하나만 보내면 되고 별도의 음성 학습·화자별 설정이 필요 없다고 공식 발표는 설명합니다.

Standard(언어 100개, 초당 $0.11)와 Pro(언어 94개+억양 14종, 다화자·배경음 유지, 초당 $0.18) 두 버전이 있으며 영상은 최대 10분까지 지원합니다. Pro는 팟캐스트·인터뷰처럼 화자가 여럿인 영상에 적합하다고 안내합니다.

교육·트레이닝 콘텐츠 다국어화, 팟캐스트 현지화, 마케팅 영상 현지화, 자체 AI 영상 제품에 더빙 기능 추가 등을 공식 사용 사례로 제시합니다. 10월 중순부터 런칭 파트너와 얼리 액세스로 운영됐고, 11월 초부터 fal에서도 제공될 예정이라고 명시합니다.

살펴볼 점
  • VEED API 계정이 있으면 바로 사용 가능한 유료 서비스이며, 가격은 처리 시간(영상 길이) 기준 과금입니다. 최소 사용량 약정은 없다고 안내하지만 실제 과금 정책은 계정 가입 후 재확인이 필요합니다.
  • 화자 목소리 복제·번역 품질에 대한 구체적 정확도 수치는 공식 발표에 포함되어 있지 않습니다. 목소리 복제 기능 특유의 동의·초상권 문제(원 화자의 동의 없는 음성 합성)를 사용 전 반드시 확인해야 합니다.
  • 직접 가입·테스트는 하지 않았으며 VEED 공식 발표와 문서에 기재된 내용을 확인한 것입니다.
