VEED Dubbing API: 목소리 복제와 립싱크를 함께 하는 영상 더빙 API

영상 URL과 목표 언어로 번역·화자 목소리 복제·립싱크를 처리하는 유료 비동기 API. Standard와 방언·목소리 유사도 조절을 지원하는 Pro를 제공하며, 현재 문서와 출시 발표의 가격이 달라 사용 전 확인 필요

#VEED#더빙#립싱크#현지화#API

무엇을 할 수 있나요?

2026-10-28 출시 발표에 따르면 영상 발화를 번역하고 화자 목소리를 복제하며 입 모양을 맞추는 API입니다. 실제 요청에는 VEED가 읽을 수 있는 영상 HTTP(S) URL과 목표 언어가 필요합니다. 요청 직후 202 Accepted와 작업 ID를 받으며 완료·실패 상태를 조회한 뒤 결과 영상을 가져오는 비동기 방식입니다. 접수됐다고 즉시 완성된 것은 아닙니다.

가격·지원 범위: 조회한 현재 API 문서·가이드는 Standard $0.077/초, Pro $0.126/초를 생성 영상 길이 기준으로 안내하며 출시 발표의 $0.11/$0.18과 다릅니다. 최종 청구 credits_charged는 사전 credits_estimated와 달라질 수 있어 계정의 현재 요금을 확인해야 합니다. 발표 당시 언어 수는 Standard 100개·Pro 94개와 방언 14종이었고, 현재 문서도 두 버전의 언어 목록이 서로 다르다고 강조합니다. 각 작업은 최대 10분으로 안내됩니다.

사용법·품질: Standard는 지역 태그를 기본 언어로 처리하고, Pro는 명시된 방언과 voice_cloning_strength(0~10, 기본 7) 조절을 지원합니다. 높은 값은 원 화자의 목소리·억양에, 낮은 값은 목표 언어의 자연스러움에 더 무게를 둡니다. 공식 가이드는 선명한 발화·정면의 밝은 얼굴·짧은 시험 영상을 권합니다. 11월 초 fal 제공은 출시 발표의 예정 설명이지 현재 연동을 직접 확인한 것은 아닙니다.

살펴볼 점
  • VEED API 계정·인증·유료 사용량이 필요한 서비스이며 일반 편집기 구독이나 다른 AI 구독과 동일한 과금으로 가정하지 마세요. 실제 호출·계정 생성·결제는 하지 않았습니다.
  • 화자 목소리 복제·번역 품질에 대한 구체적 정확도 수치는 공식 발표에 포함되어 있지 않습니다. 목소리 복제 기능 특유의 동의·초상권 문제(원 화자의 동의 없는 음성 합성)를 사용 전 반드시 확인해야 합니다.
  • 직접 가입·테스트는 하지 않았으며 VEED 공식 발표와 문서에 기재된 내용을 확인한 것입니다.
  • 목소리·얼굴·영상의 권리와 원 화자의 동의를 확인하고 민감한 영상을 무심코 공개 URL로 올리지 마세요. 외부 처리와 로그·보존 정책을 검토해야 합니다. 문서의 결과 미디어 URL 기본 만료(1일)는 서버의 모든 사본이 그때 삭제된다는 보증이 아닙니다.
