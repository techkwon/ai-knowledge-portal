DeepSeek Harness: 모든 구성요소가 플러그인인 오픈소스 에이전트 하네스

DeepSeek이 MIT 라이선스로 공개하고 데스크톱 앱 공개 미리보기를 제공하는 에이전트 런타임으로, 모델 어댑터·도구 등록·세션 로그·에이전트 루프까지 교체 가능한 플러그인으로 구성됩니다.

#DeepSeek#하네스#플러그인#Cordis#오픈소스

무엇을 할 수 있나요?

DeepSeek 공식 소개 페이지는 DeepSeek Harness(dsh)가 전 세계 공개 미리보기 상태의 오픈소스 하네스이며, 일상 문서·데이터·슬라이드 작업, 코딩, 출처를 단 조사, 백그라운드 작업, 플러그인 개발을 지원한다고 설명합니다. 데스크톱 앱으로 실행하거나 코드에서 웹 UI를 띄울 수 있습니다.

핵심 설계는 Cordis 프레임워크의 everything-is-a-plugin 구조입니다. 저장소 문서는 플러그인을 서비스로 등록하고, 이벤트 디스패치 방식과 정리 함수를 명시해 런타임에서 구성요소를 붙였다 떼는 방식을 안내합니다. 공식 플러그인 목록에는 에이전트 팀, 자동 승인 검토, 예약 작업, 음성 입력 등이 실험 기능으로 표시됩니다.

가장 빠른 시작은 Node.js 설치 후 `npx @deepseek-ai/dsh web`이며, 소스 설치는 GitHub 저장소를 복제해 안내를 따릅니다. 커뮤니티 플러그인은 GitHub의 dsh-plugin 토픽에서 찾을 수 있습니다.

살펴볼 점
  • 공식 페이지가 핵심 플러그인과 API가 계속 바뀌는 미리보기 단계라고 밝힙니다. 업무 자동화에 쓰기 전 버전을 고정하고 권한·승인 설정을 점검하세요.
  • 커뮤니티 플러그인은 DeepSeek이 검증한 것이 아니므로 설치 전 코드와 요청 권한을 확인하세요.
