Gemini 4 Hydrogen: 실행형 모델과 Antigravity Orchestrator

일상 코딩·에이전트 실행용 모델과 작업 도중 모델을 바꾸는 Orchestrator의 제공 조건

#Google#Gemini 4 Hydrogen#Antigravity#Orchestrator

무엇을 할 수 있나요?

Google은 Gemini 4 Hydrogen을 일상 코딩과 여러 단계의 에이전트 작업을 빠르게 실행하는 모델로 소개했습니다. API·AI Studio·Gemini 앱·검색 등의 제공 경로가 있으며, 각 제품의 이용 조건은 별도로 확인해야 합니다.

공식 발표의 API 가격은 입력 100만 토큰당 1.50달러, 출력 100만 토큰당 7.50달러입니다. 추론 수준은 low·medium·high·xhigh 네 단계이며 high가 기본입니다. 실제 청구와 할당량은 이용 제품과 최신 요금표를 확인하세요.

Antigravity의 Orchestrator는 처음부터 끝까지 한 모델에 고정하는 대신, 같은 작업 흐름 안에서 계획·판단과 구현·테스트에 따라 Carbon·Argon·Hydrogen을 조합하는 방식입니다.

Antigravity 공식 안내는 Hydrogen을 유료 Google AI Pro·Ultra에 순차 제공한다고 설명합니다. Orchestrator는 Ultra에 Carbon·Argon, Pro에 Argon 구성을 제공한다고 구분합니다. 모델 단독 접근과 Orchestrator 접근을 같은 혜택으로 보지 마세요.

살펴볼 점
  • 호스팅 모델 서비스 발표입니다. 오픈소스 코드나 모델 가중치의 배포·재사용 허가를 뜻하지 않습니다.
  • 발표상의 성능 수치와 시연은 직접 재현하지 않았으며, 특정 모델의 우열·개인 작업 속도를 보장하지 않습니다.
  • 부모 검토에서 Gemini API 추가 약관 영어 원문의 관련 조항을 확인했습니다. API 사용자는 만 18세 이상이어야 하고, 18세 미만을 대상으로 하거나 이들이 접근할 가능성이 있는 API 클라이언트에 서비스를 사용하지 않도록 정합니다. Gemini 앱·교육기관 계약·Antigravity의 조건은 API와 별도로 확인해야 합니다.
  • 교육용 계정 전체에 동일 모델이 이미 제공된다는 보장은 확인하지 않았습니다.
  • 무료 API 입력·출력은 제품 개선과 인적 검토에 사용될 수 있습니다. AI Studio와 Gemini API의 유료 서비스 자격은 계정·프로젝트의 결제 연결 조건이 다르므로 구분하세요. 유료의 제품 개선 미사용도 보안·법적 목적의 제한적 보관까지 없다는 보장은 아닙니다. 개인정보·기밀은 최신 계약과 기관 정책 확인 전 입력하지 않습니다.
  • 이 검토는 제품 발표와 API 약관의 관련 연령·데이터 조항 확인입니다. 모든 언어본의 동일성·지역별 실제 접근·개별 기관 계약·전체 기본 API 약관을 검증한 것은 아닙니다. 모델 호출·SDK 설정·결제·설치를 직접 하지 않았습니다.
