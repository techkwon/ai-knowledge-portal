hwpx-egpt: 공유 세션으로 HWPX를 함께 검토하기

파일을 연 사람이 유지하는 공유 주소로 문서를 함께 고치고 내려받는 HWPX 협업 서비스

#HWPX#협업#문서 검토

무엇을 할 수 있나요?

공개 화면은 PC의 문서를 열면 공유 주소가 생기고, 주소를 받은 사람과 함께 편집하며 문서를 연 사람이 창을 닫으면 협업이 끝나는 흐름을 설명합니다. rhwp 기반임을 표시합니다.

나가기 전에 수정 내용을 내려받도록 안내하며, Chrome·Edge에서 앱으로 설치하는 방법을 소개합니다. AI로 만든 HWPX의 최종 공동 검토에 사용할 수 있는 보조 도구 후보입니다.

서비스는 문서가 서버에 올라가지 않는다고 설명하지만, 여기서는 네트워크 경로·공유 권한·복구 동작을 독립 검증하지 않았습니다.

살펴볼 점
  • 공유 주소의 접근 범위를 확인하고 비민감 샘플로 먼저 시험하세요. 공개 화면의 설명만으로 비공개 문서의 보안 적합성을 보장할 수 없습니다.
  • 창 종료 전에 각자 필요한 파일을 저장하세요. 한컴 원본과의 조판·수식·표·쪽 나눔 호환은 실제 결과에서 확인해야 합니다.
  • 공식 문서 확인 기준이며 설치·실행·성능을 직접 시험하지 않았습니다.
