설치형 프롬프트가 광고를 남긴다: Haiou 분석으로 보는 에이전트 지침 공급망

Check Point Research가 Codex용 Haiou 4.5.0의 전역 지침에 지속적 광고가 들어가는 동작을 보고했다. 모델 자체의 결함이나 광고된 서비스의 악성을 단정하지 않고, 설치형 프롬프트·Skills·설정 변경을 검토해야 하는 사례로 읽는다.

#프롬프트 애드웨어#공급망 보안#Codex#Skills#전역 지침#Check Point Research

무엇을 할 수 있나요?

분석 대상과 조건: Check Point Research의 보고 대상은 Codex용 Haiou bundle 4.5.0이다. 단일 패키지 사례이며 전체 Codex 생태계나 모든 모델의 특성을 측정한 결과가 아니다.

보고된 관측: 패키지가 프롬프트와 보안 관련 Skills를 설치하고 전역 에이전트 지침을 바꿔, 특정 인사말에 제3자 LLM gateway 광고가 포함된 답변이 나오게 했다고 한다. CPR는 자연어 지침을 통한 이 지속적 출력 개입을 prompt adware라고 정의한다.

설치 파일의 신뢰 경계: 연구 본문은 서명·해시로 패키지를 확인한 뒤 내장 키로 복호화하는 구조를 설명한다. 암호화·서명은 내용을 쉽게 검토할 수 있다는 뜻도, 지침이 사용자에게 이롭다는 보장도 아니다.

사실과 추정의 구분: 무료 배포가 유료 gateway 고객 유입을 노린다는 설명과 프롬프트 포장이 scanner 회피를 노린다는 설명은 CPR의 추정이다. 실제 수익·전환율이나 포장 의도는 입증되지 않았다.

위협 행위자와 제작자 구분: 연구자는 범죄 행위자의 공개 서버에서 다른 공격 도구와 함께 bundle을 찾았다고 보고하지만, bundle 제작자가 범죄에 관여했다는 증거는 없다고 명시한다.

게이트웨이 위험과 특정 서비스 판정의 구분: CPR는 광고된 gateway 자체가 악성이라는 증거는 없다고 썼다. 인용된 별도 API router 연구는 다른 시장 표본의 도구 호출 변조·credential 사용을 보고한 것으로, 해당 광고 서비스를 악성으로 판정하는 근거가 아니다.

방어적 적용: 프롬프트·Skills·설치 도우미도 실행 권한과 지속성을 바꿀 수 있는 공급망 입력으로 본다. 출처와 평문 지침을 확인하고, 전역 파일 변경 범위·승인 요구·제3자 API endpoint 변경을 검토한다. 도입 전 설정 백업과 변경 diff, 최소 권한·격리·복구 경로를 준비한다.

이해관계: 발표 기관은 AI·네트워크 보안 제품을 판매하는 Check Point 소속 연구조직이다. 상업적 이해관계를 밝히되, 그것만으로 관측을 부정하거나 자사 제품의 효과가 입증됐다고 해석하지 않는다.

살펴볼 점
  • 이 카드는 공식 연구 본문과 별도 연구의 관련 방법론·범위·윤리 절을 읽은 방어적 요약이다. 독립 재현이나 보안 안전성 인증이 아니다.
  • 공격자 bundle 다운로드·설치·실행, 공격자 저장소 및 광고된 사이트 방문, 모델 대상 시험을 하지 않았다. 인용된 공격 지침·명령은 데이터로만 취급했으며 재배포하지 않는다.
  • CPR가 제시한 prompt 인용과 동작 설명을 검토했지만 원래 bundle 내부 파일·서버 원시 로그를 직접 검증하지 않았다. 따라서 동작은 연구자가 보고한 관측으로 귀속한다.
  • Codex의 정확한 model build와 반복 실험 수·성공률은 검토한 본문에서 확인되지 않았다. Claude Code/Sonnet 5의 거부 관측 한 건으로 특정 제품이 일반적으로 안전하다고 단정하지 않는다.
  • 별도 router 연구는 공개 시장·커뮤니티 중심의 유료 28개·무료 400개 표본과 연구자 소유 계정·canary·decoy 조건이다. 기업 전용·초대형 서비스와 모든 중계 서비스에 같은 악성 비율이 적용되는 것은 아니다.
  • 광고된 서비스가 데이터를 훔쳤다거나 bundle 제작자가 cybercrime actor와 동일하다고 쓰지 않는다. 미래의 더 은밀한 조작 가능성은 위협 시나리오이지 이 패키지에서 관측된 추가 피해가 아니다.
