Claw Office: OpenClaw용 3D 에이전트 사무실 플러그인

여러 컴퓨터에서 돌고 있는 OpenClaw·Claude Code·Codex 세션을 3D 사무실 화면에서 직원처럼 보고, 클릭으로 일을 맡기거나 권한 요청에 답하는 오픈소스 Control UI 플러그인

#OpenClaw#Claude Code#Codex#Paseo

무엇을 할 수 있나요?

공식 README: OpenClaw Control UI 안에서 동작하는 3D 사무실로, 여러 컴퓨터에서 실행 중인 OpenClaw 에이전트·Claude Code·Codex 세션을 책상에 앉은 직원으로 표시합니다. 직원을 클릭해 대화를 이어가거나, 권한 요청에 허용/자동 허용/거부로 답하거나, 폴더를 지정해 새 세션을 맡길 수 있습니다.

작동 방식: Claude Code·Codex 세션은 Paseo(별도 오픈소스 데몬)가 프로세스를 직접 실행하므로, 오피스에서 보낸 메시지가 지금 돌고 있는 그 세션에 그대로 들어가 대화가 갈라지지 않습니다. 설치는 OpenClaw 2026.9.8 이상, Node 24.16 이상, 각 컴퓨터에 로그인된 claude/codex CLI가 필요합니다.

구성·제약: 컴퓨터별 세션 상태와 CPU·메모리·디스크·GPU 보드, 세션 권한 모드를 제공합니다. 전체 일괄 모드 변경은 연결된 Claude Code 세션에 적용되며 Codex는 자기 기본값을 유지한다고 문서는 설명합니다. 컴퓨터 목록은 예제 환경에 맞게 코드에 들어 있어 다른 구성에서는 machines.ts·stats.ts·control-ui.ts와 Paseo host ID 등을 수정하고 다시 빌드해야 합니다. 단순 설치만으로 임의의 모든 컴퓨터가 자동 등록되는 방식은 아닙니다.

살펴볼 점
  • Paseo로 가져온 세션을 터미널에서 별도로 claude --resume 하면 같은 대화를 두 프로세스가 동시에 써서 충돌할 수 있다고 공식 문서가 경고합니다.
  • Claw Office 코드와 포함된 Agent Office 3D 자산은 모두 MIT로 안내되지만 저작권자와 고지가 별개입니다. 배포 시 포함된 LICENSE·NOTICE와 자산 고지를 확인해야 합니다.
  • 직접 설치·구동 테스트는 하지 않았으며 공식 README 확인에 한정합니다.
  • 원격 Paseo 연결에는 인증·접근 제한을 설정하고 신뢰할 수 있는 사설망 등을 사용하세요. 대화 입력과 파일·명령 실행 권한을 다루는 관리 UI이며, 모두 허용·일괄 권한 변경을 단순한 화면 설정으로 취급하지 않아야 합니다.
