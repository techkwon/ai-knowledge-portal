Cohere Rerank 5: 검색 후보 재정렬과 Context Focus

기존 검색으로 찾은 후보 문서를 질문과 대조해 관련 순위를 매기고 선택적으로 근거 문맥 구간을 표시하는 Cohere의 상용 서비스

#Rerank 5#검색 재정렬#Context Focus

무엇을 할 수 있나요?

Cohere의 Rerank 5 Pro와 Fast는 키워드, 벡터, 하이브리드 검색으로 먼저 찾은 후보를 질문과 비교해 다시 정렬합니다. 공급사 설명상 기존 인덱스를 다시 만들 필요가 없으며, 일반 검색엔진 자체나 답의 참거짓 판정기는 아닙니다.

공식 Rerank API는 query와 documents 목록을 입력받아 관련도 점수가 붙은 정렬 결과를 반환합니다. Rerank 5의 선택 기능 Context Focus는 문서 수준 점수와 함께 관련 텍스트 구간의 위치와 점수를 돌려주어 후속 LLM에 보낼 근거 문맥을 고르는 데 쓸 수 있습니다.

권한 있는 비민감한 짧은 자료 목록과 질문을 예시로 관련 순위와 선택된 문맥 구간의 차이를 이해할 수 있습니다. 임계값은 정답 확률 보증이 아니라 개발자가 자체 자료로 검증할 선택 기준으로 다루고, 축소 과정에서 중요한 반대 근거나 조건이 빠지지 않는지 확인해야 합니다.

Pro와 Fast는 Cohere API와 Model Vault 등에서 제공됩니다. API에는 별도 인증 키와 이용 조건이 필요하며, 운영용 키는 종량 과금입니다. Model Vault의 인스턴스 과금 및 비공개 배포 상담은 SaaS API와 구별해야 합니다.

살펴볼 점
  • Cohere SaaS API에 보내는 질문과 후보 문서는 외부 서비스로 전달됩니다. 학생 개인정보, 비공개 업무 자료 등 민감한 원문을 시험 입력으로 권장하지 않습니다. 유료 고객의 로그는 원칙적으로 30일 후 삭제되지만 법적·계약상 사유나 오남용 조사 등 예외가 있고, 학습 활용 거부 설정과 별도 ZDR 승인 여부도 확인해야 합니다. 체험 사용자는 별도 정책 대상입니다.
  • 체험 API 키는 제한적이며 상업·운영 용도로 허용되지 않습니다. Cohere API 키와 청구 설정은 ChatGPT나 Claude 구독의 OAuth 로그인으로 대체되지 않습니다. 공개 가중치 무료 로컬 모델로 소개하지 않습니다.
  • 긴 문서는 API 설정에 따라 잘릴 수 있고 Context Focus의 구간 축소가 필요한 근거를 누락할 수 있습니다. 임계값과 순위 점수만으로 사실성·정답성을 보증하지 마세요.
  • 성능과 비용 감소 수치는 공급사 발표의 시험 결과이며 독립 벤치마크나 이 카드의 설치·호출·성공 검증 결과가 아닙니다.
