SoDam WikiMate for Codex: Obsidian 지식베이스 정리 플러그인

웹·PDF·메모를 승인 기반 절차로 Obsidian Markdown 노트로 수집·검사·연결·분류·요약하는 로컬 우선 Codex 플러그인

#Obsidian#Codex#MCP#로컬 우선#커뮤니티 인사이트

무엇을 할 수 있나요?

SoDam WikiMate for Codex는 원래 Claude Code용으로 나온 WikiMate를 Codex 플러그인으로 포팅한 오픈소스 도구입니다. 공식 README에 따르면 웹 페이지·PDF 텍스트·직접 입력 메모를 Obsidian Markdown 볼트에 정리하되, 모든 새 노트 생성과 기존 노트 수정은 기본적으로 dry-run(미리보기)으로 계획만 보여주고 사용자 승인 후에만 실제로 저장합니다.

8개 스킬(wikimate, organize, query, lint, link, classify, summarize, reviewer)과 8개 MCP 도구로 구성되며, 중복 노트·끊어진 링크·고립 노트·frontmatter 누락을 검사하는 lint 기능, 관련 노트 추천 및 MOC(Map of Content) 구성, 노트 삭제 대신 99_Archive로 이동하는 안전 정책을 제공합니다.

설치는 `codex plugin marketplace add sodam-ai/SoDam-WikiMate-Codex` 후 `codex plugin add wikimate@wikimate-codex`로 진행하며, 새 Codex 작업을 열어야 스킬과 MCP 구성이 반영됩니다. Apache License 2.0으로 배포되며 Notion 연동은 선택 사항이고 핵심 MCP 서버는 Notion API를 직접 호출하지 않습니다.

살펴볼 점
  • 공식 README(2026-09-20 확인)는 핵심 검증 236개·MCP smoke 18개·보안 검사 88개 통과 등 코드 자체의 검증 상태만 밝히고 있으며, 실제 사용자 볼트에 대한 쓰기 작업과 실시간 Notion 연동은 배포 전 별도로 환경별 확인이 필요하다고 명시합니다.
  • 자료 수집 전 저작권·개인정보·robots 정책 준수 여부를 사용자가 직접 확인해야 하며, SoDam·WikiMate 명칭이나 로고를 자체 브랜드처럼 사용하는 것은 라이선스가 허용하지 않습니다.
