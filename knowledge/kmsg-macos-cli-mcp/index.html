kmsg: macOS 메시징 CLI·MCP

macOS 손쉬운 사용 API로 KakaoTalk 앱을 제어하는 비공식 오픈소스 CLI 및 네이티브 MCP 서버

#macOS#MCP#CLI

무엇을 할 수 있나요?

프로젝트 문서는 macOS 13 이상과 해당 데스크톱 앱, 설치한 바이너리의 손쉬운 사용 권한을 요구합니다.

읽기·실시간 감시·메시지 전송과 구조화된 JSON 출력을 제공하며, 비공개 통신 프로토콜 대신 화면의 Accessibility API를 이용합니다.

자동화는 읽기 전용으로 시작하고, 텍스트 전송 전에는 dry-run 결과에서 대상과 내용을 검토하세요. 실제 전송은 명시적 승인 뒤 별도 단계로 두는 것을 권장합니다.

살펴볼 점
  • 서비스 운영사의 공식 도구가 아닙니다. 서비스 약관과 조직 보안 정책, 계정 제한 가능성을 검토해야 합니다.
  • 대화 내용은 공개 저장소나 로그에 넣지 마세요. UI 변경으로 탐색이 실패할 수 있으며 이미지 전송에는 dry-run이 없다고 명시되어 있습니다.
