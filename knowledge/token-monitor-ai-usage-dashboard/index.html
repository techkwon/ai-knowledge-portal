Token Monitor AI 코딩 사용량 대시보드

여러 AI 코딩 도구의 토큰 사용량과 제공자별 한도를 로컬 중심으로 확인하고 선택적으로 기기 간 동기화하는 데스크톱 도구

#토큰 사용량#비용 관리#Claude Code#Codex

무엇을 할 수 있나요?

공식 저장소는 Claude Code, Codex, OpenCode 등 다양한 도구의 사용량을 도구·모델·세션·프로젝트별로 살펴보는 기능을 안내합니다. 토큰 집계, 계정 한도 조회, 세션 상세 지원은 도구마다 다릅니다.

기본 로컬 모드는 별도 동기화 서버 없이 시작합니다. 여러 기기를 연결하려면 위젯 내 허브, Node 허브 또는 Cloudflare Worker 중 하나를 선택할 수 있습니다.

CSV·JSON 내보내기와 과거 사용 추세를 활용해 작업별 사용량을 비교할 수 있습니다. Hermes Agent와 OpenClaw는 토큰 사용량을 지원하지만 문서 표에서 계정 한도와 세션 상세는 지원 대상으로 표시하지 않습니다.

살펴볼 점
  • 표시 비용은 실제 청구액과 같다고 단정할 수 없습니다. 일부 도구는 토큰 수를 추정하며 구독료와 API 사용 비용도 구분해야 합니다.
  • 한도 조회에 필요한 계정 정보와 선택적 동기화·외부 연동의 데이터 범위를 개인정보 정책에서 먼저 확인하세요. 수집 시작 전에 삭제된 기록은 복원할 수 없습니다.
