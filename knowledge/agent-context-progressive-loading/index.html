#실무 가이드#커뮤니티 인사이트

무엇을 할 수 있나요?

핵심 원리: 모델에 보낼 문맥은 유한합니다. 도구 결과·대화 이력·문서 전체를 계속 누적하기보다 현재 작업에 필요한 근거를 선택합니다.

설계 예시: 논문 목록에는 파일 경로와 제목·절 위치를 저장하고, 질문에 필요한 초록·방법·결과만 도구로 읽습니다. 그림 해석이 필요한 질문에는 해당 그림도 함께 확인합니다.

절차: 도구 출력을 제한하고 원문 위치를 유지합니다. 긴 작업을 요약할 때 결정·제약·미해결 항목을 남기고 핵심 근거가 사라지지 않았는지 검증합니다.

분업 예시: 하위 에이전트는 독립 조사 후 요약과 근거 위치를 반환합니다. 주 에이전트가 모든 원문을 다시 복사하지 않도록 계약을 정합니다.

살펴볼 점
  • 토큰 절감률이나 특정 검색 방식의 우월성을 보장하지 않습니다. 비용과 답변 품질을 같은 과제로 함께 측정하세요.
  • 텍스트 변환만으로 그림·표의 의미가 보존되지는 않습니다. 요약 손실과 민감정보의 외부 전송을 점검하세요.
