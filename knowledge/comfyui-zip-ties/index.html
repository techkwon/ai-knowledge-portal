Zip Ties for ComfyUI: 워크플로우 연결선 정리 확장

ComfyUI 캔버스에서 여러 노드 연결선을 묶음(지퍼타이)으로 묶어 리본 형태로 정리해 보여주는 프런트엔드 전용 확장

#ComfyUI#워크플로우#UI 확장

무엇을 할 수 있나요?

공식 GitHub README에 따르면 Z 키를 누른 채 여러 연결선을 가로지르게 드래그하면 그 선들을 하나의 "타이"로 묶어 리본처럼 겹쳐 보여주고, 다시 Z를 누른 채 타이를 가로질러 드래그하거나 더블클릭하면 묶음이 풀립니다. 키보드 없이도 캔버스 우클릭 메뉴의 Tie wires로 같은 동작을 할 수 있습니다.

타이는 색상 변경, 15도 단위 회전(Alt로 자유 회전), 그룹과 함께 이동, 복사/붙여넣기, Undo 등을 지원하며, 워크플로우 JSON의 extra.zipTies 필드에 저장되어 저장·불러오기·실행 취소 시 함께 유지됩니다. 확장이 없는 환경에서 워크플로우를 열어도 연결선 자체는 정상적으로 표시됩니다.

설치는 ComfyUI-Manager에서 "Zip Ties" 검색, Comfy CLI의 comfy node install comfyui-zip-ties, 또는 ComfyUI/custom_nodes에 직접 git clone하는 방식입니다. 순수 프런트엔드 JS 확장으로 별도 노드를 추가하지 않고 Python 의존성도 없습니다.

공식 문서는 ComfyUI 0.42.0과 프런트엔드 1.57.1(클래식 캔버스·Vue 노드 모드 모두)에서 테스트되었다고 명시하며, 숨겨진 링크 배지에서 그려지는 리라우트 조각은 묶을 수 없다는 한계도 함께 밝히고 있습니다.

살펴볼 점
  • 이 카드는 공식 README 기준 정리이며 실제 설치·조작 테스트는 하지 않았습니다. 복잡한 대형 워크플로우에서의 성능이나 다른 커스텀 노드팩과의 충돌 여부는 직접 확인이 필요합니다.
  • MIT 라이선스로 공개되어 있으나, ComfyUI 버전이 명시된 테스트 범위(0.42.0/프런트엔드 1.57.1)를 벗어나면 동작이 다를 수 있습니다.
