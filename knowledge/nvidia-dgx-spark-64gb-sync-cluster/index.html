DGX Spark 64GB: 파트너사 전용 구성과 두 대 클러스터링

NVIDIA가 발표한 DGX Spark 64GB 통합 메모리 구성은 10월 23일 파트너사 6곳에서 4,999달러부터 판매 예정이며, NVIDIA Sync로 두 대를 묶어 128GB처럼 쓰는 구성을 지원합니다.

#NVIDIA#DGX Spark#로컬 LLM#클러스터#통합 메모리

무엇을 할 수 있나요?

NVIDIA 공식 블로그에 따르면 64GB 구성은 Acer·ASUS·Dell·Gigabyte·HP·MSI에서만 판매되며, 128GB 모델과 같은 GB10 Grace Blackwell 칩, DGX OS, NVIDIA AI 소프트웨어 스택을 유지합니다. 단일 장비 기준 최대 1,000억 매개변수 모델을 지원한다고 밝힙니다.

두 대를 QSFP 케이블로 직접 연결하고 NVIDIA Sync의 Cluster Assistant를 실행하면 장치 감지와 ConnectX-7 네트워크 설정을 자동으로 해 메모리를 128GB로 묶을 수 있습니다. NVIDIA의 Qwen 3.8 27B 테스트에서는 두 대 구성이 한 대 대비 최대 1.7배 성능을 냈다고 합니다.

같은 블로그는 10월 말 NVIDIA Sync Model Launcher로 모델 다운로드·실행과 OpenCode 연결을 버튼 몇 번으로 처리하는 기능을 예고하고, build.nvidia.com의 OpenClaw·Hermes Agent 등 플레이북을 안내합니다.

살펴볼 점
  • 발표 기준 미국 달러 시작가이며 국내 판매 일정, 원화 가격, 세금·배송 포함 총액은 공식 자료로 확인되지 않았습니다.
  • 두 대를 묶어도 한 대의 128GB 장비와 같은 성능을 보장하지 않습니다. 쓰려는 모델·양자화·문맥 길이·분산 런타임 지원을 함께 비교하세요.
