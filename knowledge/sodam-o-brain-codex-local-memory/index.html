SoDam O-Brain Codex: 확정한 결정의 로컬 메모리

Codex 대화의 결정·제약을 로컬 SQLite에 저장하고 다음 작업에 관련 기억을 제공하는 커뮤니티 플러그인

#커뮤니티 인사이트#실무 가이드

무엇을 할 수 있나요?

제작자 README에 따르면 SessionEnd 훅이 확정 신호가 있는 사용자 문장을 선별해 저장하고 SessionStart 훅이 프로젝트 관련 기억을 다시 제공합니다. 질문이나 AI 답변 전체를 무조건 저장하는 방식은 아닙니다.

도입 절차: 저장소의 현재 지원 상태와 Node.js 요구 버전, Codex 플러그인 구조를 먼저 확인합니다. 민감하지 않은 테스트 프로젝트에서 설치·자체 테스트를 수행한 뒤 검색·대시보드·백업을 확인합니다.

사용 예시: 작업 규칙 하나를 확정해 저장한 뒤 새 세션에서 해당 규칙이 정확히 검색되는지 확인합니다. 중요한 내용은 제작자가 안내하는 $o-brain-remember로 직접 저장하고 잘못 저장된 기억도 점검합니다.

적용 조건: 1인 로컬 메모리와 2D·3D 그래프, 타임라인, 검색 화면이 필요한 경우 검토할 수 있습니다. 제작자는 Windows 중심 검증 범위를 구분하고 있으므로 다른 운영체제까지 동일하게 검증됐다고 해석하지 않습니다.

살펴볼 점
  • OpenAI 공식 제품이 아닌 커뮤니티 도구입니다. 이 카드에서는 설치·성능·보안 테스트를 직접 수행하지 않았습니다.
  • 로컬 저장만으로 전체 작업의 외부 전송이 차단되는 것은 아닙니다. Codex에 주입되는 기억과 모델 제공자 정책을 함께 확인하고 자동 시크릿 가림에만 의존하지 마세요.
  • 원문·기억·백업에 개인정보가 남을 수 있습니다. 최소 수집, 삭제·복구 검증, 파일 접근 권한을 확인하세요.
