Anatomy: 기술 개념을 조작 가능한 등각 구조물로 설명하는 Claude 스킬

캐시 적중을 자물쇠, GPU 컨텍스트 공유를 다중 헤드 플로터처럼 작동 원리가 곧 비유가 되는 인터랙티브 SVG/WebGL/3D 그림을 Claude가 직접 설계·검증해 만든다

#실무 가이드

무엇을 할 수 있나요?

공식 저장소에 따르면 Anatomy는 "토큰 버킷 속도 제한이 어떻게 동작하는지 인터랙티브하게 설명해줘" 같은 요청을 받으면, 개념을 실제로 작동하는 물리적 구조물(예: 핀이 모두 맞아야 돌아가는 자물쇠)로 바꿔서 SVG 부품들로 조립하고 포인터·키보드로 움직일 수 있게 만듭니다.

SVG만 쓰는 기본형, 불·연기·물결처럼 선으로 못 그리는 효과를 위한 SVG+WebGL 혼합형, 다이얼처럼 실제로 회전하는 베타 단계 3D형까지 세 종류의 결과물을 지원한다고 설명합니다. 결과는 독립 HTML 페이지, 단일 SVG 파일, React/Next.js 컴포넌트 형태로 받을 수 있습니다.

설치는 `npx skills add wheresryan22/anatomy -g -a claude-code`이며 Claude Code 외에 OpenCode(`-a opencode`), Codex(`-a codex`)에서도 동작한다고 안내합니다. API 키나 별도 npm 설치가 필요 없고 Node 기본 모듈만 사용한다고 명시합니다.

살펴볼 점
  • 3D 모드는 공식 문서에서도 베타 단계로 표시되어 있어 복잡한 장면에서는 동작이 불안정할 수 있습니다.
  • 생성된 그림의 수치·동작은 작은 모델이 직접 계산한 값이라고 설명하지만, 기술 개념 자체의 정확성은 별도로 검증이 필요합니다.
