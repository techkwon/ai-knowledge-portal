exo: 여러 기기를 묶는 로컬 AI 클러스터

기기를 자동으로 발견하고 모델을 분산 배치해 로컬 추론을 제공하는 오픈소스 클러스터 도구

#MLX#분산 추론#Thunderbolt#API

무엇을 할 수 있나요?

exo는 기기의 자원과 네트워크 연결 상태를 고려해 모델을 분산 배치하며, MLX를 추론 백엔드로 사용합니다.

공식 설치 안내에 따라 대시보드를 빌드하고 의존성을 설치한 뒤 `uv run exo`로 실행합니다. 대시보드와 API의 기본 주소는 `http://localhost:52415`입니다.

OpenAI Chat Completions, Claude Messages, OpenAI Responses, Ollama 형식의 API를 제공하므로 기존 클라이언트와의 연동을 검토할 수 있습니다.

작은 모델로 기기 검색·모델 배치·응답을 먼저 확인한 다음, 처리 속도와 메모리 사용량을 측정해 클러스터 확장 여부를 판단하는 방식으로 활용할 수 있습니다.

살펴볼 점
  • RDMA 사용에는 macOS 26.2 이상과 Thunderbolt 5 등 별도 조건이 있습니다. 모든 Mac이나 일반 네트워크에서 같은 가속 효과를 얻는 것은 아닙니다.
  • 자동 기기 검색으로 의도하지 않은 클러스터 참여가 생기지 않도록 신뢰할 수 있는 네트워크를 사용하고 EXO_LIBP2P_NAMESPACE 설정을 검토하세요. 네임스페이스를 보안 인증의 대체물로 간주하지 마세요.
  • 공식 문서는 Linux에서 현재 CPU 실행을 안내합니다. 실제 하드웨어 지원과 설치 요구사항은 최신 문서를 확인해야 하며, 여기서는 설치·성능을 실측하지 않았습니다.
