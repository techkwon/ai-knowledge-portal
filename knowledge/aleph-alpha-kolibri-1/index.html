Kolibri 1: 독일어·영어 중심 오픈 웨이트 추론 모델

Aleph Alpha가 공개한 총 78B·토큰당 활성 3.46B의 MoE 모델로, 추론 모드·도구 호출·장문 문서 처리를 지원합니다.

#Kolibri#Aleph Alpha#MoE#독일어

무엇을 할 수 있나요?

공식 모델 카드는 독일어·영어를 주요 언어로 설명하며, reasoning mode와 tool calling을 지원한다고 명시합니다.

최대 문맥은 1,048,576토큰이나, 제작자는 서빙 효율과 복잡한 과제에는 262,144토큰 이하를 권장합니다. 문서 검색·추론·코딩에 적용하기 전 실제 문서 길이와 목표 언어로 평가하세요.

Apache 2.0으로 공개된 가중치이며 FP8 모델의 메모리 규모는 약 78GB입니다. 설치 전에 공식 하드웨어 요구사항을 확인하세요.

살펴볼 점
  • 독일어·영어 중심이라는 특성을 한국어 성능 보장으로 확대하면 안 됩니다.
  • 제작자 하드웨어 표에는 최소 구성이 별도로 제시돼 있습니다. 가중치 파일 크기만 보고 단일 80GB GPU에서 모든 과제를 실행할 수 있다고 판단하지 마세요. 직접 실행 테스트는 하지 않았습니다.
