nobg: 크로마키 합성으로 투명 배경 이미지 생성하기

이미지 생성 모델에 단색 그린스크린 배경으로 그리도록 지시한 뒤 해당 색을 투명으로 치환하는 방식으로 투명 배경 PNG를 만드는 오픈소스 CLI 기법

#오픈소스#이미지 편집#투명 배경

무엇을 할 수 있나요?

핵심 원리: 이미지 생성 모델 대부분은 투명 배경을 직접 지원하지 않거나 격자무늬로 표현합니다. nobg는 모델에게 단색(기본값 #00FF00) 그린스크린 배경으로 이미지를 생성하도록 프롬프트를 지시한 뒤, sharp 라이브러리로 해당 색상 영역만 투명하게 치환하는 전통적인 크로마키 합성 기법을 AI 생성 이미지에 적용합니다.

사용 절차: bunx nobg@latest "a red apple"처럼 프롬프트만 넘기면 기본 설정(1:1 비율, 1k 해상도)으로 생성합니다. -a 16:9 -r 2k로 비율과 해상도를 조절하고, -i photo.jpg "배경 제거"처럼 기존 이미지를 입력해 배경만 제거할 수도 있으며, -c로 크로마키 색상을 직접 지정할 수 있습니다. 기본 모델은 Gemini 3 Pro Image Preview이며 GEMINI_API_KEY 환경변수가 필요합니다.

적용 조건: 아이콘, 로고, 스티커처럼 투명 배경이 필요한 생성물에 적합합니다. 원본 이미지의 피사체 경계 색이 크로마키 색과 겹치면(예: 초록 계열 피사체) 해당 부분도 함께 투명 처리될 수 있으므로 -c 옵션으로 색을 바꿔 회피할 수 있습니다.

살펴볼 점
  • GitHub star 수가 적은 개인 프로젝트(Unlicense 라이선스)로, 공식 벤더 지원이 없으며 유지보수 지속 여부가 불확실합니다.
  • Gemini API 키가 필요해 별도 비용이 발생할 수 있고, 결과 품질은 사용하는 이미지 생성 모델의 지시 순응도에 따라 달라집니다.
