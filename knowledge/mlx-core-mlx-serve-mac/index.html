MLX Core · mlx-serve

Apple Silicon Mac에서 대화·도구 호출·문서 질의와 OpenAI·Anthropic·Ollama 호환 API를 로컬로 실행하는 무료 AI 앱·서버

#Apple Silicon#MLX#로컬 LLM#MCP#Claude Code

무엇을 할 수 있나요?

메뉴 막대 앱에서 로컬 모델을 내려받아 채팅, 문서 폴더 질의, 음성·이미지·영상·음악 생성과 에이전트 작업을 Mac 안에서 실행합니다.

mlx-serve는 OpenAI Chat Completions, Anthropic Messages, Ollama 호환 API와 도구 호출·MCP 연결을 제공해 Claude Code, Cursor, Open WebUI 같은 클라이언트에 연결할 수 있습니다.

기본 서버는 127.0.0.1에 바인딩되며 계정이나 클라우드 API 키 없이 로컬에서 사용할 수 있습니다.

살펴볼 점
  • Apple Silicon 전용이며 실행 가능한 모델 크기는 통합 메모리와 저장공간에 크게 좌우됩니다.
  • 에이전트의 셸·파일 도구에는 별도 승인이나 샌드박스를 적용하고, 원격 Telegram 기능은 접근 주체와 권한을 엄격히 확인하세요.
  • 사이트의 자체 벤치마크 수치는 기기·모델·버전·설정이 다른 환경에 그대로 적용되지 않을 수 있습니다.
