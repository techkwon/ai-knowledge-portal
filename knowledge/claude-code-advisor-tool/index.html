Claude Code 어드바이저: 중요한 결정 순간에만 더 강한 모델에게 조언받기

주 모델이 작업하다가 접근법 결정·반복 오류·완료 선언 같은 순간에 더 강한 모델을 호출해 조언을 받는 Claude Code의 실험 기능 설정법과 비용 구조

#Claude Code#advisor#모델 조합#비용 관리#검증

무엇을 할 수 있나요?

Claude Code 공식 문서에 따르면 어드바이저 도구는 주 모델이 작업 중 핵심 시점, 예를 들어 방식을 정하기 전, 같은 오류가 반복될 때, 완료를 선언하기 전에 두 번째 모델을 호출해 조언을 받는 기능입니다. 어드바이저는 도구 호출과 결과를 포함한 전체 대화를 읽고 지침을 돌려줍니다.

설정 방법은 세 가지입니다. 세션 중 `/advisor opus`처럼 지정하거나, 설정 파일의 `advisorModel` 값으로 기본값을 두거나, `claude --advisor opus`로 한 세션에만 적용합니다. 끌 때는 `/advisor off`를 씁니다.

어드바이저는 주 모델보다 같거나 강해야 하며, 주 모델별 허용 조합표가 공식 문서에 있습니다. 문서가 제시하는 대표 조합은 'Sonnet 주 모델 + Opus 어드바이저'처럼 일상 작업은 빠른 모델이 하고 계획·애매한 실패·완료 점검만 강한 모델에 맡기는 방식입니다.

어드바이저 호출은 매 턴이 아니라 결정 시점에만 일어나므로 강한 모델을 처음부터 끝까지 쓰는 것보다 저렴할 수 있다고 안내됩니다. 프롬프트에 '진행 전에 어드바이저와 상의해'처럼 적어 호출을 요청할 수도 있습니다.

살펴볼 점
  • 실험 기능이며 Anthropic API 경로에서만 동작하고 Amazon Bedrock·Google Cloud·Microsoft Foundry 등에서는 제공되지 않습니다. 구독 요금제에서는 어드바이저 사용량도 한도에 포함되고, 일부 요금제에서 Fable 어드바이저는 사용 크레딧으로 과금됩니다.
  • 허용되지 않는 조합은 오류 없이 어드바이저 없이 진행될 수 있으니 `/advisor` 출력으로 적용 여부를 확인하세요. 상위 모델 한도가 끝나도 어드바이저로 계속 쓸 수 있다는 식의 사용자 전언은 공식 문서로 확인되지 않았습니다. 이 카드는 공식 문서 확인이며 실사용 측정이 아닙니다.
