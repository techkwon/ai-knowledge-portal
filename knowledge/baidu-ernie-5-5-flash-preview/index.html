ERNIE 5.5 Flash Preview: 서비스 프리뷰와 가중치 공개 예고 구분

1M 문맥을 제공하는 Baidu 프리뷰 모델, 가중치 이용권과 서비스 조건은 별도 확인

#Baidu#프리뷰#이용 조건

무엇을 할 수 있나요?

Baidu 공식 발표는 총 280B 파라미터 중 토큰당 14B 활성, 1M 토큰 문맥, 코딩·3D 모델링·지식 업무·콘텐츠 제작 용도를 제시합니다. 성능은 제작자 발표이며 독립 비교 결과가 아닙니다.

공식 발표의 가중치 공개 목표는 11월 25일까지입니다. 현재 서비스 프리뷰 접근이 곧 다운로드 가능한 가중치와 재배포 권한을 뜻하지는 않습니다.

OpenRouter의 해당 free 모델 페이지에서 1.0M 문맥과 무료 표시를 확인했습니다. 발표의 200 tok/s 초과와 서비스 페이지 관측치 90 tok/s는 측정 환경이 다르므로 사용자가 그 속도를 보장받는다고 해석하지 않습니다.

살펴볼 점
  • 추론 호출·가입·키 발급·다운로드·설치는 하지 않았습니다. 공개 예정일은 보장된 배포 완료일이 아닙니다.
  • 모델 가중치 링크는 이 확인에서 401/404로 본문·라이선스를 확인하지 못했습니다. 가중치 상업 이용·변경·재배포 권한은 미확인이므로 보류합니다.
  • OpenRouter는 18세 이상이며 모델 제공자별 약관·지역 제한을 추가 적용합니다. 해당 모델은 EU in-region routing 미지원으로 표시됩니다. 한국에서의 실제 계정 접근은 시험하지 않았습니다.
  • 입력은 제공자에게 전달됩니다. 일부 제공자는 저장·학습할 수 있고 출력 권리도 모델 약관에 따릅니다. 무료 표시만 보고 학생·금융·조직 비밀을 입력하거나 상업적 출력 권리를 확정하지 마세요.
