Dev One-Click Setting Kit: Windows 개발환경과 Android 도구 준비

Git·Python·Node.js와 Android 개발 도구를 선택 설치하는 Windows 배치 키트. 키트 코드의 권리와 설치되는 도구·모델의 이용조건은 별개입니다.

#Windows#개발환경#Android#Flutter#오픈소스

무엇을 할 수 있나요?

제작자 README는 Windows 10 21H2 이상·Windows 11에서 단일 .bat 파일로 Git·Python·Node.js 등 개발 도구를 선택 설치하고 설치 확인·업데이트·제거·결과 로그 기능을 제공한다고 안내합니다. AI 모델 자체나 코딩 서비스 이용권을 배포하는 도구는 아닙니다.

모바일 메뉴 [M]은 Git·Flutter·Android Studio·adb와 선택형 scrcpy를 준비합니다. Flutter는 공식 git 저장소의 stable을 받아 사용자 폴더에 설치하고 PATH를 추가하는 방식입니다. Android Studio 최초 실행·SDK 구성과 Android SDK 라이선스 동의는 사용자가 따로 해야 하며 iOS 빌드는 Mac이 필요합니다.

README의 2026-11-14 변경 이력은 Flutter 설치 경로 수정(v1.6.3), 모바일 메뉴(v1.7.0), 빈 입력 반복·실패 표시·번호 검증 수정(v1.7.1)을 설명합니다. 11월 15일 열람본은 [D] 분야별 개발환경을 추가한 v1.8.0까지 포함하므로 전날 대화 시점과 현재 문서의 기능 범위를 구분하세요.

README는 winget 이외에 npm, scoop 원격 설치 스크립트, Flutter git 경로를 구분합니다. scoop 설치 시 현재 사용자 PowerShell 실행 정책이 변경될 수 있고 Flutter PATH도 바뀌므로 기관 PC에서는 설치 허가와 되돌리기 방법부터 확인하세요.

저장소 LICENSE 본문은 Apache-2.0입니다. 재배포 시 라이선스 사본·고지 유지·변경 표시·해당 NOTICE 의무를 지켜야 합니다. Android SDK·Claude Code·Docker Desktop 등 설치되는 제품과 Ollama에서 별도로 받는 모델에는 각자의 이용조건이 적용됩니다.

살펴볼 점
  • 직접 다운로드·설치·제거·명령 실행·성능 측정을 하지 않았습니다. README의 작동 설명을 검토했으며 독립 코드 보안감사나 설치 성공 확인은 아닙니다.
  • v1.8.0 변경 이력은 Docker·PostgreSQL·C++ 빌드 도구의 실제 설치를 시험하지 않고 가짜 winget으로 호출·화면 흐름만 확인했다고 명시합니다. 학교 PC에서 검증된 무위험 설치라고 소개하지 마세요.
  • 보안 경고나 백신을 무조건 해제하는 안내는 재사용하지 않습니다. 공식 출처·파일 내용·기관 정책을 먼저 확인하세요. 관리자 권한이 필요한 도구, 원격 스크립트 실행, PATH·실행 정책 변경을 개별 검토해야 합니다.
  • 로그에는 PC 이름 등이 남을 수 있습니다. 로그를 공개하지 말고 설치 도구의 자체 통신과 개인정보 설정도 따로 확인하세요.
  • 키트의 Apache-2.0은 제3자 제품·모델 가중치·AI 서비스 구독·생성물의 권리를 부여하지 않습니다. 학생 사용을 권장하는 연령 검증 자료가 아니며 각 서비스의 연령·지역·학교 계정 제한을 별도 확인해야 합니다.
