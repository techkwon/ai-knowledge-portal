DeepSeek V4.1 Flash

이미지·텍스트 입력과 긴 문맥을 지원하고 추론 노력 값을 조절할 수 있는 공개 MoE 모델

#DeepSeek#이미지 이해#긴 문맥#추론 조절

무엇을 할 수 있나요?

공식 모델 카드에 따르면 이미지와 텍스트를 입력받아 텍스트를 생성하며 최대 100만 토큰 문맥을 지원합니다. 기존 V4 Flash 및 Flash Vision Exp와 구분되는 V4.1 모델입니다.

추론 노력은 1~100의 정수로 조절할 수 있습니다. 도입할 때는 동일한 문서·이미지 과제에서 낮은 값과 높은 값의 정확도, 지연, 비용을 비교하는 방식으로 평가하세요.

공식 저장소는 Jinja 채팅 템플릿 대신 encoding 폴더의 Python 참조 구현을 제공합니다. 대화·도구 호출·이미지 입력 형식을 통합할 때 이 구현과 테스트를 기준으로 삼으세요.

살펴볼 점
  • 공식 벤치마크는 최대 추론 노력 등 특정 설정의 결과이며 모든 업무의 성능을 보장하지 않습니다. 이 카드는 설치나 성능 실측이 아닌 자료 확인입니다.
  • 활성 파라미터 수와 전체 모델 크기는 다릅니다. 일반 노트북에서 쉽게 구동된다고 가정하지 말고 공식 추론 안내와 하드웨어 요구를 확인하세요.
  • 실제 API 제공 범위·가격·입력 데이터 보관 정책은 사용하려는 제공자의 최신 문서를 별도로 확인하세요.
