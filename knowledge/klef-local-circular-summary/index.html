KLEF 공람문서 요약: 기본 로컬 처리와 외부 API 모드 구별

K-에듀파인 공람 목록에 요약·조치·기한·대상을 붙이는 비공식 Chrome 확장·Windows 도우미

#공문 요약#로컬 AI#개인정보

무엇을 할 수 있나요?

배포자는 Windows·Chrome 환경에서 공람 문서를 정상 저장하고 로컬 도우미와 모델로 요약하는 설치 흐름을 안내합니다. 기관 또는 Google의 공식 제품은 아니라고 명시합니다.

개인정보처리방침은 기본 로컬 CPU 처리, 외부 API를 직접 설정하고 전송에 동의했을 때의 텍스트 전송, 선택한 Chrome 온디바이스 AI를 구별합니다. 설치 파일·모델 다운로드에는 별도 네트워크 접속이 필요합니다. 적용 버전 1.6.3 개인정보처리방침은 선택한 API가 실패해도 다른 API로 자동 전환하지 않는다고 안내합니다.

문서·요약·캐시는 사용자 PC에 남으며, Windows 도우미의 API 키는 DPAPI로 암호화하지만 문서·요약 캐시 전체가 앱 자체에서 암호화되는 것은 아니라고 설명합니다. 공유 PC의 계정·파일 접근권한을 별도로 관리해야 합니다.

현재 배포 안내는 Windows+Chrome, 17개 시도교육청을 소개하며 충북 외 지역 주소 지원은 1.8.4부터라고 설명합니다. 웹스토어 심사·배포 버전 상태가 변할 수 있으므로 실제 적용 전 현재 버전을 확인합니다. 호환성은 제작자 안내이며 독립 시험 결과가 아닙니다.

현재 설치 페이지는 도우미 제거 후에도 다운로드\KLEF에 저장한 공문이 남는다고 설명합니다. 개인정보처리방침은 저장본·요약·장부·설정·로그 삭제를 별도로 안내하므로 확장 삭제나 제거 프로그램만으로 모든 자료가 지워진다고 단정하지 않습니다.

살펴볼 점
  • 로컬 모드라도 공문 속 개인정보 처리와 PC 접근권한 관리가 필요합니다. 외부 API 모드로 비공개 문서를 보내기 전 기관 규정과 제공자 정책을 확인하세요.
  • 기관의 설치·개발자 모드 제한을 우회하지 말고 담당자에게 문의하세요. 자동 요약의 기한·대상·조치는 원문과 대조하며 공식 공문 처리를 대신하지 않습니다.
  • 공식 문서 확인 기준이며 설치·실행·성능을 직접 시험하지 않았습니다.
  • 현재 배포 안내와 적용 버전 1.6.3 개인정보처리방침의 버전 차이를 구분했습니다. 실제 설치·지역별 동작·제거 결과는 검증하지 않았습니다.
  • 외부 API 동의는 기관의 비공개 문서 반출 승인과 다릅니다. 제공자 보관·학습·삭제·비용과 기관 정책을 확인하고, 개인 구독이 API 이용권을 대신한다고 가정하지 않습니다.
  • 설치·개발자 모드 제한이나 보안 경고를 우회하도록 안내하지 않습니다. 코드 서명·배포 파일 신뢰성과 관리자 승인을 확인해야 합니다.
  • 페이지 열람만 했으며 코드 및 기본 모델 가중치 라이선스 전문은 확인하지 않았습니다. 무료 배포를 자유 재배포·상업 이용권으로 해석하지 않습니다.
