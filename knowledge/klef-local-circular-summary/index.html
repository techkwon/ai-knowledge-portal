KLEF 공람문서 요약: 기본 로컬 처리와 외부 API 모드 구별

K-에듀파인 공람 목록에 요약·조치·기한·대상을 붙이는 비공식 Chrome 확장·Windows 도우미

#공문 요약#로컬 AI#개인정보

무엇을 할 수 있나요?

배포자는 Windows·Chrome 환경에서 공람 문서를 정상 저장하고 로컬 도우미와 모델로 요약하는 설치 흐름을 안내합니다. 기관 또는 Google의 공식 제품은 아니라고 명시합니다.

개인정보처리방침은 기본 로컬 CPU 처리, 외부 API를 직접 설정하고 전송에 동의했을 때의 텍스트 전송, 선택한 Chrome 온디바이스 AI를 구별합니다. 설치 파일·모델 다운로드에는 별도 네트워크 접속이 필요합니다.

문서·요약·캐시는 사용자 PC에 남고 전체 캐시를 앱 자체에서 암호화하지는 않는다고 설명합니다. 버전·웹스토어 심사 상태·지역별 적용 범위는 배포 안내에서 확인하세요.

살펴볼 점
  • 로컬 모드라도 공문 속 개인정보 처리와 PC 접근권한 관리가 필요합니다. 외부 API 모드로 비공개 문서를 보내기 전 기관 규정과 제공자 정책을 확인하세요.
  • 기관의 설치·개발자 모드 제한을 우회하지 말고 담당자에게 문의하세요. 자동 요약의 기한·대상·조치는 원문과 대조하며 공식 공문 처리를 대신하지 않습니다.
  • 공식 문서 확인 기준이며 설치·실행·성능을 직접 시험하지 않았습니다.
