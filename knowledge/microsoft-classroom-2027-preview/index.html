Microsoft Classroom: 2027년 초 프리뷰를 예고한 수업 허브

Teams를 없애는 새 정식 출시가 아니라 선택형 교육 경험의 발표

#Microsoft 365 Education#수업 관리#프리뷰

무엇을 할 수 있나요?

Microsoft 공식 Education 블로그는 Classroom을 과제, Classwork, 성적, OneNote Class Notebook, Learning Accelerators, Insights 등을 한곳에 모으는 독립형 교육 경험으로 발표했다.

현재 이용 가능한 정식 출시로 오해하지 말아야 한다. 공식 글은 프리뷰를 2027년 초로 계획하고 있으며 관리자의 사전 등록을 안내한다. 학교 도입·프리뷰 승인·실제 기능 제공이 완료됐다는 뜻은 아니다.

Microsoft Teams for Education이나 Microsoft 365 LTI를 대체하지 않는다고 명시한다. 수업은 Classroom, 교직원 회의·협업은 Teams처럼 기관 목적에 맞추어 공존하는 선택지를 설명한다.

공식 글은 기존 A1/A3/A5/A7에는 2027년 추가 비용 없이 제공할 계획이며, 2028년 1월부터의 미래 SKU에서는 A2 이상에 포함할 계획이라고 안내한다. 웹·모바일·데스크톱 경험과 School Data Sync 기반 학급·명단 연계도 계획에 포함한다.

살펴볼 점
  • 예정 기능·일정·라이선스는 변경될 수 있다. 조직 테넌트의 실제 제공 상태와 관리자 정책을 확인해야 하며 한국 제공이나 특정 학교 사용권을 이 발표만으로 확정하지 않는다.
  • Microsoft 365 Education 서비스의 이용 조건이 적용되는 제품 발표다. 오픈소스 코드나 모델 가중치 배포·상업 재판매 권한을 제공하는 자료가 아니다.
  • 학생 개인정보·AI 기능 연령 및 기관별 계약 조건은 이 검토에서 별도 검증하지 않았다. 학생 명단 연동·계정 생성·신청·실제 사용은 하지 않았다.
