claude-mode: 작업별 플러그인 설정 전환

원본 설정 파일을 덮어쓰지 않고 세션별 모드로 도구 구성을 나누는 커뮤니티 래퍼

#실무 가이드#커뮤니티 인사이트

무엇을 할 수 있나요?

원리: claude --mode 이름 명령이 settings/settings.이름.json을 해당 세션의 --settings로 전달합니다. 원본 ~/.claude/settings.json을 변경하지 않습니다.

절차: Claude Code CLI가 먼저 작동하는지 확인하고 저장소의 설치 스크립트와 변경할 셸 설정·PATH를 검토합니다. bash와 zsh에는 jq가 필요합니다.

사용 예시: 문서 작업과 코드 리뷰에 서로 다른 모드를 만들고 claude --mode write 또는 claude --mode review로 실행합니다. 모드별 필요한 플러그인과 MCP만 허용합니다.

확인: --mode로 목록을 보고 --mode-help로 사용법을 확인합니다. bash/zsh 파일은 직접 실행하는 대신 source로 로드하며 기존 별칭 충돌도 점검합니다.

살펴볼 점
  • Anthropic 공식 제품이 아닙니다. 설치·보안 테스트를 직접 수행하지 않았습니다.
  • 자동 설치기는 셸 시작 파일이나 사용자 PATH를 변경합니다. 변경 전 백업하고 플러그인 권한과 외부 전송 대상을 확인하세요.
