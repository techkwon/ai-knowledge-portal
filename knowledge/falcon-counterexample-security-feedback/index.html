FALCON: 실행 반례로 코딩 에이전트의 보안을 검증하기

공격 입력 탐색과 행동 검증을 분리하고 실행 흔적으로 수정 피드백을 주는 보안 연구·플러그인

#보안 검증#실행 흔적#반례

무엇을 할 수 있나요?

논문과 공식 프로젝트는 공격 입력 탐색, 증거의 충실도 확인, sandbox 실행, 실행 흔적 검증과 반례 피드백을 구분합니다. 코드 소스만 읽은 판정과 실제 관찰한 행동을 구별하려는 접근입니다.

Claude Code 플러그인은 선택한 코드를 검사하거나 구현 후 공격·검증·수정을 반복하는 흐름을 안내합니다. 현재 플러그인에서 공격 대상으로 설명하는 언어는 Python입니다.

허용된 샘플 프로젝트에서 수정 전 반례를 재현하고, 수정 후 같은 반례와 기능 회귀 테스트를 함께 확인하는 보안 검수 관점으로 참고할 수 있습니다.

살펴볼 점
  • 깨끗한 판정은 실행한 probe가 위반을 찾지 못했다는 뜻이지 보안 완전성 증명이 아닙니다. 논문 성능은 저자 측 실험 보고입니다.
  • 공격·검증 코드는 허가된 격리 환경에서만 실행하세요. 실제 서비스나 비밀값·사용자 데이터에 무제한 권한을 주는 방식으로 도입하지 마세요.
  • 공식 문서 확인 기준이며 설치·실행·성능을 직접 시험하지 않았습니다.
