미성년자 대상 서비스의 OpenAI·Anthropic API 이용 시 준수 사항

OpenAI·Anthropic 공식 문서. 미성년자에게 API 기반 서비스를 제공하는 조직이 지켜야 할 연령 확인, 콘텐츠 필터링, 데이터 보호, 고지 의무 등 안전 기준 정리

#API 정책#미성년자 보호#OpenAI#Anthropic

무엇을 할 수 있나요?

OpenAI 공식 개발자 문서는 API로 18세 미만 사용자에게 서비스를 제공하는 조직에게 이용약관 외에 추가 안전장치를 요구합니다. COPPA 등 아동 보호·개인정보 법규 준수, 13세 미만 개인정보 처리 시 API의 데이터 보관 안 함(zero data retention) 설정을 먼저 적용할 것, 연령에 맞는 콘텐츠 필터링과 모니터링·신고 체계 마련을 안내합니다.

Anthropic 공식 지원 문서도 유사하게, API를 활용한 제품이 미성년자와 직접 상호작용하는 경우 연령 확인 시스템, 콘텐츠 필터링, 모니터링·신고 체계, 안전한 이용 안내 자료 제공을 권고하며, AI 시스템과 대화 중임을 사용자에게 고지할 의무를 명시합니다.

두 회사 모두 자사가 조직의 정책 준수 여부를 주기적으로 감사할 수 있으며, 미준수가 반복되면 계정이 정지되거나 종료될 수 있다고 밝힙니다.

살펴볼 점
  • 각 문서가 제시하는 구체적 연령 기준·요구 조치는 지역 법규에 따라 달라질 수 있으므로, 실제 서비스 설계 전 반드시 원문과 자국 법률을 함께 확인해야 합니다.
