미성년자 대상 서비스의 OpenAI·Anthropic·Gemini API 이용 조건

OpenAI·Anthropic은 추가 안전장치를 전제로 미성년자 대상 API 서비스를 안내하고, Gemini API 추가 약관은 18세 미만 대상이거나 접근 가능성이 있는 서비스에 API를 쓰지 않도록 정합니다. 공식 문서 기준 비교입니다.

#API 정책#미성년자 보호#OpenAI#Anthropic#Gemini API

무엇을 할 수 있나요?

OpenAI 공식 개발자 문서는 API로 18세 미만 사용자에게 서비스를 제공하는 조직에게 이용약관 외에 추가 안전장치를 요구합니다. COPPA 등 아동 보호·개인정보 법규 준수, 13세 미만 개인정보 처리 시 API의 데이터 보관 안 함(zero data retention) 설정을 먼저 적용할 것, 연령에 맞는 콘텐츠 필터링과 모니터링·신고 체계 마련을 안내합니다.

Anthropic 공식 지원 문서도 유사하게, API를 활용한 제품이 미성년자와 직접 상호작용하는 경우 연령 확인 시스템, 콘텐츠 필터링, 모니터링·신고 체계, 안전한 이용 안내 자료 제공을 권고하며, AI 시스템과 대화 중임을 사용자에게 고지할 의무를 명시합니다.

Google의 Gemini API 추가 서비스 약관은 API 사용자가 만 18세 이상이어야 하고, 만 18세 미만을 대상으로 하거나 이들이 접근할 가능성이 있는 웹사이트·앱·서비스의 일부로 API를 사용하지 않도록 정합니다. 학생이 직접 쓰는 앱을 만든다면 이 조건을 설계 단계에서 먼저 확인해야 합니다.

OpenAI와 Anthropic은 자사가 조직의 정책 준수 여부를 주기적으로 감사할 수 있으며, 미준수가 반복되면 계정이 정지되거나 종료될 수 있다고 밝힙니다.

살펴볼 점
  • 각 문서가 제시하는 구체적 연령 기준·요구 조치는 지역 법규와 약관 개정에 따라 달라질 수 있으므로, 실제 서비스 설계 전 반드시 원문과 자국 법률을 함께 확인해야 합니다.
  • Google Workspace for Education 등 기관 계약으로 제공되는 Gemini 앱은 API 약관과 조건이 다를 수 있으니 별도로 확인하세요.
