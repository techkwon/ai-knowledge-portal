Claude Docs·Slides: 보고서와 발표를 한 대화에서

통합 Claude에서 문서와 발표 자료를 이어 만들고 편집·내보내기까지 검토하는 흐름

#실무 가이드#커뮤니티 인사이트

무엇을 할 수 있나요?

공식 발표: Cowork와 채팅이 통합되며 Docs·Slides와 대화 내 Design이 제공됩니다. 통합은 Pro·Max부터 수 주에 걸쳐 순차 적용됩니다.

절차: 출처 자료와 보고서 독자·분량·완료 기준을 지정하고 먼저 문서를 작성합니다. 확정한 문서를 기준으로 발표용 핵심 내용만 슬라이드로 변환합니다.

검수 예시: 문서의 수치와 슬라이드 수치를 대조하고 직접 편집합니다. 발표하거나 PowerPoint·PDF로 내려받은 뒤 글꼴·표·페이지 배치를 별도로 확인합니다.
