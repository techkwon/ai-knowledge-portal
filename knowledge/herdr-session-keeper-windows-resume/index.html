Herdr Session Keeper: Windows에서 AI 대화 기록을 이어 열기

Herdr 창과 Claude Code·Codex 세션의 연결을 기록하고 재개를 돕는 독립 보조 도구

#Windows#세션 관리#오픈소스

무엇을 할 수 있나요?

Herdr Session Keeper는 Windows의 Herdr 사용자용 보조 도구입니다. 제작자 문서는 창과 AI 대화의 연결을 주기적으로 기록하고, 남아 있는 대화 파일을 Claude Code 또는 Codex의 resume 기능으로 이어 여는 방식을 설명합니다.

목록에서 대화를 골라 재개하는 창과 Herdr가 받아 둔 앱 업데이트를 적용하는 기능도 제공합니다. Herdr 자체나 AI 모델을 배포하는 프로젝트가 아니라 별도 보조 프로그램입니다.

문서의 요구 환경은 Windows 10/11 64비트, Windows PowerShell 5.1, Node.js 18 이상과 Herdr입니다. 실제 개발자 시험은 Windows 11에서 이뤄졌으며 Windows 10은 미확인으로 적혀 있습니다.

복구 대상은 대화 기록입니다. 전원 종료 때 실행 중이던 단일 작업이나 세션 내부의 감시·예약을 되살리는 기능과는 다릅니다. 컴퓨터 자체를 켜 주지도 않습니다.

저장소 LICENSE는 Apache-2.0입니다. 조건에 따른 상업적 이용·수정·배포가 가능하지만 라이선스 사본과 관련 고지 유지, 수정 표시 등 의무가 있습니다. 상표 사용권은 별도로 주어지지 않습니다.

살펴볼 점
  • 직접 설치·실행·재부팅·복구를 시험하지 않았습니다. 제작자도 실제 재부팅 후 전부 복구, 실제 Codex 복구, 다른 PC 설치, 최종 UI 클릭 시험 등의 미검증 항목을 명시합니다.
  • 제작자 문서는 세션 제목·마지막 요청 일부·폴더·모델 정보와 화면 글자 일부를 로컬에서 읽는다고 설명합니다. 로그·매핑 파일에 프로젝트 정보가 남을 수 있으므로 공유하지 말고 공용·학교·회사 PC 정책과 동의를 확인하세요. 독립 코드 보안감사를 한 것은 아닙니다.
  • 설치는 설정 파일·작업 스케줄러·바로가기 등에 영향을 줄 수 있으며 앱 자동 업데이트 기능도 있습니다. 문서의 백업·되돌리기 범위를 검토한 뒤 별도로 판단하세요.
  • 코드 라이선스는 Herdr·Node.js·Windows·Claude Code·Codex 및 연결 SaaS의 약관이나 이용권을 대신하지 않습니다. 모델 가중치나 구독 이용권을 포함하지 않습니다. 연결 서비스의 연령·지역·조직 계정 조건은 각각 확인해야 합니다.
