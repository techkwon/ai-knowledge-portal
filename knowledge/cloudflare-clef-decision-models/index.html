Cloudflare Clef: Jev API와 호환되는 공개 가중치 판단 모델

Cloudflare가 Workers AI에서 호스팅하고 Hugging Face에 Apache 2.0으로 공개한 Clef·Clef-flash 판단 모델로, 선택·예/아니오·점수와 확률을 생성 문장 없이 반환하며 이미지 입력과 64K 문맥을 지원합니다.

#Cloudflare#Clef#판단 모델#Workers AI#Jev 호환

무엇을 할 수 있나요?

Cloudflare 공식 블로그는 판단 모델을 입력 상태와 질문을 받아 타입이 정해진 답과 확률을 돌려주는 모델로 설명합니다. 예를 들어 고객 문의가 긴급한지, 어느 팀이 맡을지, 심각도가 어느 정도인지를 한 번에 판정해 코드가 라우팅·에스컬레이션·사람 검토로 분기하게 할 수 있습니다.

Clef는 Qwen 계열 백본을 고정하고 라우팅 헤드와 어댑터를 후학습해, 텍스트를 한 토큰씩 생성하지 않고 스키마의 선택지를 병렬로 점수화합니다. 블로그는 Jev API와 완전 호환, 이미지 입력용 비전 인코더, 64K 문맥을 차별점으로 들고, 큰 Clef는 정확도용·Clef-flash는 지연 시간용으로 구분합니다.

Workers AI의 `@cf/cloudflare/clef` 엔드포인트로 호출하거나 Hugging Face의 가중치를 내려받아 로컬에서 실험할 수 있습니다. 블로그는 요청·응답을 읽거나 저장하거나 학습에 쓰지 않는다고 밝히며, 별도 미세조정 서비스는 전담 엔지니어 협업 형태로 먼저 제공한다고 안내합니다.

살펴볼 점
  • 블로그의 벤치마크는 Cloudflare 자체 평가이며 일부 항목은 Jev가 앞섭니다. 실제 한국어 업무 문서로 정확도와 확률 보정을 따로 측정한 뒤 자동 처리 임계값을 정하세요.
  • 판단 모델은 자유 서술 답변이나 도구 호출 생성용이 아닙니다. 생성형 LLM과 역할을 나눠 쓰는 구성이 전제입니다.
