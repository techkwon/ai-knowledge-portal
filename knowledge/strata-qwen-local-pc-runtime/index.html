Strata: GPU·RAM을 함께 쓰는 Qwen 로컬 추론 엔진

Qwen3.8-Flash-Next를 NVIDIA·AMD PC에서 실행하고 OpenAI·Anthropic 호환 인터페이스로 코딩 도구에 연결하는 오픈소스 런타임입니다.

#Strata#Qwen#GPU 오프로딩#로컬 LLM

무엇을 할 수 있나요?

제작자 README는 Windows·Linux, 지원 GPU의 VRAM 12GB 이상, RAM 32GB 이상, 약 80GB 여유 디스크를 안내합니다. 모델 변형에 따라 더 많은 RAM이 필요하며 64GB는 모든 안내된 기본 크기를 실행하는 기준입니다.

설정 도구가 GPU·RAM·디스크와 모델 크기·문맥 길이를 선택합니다. 기본 UI는 로컬 8080 포트이며 OpenAI 호환 /v1, Anthropic Messages, OpenAI Responses 인터페이스를 제공합니다.

처음에는 작은 모델 크기와 한 요청으로 한국어·코딩 표본을 평가한 뒤 문맥 길이·동시성을 늘리세요. 기본 동시 요청은 하나이며 늘리면 작은 GPU에서 각 응답이 느려질 수 있습니다.

살펴볼 점
  • README의 속도 수치는 제작자가 특정 PC·엔진·양자화 설정에서 측정한 값이지 이 환경의 실측이 아닙니다.
  • Coder 변형은 일부 전문가를 제거해 RAM을 줄이며 제작자가 CJK 등 비코딩 과제의 약점을 안내합니다. 한국어 목적이면 별도 확인하세요.
  • 다른 기기에서 접속하도록 바인딩을 넓히면 API 키와 네트워크 접근 제어를 설정하세요. 설치 스크립트는 실행하지 않았습니다.
