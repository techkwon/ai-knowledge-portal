Strata: 모델별 조건을 나눠 보는 멀티플랫폼 로컬 런타임

현재 README는 Windows·Linux·Mac과 Apple Silicon 경로를 안내합니다. 운영체제 지원과 모델별 메모리·저장공간 요구를 따로 확인해야 합니다.

#Strata#로컬 LLM#Apple Silicon#GPU 오프로딩

무엇을 할 수 있나요?

현재 제작자 README는 Windows·Linux·Mac 데스크톱 앱과 Apple Silicon M1 이상 하드웨어 가이드를 안내합니다. NVIDIA RTX 계열, AMD GPU, Intel Arc Linux, Strix Halo, DGX Spark Linux 등은 별도 가이드 경로로 구분합니다. 운영체제 지원이 모든 모델·엔진의 동일 동작을 뜻하지는 않습니다.

모델별 요구조건을 따로 보세요. README의 Apple Silicon 64GB 이상 조건은 DeepSeek V4.1-Flash-1017 지원 설명에 붙는 조건이지 전체 모델의 공통 최소 RAM이 아닙니다. 해당 DeepSeek 변형의 다운로드 예시는 약 191~274GB로 안내되어 저장 공간도 함께 검토해야 합니다.

현재 README는 OpenAI-compatible 및 Anthropic-compatible API를 설명합니다. 세부 포트·endpoint·동시 요청 설정은 해당 버전의 모델·엔진 문서에서 확인하고, 작은 비민감 표본에서 시작해 문맥 길이·동시성을 늘리는 계획이 적절합니다.

기존 Qwen 중심 안내에 있던 VRAM 12GB·RAM 32GB·디스크 80GB를 현재 모든 모델과 Mac에 공통 적용하지 않습니다. 현재 README에서 확인하지 못한 과거의 세부 설정이 제거됐다고 단정하는 것도 아닙니다.

살펴볼 점
  • 제작자 README를 확인했으며 설치·모델 다운로드·속도 측정은 하지 않았습니다. 모델 적재 가능 여부와 실제 처리량·동시성·지연은 별도 검증 항목입니다.
  • 코드 라이선스와 모델 가중치·런타임·연결 서비스 조건은 별개입니다. 이번 갱신에서는 라이선스 전문과 모델별 세부 문서를 모두 읽지 않았으므로 이용권이나 포괄적 상업 허가를 새로 주장하지 않습니다.
  • 로컬 실행만으로 외부 통신·로그·악성 코드 위험이 없어지는 것은 아닙니다. API 노출을 넓히기 전 인증·네트워크 접근과 비밀정보 범위를 점검하세요.
