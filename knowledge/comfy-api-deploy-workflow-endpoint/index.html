Comfy API: ComfyUI 워크플로를 환경째 패키징해 API로 배포

노드·모델·LoRA·파이썬 의존성을 묶은 Build에서 불변 릴리스를 만들고 자동 확장 엔드포인트로 배포하는 유료 플랜용 서비스로, CLI와 SDK를 제공합니다.

#ComfyUI#Comfy API#배포#엔드포인트#SDK

무엇을 할 수 있나요?

Comfy 공식 블로그는 Comfy API를 ComfyUI 워크플로를 앱·도구·서비스의 엔진으로 바꾸는 서비스라고 소개하며, 현재 유료 Comfy 플랜 이용자에게 열려 있다고 밝힙니다.

흐름은 워크플로 JSON 또는 Comfy Desktop 스냅샷으로 Build를 만들고, 필요한 모델·커스텀 노드·의존성을 확인한 뒤 불변 릴리스를 잘라 고유 URL의 엔드포인트로 배포하는 것입니다. 터미널에서는 comfy build init 과 comfy build push --release 로 진행합니다.

최소 워커를 0으로 두면 요청이 없을 때 GPU 시간이 들지 않고, 지연이 중요하면 워커를 켜 둘 수 있습니다. GPU는 초 단위, 저장소는 시간 단위로 정산되고 사용 요금은 플랜과 별도입니다. 사용량·비용·API 키는 platform.comfy.org 콘솔에서 봅니다.

살펴볼 점
  • 유료 플랜과 사용량 요금이 필요합니다. 이미 RunPod나 Modal에서 잘 돌리고 있다면 바꿀 이유가 적다고 공식 글도 밝힙니다.
  • 공개 전 워크플로에 포함된 모델과 커스텀 노드의 라이선스를 확인하세요.
