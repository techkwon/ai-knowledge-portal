NobodyWho: 모바일·데스크톱·Godot 앱에 넣는 온디바이스 LLM SDK

GGUF 모델을 Kotlin·Swift·React Native·Flutter·Python·Godot에서 오프라인 실행하고 도구 호출·비전·음성 기능을 붙이는 EUPL-1.2 추론 엔진

#NobodyWho#온디바이스 AI#GGUF#llama.cpp#모바일

무엇을 할 수 있나요?

NobodyWho는 앱 안에서 GGUF 형식의 공개 LLM을 오프라인으로 실행하는 EUPL-1.2 추론 엔진입니다. Kotlin, Swift, React Native·Expo, Flutter, Python, Godot 바인딩을 제공해 모바일·데스크톱·게임에 같은 로컬 추론 코어를 넣을 수 있습니다.

llama.cpp 기반 텍스트·비전·임베딩·재순위화와, ONNX Runtime 기반 음성 인식·합성·음성 활동 감지를 묶습니다. 함수 서명에서 구조화 문법을 만들어 타입이 정해진 도구 호출을 지원하고 모델은 Hugging Face나 URL에서 내려받습니다.

가속은 macOS·Apple 기기의 Metal, Linux·Windows·Android의 Vulkan 등을 사용하며 GPU 메모리에 다 들어가지 않는 모델은 일부 계층을 CPU로 넘길 수 있습니다. 원격 API 키나 별도 서버 없이 기기 안에서 데이터 흐름을 유지하는 앱을 만들 때 유용합니다.

공식 문서는 데스크톱에서 모델 파일의 약 1.5배 여유 RAM, 바쁜 시스템에서는 약 2배를 권장합니다. 모바일은 기기와 운영체제가 차지하는 메모리를 제외하고 모델 파일의 약 2배를 확보하는 것을 경험칙으로 제시합니다.

살펴볼 점
  • 웹 내보내기와 Windows ARM64는 지원하지 않고, Godot의 iOS 내보내기도 제공하지 않습니다. 플랫폼별 패키지와 현재 지원표를 먼저 확인하세요.
  • 온디바이스 실행이 곧 정확성이나 완전한 개인정보 보호를 뜻하지 않습니다. 선택한 모델의 라이선스·편향·메모리 요구량, 앱 로그·백업·크래시 수집 경로를 별도로 검토해야 합니다.
