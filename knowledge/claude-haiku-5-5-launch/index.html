Claude Haiku 5.5: 더 싸고 빠른 소형 모델 + Max/Team 월간 API 크레딧

Anthropic 공식 발표. Haiku 4.5 대비 평균 75% 저렴하며, Sonnet 5.5 캐시읽기 반값 인하와 Claude Max/Team 구독자용 신규 월간 API 크레딧이 함께 도입됩니다.

#Claude#Anthropic#Haiku#API 크레딧#소형 모델

무엇을 할 수 있나요?

Anthropic 공식 발표에 따르면 Claude Haiku 5.5는 요약, 컨텍스트 압축(compaction), DB 조회, 분류 같은 대량·반복 작업과 코딩 서브에이전트, 브라우저 사용 등 속도가 중요한 작업에 적합하도록 설계된 소형 모델입니다. Haiku 4.5 대비 평균 약 75% 저렴하며(10만 토큰 이하 요청은 90% 저렴, 이상 요청은 50% 저렴), 처리 속도도 자사 모델 중 가장 빠릅니다.

함께 발표된 가격 변경: Sonnet 5.5의 캐시 읽기 비용이 100만 토큰당 $0.20→$0.10으로 반값 인하되어 대부분의 에이전틱 작업 비용이 약 20% 줄어듭니다. 또한 이번 주부터 Claude Max·Team 구독자에게 Claude Platform(API) 사용을 위한 신규 월간 크레딧이 제공됩니다: Max 5x는 월 $100, Max 20x는 월 $200, Team은 사용자 풀링 기준 월 최대 $500.

Haiku 5.5는 자사 소형 모델 최초로 조절 가능한 effort(노력) 설정을 지원해 비용과 지능 중 우선순위를 선택할 수 있습니다. AWS·Google Cloud·Microsoft Azure 등 주요 플랫폼에서 바로 사용 가능하며, Claude Platform에서는 모델명 claude-haiku-5-5로 호출합니다.

살펴볼 점
  • Terminal-Bench 4.0(복잡한 멀티스텝 CLI 작업) 기준 Haiku 5.5는 39.2%로 Sonnet 5.5(70.6%)보다 크게 낮습니다. 복잡한 에이전틱 코딩에는 Sonnet/Opus가 여전히 더 적합하며, Haiku 5.5는 좁게 정의된 반복 작업에 최적화된 모델입니다.
  • Max/Team 월간 API 크레딧은 구독 플랜과 별도로 API(Claude Platform) 호출에만 사용 가능하며, 정확한 적용 범위와 소진 규칙은 Anthropic Help Center 문서를 직접 확인해야 합니다.
