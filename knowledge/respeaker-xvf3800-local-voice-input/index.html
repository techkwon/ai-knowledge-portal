ReSpeaker XVF3800: 로컬 음성 비서의 마이크와 AI 처리를 분리하기

4마이크 음성 입력 보드의 USB·I2S 연결과 로컬 STT·LLM·TTS 구성을 구분하는 제조사 자료 안내. 완성형 AI 스피커나 음악 재생 품질 보장은 아니다.

#ReSpeaker#XVF3800#STT#TTS#개인정보

무엇을 할 수 있나요?

Seeed Studio는 XVF3800 기반 원형 4마이크 보드에 AEC·AGC·빔포밍·방향 감지·VAD·잡음 및 잔향 억제 기능과 최대 5m·360도 음성 포착을 안내한다. 이는 제조사 사양이며 교실 환경에서 직접 확인한 성능이 아니다.

PC USB 연결 모드와 임베디드 I2S 모드는 펌웨어가 다르다. XIAO 포함 여부와 출고 펌웨어를 먼저 확인한다. 공식 문서는 Windows·macOS·Raspberry Pi OS USB 호스트를 안내하지만 특정 Mac에서 전체 음성 비서를 즉시 실행할 수 있다는 뜻은 아니다.

보드의 음성 입력·음소거 기능과 음성인식(STT)·대화 모델(LLM)·음성합성(TTS)은 별도 계층이다. 제조사의 로컬 음성 비서 예시는 Jetson AGX Orin 32GB와 Whisper·Ollama/Gemma·Piper를 조합하며, Mac용 완성 설치 안내나 한국어 성능 검증이 아니다.

로컬 모델만 연결할지 외부 API를 연결할지에 따라 전송 데이터와 비용이 달라진다. 하드웨어 구입비·호스트 컴퓨터·모델 저장공간·전력·선택적 API 요금을 따로 계산하며, 개인 챗봇 구독이 API 사용권이나 크레딧을 제공한다고 가정하지 않는다.

살펴볼 점
  • 실물 연결·펌웨어 변경·녹음·STT/TTS 실행·한국어 인식·음악 재생·지연·비용 시험 없음. 공식 문서 열람만 수행했다.
  • 로컬 처리 예제의 공개 명령에는 모델 파일명·언어 및 음성 설명이 일관되지 않은 부분이 있어 명령을 그대로 복사하지 말고 사용 모델·경로·언어를 확인한다. 이 카드에는 실행 명령을 재배포하지 않는다.
  • 하드웨어 호환성·코드 라이선스·펌웨어 배포권·STT/LLM/TTS 가중치 및 음성 모델 이용권은 별개다. 이번에는 개별 라이선스 전문을 확인하지 않았으므로 전체 구성을 상업 이용 가능한 오픈소스로 단정하지 않는다.
  • 학생 연령별 서비스 이용조건이나 교육용 승인 여부는 확인하지 않았다. 학생·주변인의 음성 입력은 기관 기준, 적법한 동의·거부 대안, 최소 수집·보관·삭제를 먼저 설계한다. 로컬 처리만으로 녹음 동의가 대체되지 않는다.
  • 제조사 문서를 독립 요약·링크하며 문서·사진·코드 전재나 재배포 허가를 주장하지 않는다. 국내 판매가·총구매비·보증·세금은 확인하지 않았다.
