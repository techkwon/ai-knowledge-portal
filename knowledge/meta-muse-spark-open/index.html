Meta Muse Spark Open: 816B(42B 활성) 오픈 웨이트 멀티모달 모델

Meta가 공개한 816B 파라미터(42B 활성) 네이티브 멀티모달 오픈 웨이트 모델로, 1M 토큰 문맥과 코딩·에이전트 작업에 최적화되어 있으며 Apple M5 Ultra Mac Studio 2대로 로컬 구동이 가능하도록 MLX에 맞춰졌다.

#Meta#Muse#오픈 웨이트#MLX#Apple Silicon

무엇을 할 수 있나요?

Meta 공식 리서치 블로그(research.meta.ai)에 따르면 Muse Spark Open은 816B 총 파라미터(42B 활성)의 네이티브 멀티모달 모델로, 1M 토큰 문맥 창을 지원하며 장기 과제·복잡한 소프트웨어 엔지니어링·다단계 추론에 맞춰 개발되었습니다.

공식 발표에 따르면 Apple M5 Ultra Mac Studio 2대(유니파이드 메모리로 최대 1TB)를 MLX 프레임워크로 묶어 데스크톱에서 구동할 수 있는 동급 최초의 모델이라고 소개합니다. SGLang, vLLM, TensorRT-LLM, Hugging Face Transformers, llama.cpp, Unsloth 등 주요 추론 엔진도 지원합니다.

Hugging Face 공식 컬렉션(meta-models/muse-spark-open)에 BF16 전체 가중치와 NVFP4 양자화 가중치 두 가지 형태로 공개되어 있습니다. 라이선스는 제한적 상업 조건이 포함된 Muse Model License입니다.

Meta는 코딩 에이전트 Muse Code와 결합한 온디바이스 에이전틱 워크플로(오픈소스 iOS 앱 빌드, 영상 편집 자동화 등) 예시를 공식 블로그에서 시연했으며, Meta Superintelligence Scaling Framework 기준 안전성 평가를 완료했다고 밝혔습니다.

살펴볼 점
  • 이 글은 Meta 공식 리서치 블로그와 Hugging Face 공식 모델 카드 기준 정리이며, 직접 설치하거나 성능을 실측하지 않았습니다.
  • Muse Model License는 일반 오픈소스 라이선스가 아니라 제한적 상업 조건이 포함되어 있으므로 상업적 활용 전 원문 라이선스를 직접 확인해야 합니다. 두 대의 Mac Studio(M5 Ultra)처럼 상당한 하드웨어가 필요합니다.
