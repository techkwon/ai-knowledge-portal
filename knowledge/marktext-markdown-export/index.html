MarkText Markdown 편집·내보내기

AI가 생성한 Markdown 초안을 실시간 미리보기로 정리하고 HTML·PDF로 내보내는 오픈소스 편집기

#Markdown#오픈소스#PDF#문서 검토

무엇을 할 수 있나요?

공식 저장소는 실시간 미리보기와 CommonMark·GitHub Flavored Markdown 지원, 일부 Pandoc Markdown 지원을 안내합니다. 수식 표현과 front matter도 다룹니다.

소스 코드·타자기·집중 모드를 선택해 AI가 만든 초안의 구조와 문장을 검토하고 HTML 또는 PDF로 내보낼 수 있습니다. 클립보드 이미지 붙여넣기도 지원합니다.

Linux·macOS·Windows 배포를 제공하며 MIT 라이선스입니다. 설치 파일은 운영체제와 CPU 아키텍처에 맞춰 공식 릴리스에서 선택하세요.

살펴볼 점
  • 자체 AI 생성 기능을 소개하는 카드가 아니라 Markdown 후처리 도구입니다.
  • Markdown 방언과 확장 기능의 호환성이 동일하지 않으므로 수식·표·이미지가 포함된 문서는 내보낸 결과를 확인하세요. 설치 및 렌더링 실측은 하지 않았습니다.
