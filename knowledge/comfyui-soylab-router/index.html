ComfyUI SOYLAB Comfy Router: Comfy Router API 연동 노드

개인 Comfy API 키로 Comfy Router의 이미지·영상·오디오 모델 154개를 호출하는 로컬 ComfyUI 커스텀 노드

#ComfyUI#Comfy Router#모델 라우팅#한국어 문서

무엇을 할 수 있나요?

공식 README(한국어 포함 4개 언어 제공)에 따르면 이 노드는 개인 Comfy API 키로 Comfy Router를 호출하는 로컬 ComfyUI 커스텀 노드로, 모델과 실행 공급자(Comfy 기본 경로 또는 fal·higgsfield·runware·wavespeed 등 대체 경로)를 따로 선택할 수 있습니다. Router 공식 목록의 이미지·영상·오디오 모델 154개를 등록했다고 설명합니다.

ComfyUI Registry에 버전 1.0.1로 정식 발행됐으며, Git 클론 또는 ChatGPT 데스크톱 앱에 설치 문장을 입력하는 방식으로 설치할 수 있습니다. Comfy 개발자 플랫폼에서 API 키를 발급해 노드에 입력하거나 별도 API KEY.INI 파일에 저장하며, 이 파일은 Git에서 제외되어 워크플로 공유 시 키가 노출되지 않는다고 안내합니다.

노드 상단에 예상 비용 확인 창을 제공하며, 공급자마다 가격 산정 기준이 다르다는 점(공개 파트너 노드 가격표 추정치, 실제 청구는 Router가 제공하는 사용 크레딧 헤더 기준)을 README가 스스로 구분해 설명합니다.

살펴볼 점
  • V3 DynamicCombo·Autogrow를 지원하는 최신 ComfyUI가 필요하며, 유료 API 호출이므로 실행 전 예상 비용을 확인해야 합니다. 상단에 표시되는 가격은 참고용 추정치이고 실제 청구액을 보장하지 않는다고 공식 문서가 명시합니다.
  • 전 모델·조합을 유료 생성으로 검증한 것은 아니라고 README가 밝히고 있어, 공급자별 실제 제한이나 요금은 사용 중 직접 확인이 필요합니다. 설치·실행은 이번에 직접 테스트하지 않았습니다.
