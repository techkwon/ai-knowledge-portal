Rakazo: 기억·예약·컴퓨터를 갖춘 AI 동료를 직접 호스팅하기

지속적인 대화·메모리·반복 작업을 가진 봇을 Docker 기반으로 운영하고, 웹·데스크톱·모바일 클라이언트에서 접속하는 베타 오픈소스 에이전트 플랫폼.

#Docker#MCP#반복 작업#승인 흐름

무엇을 할 수 있나요?

제작자 README는 봇별 대화·메모리·루틴·작업 이력, 다른 봇이나 일시적 하위 에이전트로의 위임, 브라우저·터미널·파일·화면 접근을 지원한다고 설명한다. 여러 봇이 공유하는 Team Computer와 분리된 Private Computer를 구분하며, 모델 자격증명과 컴퓨터 제공자를 선택하도록 설계돼 있다.

공개 이미지 설치에는 Docker Engine, Compose 플러그인, curl, OpenSSL이 필요하다. 공식 설치 스크립트가 Compose 파일을 받고 임의의 비밀값을 담은 환경 파일과 서비스를 준비한다. 앱을 설치했다고 백엔드가 필요 없어지는 것은 아니며, 서버에서 계속 실행해야 봇의 반복 작업도 지속된다.

로컬 Docker 컴퓨터 외에 여러 클라우드 실행 환경, MCP·OpenAPI 및 외부 앱 연동을 안내한다. 웹, Electron 데스크톱, iOS·Android 클라이언트는 같은 Rakazo API에 연결한다. 코드는 Apache-2.0이며 현재 베타로 안내한다.

살펴볼 점
  • 브라우저·파일·쉘·화면을 조작하는 에이전트다. 설치 스크립트를 검토하고 로그인·비밀키·파일 접근을 최소화하세요. 로컬 호스팅이라고 모델 제공자나 외부 연동까지 로컬 처리되는 것은 아니다.
  • 공개 서버에는 HTTPS와 호스트 보안 구성이 필요하다. 선택한 모델·음성·클라우드 샌드박스 및 연동 서비스의 비용과 약관은 소프트웨어 라이선스와 별개다. 원격 실행 환경의 네트워크·자격증명 범위를 확인하세요.
  • 공식 저장소 본문 기준 정리이며 설치·상시 운영·권한 격리·성능을 직접 검증하지 않았습니다.
