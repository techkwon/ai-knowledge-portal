FineDNA: DNA·텍스트 모델의 3단계 학습 데이터와 재현 조건

Carbon-X의 중간학습·SFT·RL 자료를 묶은 연구용 데이터셋. 혼합비와 실제 학습량, 상류 라이선스, 평가 누출 제거와 개인정보 비식별의 차이를 함께 확인할 수 있다.

#FineDNA#Carbon-X#DNA#공개 데이터#재현성#라이선스

무엇을 할 수 있나요?

모델이나 건강상담 서비스가 아니라 Qwen3-14B 기반 Carbon-X의 중간학습, 지도 미세조정, 강화학습에 쓰인 자료 묶음이다. mid_*는 23개 원천별 config, sft_mix는 203,923 대화, rl_mix는 98,433행이다.

중간학습 데이터의 추정 고유 토큰은 514.30B지만 발표된 run은 302B를 소비했다. DNA 55%, 생물학 텍스트 15%, 영어 20%, instruction 10%의 혼합비에 따라 일부 자료는 반복하고 일부만 읽었다. 전체 공개량과 실제 학습량은 다르다.

재현에는 Carbon-X 토크나이저, 동일한 단계별 시작 체크포인트, config 혼합비, SFT의 chat_template_kwargs, RL seed 0의 행 순서와 보상함수, 학습환경을 맞춰야 한다. 공개 recipe는 초기 DNA 임베딩 freeze 단계의 데이터 chunking이 발표 당시와 동일하지 않고 동등한 대체라고 밝힌다.

FineDNA 데이터카드는 Apache 2.0을 선언하고 연결 코드 저장소의 실제 LICENSE도 Apache 2.0이다. 그러나 상류 GENERator 카드의 MIT, OpenGenome2의 Apache 2.0, FineWeb-Edu·DCLM·FinePDFs-Edu의 ODC-By, Nemotron v3의 CC BY 4.0 및 ODC-By 등 원천 조건은 별도로 유지된다. 이는 전체 데이터 권리 심사를 끝냈다는 뜻이 아니다.

중간학습 config는 약 950GB이며 카드가 streaming을 안내한다. 공개 중간학습 recipe는 Python 3.12 및 Megatron 계열·Transformer Engine, 사용한 NeMo 환경을 설명하고 32노드×8GPU 설정을 제시한다. 학생용 가벼운 웹도구가 아니라 연구 인프라용 자료다.

연결 Carbon-X의 발표 평균 66.7은 서로 다른 5개 DNA benchmark 지표의 평균이다. thinking off, temperature 0.6, top-p 0.95, top-k 20, 문제당 1회 생성이라는 조건의 발행자 결과이며 FineDNA의 데이터 정확도나 모든 과학 질문의 정답률이 아니다.

데이터의 DNA overlap·text n-gram·homology 제거는 평가 누출 방지다. 개인식별정보 비식별과 같지 않으며 읽은 카드에는 FineDNA 전 행의 독립 개인정보 감사나 완전 비식별 보장이 없다. 일부 문헌·웹·실제 사용자 채팅 계열 자료 및 Gemini 합성 설명을 포함하므로 출처와 라벨을 따로 검토해야 한다.

살펴볼 점
  • 설치·추론·학습·대용량 데이터 다운로드는 수행하지 않았다. 성능과 실행 가능성은 직접 재현한 결과가 아니다.
  • FineDNA 루트의 별도 LICENSE 파일은 확인되지 않았다. 데이터 라이선스는 카드상 선언, 코드 라이선스는 실제 LICENSE 확인으로 구분한다. 모든 PubMed·bioRxiv·Biostars 문서와 SFT/RL 원천의 개별 이용조건을 전수 심사하지 않았다.
  • 비식별·동의·재배포 적법성을 보장하지 않는다. 개인·학생·환자의 서열을 공개 API나 데모에 올리지 말고 제공자별 처리정책과 권한을 먼저 확인한다.
  • Carbon-X는 임상 검증되지 않았고 의료결정에 쓰면 안 된다고 카드에 명시한다. 이 자료를 의학 효능·진단 성능으로 소개하지 않는다.
  • 서열 계수·좌표·편집은 코드로 독립 검산해야 하며 생성한 서열 기능·근거 설명도 사실로 단정하지 않는다. 합성 설명이나 code-checked reward가 전체 생물학적 설명의 정확성을 보장하지 않는다.
  • 연결 원천 GENERator-v2 논문은 접근 제한으로 읽지 못했고 별도 Carbon-X 기술논문 본문은 이번에 확인하지 않았다. 발표 카드·공개 코드와 recipe에 근거한 자료 검토다.
