RGB MoCap: 일반 영상을 편집 가능한 3D 애니메이션으로 바꾸는 윈도우 앱

영상만으로 모션캡처를 하고 Mixamo/VRM/PMX 캐릭터에 리타게팅까지 해주는 무료 오픈소스 Windows 앱으로, 여러 공개 모션 추정 모델(ExMR·FlowHMR·GVHMR) 중 하나를 골라 쓸 수 있다

#모션캡처#리타게팅#Windows#MIT

무엇을 할 수 있나요?

핵심 기능: 영상을 입력하면 사람(들)의 3D 바디 메시와 애니메이션 본을 복원하고, 발/손 미끄러짐을 줄이는 접촉 보정, Mixamo FBX·VRM·PMX 휴머노이드 캐릭터로의 모션 리타게팅, FBX/VMD(MMD용) 내보내기를 지원한다.

사용 절차: (1) Model Manager에서 쓸 AI 모델(ExMR/FlowHMR/GVHMR 중 선택, 일부는 가입·라이선스 동의 필요)을 준비 → (2) 영상을 열고 복원할 사람을 골라 "Reconstruct 3D" 실행 → (3) 결과를 검토하며 접촉 보정 적용 → (4) FBX로 내보내거나 캐릭터를 불러와 리타게팅 후 내보낸다.

설치 요구사항: 64비트 Windows, 호환 NVIDIA GPU/드라이버, OpenGL 4.3이 필요하고, 앱+모든 AI 런타임+Blender+전체 모델 파일을 위해 약 45GB의 디스크 공간을 요구한다. 영상·프로젝트·캐시 등은 별도 공간이 추가로 필요하다.

지원 모델 비교: ExMR(SMPL-X, 손가락 포함), FlowHMR(SMPL-H, 손가락 포함), GVHMR(SMPL-X, 손가락은 추가 HandFlow 애드온 필요) 세 가지 중 선택 가능하며 각각 원본 프로젝트가 따로 있다.

살펴볼 점
  • 직접 설치·실행 테스트는 하지 않았으며 공식 README·사용자 가이드의 설명을 전달한다.
  • 코어 코드는 MIT지만 AI 모델·Blender·FFmpeg 등은 각자의 라이선스를 따른다. 특히 선택 가능한 FlowHMR 가중치는 비상업 교육·연구·비영리 목적 전용이며, 앱의 MIT 라이선스가 이 제한을 없애지 않는다. SMPL 계열 등은 별도 가입·동의가 필요할 수 있으므로 사용 모델별 조건을 확인해야 한다.
  • NVIDIA GPU 전용이며 Mac/Linux 지원 언급은 없다.
