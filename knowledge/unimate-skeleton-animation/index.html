UniMate: 임의 스켈레톤을 위한 통합 모션 생성 모델

사람·동물·사물 등 서로 다른 뼈대 구조를 가진 캐릭터에 텍스트 설명만으로 모션을 생성하는 SIGGRAPH Asia 2026 모델

#UniMate#SIGGRAPH Asia#Flow matching#모션 생성

무엇을 할 수 있나요?

Hugging Face 공식 모델 카드(SIGGRAPH Asia 2026)는 UniMate를 텍스트 조건 flow-matching 모델로 설명합니다. 동물·휴머노이드·리깅된 사물 등 임의 토폴로지의 스켈레톤에 대해 60프레임(2초) 모션을 생성합니다.

Mixamo(22조인트)·Truebones(동물 73종)·UniML3D 범용 체크포인트가 구분되어 제공되며, 공식 코드 저장소(github.com/Friedrich-M/UniMate)의 안내대로 모델 다운로드 후 `unimate.inference.sample`로 텍스트 프롬프트를 넣어 GLB/FBX 메시에 모션을 입힙니다.

프롬프트 확장, 인베트위닝, 조인트 편집 등 추가 기능은 코드 저장소 README에서 다룹니다.

살펴볼 점
  • 공식 카드는 접지(contact) 모델이 없어 접지가 중요한 동작에서 미끄러짐·관통이 생길 수 있다고 명시합니다. 발 고정이나 IK 후처리가 필요할 수 있습니다.
  • Truebones ZOO 학습 데이터의 상업 게임 자산 유래 의혹이 제3자로부터 제기되었으나 모델 제작자는 이를 검증하지 않았다고 밝혔습니다. Truebones 학습 모델의 데이터 출처는 불확실한 상태로 다루세요.
  • 학습 데이터(Mixamo, Objaverse-XL)는 각자의 라이선스를 따르며 일부는 비상업적 조건입니다. 실제 설치·생성 테스트는 하지 않았습니다.
