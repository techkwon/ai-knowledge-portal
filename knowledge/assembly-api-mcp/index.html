국회 API MCP (공공데이터 에이전트 연동)

대한민국 국회 공공데이터를 MCP(Model Context Protocol) 형태로 다루는 오픈소스 프로젝트

#MCP#공공데이터#국회 API

무엇을 할 수 있나요?

국회 관련 공공데이터를 MCP 형식으로 노출해 에이전트가 직접 조회·활용할 수 있게 만든 프로젝트입니다.

공공데이터 기반 에이전트나 서비스를 설계할 때 참고 사례로 유용합니다.

살펴볼 점
  • 공공데이터 API의 이용 약관과 호출 제한을 별도로 확인해야 합니다.
