Higgs TTS 3: 음성 연출과 콘텐츠·서비스 라이선스 구분

한국어를 포함한 다국어 음성 합성과 인라인 감정·속도·쉼 제어를 지원하는 Boson AI 모델. 창작물 공개와 모델 서비스 제공의 권한을 구분해야 합니다.

#TTS#Higgs TTS 3#보이스 클로닝#라이선스

무엇을 할 수 있나요?

제작자 모델 카드는 약 4B 백본, 24kHz 출력, 한국어를 포함한 100개 이상 언어, 참조 음성을 이용한 제로샷 음성 복제를 안내합니다. 성능 수치는 제작자 평가이며 직접 검증하지 않았습니다.

감정·스타일·속도·피치 등 발화 전체 제어는 입력 앞에, 쉼·효과음은 필요한 위치에 배치합니다. 효과음 태그 뒤에는 대응하는 의성어가 필요합니다.

모델 라이선스는 연구·비상업용 source-available이며 오픈소스 라이선스가 아니라고 명시합니다. 별도 Creator Use Grant는 자기 채널의 영상·팟캐스트 등 창작물에 수익화까지 허용하되 Boson AI의 Higgs Audio임을 오디오나 눈에 띄는 설명에 표시해야 합니다.

창작물 제작 예외는 모델 API·SaaS·앱 제공, 제품 내장, 모델·파생물의 재판매·배포 권한까지 주지 않습니다. 이런 용도는 별도 상업 계약 검토가 필요합니다.

로컬 경로는 SGLang-Omni 또는 vLLM-Omni, 호스팅 경로는 Boson API입니다. 호스팅 API는 별도 키와 크레딧이 필요하며 모델 다운로드와 무료 API 이용은 같은 의미가 아닙니다.

살펴볼 점
  • 실행·음성 청취·품질 비교·미세조정 직접 테스트 없음. 특정 언어의 끝음절 잘림 개선이나 LoRA 학습 횟수는 확인하지 않았습니다.
  • 모델 카드의 H100 처리량 측정은 최소 장비 요건이나 일반 PC/Mac 성능 보장이 아닙니다. 최소 VRAM과 Apple Silicon 지원은 이번 범위에서 미확인입니다.
  • 음성 복제는 실존 인물의 명시적·검증 가능한 동의와 참조 녹음 권리가 필요합니다. 공개 합성 음성은 법령상 요구되거나 오인 가능성이 있으면 합성임을 밝혀야 합니다.
  • 개인 ChatGPT·Claude 구독과 Boson API는 별개입니다. 학생 직접 이용 가능 연령은 이번에 확인하지 않았으며 모델 라이선스는 계약 체결 가능한 연령을 요구합니다. 학생 대상 서비스·기관 운영이 자동 허용된다고 해석하지 마세요.
