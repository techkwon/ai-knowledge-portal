fold-agent: 확인 게이트와 사람 개입을 갖춘 안드로이드 화면 조작 에이전트

접근성 트리·온디바이스 음성 인식·LLM 도구 루프로 폰 앱을 조작하고, 되돌릴 수 없는 동작은 코드 규칙으로 확인받는 MIT 프로젝트

#fold-agent#Android#접근성 서비스#Human-in-the-loop#Claude Code

무엇을 할 수 있나요?

fold-agent는 음성이나 글 요청을 받아 안드로이드 접근성 트리를 읽고, LLM 도구 루프가 탭·입력·스크롤·스와이프를 수행하는 Claude Code 스타일의 휴대폰 에이전트입니다. 공개 저장소는 Android 11 이상을 대상으로 하며 Galaxy Z Fold8·One UI 9에서 확인됐습니다.

안전 경계는 모델의 말이 아니라 코드로 둡니다. 발송·결제·삭제 같은 되돌릴 수 없는 동작과 일정·메일 등 쓰기 도구는 실행 직전에 확인을 요구하고, 40초 동안 응답이 없으면 거부합니다.

같은 화면을 반복하거나 진척이 없으면 본 내용·가설·다음 전략을 다시 세우며, 사용자가 중간에 직접 조작한 뒤 현재 화면에서 에이전트에게 다시 넘길 수 있습니다. 비밀번호 칸 입력은 개입 기록에 남기지 않는다고 설명합니다.

선택형 홈 서버 계약은 캘린더·메일·메모, 정책 기반 스킬 실행, 장시간 작업, 헤드리스 Claude Code 위임을 추가합니다. 다만 실제 홈 서버는 공개하지 않고 계약 문서와 목 서버만 제공합니다.

살펴볼 점
  • 접근성 서비스는 화면 읽기와 대신 조작이라는 강한 권한을 요구합니다. 저장소의 dev.sh와 권한 목록을 검토하고 시험용 기기·계정에서 먼저 확인하세요.
  • 제작자가 확인한 기기는 한 대뿐이고 공개본 재빌드와 자동화 테스트가 거의 없다고 명시합니다. 금융·보안 앱, 빈약한 접근성 트리, 종량제 LLM 비용에서도 한계가 있습니다.
