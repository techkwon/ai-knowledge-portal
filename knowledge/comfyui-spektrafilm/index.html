ComfyUI-Spektrafilm: 분석 필름 공정을 스펙트럼 단위로 시뮬레이션하는 노드팩

필름·인화지 제조사 데이터시트 기반 스펙트럼 시뮬레이션으로 노출·인화·스캔 전 과정을 재현하는 ComfyUI용 오픈소스 필름 룩 도구

#ComfyUI#필름 시뮬레이션#색보정#오픈소스

무엇을 할 수 있나요?

공식 README: 입력 이미지를 가상 필름 네거티브에 노출시키고, 컬러 인화기를 거쳐 인화지에 프린트한 뒤 스캔하는 과정을 스펙트럼 단위로 시뮬레이션합니다. 필름 스톡·인화지·커플러·그레인·할레이션·인화기 필터 값은 제조사 데이터시트를 바탕으로 만들어졌다고 설명하며, 20개 필름 스톡과 8개 인화지 프리셋을 제공합니다. 색 과학 자체는 Andrea Volpato의 오픈소스 spektrafilm 라이브러리를 그대로 쓰고 이 노드팩은 ComfyUI 프론트엔드 역할만 한다고 명시합니다.

메인 노드는 필름 시뮬레이션(필름/프린트 출력, 노출 보정 등)과 실시간 미리보기(3D LUT를 구워 WebGL로 약 0.2초 내 갱신)로 구성되고, 카메라·할레이션·커플러·그레인·스캐너 등 세부 파라미터는 별도 노드로 체인에 연결합니다. RAW 파일 디모자이킹, 16/32비트 고정밀 입출력(EXR/TIFF)도 지원합니다.

설치는 ComfyUI Manager 또는 git clone + pip install로 가능하며, 모든 연산은 CPU(numpy/scipy/numba)에서 실행돼 특별한 GPU 요구사항이 없다고 설명합니다. 그레인·할레이션 등 공간 효과를 포함한 전체 연산은 12MP 이미지 기준 8코어 CPU에서 약 1분이 걸린다고 안내합니다.

살펴볼 점
  • 제작자 README의 자체 설명이며 독립 재현 테스트나 직접 실행 검증은 하지 않았습니다.
  • 핵심 색 과학 라이브러리(spektrafilm)는 별도 개발자가 만든 업스트림 프로젝트로, 이 노드팩은 그 결과를 ComfyUI에 노출하는 래퍼입니다. 라이선스는 노드팩 자체가 GPL-3.0, 필름 프로필은 CC BY-SA 4.0, LUT는 전용 라이선스(상업적 사용·무료 공유 허용, 재판매 금지)로 각각 다르게 적용됩니다.
  • 모든 연산이 CPU 기반이라 고해상도·연속 프레임(영상) 처리 시 속도가 느릴 수 있습니다.
