ComfyUI-Spektrafilm: 아날로그 필름 공정의 스펙트럼 시뮬레이션

제조사 데이터시트 기반 필름·인화지 프로필로 노출·인화·스캔을 시뮬레이션하는 ComfyUI 래퍼. 코드와 프로필·파생 LUT의 라이선스, 완성 이미지의 조건을 구분해야 한다.

#ComfyUI#필름 시뮬레이션#색보정#오픈소스

무엇을 할 수 있나요?

README는 이미지를 가상 네거티브에 노출하고 컬러 인화기를 거쳐 인화지에 프린트한 뒤 스캔하는 과정을 시뮬레이션한다고 설명한다. 제조사 데이터시트를 바탕으로 한 20개 필름·8개 인화지 프리셋을 소개하며, 색 과학은 Andrea Volpato의 spektrafilm 런타임을 감싼 래퍼임을 명시한다.

노출·필름·인화지·그레인·할레이션·카메라·스캐너 등을 노드로 연결한다. RAW 디모자이킹과 고정밀 EXR·TIFF·PNG 입출력을 안내한다. 백엔드 연산은 numpy/scipy/numba 기반 CPU이며, 제작자의 12MP 약 1분 수치는 8 CPU 스레드 환경의 보고이지 독립 측정이 아니다.

라이브 미리보기는 백엔드가 33³ 3D LUT를 만들고 브라우저가 WebGL로 적용하는 별도 경로다. 약 0.2초 갱신은 제작사 설명이며, 그레인·할레이션·블러 같은 공간 효과를 포함한 전체 시뮬레이션과 같지 않다. 최초 실행 후 입력이 필요하고, 공간 효과 미리보기는 640px 백엔드 렌더로 더 느릴 수 있다.

살펴볼 점
  • 직접 설치·사진 처리·속도·색 정확도 시험은 하지 않았다. 실제 필름의 물리적 측정과 완전히 같다는 보증으로 제시하지 않는다.
  • 코드는 GPL-3.0으로 안내된다. 동봉 SPEKTRAFILM_LICENSE.txt(v1.1)는 프로필과 직접 파생 LUT를 CC BY-SA 4.0으로 설명하며, 배포·수정 시 저자·출처·라이선스·변경 고지와 동일조건 공유를 요구한다.
  • README의 LUT 재판매 금지 요약과 실제 동봉 문서의 설명이 다르다. 문서는 CC BY-SA가 유료 LUT팩 재판매를 기술적으로 허용한다고 밝히며, 재판매·상업 AI 학습 자제는 법적 요건이 아닌 제작자의 추가 요청으로 구분한다. 요청과 법적 금지를 섞지 말고 실제 사용·배포 시 최신 동봉 조건을 확인한다.
  • 문서는 색보정한 완성 영화·사진 자체에 동일조건 공개 의무가 자동 적용되지는 않는다고 설명한다. 이는 프로필·LUT 파일의 재배포와 다른 문제이며 원본 촬영물의 권리는 별도다.
  • 전체 시뮬레이션은 CPU 중심이지만 브라우저 미리보기에는 WebGL을 쓴다. 노드는 축소 입력 이미지를 캐시하고 ComfyUI HTTP 경로로 제공하므로, 공유 서버·외부 노출·보관 설정을 확인한다.
