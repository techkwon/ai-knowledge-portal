datapitfalls: 데이터 분석·차트의 함정을 점검하는 MCP와 스캐너

질문 설정부터 수집·변환·분석·시각화·해석까지 점검하는 데이터 검토 도구. 규칙을 제공하는 MCP와 Claude API로 검사하는 CLI·웹 스캐너는 동작·비용·전송 범위가 다르다.

#데이터 검증#차트#SQL#루브릭

무엇을 할 수 있나요?

Ben Jones가 자신의 책 Avoiding Data Pitfalls의 분류 체계를 소프트웨어로 옮긴 프로젝트다. 차트 축뿐 아니라 누락값 제거, 잘못된 JOIN, 생존자 편향, 상관과 인과의 혼동처럼 분석 과정의 문제를 검토한다. 완성 차트가 깔끔하다는 사실과 분석이 타당하다는 판단을 구분할 때 참고할 수 있다.

MCP 서버는 get_checklist, get_pitfall, list_pitfalls, search_pitfalls 등으로 규칙을 제공하고, 연결된 Claude가 그 규칙을 사용해 판단한다. 제작자 README에 따르면 MCP 자체는 읽기 전용이며 네트워크 호출이나 별도 Anthropic API 키가 필요 없다. Claude Code 등록 예시는 claude mcp add datapitfalls -- npx -y datapitfalls mcp다.

반면 CLI·검사 엔진은 Claude API 키를 사용한다. npx datapitfalls scan ./chart.png 또는 SQL 파일·분석 설명을 넣는 방식이며 Node.js 18 이상이 필요하다. 웹 스캐너는 PDF·Word·PowerPoint 등의 문서와 여러 차트를 받는다. 입력에서 확인된 문제와 추가 데이터 검토가 필요한 잠재적 문제를 구분해 사람이 원자료를 재확인하는 보조 수단으로 쓰세요.

살펴볼 점
  • 코드(engine·CLI·MCP·웹)는 MIT지만 현행 검사 규칙과 텍스트는 CC BY-NC 4.0이다. 제작자는 업무에서 규칙을 쓰는 것은 무료라고 설명하되 유료 제품·강좌에 규칙을 포함하거나 판매할 때는 별도 허가가 필요하다고 안내한다. 과거 0.11.0까지의 규칙 배포본과 현행 조건을 혼동하지 마세요.
  • 웹 스캐너 입력은 Claude API로 전송된다. MCP 서버 자체가 통신하지 않는다는 설명이 연결된 AI 서비스까지 오프라인이라는 뜻은 아니다. 학생·고객·업무 기밀을 넣기 전에 사용 경로와 데이터 정책을 확인하세요.
  • 규칙을 만족했다고 통계적 정확성이나 인과관계가 증명되지는 않는다. 공식 제작자 문서 확인 기준이며 설치·검사·성능 실측은 하지 않았습니다.
