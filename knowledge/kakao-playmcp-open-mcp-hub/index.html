카카오 PlayMCP: 설치 없이 쓰는 국내 MCP 허브 플랫폼

카카오 공식 플랫폼으로, 카카오 계정 로그인만으로 다양한 MCP 서버를 체험·도구함에 담아 ChatGPT·Claude·OpenClaw 등 외부 AI에 연결할 수 있습니다.

#MCP#카카오#도구 연결#한국 서비스

무엇을 할 수 있나요?

카카오 공식 사이트와 카카오corp 보도자료에 따르면 PlayMCP는 2025년 8월 베타 오픈한 'MCP(Model Context Protocol) 기반 개방형 플랫폼'으로, 로컬 설치나 JSON 설정 파일 편집 없이 웹 브라우저에서 카카오 계정으로 로그인만 하면 다양한 MCP 서버를 바로 체험할 수 있습니다. 2026년 7월 기준 외부 개발자가 등록한 MCP 서버가 약 200개 이상이며, 일일 호출이 8만 건을 넘는다고 보도됐습니다.

핵심 기능은 세 가지입니다: ①사이트 내 채팅창에서 선택한 MCP를 바로 테스트하는 플레이그라운드, ②2025년 11월 추가된 '도구함' 기능으로 여러 MCP를 모아 한 번의 계정 인증으로 사용, ③개발자가 자신의 원격(remote) MCP 서버를 등록·배포하는 기능(로컬 stdio 방식은 미지원). 도구함에 담은 도구는 Claude, ChatGPT, OpenClaw 등 외부 AI 서비스에 URL 하나로 연결해 그대로 사용할 수 있습니다.

카카오톡 나와의 채팅방, 톡캘린더, 카카오맵, 멜론, 선물하기 등 카카오 자체 서비스뿐 아니라 사람인(채용 정보), 한국 주식 정보, 아파트 정보, 법제처 판례 검색 등 외부 개발자가 만든 국내 서비스 특화 MCP도 다수 등록되어 있습니다.

살펴볼 점
  • 원격(remote) MCP만 지원하며 로컬 파일이나 사내 시스템을 다루는 stdio 방식 MCP는 등록·사용할 수 없습니다. 민감한 로컬 데이터 작업에는 적합하지 않습니다.
  • 카카오 계정 인증이 필요하고, 외부 AI 서비스에서 PlayMCP 도구함에 접근할 때 해당 서비스가 어떤 데이터에 접근하는지 연결 전에 확인해야 합니다. Claude Code는 카카오 계정 인증을 직접 지원하지 않아 claude.ai에서 먼저 연결 후 플러그인으로 불러와야 합니다.
