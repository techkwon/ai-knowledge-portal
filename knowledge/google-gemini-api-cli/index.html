Gemini API CLI: 기존 에이전트에서 Gemini API 호출하기

Google의 실험적 gemini-api 바이너리로 다른 코딩 에이전트나 쉘 스크립트에서 모델·미디어·관리형 에이전트 API를 호출한다. 대화형 Gemini CLI와 별개다.

#Gemini API#CLI#쉘 자동화#멀티모달#Google

무엇을 할 수 있나요?

Google 공식 gemini-api는 macOS·Linux·Windows용 단일 Go 바이너리다. 기존 Codex·Claude Code·Hermes 같은 호스트 에이전트가 명령행에서 Gemini API 기능을 사용하도록 연결한다. 독립적인 대화형 코딩 에이전트 Gemini CLI(gemini 명령)와 구분한다.

공식 README는 운영체제별 설치 스크립트, Go install, 사전 빌드 바이너리를 안내한다. Gemini API 키를 구성한 뒤 generate, analyze, image, tts, video, agent 등의 명령을 쓸 수 있으며 --help, --schema, --dry-run으로 호출 내용을 살펴볼 수 있다.

Apache-2.0은 CLI 소프트웨어 라이선스다. API 호출은 모델·기능별 무료 한도/유료 요금과 계정 권한이 적용된다. 공식 Gemini API 지역 목록에는 한국이 있다.

살펴볼 점
  • beta라 명령과 API가 달라질 수 있다. 설치 스크립트와 에이전트의 쉘·파일·네트워크 권한을 검토하고 API 키를 노출하지 마세요.
  • Gemini CLI의 개인 계정 무료 사용량을 이 CLI의 무료 보장으로 혼동하지 마세요. 모델별 비용과 기능 가용성을 호출 전에 공식 가격표·계정에서 확인하세요.
  • 공식 문서 본문 확인 기준이며 직접 설치·API 호출·성능 검증은 하지 않았습니다. 소개 페이지 자체는 웹 읽기에서 본문이 비어 공식 저장소와 문서로 교차 확인했습니다.
