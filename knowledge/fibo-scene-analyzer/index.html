FIBO Scene Analyzer: 구조화된 장면 이해 모델

이미지 캡션·객체 탐지·세그멘테이션·키포인트·OCR·프롬프트 확장을 하나의 장면 기술(scene description) 형식으로 처리하는 Bria의 비전-언어 모델

#FIBO#Bria#Scene description#OCR#Qwen3.6

무엇을 할 수 있나요?

Hugging Face 공식 모델 카드는 FIBO Scene Analyzer를 Qwen3.6-35B-A3B 기반으로 다단계 SFT와 GRPO 강화학습을 거쳐 만든 이미지 이해 모델로 설명합니다. 이미지 전체의 일반 설명부터 객체별 바운딩박스·마스크·관계·텍스트(OCR)까지 하나의 장면 기술 스키마로 출력합니다.

지원 작업은 caption(캡션), detect/mask/keypoints(탐지·마스크·키포인트), ocr, describe(특정 객체 설명), expand(짧은 프롬프트를 장면 기술로 확장), refine/edit(기존 장면 기술 수정)입니다. 상세도는 general/short/long/full/full_mask 5단계로 조절합니다.

실행은 Transformers, vLLM, OpenAI 호환 서버(vllm serve) 세 가지 하네스를 제공하며 bfloat16 기준 약 70GB GPU 메모리가 필요하다고 공식 문서에 명시되어 있습니다.

살펴볼 점
  • 대형 모델(36B 파라미터)로 로컬 구동에는 상당한 GPU 자원이 필요합니다. 실제 설치·추론 테스트는 하지 않았습니다.
  • 키포인트·마스크 등 세부 기하 정보의 실사용 정확도는 공식 예시 외 별도 검증이 필요합니다.
