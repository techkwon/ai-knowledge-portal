OXR: 문서를 Markdown·JSON으로 파싱하는 공개 가중치 모델

레이아웃 분석과 문자·읽기순서 인식을 나누는 문서 파서. 자체 호스팅과 무료 외부 API의 데이터 처리·라이선스 조건을 구분해야 한다.

#OCR#문서파싱#로컬AI#개인정보

무엇을 할 수 있나요?

OXR는 SoMark 제작팀이 공개한 문서 파싱 모델이다. PDF와 문서 이미지를 Markdown 또는 JSON으로 바꾸며 표·수식·코드 등 문서 요소, 좌표와 읽기 순서를 함께 다룬다. 레이아웃 분석 모델을 별도로 두고 교체할 수 있게 설계했으며, 파싱 모델은 내용 인식과 읽기 순서를 담당한다.

공식 권장 로컬 구성은 Linux·NVIDIA BF16 GPU·CUDA13.0 호환 드라이버와 vLLM 기반이다. 낮은 동시성 시험은 단일 GPU24GB부터, 긴 문서·높은 동시성은48GB 이상을 권장한다. 준비 순서는 코드·가중치 확보, 레이아웃/인식 서비스 및 파싱 API 구성, PDF·이미지 입력, 원본과 출력·좌표·읽기순서 대조다. 이는 문서에서 확인한 절차로 실제 설치하거나 실행하지 않았다.

예를 들어 여러 종류의 서류에서 표와 본문을 먼저 구조화한 뒤, 필요한 날짜·항목을 후속 추출 단계에서 정리할 수 있다. 다만 OXR 자체는 지정된 필드 구조로 금액·ID 등을 직접 추출하거나 페이지를 넘는 표를 병합하지 않는다. 문서 파싱과 업무 필드 매핑을 같은 정확도 보장으로 보지 말아야 한다.

언어 학습은 중국어·영어 중심이고 제작자는 CJK·서구 언어에서도 작동할 것으로 안내하지만 언어별 평가를 제공하지 않는다. 따라서 한국어를 완전 미지원이라 단정할 수도, 한국어 업무 정확도를 보장할 수도 없다. 촬영 문서·필기·복잡한 양식은 대표 샘플을 원본과 대조할 계획을 세우는 것이 좋다.

자체 호스팅은 환경 준비 후 파싱 중 외부 서비스 호출 없이 실행할 수 있다고 FAQ가 안내한다. 반대로 무료 온라인 API에 보낸 데이터는 모델 개선에 사용된다고 FAQ에 명시되어 있다. 기밀·학생·고객 자료를 무료 API에 보내도 되는 서비스로 소개하지 않는다.

살펴볼 점
  • 직접 테스트하지 않았음. 모델 속도·한국어 인식률·개별 업무 정확도를 재현하지 않았고 성능 순위는 채택 근거로 사용하지 않았다.
  • 표준 Apache2.0 단독이 아니라 추가 조건이 있는 OXR Open Source License다. 본인·관계사 합산 투자 또는 연매출이 각각 미화200만 달러를 초과하면 내부 사용도 별도 서면 상용 라이선스가 필요하다. 개인 사용·비상업 연구·평가·교육은 해당 규모 조항 예외다.
  • 별도 상용 라이선스 없이 제3자에게 제품·서비스·결과를 제공하면 Powered by SoMark OXR 문구와 공식 저장소 링크를 눈에 띄게 표시해야 한다. 재배포 시 추가 조건과 Apache2.0을 동봉하며 제3자 구성요소는 각 라이선스가 적용된다.
  • 무료 API는 운영 안정성을 보증하지 않으며 제작자는 운영환경 사용을 권하지 않는다. 무료 API 입력의 학습 활용 조건에 특히 주의한다.
  • CPU·Mac 경로는 FAQ상 가능하나 느리거나 추가 설정이 필요하며 Ollama와 GGUF/ONNX는 공식 제공·지원 경로가 아니다.
