Intelligent Terminal (Windows Terminal 포크)

Microsoft가 공개한, 네이티브 에이전트 통합 기능이 추가된 Windows Terminal 포크

#Microsoft#터미널#에이전트 통합

무엇을 할 수 있나요?

터미널 작업 흐름에 에이전트를 네이티브로 통합해 지원하는 Windows Terminal 기반 프로젝트입니다.

살펴볼 점
  • Windows 환경 전용 기능일 수 있어 macOS/Linux 사용자는 대체 도구 확인이 필요합니다.
