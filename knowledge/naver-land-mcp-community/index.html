Naver Land MCP: 비공식 부동산 조회

아파트 매물·시세·실거래가와 관심 단지의 변화를 자연어로 조회하는 커뮤니티 MCP 서버

#부동산#비공식 API#조회 자동화

무엇을 할 수 있나요?

지역·가격 범위별 매물 검색, 단지 상세 정보, 평형별 시세와 최근 실거래가, 관심 단지의 스냅샷 비교 등 여섯 도구를 제공합니다.

저장소를 내려받고 uv run으로 server.py를 실행하는 형태입니다. MCP 설정의 --directory는 실제 설치 폴더의 절대 경로로 바꿔야 합니다.

개인 학습용으로 지역과 가격 조건을 좁혀 조회하고, 결과의 기준 시점과 매물 정보는 원 서비스에서 다시 확인하세요.

살펴볼 점
  • 네이버 공식 서비스가 아니라 비공식 내부 API를 사용하는 프로젝트입니다. API 구조·차단 정책과 저장소 공개 여부가 예고 없이 바뀔 수 있습니다.
  • 제작자는 약관 충돌 가능성과 상업적 이용 위험을 고지합니다. 차단·중단 요청을 받으면 사용을 중단하고 요청 간 최소 0.5초 지연을 줄이지 마세요.
  • 코드의 MIT 라이선스가 원 데이터의 이용 권리나 정확성을 보장하지 않습니다. 투자 판단이나 대량 수집의 근거로 단독 사용하지 마세요.
