TypeSafe Jev 실습 코드 모음: 라우터부터 CCTV 상태 판단까지

토큰을 생성하지 않고 확률을 내는 판단 모델 Jev를 Claude Code·Codex·OpenClaw에 붙여 라우팅 비용 계산, 악플 탐지 비교, CCTV 영상 상태 판단까지 직접 돌려보는 공개 실습 코드

#실무 가이드#커뮤니티 인사이트

무엇을 할 수 있나요?

공식 저장소 설명에 따르면 이 실습 코드는 TypeSafe의 구조화 출력 모델 Jev를 OpenRouter로 직접 호출해보고, 일반 LLM과 Jev로 악플 댓글 100~471건을 비교하는 사이트(RouteLab)까지 포함합니다. 모든 수치는 저자가 2026-09-23에 직접 돌려본 값이라고 명시합니다.

2강에서는 메시지 라우터를 완성본까지 만들어 40건 채점·비용 계산을 해보고, OpenClaw 플러그인·Codex 전처리·Claude Code 스킬 훅 형태로 각 에이전트별 라우터 3종을 따로 제공합니다. 3강은 Jev와 비슷한 프로젝트(로컬 decider 서버, API vs 로컬 채점)를 다루며 Colab 노트북도 함께 제공합니다.

특강으로 추가된 4강은 동영상을 입력으로 받는 공개 판단 모델 OneJev로 CAVIAR CCTV 클립 13개를 '쓰러짐·다툼·물건 방치' 여부로 판단해보는 실습이며, Colab에서 바로 열어볼 수 있는 노트북(04_CCTV상태판단.ipynb)으로 제공됩니다.

TypeSafe API 키가 없어도 저장된 Jev 응답을 재생하거나 3강의 로컬 서버 주소로 바꿔서 실습할 수 있다고 안내하며, 모든 코드는 비공식 교육용 예제이고 TypeSafe·Jev·Claude Code·Codex·OpenClaw는 각 회사 제품이라고 명시합니다.

살펴볼 점
  • 악플 탐지 실습에 쓰는 데이터셋(korean-hate-speech, CC BY-SA 4.0)에는 실제 악성 댓글 원문이 포함되어 있다고 저장소가 직접 경고합니다.
  • 비공식 교육 자료이며 슬라이드·전체 실측 기록은 유료 강의 수강생 배포본에만 있어 이 저장소만으로는 강의 내용 전체를 재현할 수 없습니다. TypeSafe 신규 가입이 한동안 제한됐던 시기가 있었다고 안내하므로 API 키 발급 가능 여부는 별도 확인이 필요합니다.
