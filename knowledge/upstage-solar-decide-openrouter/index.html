Solar Decide: 512K 문맥에서 선택·점수·예/아니오를 반환하는 판단 모델

Solar Mini 4 기반 System One 엔드포인트로 긴 문서를 상태로 넣고 생성 문장 대신 구조화된 결정과 확률을 한 번의 순전파로 반환

#Upstage#Solar Decide#OpenRouter#System One#구조화 판단

무엇을 할 수 있나요?

Solar Decide는 Upstage의 Solar Mini 4를 기반으로 한 구조화 판단 모델입니다. 상태(state)와 형식이 지정된 질문을 보내면 자유 문장 대신 선택, 점수, 예/아니오와 모델 확률을 반환합니다.

OpenRouter 설명 기준 512K급 문맥을 지원해 긴 문서 전체를 상태로 넣는 분류·라우팅·정책 검사에 사용할 수 있습니다. 출력 문장을 생성하지 않아 출력 토큰 요금은 0으로 표시됩니다.

Jev와 같은 `/v1/systemone` 스키마를 사용하므로 생성형 답변이 필요하지 않은 1차 판정 단계를 기존 System One 파이프라인에서 교체·비교하기 쉽습니다.

적용 절차: 실제 한국어 업무 문서로 선택 정확도와 확률 보정을 측정하고, 오판 비용에 따라 자동 처리·사람 검토·차단 임계값을 따로 정한 뒤 점진적으로 자동화합니다.

살펴볼 점
  • OpenRouter의 현재 가격에는 기간 한정 50% 할인이 표시되어 있어 기본 단가로 고정해 기록하면 안 됩니다. 컨텍스트 길이, 가격, 지연 시간은 최신 모델 페이지를 확인하세요.
  • 모델이 주는 확률은 업무별 신뢰도를 자동으로 보장하지 않습니다. 카드 작성 시점에 독립 벤치마크나 사용자 데이터 보정은 수행하지 않았습니다.
