herdr web ui / Ovis: 현재 연결 대상과 공식 모바일 구분하기

기존 저장소 URL의 현재 README는 Ovis를 소개합니다. 과거 웹 클라이언트 소개, 현재 제작자 안내, Herdr 공식 모바일의 서버를 구분해야 합니다.

#herdr#Claude Code#Codex#원격 관리#PWA

무엇을 할 수 있나요?

이 카드의 기존 저장소 URL을 이번에 읽으면 현재 Ovis README가 반환됩니다. 제작자는 Ovis를 herdr 위에 구축한 도구로 소개하고 기존 herdr/Herdr 앱과 나란히 쓸 수 있다고 설명합니다. 리다이렉트 관측만으로 공식 개명 이력이나 안전한 자동 이관이 확인된 것은 아닙니다.

따라서 과거 herdr web ui의 설치·접속 안내와 현재 README를 버전별로 비교해야 합니다. 기존 설치가 자동으로 호환되거나 마이그레이션된다고 보장하지 않으며, 실제 설치·업데이트는 수행하지 않았습니다.

Herdr 공식 모바일은 별도 제품 경로입니다. 공식 문서는 herdr-core에 SSH로 연결하고 Herdr TUI와는 서버가 달라 TUI의 에이전트가 보이지 않는다고 명시합니다. 원격 접속에는 SSH/VPN 도달성과 적절한 장치 권한이 필요합니다.

Ovis README의 기본 활성 익명 사용량 집계와 Herdr 공식 모바일의 자체 분석 없음, 데스크톱의 기본 익명 보고·피드백 전송 설명은 제품별로 구분해야 합니다. 한 제품의 설정을 모든 Herdr 도구에 공통 적용한다고 해석하지 않습니다.

살펴볼 점
  • 현재 제작자 README와 공식 모바일·프라이버시 문서를 읽은 정정입니다. 공식 개명 날짜·이관 이력, 기존 사용자 설치의 호환·보안성, 개별 앱스토어 약관은 검증하지 않았습니다.
  • Ovis 코드의 MIT 조건과 연결 서비스·운영체제·모델 이용권은 별개입니다. 재배포 시 저작권·허가 고지 등 조건을 확인해야 합니다.
  • SSH와 터미널 제어는 실제 파일·계정·에이전트 승인 권한에 영향을 줍니다. 공식 배포처·서버 종류·접근 범위를 확인하고 신뢰한 네트워크에서만 노출하세요. 직접 설치·연결·실행하지 않았습니다.
