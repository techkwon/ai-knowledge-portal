herdr web ui: 여러 PC의 Claude Code·Codex 세션을 휴대폰에서 이어 보기

herdr 플러그인으로 동작하는 오픈소스 웹·PWA 클라이언트로, 실행 중인 코딩 에이전트 세션을 채팅과 터미널로 보고 승인 요청에 응답하며 SSH로 등록한 여러 PC를 한 사이드바에서 관리합니다.

#herdr#Claude Code#Codex#원격 관리#PWA

무엇을 할 수 있나요?

README에 따르면 herdr web ui는 herdr가 관리하는 에이전트 세션에 붙는 브라우저·휴대폰 클라이언트입니다. 같은 세션을 채팅 형태로 읽고 답하며, 필요할 때 실제 터미널을 열 수 있습니다. 지원 대상으로 Claude Code, Codex 등의 기록 형식을 명시합니다.

승인·질문·계획 메뉴를 카드로 바꿔 현재 상태인지 확인한 뒤 응답을 보내고, 입력이 필요하거나 작업이 끝나면 푸시 알림을 줍니다. 에이전트가 만든 파일을 열거나 내려받고, SSH로 Linux·macOS·Windows PC를 추가해 한 사이드바에서 볼 수 있습니다.

Linux·macOS는 설치 스크립트가 herdr·Bun·Node 선행 조건과 플러그인을 설치하고, Windows는 PowerShell 스크립트를 제공합니다. 서버는 기본적으로 127.0.0.1에서만 열리며, 휴대폰 접속은 Tailscale 주소와 QR 코드를 쓰는 방식을 안내합니다.

일반 SSH 클라이언트와의 차이: 여러 서버에 셸·파일 전송으로 접속하는 범용 원격 접속 도구와 달리, 이 도구는 에이전트 세션의 작업 상태와 승인 대기를 관제하는 데 초점이 있습니다.

살펴볼 점
  • 원격 접속을 열면 휴대폰에서 에이전트 승인과 터미널 입력이 가능해집니다. README의 접근·안전 문서를 따라 신뢰한 네트워크 안에서만 노출하세요.
  • 설치 스크립트를 파이프로 바로 실행하기 전에 내용을 확인하는 것이 안전합니다.
