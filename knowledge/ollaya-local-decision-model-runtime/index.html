Ollaya: 여러 공개 판단 모델을 로컬 System One API로 실행하는 런타임

Laya·Winnow·NLI·Qwen3Guard·CLM 등을 내려받아 CPU·GPU에서 실행하고 TypeSafe 호환 판단 API로 제공하는 Apache-2.0 로컬 도구

#Ollaya#System One#판단 모델#로컬 AI#TypeSafe

무엇을 할 수 있나요?

Ollaya는 생성형 문장을 쓰지 않고 선택·점수·예/아니오와 확률을 반환하는 공개 판단 모델을 로컬에서 내려받고 실행하는 Apache-2.0 런타임입니다. 명령 구조와 로컬 데몬 경험은 Ollama와 비슷하지만 별도 독립 프로젝트입니다.

Laya, Winnow, Decider, NLI, GLiClass, Qwen3Guard, CLM 등 서로 다른 모델 계열을 지원합니다. 모델 가중치는 각 제작자의 Hugging Face 저장소에서 고정 커밋으로 받고 SHA-256을 확인하며, Ollaya는 작은 변환 그래프와 매니페스트만 제공합니다.

TypeSafe의 `/v1/systemone` 응답 형식과 호환돼 기존 SDK는 기본 URL만 로컬 서버로 바꿔 쓸 수 있습니다. 자체 `/api/decide`와 MCP 서버도 제공해 분류·라우팅·정책 검사를 에이전트 도구로 연결할 수 있습니다.

CPU와 NVIDIA CUDA를 지원하고, GGUF 계열은 llama.cpp를 통해 Apple silicon Metal도 사용할 수 있습니다. 실제 도입 전에는 업무 데이터로 정확도와 확률 보정을 재측정하고 자동 처리·사람 검토 임계값을 나눠야 합니다.

살펴볼 점
  • Ollaya는 Ollama나 TypeSafe가 만들거나 보증한 제품이 아닙니다. 모델마다 라이선스, 언어 성능, 하드웨어 요구량과 보정 방식이 다릅니다.
  • 프로젝트가 제시한 정확도·지연 시간은 특정 벤치마크와 하드웨어의 자체 측정입니다. 로컬 실행은 외부 전송을 줄일 수 있지만 접근 통제, 로그, 디스크의 모델·입력 데이터 보안은 사용자가 관리해야 합니다.
