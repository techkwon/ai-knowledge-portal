Ming-3.0-tts: 다국어 음성 합성과 스타일 제어

한국어를 포함한 다국어 음성 합성, 참조 음성 복제와 자연어 스타일 지시를 제공하는 TTS 프로젝트

#TTS#음성 합성#한국어

무엇을 할 수 있나요?

프로젝트는 0.5B dense 계열과 별도 tiny MoE 계열을 구분합니다. 공식 0.5B 카드에는 한국어·영어·중국어 등 언어, 참조 음성, Voice Design과 감정·속도·음높이 제어가 안내됩니다.

각 기능은 별도 task 모드와 입력 조건을 사용합니다. 한국어 등은 MULTILINGUAL에서 language_id를 지정하며, FREEFORM을 음성 설계·감정·방언·속성 제어와 임의로 결합할 수 있는 것은 아닙니다. 다중 화자 대화는 프로젝트에서 tiny 전용으로 구분합니다.

체크포인트만으로 독립 실행되는 패키지가 아니라 공식 GitHub 추론 코드와 의존성이 필요합니다. 공식 모델 카드와 저장소는 MIT 라이선스를 명시합니다.

살펴볼 점
  • 0.5B는 backbone 기준 설명이며 전체 구성요소의 메모리 요구량과 같지 않습니다. 최소 VRAM·Mac 지원·처리 속도는 별도로 확인하세요.
  • 식별 가능한 사람의 목소리는 허락을 받고 사용하세요. 다국어 발음·고유명사·수치는 직접 청취 검수하고 합성임을 알리는 방식이 적절합니다.
  • 공식 문서 확인 기준이며 설치·실행·성능을 직접 시험하지 않았습니다.
