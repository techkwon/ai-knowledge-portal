NVIDIA Sol-H3: DGX Spark 한 대에서 768p 5초 영상을 56초에 생성

MiniMax-H3 초안과 LTX-2.5 정제를 결합해 단일 DGX Spark의 통합 메모리에 상주시킨 NVIDIA Research의 2단계 영상 추론 파이프라인

#NVIDIA#Sol-H3#DGX Spark#MiniMax-H3#LTX-2.5

무엇을 할 수 있나요?

NVIDIA Research의 Sol-H3 Spark 공개 자료는 단일 DGX Spark에서 5초 길이 1344×768 영상을 요청부터 재생 가능한 결과까지 56초에 생성했다고 보고합니다. 먼저 MiniMax-H3로 저해상도 초안을 만들고 LTX-2.5로 768p 정제하는 2단계 구조입니다.

핵심은 두 모델 전체를 그대로 올리지 않는 것입니다. NVFP4·FP8 양자화, H3 잠재표현을 LTX 공간으로 직접 옮기는 VAE Adapter, 정제 단계의 공통 프롬프트 캐시로 중복 구성요소와 중간 디코드·재인코드를 줄입니다.

Sol-Attn은 질의 블록마다 필요한 키·값 블록을 실행 중 선택하고, 선택한 블록은 정확한 어텐션으로 처리하면서 건너뛴 부분은 요약 K/V로 보정합니다. 별도 라우팅 맵을 만들지 않는 한 번의 online-softmax 경로를 지향합니다.

활용 관점: 소형 통합 메모리 장비에 여러 영상 단계를 상주시켜야 할 때 양자화만이 아니라 잠재공간 전달, 조건 캐시, 커널·입출력 융합을 함께 설계한 사례로 볼 수 있습니다.

살펴볼 점
  • 56초 수치는 DGX Spark, 지정 모델·해상도·5초 클립과 프로젝트 측 실행 조건의 결과입니다. 다른 GPU나 프롬프트, 길이, 품질 설정으로 일반화하면 안 됩니다.
  • 프로젝트 페이지 확인이며 이 환경에서 모델을 내려받아 실행하거나 결과 품질을 독립 측정하지 않았습니다.
