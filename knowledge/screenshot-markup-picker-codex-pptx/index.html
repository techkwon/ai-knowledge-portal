ScreenshotMarkupPicker: 캡처 설명과 편집형 PPTX

여러 캡처에 마크업과 설명을 배치하고 Codex로 설명 초안을 보조받아 편집 가능한 PowerPoint로 내보내는 앱

#스크린샷#Codex#PPTX#마크업

무엇을 할 수 있나요?

이미지 추가·붙여넣기·화면 캡처 뒤 박스·화살표·번호·글상자를 배치하고, 이미지 옆이나 아래 또는 격자로 자동 배치할 수 있습니다. 사용 절차를 캡처한 안내 자료를 만드는 흐름입니다.

설명은 직접 작성하거나 Codex 초안 생성·문장 다듬기를 이용할 수 있습니다. 생성 버튼은 컴퓨터에 설치하고 로그인한 Codex CLI를 사용하며 앱에 별도 API 키를 입력하는 방식이 아닙니다.

한 페이지를 한 슬라이드로 출력하며 원본 이미지는 이미지, 추가한 마크업은 별도 PowerPoint 개체로 보존합니다. 프로젝트 폴더·ZIP 저장도 지원합니다.

AI 설명 생성 없이도 직접 설명 입력·마크업·배치·PPTX 출력을 사용할 수 있습니다. AI로 작성한 설명은 실제 화면과 대조해 확인한 뒤 공유하세요.

살펴볼 점
  • Codex 생성 버튼을 누르면 선택한 이미지 원본·마크업 미리보기·설명이 Codex로 전달됩니다. 학생·계정·기관 정보를 가린 자료로 작업하세요.
  • 확인한 배포 안내는 Windows 10/11 x64와 Apple Silicon macOS용입니다. Windows는 코드 서명 미적용, Mac은 Apple 공증 미완료로 안내되므로 배포 출처와 무결성을 먼저 확인하세요.
  • 전체 소스는 비공개이고 공개 저장소는 배포와 사용 안내용입니다. PowerPoint에서 수정한 내용을 앱 프로젝트로 역반영하지는 못합니다. 이 카드는 문서 확인이며 실행 검증은 아닙니다.
