FlowHMR: 영상에서 물리적으로 그럴듯한 3D 모션캡처 추출

영상 속 사람의 동작을 3D 모션으로 복원하는 연구 모델. 코드와 가중치를 공개했지만 코드는 Apache 2.0, 가중치는 비상업 교육·연구·비영리 목적 전용 라이선스로 구분

#모션캡처#3D 휴먼 모션#GRPO#코드 Apache 2.0

무엇을 할 수 있나요?

기능: 사람 탐지(YOLOX)→카메라 추정(VGGT-Omega)→신체 특징 추출(SAM 3D Body)→FlowHMR 순서로 영상을 처리해 3D 모션을 `.npz`로 저장하며, 별도 FBX 내보내기 구성 시 `.fbx`도 지원한다. V2M 환경과 필요한 자산을 설치한 뒤 웹 데모 서버를 직접 실행하면 브라우저에서 영상을 올려 복원할 수 있다. 가입 없이 바로 쓰는 공개 호스팅 데모가 확인됐다는 뜻은 아니다.

모델 종류: `flowhmr_base`(0.46B, Wild-4K 벤치마크 추적 성공률 78.79%)와, 물리 시뮬레이터 PHC+의 보상을 이용한 GRPO 후처리를 추가한 `flowhmr_latest`(같은 0.46B, 82.47%, 공식 추천)가 Hugging Face에 공개돼 있다.

설치 난이도: V2M은 NVIDIA/CUDA 환경에서 Python 3.10·PyTorch 2.5.1(cu118)로 테스트됐다. Python·PyTorch만 설치하면 끝나는 것은 아니며 YOLOX와 체크포인트·신체 모델 등 추가 의존성이 필요하다. GRPO 후처리 학습은 별도의 Linux용 Isaac Gym 환경(Python 3.8·PyTorch 1.13)을 사용하고 두 환경이 파일로 통신한다. SMPL 계열·VGGT-Omega·SAM 3D Body 등은 가입·라이선스 동의나 접근 승인이 필요한 자산이다.

라이선스: 소스 코드는 Apache License 2.0이지만 `flowhmr_base`와 `flowhmr_latest` 가중치는 별도의 FlowHMR Model Weights License로 비상업 교육·연구·비영리 목적에 한정된다. 코드의 Apache 2.0만 보고 가중치까지 상업적으로 자유롭게 사용할 수 있다고 해석하지 말 것.

살펴볼 점
  • 직접 설치·추론을 실행해 본 것은 아니며 공식 README의 설명을 그대로 전달한다. 벤치마크 수치(78.79%/82.47%)는 제작자가 자체 Wild-4K 평가 세트로 측정한 결과다.
  • 학습 데이터(사용자가 직접 준비해야 함)와 평가 세트(Wild-4K, 4182개 클립의 ID 목록만 공개, 영상 자체는 비공개) 성격이 다르다는 점에 주의.
  • 체계적인 설정이 필요한 전체 파이프라인(모션캡처 앱 등)에서는 FlowHMR이 선택 가능한 모델 중 하나로 쓰이는 경우가 있다.
  • 공식 설치 예제는 A100 40GB에서 기본 카메라 추정 옵션 사용 시 약 30GB GPU 메모리 피크를 보고하며, 더 작은 GPU용 옵션도 안내한다. 모든 영상·설정의 고정 최소 VRAM이나 직접 실측 결과는 아니다.
