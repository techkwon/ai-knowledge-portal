FlowHMR: 영상에서 물리적으로 그럴듯한 3D 모션캡처 추출

영상 속 사람의 동작을 3D 휴먼 모션으로 복원하는 오픈소스 모델로, 물리 시뮬레이터(PHC+) 보상을 이용한 GRPO 후처리 학습으로 추적 성공률을 끌어올린 연구 코드·가중치 공개

#모션캡처#3D 휴먼 모션#GRPO#Apache 2.0

무엇을 할 수 있나요?

기능: 영상을 입력하면 사람 탐지(YOLOX)→카메라 추정(VGGT-Omega)→신체 특징 추출(SAM 3D Body)→FlowHMR 순서로 파이프라인을 거쳐 3D 모션을 `.npz`(FBX 내보내기 설치 시 `.fbx`도) 형식으로 저장한다. 웹 데모로 브라우저에서 영상을 올려 바로 복원해볼 수도 있다.

모델 종류: `flowhmr_base`(0.46B, Wild-4K 벤치마크 추적 성공률 78.79%)와, 물리 시뮬레이터 PHC+의 보상을 이용한 GRPO 후처리를 추가한 `flowhmr_latest`(같은 0.46B, 82.47%, 공식 추천)가 Hugging Face에 공개돼 있다.

설치 난이도: 기본(V2M) 구성은 Python 3.10 + PyTorch 2.5.1이면 추론·웹데모·베이스 학습이 가능하지만, GRPO 후처리 학습을 하려면 별도의 Isaac Gym 환경(Python 3.8 + PyTorch 1.13)이 추가로 필요해 두 환경을 파일로 통신시켜야 한다. SMPL 계열 신체 모델 등 일부 구성 요소는 라이선스 동의나 가입이 필요한 게이트 자산이다.

라이선스: 소스 코드는 Apache License 2.0이지만, 모델 가중치는 별도 모델 카드에 명시된 라이선스를 따른다.

살펴볼 점
  • 직접 설치·추론을 실행해 본 것은 아니며 공식 README의 설명을 그대로 전달한다. 벤치마크 수치(78.79%/82.47%)는 제작자가 자체 Wild-4K 평가 세트로 측정한 결과다.
  • 학습 데이터(사용자가 직접 준비해야 함)와 평가 세트(Wild-4K, 4182개 클립의 ID 목록만 공개, 영상 자체는 비공개) 성격이 다르다는 점에 주의.
  • 체계적인 설정이 필요한 전체 파이프라인(모션캡처 앱 등)에서는 FlowHMR이 선택 가능한 모델 중 하나로 쓰이는 경우가 있다.
