Malkuth: 한국어 중심 다국어 판단(분류) 모델

텍스트를 생성하지 않고 선택지·예/아니오·단계형 확률만 반환하는 한국어 중심 경량 분류 모델(4B·2B), Kev 프레임워크로 서빙

#분류#판단 모델#한국어#오픈 웨이트#커뮤니티 인사이트

무엇을 할 수 있나요?

Malkuth는 문장을 생성하는 대신 고정된 선택지에 대한 확률을 반환하는 다국어 판단 모델로, 한국어에 중점을 두고 만들어졌습니다. 공식 README에 따르면 choice(최대 255개 선택지 중 하나), noul(예/아니오), score(순서 있는 단계) 세 가지 질문 유형을 지원하며, 하나의 요청에 같은 입력에 대해 여러 독립적인 질문을 함께 보낼 수 있습니다.

Malkuth-4B(Qwen3.5-4B-Base 기반)와 Malkuth-2B(Qwen3.8-2B-Distill 기반) 두 크기가 있으며 Kev 프레임워크로 사후학습·서빙됩니다. Kev와 uv를 설치한 뒤 `uv run --extra serve python -m kev.serve --run dhtocks/malkuth-4b --port 8009` 명령으로 로컬에 띄우고, `/v1/systemone` 엔드포인트에 상태(state)와 질문(questions)을 JSON으로 보내 선택·확률을 받는 구조입니다.

공식 README는 29개 평가 스위트·약 12만9천 문항 기준 정확도·Brier 점수 표를 공개하며, 이 중 9개는 학습에 쓰이지 않은 held-out 세트입니다. 코드는 Apache-2.0이지만 가중치는 연구용으로만 배포되고, 학습 데이터 일부(XNLI 등)는 비상업적 라이선스이므로 상업적 사용 전 라이선스 조건을 직접 확인해야 합니다.

살펴볼 점
  • README에 공개된 정확도·Brier·지연시간 수치는 제작자가 자체 측정한 벤치마크이며, TypeSafe Jev API 등 타사 모델과의 비교치도 같은 문서 내 자체 평가입니다. 독립된 제3자 재현 검증은 별도로 확인해야 합니다.
  • 가중치는 연구 목적(research use only) 라이선스이며 학습 데이터 일부는 비상업적 조건입니다. 상업적 서비스에 적용하려면 각 데이터셋 라이선스와 모델 카드 조건을 직접 확인해야 합니다. 설치·구동 테스트는 이번에 직접 수행하지 않았습니다.
