OpenDots: 자체 컴퓨터를 가진 상시 AI 동료를 직접 호스팅하는 오픈소스 템플릿

CopilotKit이 MIT 라이선스로 공개한 템플릿으로, 역할별 Dot·문서 공간·통화·Slack·승인 카드·Dot별 격리 컴퓨터를 자기 인프라에서 구성합니다. 호스팅 제품이 아니라 직접 실행·설정하는 출발점입니다.

#OpenDots#CopilotKit#AG-UI#상시 에이전트#셀프호스팅

무엇을 할 수 있나요?

README는 OpenDots를 텍스트·통화·Slack을 오가며 일하는 지속형 AI 동료를 만드는 오픈소스 템플릿으로 설명합니다. 이름·역할 지침·허용 도구를 정한 전문 Dot을 만들고, Space라는 문서 공간에 결과를 저장합니다.

구조는 AG-UI가 메시지·도구 호출·에이전트 상태를 화면과 연결하고, CopilotKit 런타임과 Threads, Channels SDK(Slack), TanStack AI(OpenAI 호환 모델 공급자)를 조합하는 방식입니다. 저장 전 승인·거절 카드를 띄우는 사람 검토 흐름이 포함되어 있습니다.

Dot마다 OpenBot 기반의 별도 컴퓨터(브라우저 프로필, 파일, 셸)를 붙이고 Dot별로 브라우저·파일·셸 권한을 나눌 수 있습니다. 시작은 Node.js 24에서 저장소를 복제하고 `npm ci`, `.env` 설정, `npm run dev` 순서입니다.

살펴볼 점
  • README 스스로 초기 개발 단계이며 단일 소유자용 출발점이라고 밝힙니다. 공유 편집·초대·파일 업로드는 포함되지 않고, Slack과 음성 위임 등 일부 기능은 연결 서비스 검증이 남아 있다고 적혀 있습니다.
  • 기본 웹 조사 도구는 질의·URL·조사 목적을 외부 검색 서비스로 보냅니다. 민감한 내용이 조사 목적에 섞이지 않게 설정을 확인하세요.
