FLUX.3 Image Klein: 5.6B 이미지 모델과 전용 프롬프트 업샘플러(FLUX Kommunity License)

Black Forest Labs의 5.6B 이미지 생성·편집 모델로, 짧은 요청을 상세 장면 캡션으로 확장해주는 별도의 9B 프롬프트 업샘플러(PUP)와 함께 쓰도록 설계됨. 이미지 모델은 FLUX Kommunity License(비상업용+제한적 상업 예외), PUP과 별도 텍스트 인코더는 Apache 2.0

#FLUX#Black Forest Labs#이미지 생성#Hugging Face

무엇을 할 수 있나요?

Black Forest Labs의 공식 Hugging Face 모델 카드에 따르면 FLUX.3 Image Klein은 5.6B 규모 이미지 트랜스포머(파라미터 수는 이미지 트랜스포머 기준이며 텍스트 인코더는 별도)로, 텍스트-이미지 생성과 최대 10장 참조 이미지를 활용한 편집·합성을 하나의 모델로 처리하고, 0~1000 격자의 바운딩 박스로 요소 배치를 지정할 수 있습니다.

공식 카드는 '프롬프트 업샘플러 없이는 쓰지 말라'고 명시합니다. 짧은 프롬프트를 그대로 넣으면 범용적인 결과가 나오므로, 요청을 상세한 장면 캡션(매체·스타일·장면·조명·구도, 각 피사체의 색상·재질·위치)으로 확장해주는 별도의 9B 모델인 FLUX.3 Image Klein PUP(Qwen3.5-9B 파인튜닝)를 기본으로 함께 로드해 쓰도록 설계되어 있습니다. PUP은 이미지를 생성하지 않고 텍스트·참조 이미지를 받아 상세 프롬프트를 작성하는 9B 비전·언어 모델입니다.

라이선스가 구성 요소별로 다릅니다. 이미지 트랜스포머(base/메인/ComfyUI용)는 FLUX Kommunity License v1.0으로, 비상업적 사용과 라이선스 조건을 충족하는 상업적 출력물 생성 예외를 규정합니다. 예외는 본인·계열사 합산 연환산 총매출이 500만 달러 미만인 적격 사용자에게 적용되며 콘텐츠 필터 또는 출력물 검토 등 조건도 확인해야 합니다. PUP과 별도 Qwen3-VL-4B-Instruct 텍스트 인코더는 Apache License 2.0입니다.

배포 형태는 파인튜닝·LoRA·연구용 Base, 증류된 배포용 Klein(BF16/FP8/NVFP4 변형), ComfyUI용 변형, PUP까지 총 4종 저장소로 공개되어 있으며, 공식 Hugging Face Space 데모도 제공됩니다.

살펴볼 점
  • 이 글은 공식 Hugging Face 모델 카드 기준 정리이며, 실제 생성 품질이나 성능을 직접 테스트하지 않았습니다.
  • 이미지 트랜스포머는 오픈소스로 일반화할 수 없는 FLUX Kommunity License 대상이며, 상업적 활용 전 적격 사용자·매출 산정·출력물 생성 범위·안전 조치·금지 용도 등 원문 조건을 직접 확인해야 합니다. PUP 및 별도 텍스트 인코더의 Apache 2.0 라이선스와 구별해야 합니다.
