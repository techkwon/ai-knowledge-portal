Phone Autopilot: 승인한 휴대폰 작업을 체크포인트로 반복

Phone Harness 위에 루틴 저장·버전 승인·실패 기록을 더하는 별도 Hermes 플러그인

#Phone Autopilot#Hermes#Android#승인#체크포인트

무엇을 할 수 있나요?

제작자 README에서 Phone Harness를 선행 플러그인으로 요구하는 별도 저장소다. Phone Harness는 phone_exec로 실시간 조작하고, Phone Autopilot은 성공한 절차를 Python 루틴으로 저장해 모델 없이 재생한다.

Hermes Agent 0.21.6 이상과 Phone Harness 플러그인, adb 및 USB 디버깅 Android가 필요하다. 기반 도구의 iPhone 지원과 달리 이 플러그인은 Android를 기준으로 제작·시험됐다고 명시한다.

루틴 저장과 미승인 루틴 실행은 승인을 요구하며 수정된 버전은 재승인이 필요하다. 화면 전환 뒤 텍스트·앱·이미지 체크포인트가 실패하면 중단하고 스크린샷과 실행기록을 남긴다.

예약 실행 중에는 자동 수리하지 않는다. 수리는 승인 가능한 대화에서 다시 요청한다. ask_before_apps 설정을 켜야 앱별 사용 허가를 묻는다. 기본값은 모든 앱 허용이다.

살펴볼 점
  • 코드는 MIT: 저작권·허가문 유지 조건으로 수정·배포·상업적 이용이 가능하지만 보증은 없다. 별도 SaaS/모델/휴대폰 앱 약관까지 허용하는 라이선스가 아니다.
  • 모델이 쓴 Python이 컴퓨터 사용자 권한으로 실행되며 실제 폰 앱을 누른다. 앱 허용목록은 샌드박스가 아니므로 결제·전송·삭제 같은 작업은 별도 승인과 검토를 유지한다.
  • 실패 스크린샷·루틴·입력·실행로그에 사적 정보가 남을 수 있다. 외부 모델·클라우드폰의 데이터 처리와 비용은 별도다.
  • 직접 설치·연결·실행하지 않았다. 연령·지역별 앱/외부서비스 조건은 확인하지 않았으며 미성년자 이용 적합성을 보장하지 않는다.
