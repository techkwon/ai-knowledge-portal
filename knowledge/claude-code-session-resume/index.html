재부팅 뒤 Claude Code 작업 이어가기

대화 재개와 파일·프로세스 복구를 구분하고 마지막 작업 상태를 확인하는 세션 관리 가이드

#커뮤니티 인사이트#실무 가이드

무엇을 할 수 있나요?

핵심 원리: Claude Code는 대화를 로컬에 저장합니다. 같은 프로젝트 디렉터리에서 claude --continue로 가장 최근 세션을 이어가고, claude --resume으로 다른 세션을 선택할 수 있습니다. 실행 중에는 /resume을 사용합니다.

종료 전에는 수정 파일을 저장하고 현재 브랜치, 완료 항목, 미완료 항목, 마지막 검증 결과를 짧게 기록합니다. 중요한 변경은 별도 백업이나 검토된 Git 커밋으로 보존합니다.

재개 후 예시: “먼저 현재 파일과 Git 차이를 읽고 마지막 완료 단계와 다음 할 일을 정리해줘. 이미 실행한 배포나 전송은 반복하지 말고, 불확실한 상태는 확인부터 해줘.”

적용 조건: 로컬에 이전 대화가 남아 있는 Claude Code 환경을 위한 절차입니다. 대화가 없는 디렉터리에서는 --continue가 종료될 수 있으므로 올바른 프로젝트와 세션을 선택합니다.

살펴볼 점
  • 세션 재개는 종료된 서버·터미널 프로세스·저장하지 않은 파일의 복구를 보장하지 않습니다.
  • 다른 에이전트에도 같은 명령이 통한다고 가정하지 마세요. 이 카드에서는 설치나 재부팅 실험을 수행하지 않았습니다.
