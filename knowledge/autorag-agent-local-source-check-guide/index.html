AutoRAG Agent 2.0: 문서 검색과 원문 근거 확인

모델 없이 검색하는 Lite와 모델 기반 사서 에이전트를 구분하고 로컬 문서의 근거를 확인하는 활용 안내

#AutoRAG#MCP#원문 확인#로컬 검색

무엇을 할 수 있나요?

AutoRAG 저장소는 2.0의 문서 사서형 에이전트로 전환됐으며 기존 Python AutoML 도구는 legacy 디렉터리에서 유지됩니다. 두 계열의 설치법과 기능을 혼동하지 마세요.

Lite는 LLM 없이 로컬 문서를 색인하고 검색하며 MCP로 검색 결과를 외부 모델에 제공할 수 있습니다. 모델 기반 사서는 원문을 열어 근거를 확인하고 출처를 붙이는 흐름을 안내합니다.

검색 결과에 나온 주장을 원본 파일의 해당 부분과 대조하는 용도로 시작하세요. Node.js 24 이상 또는 Bun이 필요하며 2.0은 MIT, legacy는 Apache 2.0으로 라이선스가 다릅니다.

살펴볼 점
  • 원격 재정렬은 선택 기능이고 모델 기반 모드는 설정된 공급자를 호출할 수 있습니다. 모든 구성에서 데이터가 기기 밖으로 나가지 않는다고 단정하지 마세요.
  • 색인 산출물이 작업 폴더에 남으며 외부 커넥터는 별도 설정·권한이 필요합니다. 민감한 대화·학생 자료를 무단 색인하지 마세요.
  • 공식 문서 확인만 했으며 설치·색인·개인 문서 테스트는 실행하지 않았습니다.
