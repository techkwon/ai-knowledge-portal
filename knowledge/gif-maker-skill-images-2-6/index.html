gif-maker-skill: Claude Code/Codex로 반복 루프 GIF를 만드는 오픈소스 스킬

프롬프트나 참고 이미지로 반복 GIF 제작을 돕는 Claude Code/Codex 스킬. 제작자는 API 키가 있으면 GPT-Image-2.6 GIF 직접 출력, 키가 없으면 ChatGPT 구독·Codex CLI로 6칸 시트를 그려 합치는 경로를 안내한다.

#GIF#Claude Code#Codex CLI#GPT-Image-2.6#스프라이트시트

무엇을 할 수 있나요?

공식 README에 따르면 기본 경로(`--via auto`)는 `OPENAI_API_KEY` 존재 여부로 두 방식 중 하나를 고른다: 키가 있으면 GPT-Image-2.6 Flare/Sunburst의 GIF 출력을 직접 받고, 키가 없으면 ChatGPT 구독+Codex CLI로 움직임을 6칸 스프라이트시트 한 장에 그린 뒤 잘라 GIF로 합친다.

제작자가 2026-11-05 기준 실측했다고 밝힌 처리 시간은 키 있음(Flare 12~14초, Sunburst 24초, 512px 9프레임), 키 없음(시트 방식 23~60초), SVG 내보내기(49초, 키 필요)다.

키 없는 경로를 쓰는 이유로, 2026-11-05 기준 Codex CLI(0.165·0.166) 이미지 도구가 prompt·참고 이미지·투명 배경만 받고 GIF·SVG·품질·복잡도 옵션이 없다는 점을 명시한다.

설치는 `git clone`으로 Claude Code 스킬 폴더에 넣고 `pip install pillow`(ffmpeg는 --mp4 사용 시만 필요), 키 없는 경로는 Codex CLI 로그인이 필요하다. MIT 라이선스, 유튜버 '코난쌤'이 OpenAI Images 2.6 소개 영상 제작 과정에서 만든 스킬이다.

살펴볼 점
  • 처리시간은 제작자 1인의 환경·시점 기준이며, 독립 재현이나 OpenAI 공식 성능 수치가 아니다. README의 API 직접 출력 설명을 여기서 실행 검증하지 않았고, Codex CLI 버전에 따라 지원 옵션도 바뀔 수 있다.
  • GPT-Image-2.6 API를 쓰는 경로는 OpenAI API 키·요금이 별도로 발생한다. 민감한 캐릭터·인물 이미지를 입력할 때는 각 서비스의 이용정책을 따로 확인해야 한다.
  • 직접 설치·실행 테스트는 하지 않았다. 본 카드는 공식 저장소 README를 정리한 것이다.
  • 에이전트 스킬은 실행 코드와 지침을 포함한다. 전역 스킬 폴더에 설치하기 전에 SKILL.md·스크립트·외부 전송 경로를 검토하고, 민감하지 않은 이미지로 격리 시험한다. 원하는 루프 경계와 출력 품질도 결과물을 직접 확인해야 한다.
