CodeBoarding: AI 코드베이스 구조 시각화

정적 분석과 LLM 추론으로 코드 구조도와 컴포넌트 문서를 생성하는 개발 보조 도구

#아키텍처#Mermaid#코드 리뷰#정적 분석

무엇을 할 수 있나요?

코드베이스의 상위 구조도와 세부 컴포넌트 다이어그램을 생성하고 .codeboarding/에 Markdown 문서와 분석 결과를 저장합니다. Mermaid 출력은 문서나 코드 변경 검토에 활용할 수 있습니다.

Python 3.12 또는 3.13 환경에서 pipx install codeboarding --python python3.12로 CLI를 설치하고 codeboarding-setup 뒤 codeboarding full --local 경로로 전체 분석을 실행하는 방법을 안내합니다.

전체 분석 결과를 기준선으로 만든 다음 incremental 명령으로 변경 부분을 다시 분석하거나 partial 명령으로 특정 컴포넌트만 분석할 수 있습니다. 기존 analysis.json은 LLM을 다시 호출하지 않고 별도 렌더러로 문서화할 수 있습니다.

AI가 수정한 코드를 검토할 때 구조도와 실제 변경 파일을 대조해 의존 관계와 영향 범위를 확인하는 보조 자료로 활용하세요. 구조도만으로 코드의 정확성을 판정하지는 마세요.

살펴볼 점
  • 외부 LLM 제공자를 쓰면 분석 과정의 데이터 처리 조건과 API 비용을 확인해야 합니다. 로컬 저장소를 분석한다는 말이 모든 처리가 기기 안에서 끝난다는 뜻은 아닙니다. Ollama 등 로컬 제공자 설정도 지원합니다.
  • 사용량 텔레메트리는 기본 켜짐으로 안내됩니다. 조직 정책에 맞게 공식 TELEMETRY.md와 비활성화 환경변수를 확인하세요.
  • 증분 분석에는 기존 기준선이 필요합니다. 이 카드는 제작자 문서 확인이며 설치·정확도 실험을 수행한 결과가 아닙니다.
