Microsoft MAI-Code-1.1-Flash: 온디바이스 코딩 모델, 1.0 대비 1/4 비용

Microsoft AI 공식 발표. 3비트 양자화로 로컬 하드웨어에서 구동 가능한 코딩 전용 소형 모델로, GitHub Copilot에 통합되어 무료 온디바이스 코딩 옵션을 제공합니다.

#Microsoft#GitHub Copilot#온디바이스#코딩 모델

무엇을 할 수 있나요?

Microsoft AI 공식 발표(2026-10-07)에 따르면 MAI-Code-1.1-Flash는 3비트 양자화를 적용해 25.6만(256K) 컨텍스트 윈도우를 유지하면서도 로컬 하드웨어에서 구동 가능한 코딩 전용 모델입니다. 권장 사양은 RAM 120GB 이상이며, 로컬 호출은 추론 비용이 없습니다(zero inference charges).

2026년 6월 Microsoft Build에서 출시한 1.0 버전 대비 토큰 효율 25% 향상, 비용은 1/4 수준으로 낮아졌고, GitHub Copilot CLI에서 Terminal-Bench 2.1 기준 22% 성능 향상, .NET 작업에서 15% 향상을 기록했다고 밝혔습니다. 실제 운영 지표로는 코드 생존율 4% 상승, 재방문율 9% 상승을 제시했습니다.

GitHub Copilot 앱·CLI·VS Code에 이번 달 말까지 실험적으로 통합될 예정이며, Copilot의 라우터가 적합한 작업을 온디바이스로 보낼 수 있는 옵션으로 추가됩니다. 클라우드 모델을 완전히 대체하는 것이 아니라 더 큰 능력이 필요한 작업은 여전히 클라우드로 보완하는 구조입니다.

살펴볼 점
  • 온디바이스 구동에 RAM 120GB 이상을 권장해, 일반 소비자용 PC보다는 고사양 워크스테이션급 하드웨어가 필요합니다.
  • 성능 수치(토큰 효율, Terminal-Bench 개선율, 코드 생존율 등)는 모두 Microsoft 자체 측정·보고 기준이며, 외부 독립 벤치마크 재현 결과는 아직 공개되지 않았습니다.
