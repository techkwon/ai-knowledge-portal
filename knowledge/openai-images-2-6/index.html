OpenAI Images 2.6: GIF 제작과 이미지 편집·속도 업데이트

ChatGPT·Codex·API의 이미지 생성 업데이트. 공식 발표는 GIF 제작 활용과 편집 일관성 개선을 소개하며, API에서는 GPT-Image-2.6 Flare(저지연)와 Sunburst(고품질)를 선택할 수 있다고 안내한다.

#OpenAI#GPT-Image-2.6#GIF#이미지 편집#API

무엇을 할 수 있나요?

공식 발표(2026-11-04)에 따르면 Images 2.6은 ChatGPT, Codex, API에 적용되며 이전보다 약 50% 빠르게 이미지를 생성한다고 설명한다. API에서는 저지연의 GPT-Image-2.6 Flare와, 품질을 중간·높음으로 올려 편집 일관성을 높인 Sunburst 중에서 선택한다.

공식 발표는 마스코트·제품 비주얼·스토리보드 등의 GIF 제작 활용을 소개한다. 공개 예시에는 6칸 스프라이트시트 프롬프트도 포함돼 있으므로, 이를 모두 스프라이트시트 없는 직접 GIF 파일 출력이라고 단정하지 않는다. API 직접 출력과 구독 도구의 시트 조합 경로는 gif-maker-skill 제작자의 설명과 구분해 읽는다.

API에는 이미지 마크업(수정할 위치 지정), SVG 내보내기, '복잡도' 매개변수(장면에 담을 요소 수 조절)가 추가됐다. 복잡도와 품질은 서로 다른 축으로, 복잡도는 빠른 편집에 낮게 설정하는 것을 공식 가이드가 권장한다.

가격은 공식 가격 페이지(developers.openai.com/api/docs/pricing#image-generation)를 확인해야 하며, 발표문 자체에는 구체적 단가가 나와 있지 않다.

살펴볼 점
  • 발표문의 Flare 최소 6초, 50% 속도 향상 등 수치는 OpenAI 자체 소개 자료의 수치이며 독립 재현 측정은 아니다. 실제 체감 속도는 품질·복잡도 설정, 프롬프트 복잡도에 따라 달라질 수 있다.
  • 발표일 기준 전 세계 모든 ChatGPT·Codex 구독 요금제에서 제공한다고 안내하지만, GIF의 구체적인 도구별 옵션·길이·해상도·사용 한도와 API 별도 요금은 실제 이용 시 최신 문서에서 확인해야 한다.
  • 직접 설치나 API 호출, GIF 생성 테스트는 하지 않았다. 본 카드는 공식 발표문 내용을 정리한 것이다.
