oMLX 0.8.0rc1: 다른 Mac·NVIDIA PC로 긴 프롬프트 처리 나누기

Mac의 모델·캐시·답변 생성을 유지하면서 프리필 앞부분을 보조 장비에 맡기는 실험 기능

#oMLX#Apple Silicon#프리필#릴리스 후보

무엇을 할 수 있나요?

oMLX는 Apple Silicon Mac에서 여러 언어·시각 모델을 관리하고 OpenAI·Anthropic 호환 API로 제공하는 로컬 추론 서버입니다. 메모리와 SSD를 사용하는 KV 캐시, 관리 화면, 메뉴 막대 앱을 제공합니다.

0.8.0rc1의 Prefill Accelerator는 긴 텍스트 프롬프트의 앞쪽 레이어를 보조 Mac 또는 NVIDIA GPU 장비에서 계산합니다. 주 Mac은 나머지 레이어와 디코딩을 수행하며 전체 KV 캐시를 보유합니다. 모델 전체를 여러 장비에 분할하는 방식과 구분하세요.

보조 장비의 계산 속도와 연결 속도를 측정해 배분하며, 통신 때문에 느려질 것으로 판단하면 프롬프트를 주 Mac에 남깁니다. 짧은 프롬프트와 이미지가 포함된 프롬프트는 주 Mac에서 처리하는 제한이 문서에 있습니다.

Mac끼리는 같은 oMLX 버전과 로컬 네트워크 접근, 보조 Mac의 Remote Login이 필요합니다. NVIDIA helper는 모델 계열별 호환성을 확인하며, 출시 설명은 Ampere 이상 또는 GB10과 드라이버 580 이상을 요구합니다. 문서와 릴리스 모두 실험 단계라는 전제로 확인해야 합니다.

살펴볼 점
  • 정식 안정판이 아닌 릴리스 후보입니다. 출시 안내는 안정 버전이 필요하면 0.7.3을 사용하라고 명시하며 Windows helper는 미검증 상태라고 적습니다. 설치·기기 연결·속도 측정은 직접 하지 않았습니다.
  • CUDA와 Metal 계산의 반올림 차이가 후속 토큰을 바꿀 수 있어 단독 실행과 결과가 완전히 같다고 보장하지 않습니다. 공식 벤치마크를 일반적인 성능 보장으로 옮기지 않았습니다.
  • Apache-2.0은 서버 코드의 조건입니다. 재배포할 때 라이선스·저작권·해당 NOTICE와 수정 표시를 보존해야 하며, 모델 가중치·외부 구성요소의 조건은 각각 별도입니다.
  • 로컬 추론도 캐시·로그·보조 장비에 데이터가 남을 수 있습니다. 모델 파일과 중간 상태가 다른 장비로 이동하므로 신뢰하는 네트워크와 장비만 사용하고, 외부 API·검색·MCP를 붙였다면 데이터 경계를 다시 검토하세요. 미성년자용 서비스 적합성을 확인한 것은 아닙니다.
