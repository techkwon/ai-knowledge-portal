DeepInfer: DeepSeek의 오프라인 추론 프레임워크

DeepSeek-V4.1-Flash용 커널·분산 실행·스케줄러를 공개한 고성능 추론 엔진으로, 완성형 서비스와는 구별해야 한다

#DeepSeek#추론 엔진#인프라

무엇을 할 수 있나요?

공개 릴리스는 DeepSeek-V4.1-Flash 오프라인 추론을 지원하며, DSpark·비동기 스케줄링·구조화 출력과 분산 병렬 실행 기능을 안내합니다.

공식 지원 하드웨어는 NVIDIA SM100 GPU와 Huawei Ascend 950 NPU입니다. Linux·Python 3.12·GCC 13 이상, NVIDIA에서는 CUDA 13, Ascend에서는 CANN 9.2가 전제됩니다.

완전한 추론 서비스에 필요한 KV 캐시 시스템, prefill/decode 분리 구성과 데이터 병렬 복제본의 로드밸런싱 등은 별도 구현 대상이라고 명시합니다. 코드는 Apache-2.0입니다.

살펴볼 점
  • 개인 PC의 모든 GPU나 Mac에서 바로 실행되는 범용 런처로 해석하지 마세요. 모델 가중치와 환경별 사용 조건도 따로 확인하세요.
  • 제공자 벤치마크를 사용자 환경 성능으로 일반화하지 않습니다. 배포 전 자원·보안·서비스 운영 구성 검토가 필요합니다.
  • 공식 문서 확인 기준이며 설치·실행·성능을 직접 시험하지 않았습니다.
