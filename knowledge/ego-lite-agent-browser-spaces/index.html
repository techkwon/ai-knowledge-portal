ego lite: 사람과 에이전트가 별도 Space에서 쓰는 브라우저

기존 에이전트 CLI가 ego-browser 스킬로 브라우저를 조작하고, 사람과 에이전트가 별도 작업 공간에서 병렬로 일하도록 설계된 브라우저

#브라우저 자동화#Spaces#CLI

무엇을 할 수 있나요?

ego lite는 에이전트별 Space를 제공하고 ego-browser를 통해 snapshot·입력·클릭 등 JavaScript 기반 브라우저 도구를 노출합니다. 에이전트 CLI와 함께 쓰는 연결 계층이지 별도의 모델 구독을 제공하는 서비스는 아닙니다.

공식 안내는 macOS와 Windows를 지원하고 Linux는 로드맵으로 구분합니다. Chrome 데이터 이전은 선택 사항이며, 선택하면 기존 로그인·쿠키·확장·북마크를 사용할 수 있다고 설명합니다.

도입 시 비민감 계정과 작은 읽기 작업으로 동작을 확인하고, 에이전트 Space의 진행 상황과 중지·인계 방식을 익히는 순서가 적절합니다.

살펴볼 점
  • 로그인 세션을 사용할 수 있으므로 허용 계정과 작업 범위를 제한하세요. 별도 Space를 권한·데이터 보안 격리의 보증으로 해석하지 마세요.
  • 저장소 내용의 MIT 라이선스와 별도 배포되는 무료 브라우저 바이너리를 구별하세요. 제작자의 속도·성공률 비교는 여기서 재현하지 않았습니다.
  • 공식 문서 확인 기준이며 설치·실행·성능을 직접 시험하지 않았습니다.
