MOSS-Image-SFT: 프롬프트·태그·JSON 레이아웃 기반 이미지 생성

자연어와 구조화된 배치 입력으로 정적 이미지를 만드는 5B 텍스트-이미지 모델

#MOSS#이미지 생성#레이아웃

무엇을 할 수 있나요?

MOSS-Image-Base를 지도 미세조정한 모델로, 자연어 프롬프트·태그·JSON 레이아웃 형식을 안내합니다. 문자와 오브젝트 배치를 조절하는 정적 이미지 생성 모델이지 영상 모델은 아닙니다.

공식 실행 안내는 CUDA 지원 NVIDIA GPU와 해당 PyTorch·diffusers·transformers 환경을 전제합니다. 파일 총량을 VRAM 최소치로 해석하거나 CPU offload를 CPU 단독 지원 보장으로 읽지 마세요.

공식 카드와 실제 라이선스 파일은 가중치 및 동봉 추론 코드에 Apache-2.0을 명시합니다. 프로젝트 가이드는 영어 프롬프트를 권장하며 모든 언어의 동일 품질을 보장하지 않습니다.

살펴볼 점
  • 생성한 글자·수치·배치는 반드시 눈으로 확인하세요. 제공자의 SFT 비교 예시는 품질 보증이나 독립 재현 결과가 아닙니다.
  • 상업 이용·재배포 시 Apache 고지 조건과 제3자 권리를 확인하고, 입력 이미지와 생성물의 권리도 따로 검토하세요.
  • 공식 문서 확인 기준이며 설치·실행·성능을 직접 시험하지 않았습니다.
