OpenAI dots: 자체 클라우드 컴퓨터로 일하는 상시 작동 에이전트

GPT-6 Astra 기반의 dots가 Pro·Business Premium부터 순차 제공되며, 자체 컴퓨터·권한 규칙·행동 승인 구조와 사용량 산정 방식이 공식 발표에 정리되어 있습니다.

#OpenAI#dots#GPT-6 Astra#상시 에이전트#권한 관리

무엇을 할 수 있나요?

OpenAI 발표(2026-09-29)에 따르면 dots는 GPT-6 Astra 기반이며 자체 클라우드 컴퓨터와 브라우저를 갖고 24시간 일하는 에이전트입니다. 플러그인 생태계로 4,000개 넘는 앱에 연결할 수 있고 ChatGPT, Slack, Teams에서 대화하며 음성 통화도 가능합니다. 문자 메시지는 곧 제공 예정입니다.

제공 범위: 지원 지역의 Pro와 Business Premium에 순차 제공하고, Enterprise(Edu·Healthcare 포함)는 워크스페이스 관리자가 베타를 켜면 쓸 수 있습니다. 첫 번째 dot은 추가 비용 없이 요금제에 포함되고, 출시 첫 달은 한도가 확대됩니다.

사용량: dot과의 대화는 ChatGPT 사용 한도에 포함되지 않지만, dot이 Codex나 ChatGPT Work에서 작업을 시작·관리하면 평소대로 한도에 반영됩니다.

통제 방식: 각 dot은 자체 컴퓨터에서 일하며 사용자 기기는 직접 연결하기로 한 경우에만 연결됩니다. 접근할 앱은 사용자가 고르고, 맞춤 규칙으로 행동을 허용·승인 요구·차단할 수 있으며 활동 보기에서 백그라운드 작업도 확인합니다. 선제적 조사는 읽기 전용 도구로만 하고, 비밀번호 변경 같은 민감 작업은 항상 사용자가 직접 합니다.

살펴볼 점
  • 지역·요금제·단계적 출시에 따라 계정마다 사용 가능 시점이 다릅니다. 커뮤니티의 사용량 차감 추측은 공식 문서로 확인되지 않았습니다.
  • 회사나 학교 데이터를 연결하기 전에 조직의 정책과 데이터 설정(모델 개선 사용 여부)을 확인하세요.
