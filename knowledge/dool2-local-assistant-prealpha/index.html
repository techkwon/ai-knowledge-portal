두리(dool2): 로컬 PC 비서의 개발 단계와 승인 게이트

Claude Code·Codex 등을 사용자 PC에서 실행하는 오픈소스 비서 프로젝트. 일반 설치 앱과 완성된 폰 승인 서비스를 기대하기 전 저장소의 개발 단계를 확인해야 합니다.

#두리#dool2#pre-alpha#승인 게이트

무엇을 할 수 있나요?

공식 랜딩은 폰으로 요청하고 자기 Mac·Windows PC의 브라우저로 작업하는 구상을 소개하지만, 저장소 README는 pre-alpha이며 일반 사용자용 설치 파일이 없다고 명시합니다.

README 진행표에서는 PC 대화·첫 설정·브라우저 기능·PC 승인 게이트는 완료로, PC 앱 제어·스킬은 진행 중으로, 배포와 폰 연동은 예정으로 구분합니다. 홍보 예시를 완성된 기능으로 소개하지 않습니다.

개발용 실행 안내는 Node.js 24 이상과 pnpm, Claude Code 또는 Codex 인증 경로를 제시합니다. README에는 API 키를 사용하는 OpenCode 종량제 모드도 안내되어 있습니다.

설계상 에이전트 내장 도구를 제한하고 별도 MCP 도구와 승인 게이트를 사용합니다. 위협 모델은 PC 승인 구현과 향후 폰 서명을 구분하고, 감염된 PC·확인 없이 승인한 행동·AI 회사 사고·각 사이트 자동화 약관을 막지 못하는 영역으로 적습니다.

저장소의 공개 운영 문서는 코드 Apache-2.0, skills 문서 CC BY-SA 4.0, 이름·로고 상표를 분리한다고 명시합니다. 포크 배포 시 이름·로고 변경과 적용 범위별 의무 확인이 필요하다고 안내합니다.

살펴볼 점
  • 직접 설치·보안 감사·코드 실행 테스트 없음. 문서에 표시된 구현 단계는 제작자 설명이며 실제 보안 보장이 아닙니다.
  • 랜딩의 폰 생체인증·종단간 암호화 약속과 README 로드맵, 위협 모델의 세부 진행 상황이 일치하지 않는 부분이 있습니다. 최신 커밋과 구현을 별도 확인해야 합니다.
  • 두리 이용료 0원과 AI 비용 0원은 다릅니다. 개인 유료 구독 경로와 API 키 종량제 경로를 분리하고, 두리 FAQ도 서비스별 이용조건은 베타 전 안내 예정이라고 적고 있어 구독 약관 준수를 이번 검토로 확정하지 않습니다.
  • 상시 동작에는 켜진 PC가 필요합니다. 폰·중계 서버·서명된 설치 파일이 일반 사용자용으로 완성되었다고 보지 마세요.
  • 학생용 도구나 학교 계정 운영의 연령·기관 승인·개인정보 처리 요건은 미확인입니다. 개발 초기 프로그램에 민감한 학교·금융·업무 계정을 연결하는 것을 권하지 않습니다.
  • 라이선스 설명은 README와 공개 운영 원칙의 선언 범위입니다. 코드 LICENSE·각 자산·TRADEMARKS 전문을 모두 별도 검토한 것은 아니므로 실제 포크·재배포 전에 적용 범위를 확인하세요.
