Markdown 문서를 읽고 편집해 PDF로 공유하며 간단한 AI 문장 작업을 함께 사용할 수 있는 데스크톱 앱

#Markdown#PDF#문서 편집#AI 글쓰기

무엇을 할 수 있나요?

공식 소개는 표·이미지·코드·제목·목록의 문서형 표시와 문서 화면 편집, Markdown 원문 확인을 지원한다고 안내합니다. AI가 만든 Markdown 초안을 사람이 읽고 다듬는 단계에 활용할 수 있습니다.

긴 문서는 목차와 검색으로 탐색하고 글꼴과 이미지 크기를 조정할 수 있습니다. 인쇄 또는 PDF 저장으로 편집 결과를 공유합니다.

AI 보조 기능으로 다시 쓰기, 요약, 번역, 이어 쓰기를 소개합니다. 공식 페이지에서 macOS Apple Silicon·Intel, Windows x64, Linux AppImage 배포 링크를 구분합니다.

살펴볼 점
  • 공식 소개만 확인했으며 실제 설치와 PDF 출력 품질은 테스트하지 않았습니다.
  • 소개 페이지에서 AI 제공자·요금·문서 전송 및 보관 조건을 확정할 수 없어 민감한 문서는 조건을 확인하기 전 AI 기능에 입력하지 않는 편이 안전합니다.
