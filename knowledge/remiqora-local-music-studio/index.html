Remiqora: ACE-Step·YuE2 통합 로컬 음악 생성 스튜디오

두 개의 오픈소스 음악 생성 엔진을 하나의 UI와 멀티트랙 DAW로 묶은 로컬 GPU 도구

#음악 생성#로컬 AI#오픈소스#커뮤니티 인사이트

무엇을 할 수 있나요?

Remiqora는 오픈소스 음악 생성 엔진 ACE-Step 1.5와 YuE2-3B를 하나의 로컬 웹 UI로 통합한 GPU 기반 음악 제작 스튜디오입니다. 공식 GitHub README에 따르면 두 엔진은 한 GPU에서 동시 실행이 어려워 헤더에서 모델을 선택하면 자동으로 전환·정지되는 상호 배타적 오케스트레이터를 제공합니다.

생성된 트랙은 SQLite 기반 공유 라이브러리에 저장되며 Demucs 스템 분리, MuScriptor MIDI 전사, 멀티트랙 DAW(이펙트 랙·페이드·워프·언두 30단계 등)로 후처리할 수 있습니다. 브라우저에서 바로 ACE-Step LoRA 파인튜닝(데이터셋 업로드부터 학습까지)도 지원한다고 설명합니다.

Windows(NVIDIA CUDA)와 macOS(Apple Silicon, Metal/MPS)를 모두 지원하며, 아직 개발 초기(actively in development) 단계로 파괴적 변경이 있을 수 있다고 README에 명시돼 있습니다.

살펴볼 점
  • Remiqora 자체 코드는 MIT 라이선스지만, 생성된 음악의 라이선스는 사용한 모델마다 다릅니다. ACE-Step 1.5는 상업적 이용이 가능하다고 명시하지만, YuE2-3B 가중치는 CC BY-NC 4.0(비상업적 이용만 허용, 출처 표기 필수)이므로 배포 전 반드시 해당 모델의 라이선스를 확인해야 합니다.
  • NVIDIA GPU 드라이버는 스크립트가 자동 설치하지 않으며 수동 설치가 필요합니다. 아직 안정 릴리스가 아니라고 제작자가 직접 경고하고 있습니다.
