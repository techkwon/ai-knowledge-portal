side-panel: Claude Code 질문·결과물과 다른 세션 상태를 한 눈에 보는 패널 플러그인

터미널 오른쪽에 질문/결과물 목록과 컨텍스트·사용량 현황, 동시에 돌아가는 다른 Claude 세션 상태를 보여주는 MIT 라이선스 Claude Code 플러그인. 전체 파일 열기 기능만 Windows 메모장에 의존하고 나머지는 플랫폼 영향이 적다고 공식 저장소가 설명함

#실무 가이드#커뮤니티 인사이트

무엇을 할 수 있나요?

공식 저장소 설명에 따르면 side-panel은 Claude Code 플러그인으로, 터미널 폭의 1/3 크기 패널을 띄워 위쪽엔 질문 목록을, 아래쪽엔 그 질문으로 만들어지거나 바뀐 파일·페이지 목록을 보여줍니다.

Bash·PowerShell 명령이 만든 파일도 git 변경 내역으로 추적해 결과 목록에 추가하고, 작업 폴더·모델·컨텍스트 사용률(예: ctx 42%)·사용 한도 잔량을 상태 박스에 표시한다고 설명합니다. `claude agents --json`을 주기적으로 읽어 동시에 실행 중인 다른 Claude 세션의 진행 상태도 함께 보여줍니다.

설치는 Claude Code 안에서 `/plugin marketplace add caesar00723-max/side-panel` → `/plugin install side-panel@side-panel` 후 `/panel` 명령으로 엽니다. MIT 라이선스로 공개되어 있습니다.

살펴볼 점
  • 공식 저장소는 "전체 파일 열기" 기능만 Windows의 notepad.exe를 사용한다고 명시하며, 나머지 기능(패널 표시·요약·세션 추적·미리보기)은 플랫폼 영향이 적다고 설명합니다. 다만 macOS/Linux에서 직접 테스트된 결과는 아니므로 실제 동작은 사용 전 확인이 필요합니다.
  • 다른 세션 추적에는 `claude` CLI가 PATH에 있어야 합니다. 셸 명령 결과물 추적에는 `git`이 PATH에 있어야 하고 작업 폴더가 git 저장소여야 하며, 둘 중 하나라도 없으면 저장소 밖에서는 해당 기능만 꺼진다고 공식 저장소가 설명합니다. 설치·실측은 하지 않았습니다.
