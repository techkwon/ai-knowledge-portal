Aseprite: AI 이미지 초안을 스프라이트로 정리하고 재배포 권한 구분하기

레이어·프레임으로 픽셀 그래픽을 다듬고 시트로 내보내는 도구. 소스 공개와 자유 재배포는 다르다.

#Aseprite#픽셀아트#스프라이트#라이선스

무엇을 할 수 있나요?

Aseprite는 레이어와 프레임을 분리해 픽셀아트 애니메이션을 편집하는 도구다. 공식 기능에는 프레임 태그, 어니언 스킨, 팔레트와 알파 관리, 픽셀 퍼펙트 선, GIF·PNG 시퀀스·스프라이트 시트 내보내기가 있다. AI가 생성한 그래픽을 그대로 게임에 넣기보다 프레임 크기·팔레트·연속성을 사람이 다듬는 후처리 도구로 검토할 수 있다. AI 자동 보정이나 MCP 지원을 공식 기능으로 확인한 것은 아니다.

스프라이트 시트는 여러 프레임을 한 장의 이미지에 가로·세로·격자로 배치한 것이다. File > Import Sprite Sheet에서 파일을 선택하고 시작 위치 x·y, 각 스프라이트 너비·높이, 필요하면 프레임 사이 padding과 읽는 순서를 설정한다. 분리된 프레임을 레이어·타임라인에서 확인한 뒤 File > Export Sprite Sheet에서 보이는 레이어 또는 특정 레이어와 태그 기준 프레임을 선택해 내보낸다.

예를 들어 직접 만든 4프레임 캐릭터를 같은 셀 크기로 정리한 뒤 대기·걷기 태그별로 시트를 만들 수 있다. 이 예시는 공식 가져오기·내보내기 기능을 적용한 설명이며 직접 실행한 결과가 아니다. GIF는 색상 수 제약으로 RGB 원본과 다르게 보일 수 있으므로 팔레트와 색상 모드를 확인하고, 레이어·프레임 원본은 .aseprite 형식으로 따로 보존한다.

현재 저장소와 공식 바이너리는 Aseprite EULA 적용 대상이다. 공식 FAQ는 2016년 8월 이후 GPL 대신 자체 EULA를 사용하며 소스를 개인 목적으로 컴파일·수정할 수 있지만 컴파일된 프로그램을 제3자에게 재배포할 수 없다고 설명한다. 일부 내부 라이브러리의 MIT 라이선스가 Aseprite 전체를 MIT 또는 일반적인 자유 오픈소스로 바꾸지는 않는다.

공식 FAQ는 자신이 만든 그래픽을 개인·상업 제품에 사용할 수 있다고 명시한다. 프로그램 재배포 권한과 제작 에셋 이용 권한은 서로 다르다. 기업은 개발자별 라이선스를 확인하고, 교육기관의 교실 사용은 별도 교육 라이선스를 요청할 수 있다. AI 입력·생성물이나 기존 게임 캐릭터의 권리는 Aseprite 라이선스로 해결되지 않는다.

살펴볼 점
  • 직접 테스트하지 않았음. 프로그램 설치·소스 빌드·구매·MCP 연결을 하지 않았다.
  • 소스 공개만 보고 무료 오픈소스 또는 바이너리 자유 배포 가능이라고 소개하지 않는다. EULA와 공식 FAQ 기준으로 요약했다.
  • 본인 제작 그래픽의 상업 활용 허용과 제3자 이미지·캐릭터·AI 생성물의 권리 확보는 별개다.
  • 게임 복원물이나 기존 저작물의 배포를 정당화하는 도구로 소개하지 않는다.
