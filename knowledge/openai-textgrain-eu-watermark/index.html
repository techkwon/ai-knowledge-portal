OpenAI textGrain: EU AI Act 대응 텍스트 워터마킹

OpenAI 공식 발표로, 모델이 생성한 텍스트에 보이지 않는 통계적 신호를 넣는 textGrain 워터마킹 기술과 그 한계를 설명합니다.

#OpenAI#워터마킹#콘텐츠 출처#EU AI Act

무엇을 할 수 있나요?

OpenAI 공식 발표에 따르면 EU AI Act의 생성 텍스트 식별 요구에 대응해 'textGrain'이라는 텍스트 워터마킹 기술을 선보였습니다. 모델의 단어 선택에 보이지 않는 통계적 신호를 추가하고, 탐지기가 해당 신호의 존재 여부를 판별하는 방식입니다. API 고객은 전역적으로 선택 모델에 대해 워터마킹을 opt-in 할 수 있으며 API 기본값은 꺼짐 상태이고, EU 내 ChatGPT·Codex 출력에는 단계적으로 적용됩니다.

공식 평가에 따르면 200토큰 분량의 짧은 글은 400토큰 글보다 탐지가 어렵고(위양성률 1% 기준 약 80% vs 95% 탐지), 수학처럼 단어 선택의 자유도가 낮은 콘텐츠는 탐지율이 더 낮습니다. 400토큰 글에서 단어의 10%를 동의어로 바꾸면 탐지율이 92%에서 66%로, 25%를 바꾸면 17%까지 떨어진다고 공개했습니다.

OpenAI는 이러한 한계 때문에 탐지기 접근을 승인된 연구자·전문기관으로 제한하고 있으며, 기술을 향후 오픈소스로 공개할 계획이라고 밝혔습니다. 이미지·오디오용 검증 도구(openai.com/verify, Content Provenance API)는 이번 발표와 별개로 계속 공개 운영됩니다.

살펴볼 점
  • 짧은 글, 특정 분야(예: 수학), 사후 편집(동의어 교체 등)에서는 탐지율이 크게 낮아진다고 OpenAI 스스로 명시합니다. 워터마크 탐지 결과를 단정적 증거로 사용하지 마세요.
  • 현재 탐지기 접근은 일반 공개가 아니라 승인된 연구자·기관으로 제한되어 있습니다. 적용 범위(EU 우선, API는 opt-in)도 지역·서비스별로 다릅니다.
