Humanize KR: 한글 AI 문체 교정 CLI 스킬

내용은 그대로 두고 번역투와 AI 특유 표현만 잡아 고치는 한국어 전용 오픈소스 CLI 스킬

#한국어#글쓰기#CLI 스킬#오픈소스

무엇을 할 수 있나요?

저장소 설명에 따르면 번역투, 기계적인 병렬 나열, '결론적으로' 같은 관용구, 피동태 남용, 이모지·불릿 남용 등을 10개 대분류와 70개 세부 패턴으로 정리하고 심각도(S1~S3)를 매겨 문장 구간 단위로 탐지한 뒤 다듬습니다.

네 가지 원칙을 명시합니다. 사실·주장·수치·고유명사·직접 인용은 100% 보존하고, 탐지된 구간만 고치며, 글의 장르를 바꾸지 않고, 변경률이 30%를 넘으면 경고·50%를 넘으면 중단합니다.

Claude Code, GitHub Copilot CLI, OpenAI Codex CLI, Gemini CLI를 지원합니다. 플러그인 마켓플레이스 방식은 저장소 클론 없이 설치할 수 있고, 클론 후 install.sh로 전역 설치하는 경로도 제공합니다.

글 상태에 따라 light(1회 호출)·standard(2회)·heavy(3회 이상) 경로를 자동으로 고르는 구조라, 이미 다듬어진 글은 호출 수가 줄어듭니다. 영어권 humanizer가 한국어 번역투를 잘 못 잡는 문제를 겨냥한 도구입니다.

살펴볼 점
  • 개인이 공개한 커뮤니티 스킬이며 특정 AI 제품사의 공식 기능이 아닙니다. 조직에서 쓰기 전 라이선스와 유지 상태를 직접 확인하세요.
  • 다중 호출 경로(진단·finalize 포함)는 Claude Code 전용으로 안내되고, Copilot CLI와 Codex CLI는 단일 호출 경로만 제공합니다. 도구마다 동작 범위가 다릅니다.
  • AI 탐지기를 통과시켜 준다는 보장은 저장소에서 제시되지 않습니다. 과제·논문 등 출처 표기 규정이 있는 글에 쓰면 규정 위반이 될 수 있으니 용도를 먼저 확인하세요. 이 카드는 공개 문서 확인이며 설치·품질 실측이 아닙니다.
