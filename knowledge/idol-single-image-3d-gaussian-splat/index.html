Idol: 이미지 한 장을 3D Gaussian Splat으로, ComfyUI 재포장 지원

사진·렌더 한 장에서 표준 3DGS PLY를 생성하는 모델과 SDK. ComfyUI용 재포장도 제공하지만 폴리곤 메시나 실물 치수를 복원하는 도구는 아니며 보이지 않은 면은 추정한다.

#Idol#3DGS#Gaussian Splatting#ComfyUI#단일 이미지

무엇을 할 수 있나요?

공식 모델카드는 한 장의 사진·렌더·생성 이미지를 배경 제거·크롭한 뒤 3D Gaussian Splat으로 변환한다고 설명한다. 표준 3DGS .ply와 전처리 이미지·예측 카메라 정보를 출력한다.

Gaussian 수는 32,768~1,048,576이며 기본값은 262,144다. .ply라는 확장자가 같아도 결과는 폴리곤 메시가 아니므로 일반 메시 편집·3D 프린팅용 완성 모델과 구별해야 한다.

공식 SDK는 Python 3.10 이상·PyTorch 2.5 이상·CUDA NVIDIA GPU 환경을 안내한다. 사진은 real, 렌더·생성 이미지는 synthetic 모드로 크롭 여백을 다르게 설정한다. 첫 요청에는 컴파일 지연이 생길 수 있다.

Comfy-Org는 ComfyUI용 FP16 모델·디코더를 재포장하고 DINOv3 비전 인코더·FLUX.2 VAE 파일 배치 및 이미지→Gaussian Splat 템플릿을 안내한다. 기존 TripoSplat 워크플로와 호환된다는 배포 설명이며 SDK와 재포장 실행 환경을 동일시하지 않는다.

원모델 배포 페이지는 Apache-2.0을 표기하고 SDK의 실제 LICENSE도 Apache-2.0이다. 다만 필수 이미지 인코더 DINOv3와 FLUX.2-dev VAE는 별도의 접근 승인·약관 대상이므로 전체 파이프라인이 같은 라이선스라고 해석하지 않는다.

살펴볼 점
  • 보이지 않는 뒷면·측면을 생성하는 것은 실제 관측·정확한 구조나 치수를 복원했다는 뜻이 아니다. 안전·공학 측정·제조 가능성의 근거로 바로 사용하지 않는다.
  • 제작자의 7.2GB 피크 VRAM 설명을 모든 구현의 최소·최대 사양으로 보장하지 않는다. 공개 50단계·262,144 Gaussians·8장 중앙값 표는 B300 3.4초, RTX 4090 19.1초, RTX 3080 46.2초로 장비 차이가 크다. 소개 문구의 2초 미만을 일반 실행 속도로 확정하지 않는다.
  • SDK에서 DINOv3와 FLUX.2-dev VAE 접근을 승인받고 인증해야 한다. 재포장된 파일을 받는다고 기반 모델의 조건이 없어지는 것은 아니며 상업 배포 전 각 배포처 약관을 확인한다.
  • 로컬 SDK 처리와 온라인 Hugging Face 데모 업로드를 구분한다. 개인·학생 사진, 미공개 디자인을 외부 데모에 올리기 전 권리·동의와 서비스의 보관·전송 정책을 확인한다.
  • 설치·가중치 다운로드·추론·온라인 데모 실행·ComfyUI 연결·성능 측정은 하지 않았다. 기능과 수치는 제작자 문서·배포 페이지를 확인한 범위다.
