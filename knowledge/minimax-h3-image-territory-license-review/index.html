MiniMax H3 Image: 한국은 기본 허가 제외, 별도 면제 신청 확인

한국은 기본 커뮤니티 허가 지역에서 제외된다. 공식 Q&A의 별도 허가·면제와 MiniMax 자체 API 안내를 가중치·파생물의 권리와 구분한다

#MiniMax H3 Image#ComfyUI#지역 제한#라이선스#별도 허가#waiver

무엇을 할 수 있나요?

ComfyUI 공식 발표는 한 체크포인트의 텍스트 이미지 생성·다중 참조 편집, 6단계 guidance 1 샘플링, 정사각형 최대 4096×4096 등 네이티브 고해상도 출력을 설명한다. 이는 공식 설명이며 직접 성능·속도를 시험한 결과가 아니다.

Comfy-Org 배포는 원본 MiniMaxAI 모델의 ComfyUI 재패키징이다. 다운로드 가능성과 오픈소스의 무제한 이용을 혼동하지 말아야 한다.

2026-11-10 라이선스는 대한민국·미국·영국·EU를 허가 지역(Applicable Territory)에서 제외한다. V.4는 허가 지역 밖, 즉 이들 제외지역에서 모델뿐 아니라 출력의 사용·복제·수정·배포·표시도 기본 계약으로 허용하지 않는다.

허가 지역에서도 본인/계열사 연환산 매출 100만 달러 초과 또는 제3자 대상 호스팅 서비스 제공은 별도 사전 서면 허가가 필요하다. 모델 코드·가중치·파생물은 커뮤니티 라이선스이며 MIT/Apache의 포괄적 이용권으로 설명할 수 없다.

2026-11-17 확인한 MiniMax 공식 Hugging Face Q&A는 대한민국 등 제외지역의 조직도 이용 시나리오와 보호조치 검토를 거쳐 정식 라이선스를 신청할 수 있다고 안내한다. 같은 공식 계정의 개인 창작자·Colab 질문 답변은 연매출 100만 달러 미만의 면제 신청이 무료라고 설명하며, 신청 뒤 이메일로 waiver가 온다고 안내한다. 한국이 기본 커뮤니티 허가 지역에 포함된 것으로 바뀐 것은 아니므로 실제 허가 수신과 적용 범위를 확인해야 한다.

공식 Q&A는 MiniMax가 운영하는 H3 Image API를 전 세계 제공한다고 설명하고 공개 가중치와 분리한다. 이 설명은 제3자 API·파생 체크포인트·사용자가 직접 여는 호스팅 서비스가 자동 승인됨을 뜻하지 않는다. API 요금·보관·전송·연령·결과물 이용조건은 해당 서비스 계약에서 별도로 확인한다.

Character Swap 같은 파생 체크포인트에도 기본 모델 라이선스와 별도 참조 이미지·초상·캐릭터 권리 검토가 필요하다. 작은 LoRA 파일이나 다른 실행 도구를 사용한다는 사실이 지역 제한의 면제를 뜻하지 않는다.

살펴볼 점
  • 한국 이용자에게 설치·로컬실행·상업활용을 권하는 카드가 아니라 권리 제약 확인용 정보다. 별도 서면 허가가 없는 한국 사용을 허용한다고 해석하지 않는다.
  • 공식 MiniMax 운영 API의 전 세계 제공 안내는 해당 API 계약 범위에서 확인한다. 제3자 API·파생 체크포인트·개인 호스팅이 자동 승인되는 것은 아니며 우회 사용을 권하지 않는다.
  • 참조 이미지·실존인물·목소리·캐릭터는 별도 권리와 동의 확인이 필요하다. 공개 출력의 AI 생성 표시, 타 모델 개선 금지 등 추가 사용제약도 있다.
  • 직접 다운로드·실행하지 않았다. 학생 개인정보를 입력하지 않으며 미성년자 이용 적합성이나 서비스별 연령 요건을 확인한 것은 아니다.
  • 기본 라이선스의 대한민국 제외, V.4의 가중치·파생물·출력 이용 제한은 유효하다. 면제 신청이 가능하다는 안내를 신청만으로 즉시 허용되거나 모든 파생물·지역·상업용도가 승인된다는 뜻으로 확대하지 않는다. 공식 댓글의 이메일 발급 시간은 보장하지 않는다.
  • 연매출 100만 달러 미만의 면제 비용 안내와 유료 API 호출 비용은 다른 문제다. 본인/계열사 연환산 매출 100만 달러 초과 또는 제3자 호스팅은 별도 사전 서면 허가 조건이다.
  • 모델 코드·가중치·LoRA·파생 체크포인트는 MiniMax 커뮤니티 라이선스 계열로, MIT/Apache의 포괄적 이용권으로 적지 않는다. 예시 데이터·참조 이미지·실존인물 초상·캐릭터의 권리는 별도다. 동의 없는 인물 합성이나 학생 개인정보 업로드를 권하지 않는다.
  • 외부 인코더로 계산을 나누는 제작자 예시는 외부 데이터 전송이 생긴다. 로컬 도구를 쓴다는 이유로 완전한 로컬 처리라고 표시하지 않는다. 성인·미성년자 이용 허용 여부와 API 데이터 보관·요금은 이번 읽기 범위에서 독립 검증하지 않았다.
