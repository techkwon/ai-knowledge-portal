Shader Skills: GLSL 생성에 라이브러리·검사 루프를 더하는 스킬

코딩 에이전트가 절차적 GLSL을 만들 때 참고할 함수·템플릿과 번들러·검사기를 제공하는 공개 스킬

#GLSL#Shadertoy#시각화

무엇을 할 수 있나요?

SDF·노이즈·조명·색 변환 등의 GLSL 구성요소와 예제를 제공하며, 필요한 함수 의존성을 한 파일로 묶는 번들러와 코드 검사기를 갖춥니다.

에이전트에게 원하는 장면과 표현을 설명한 뒤 라이브러리 검색, 셰이더 작성, 번들링, 컴파일·렌더 확인 순서로 사용하는 구조입니다. 수학적 패턴·지형·빛 표현을 시각화하는 출발점으로 활용할 수 있습니다.

저장소는 WebGL2 검사 및 GPU 속성 테스트를 설명하고 MIT 라이선스로 배포합니다. 이는 제공자 측 테스트 설명이며 새로 생성한 모든 셰이더의 정확성을 보장하지는 않습니다.

살펴볼 점
  • 일부 검사에는 glslangValidator 등 별도 도구가 필요합니다. 실제 결과는 대상 브라우저·GPU에서 확인하세요.
  • 영화 수준 품질·실시간 성능이나 한 번에 컴파일 성공을 보장하는 도구로 소개하지 않습니다. 외부 스킬 코드를 먼저 검토하세요.
  • 공식 문서 확인 기준이며 설치·실행·성능을 직접 시험하지 않았습니다.
