Awesome Opus 5.5 Videos: 코드 애니메이션 프롬프트 사례 모음

HTML·Canvas·SVG·Three.js 등으로 만든 모션그래픽·설명·3D·인터랙티브 사례와 제작자가 공개한 프롬프트 또는 원 게시물을 모은 비공식 자료집.

#코드 애니메이션#HTML#Canvas#모션그래픽

무엇을 할 수 있나요?

저장소는 Claude Opus 5.5에 애니메이션 코드를 작성하게 해 만든 사례를 모션그래픽, 설명, 3D 장면, 게임·인터랙티브 유형으로 묶는다. 각 항목은 원 제작자 게시물과 공개된 프롬프트를 연결하며 일부는 재제작된 결과도 함께 보여준다. 모델 성능을 통제 비교한 벤치마크는 아니다.

안내된 활용 순서는 프롬프트 파일의 Prompt 부분을 확인하고, 코딩 에이전트에 단일 HTML로 렌더링하도록 요청한 뒤 필요하면 페이지를 녹화하는 것이다. 기존 영상 제작 파이프라인 도구와 달리 표현 방식과 요청문을 살펴보는 참고 자료로 활용할 수 있다.

일부 파일은 제작자가 공개한 프롬프트가 일부뿐이거나 결과에 대한 설명만 담고 있다고 명시한다. 예시의 장면·동작·기술 선택을 학습하되 자기 목적에 맞게 다시 작성하고 실제 브라우저에서 동작을 확인하세요.

살펴볼 점
  • 제작자별 영상과 프롬프트의 권리는 각 원 제작자에게 있다고 Credits가 명시한다. 모음에 실렸다는 이유로 상업적 재사용·재배포가 일괄 허가된 것으로 보지 말고 원 게시물과 개별 조건을 확인하세요.
  • 데모와 프롬프트만으로 같은 출력이나 성능을 재현할 수 있다는 보장은 없다. 공식 제품 문서가 아닌 비공식 큐레이션 저장소이며, 직접 생성·녹화·재현 실험은 하지 않았습니다.
