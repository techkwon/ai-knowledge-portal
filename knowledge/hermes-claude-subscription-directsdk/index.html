Hermes Agent에서 Claude 구독을 공식 CLI로 연결하기

공식 Claude Code CLI의 로그인 상태를 사용하면서 Hermes의 도구·승인·컴팩션 흐름을 유지하는 실험적 모델 제공자 플러그인

#Hermes Agent#Claude Code#구독 연결#실험적

무엇을 할 수 있나요?

핵심 원리: Hermes의 실험적 Claude Subscription DirectSDK 플러그인은 별도 Anthropic API 키 대신 로그인된 공식 Claude Code CLI를 요청 단위 모델 클라이언트로 실행합니다. 모델 호출은 Claude 구독을 사용하지만, 도구 실행·승인·대화 저장·컴팩션은 계속 Hermes가 담당합니다.

설치 조건: Hermes Agent 0.21.4 이상, Python 3.10 이상, 공식 Claude Code CLI가 필요합니다. `hermes plugins install claude-subscription-directsdk`로 플러그인을 설치하고 `claude auth login`으로 로그인한 다음 `hermes model`에서 Claude Subscription DirectSDK (Experimental)을 선택합니다.

자격 증명 경계: 플러그인은 Claude Code의 인증 파일을 열거나 복사·갱신·출력하지 않으며 Hermes API 키도 요구하지 않습니다. 일반 실행 경로에서는 API 키, 사용자 지정 Anthropic 엔드포인트, 클라우드 백엔드 재정의가 함께 설정되어 있으면 조용히 우회하지 않고 충돌을 오류로 표시합니다.

안전한 시험 절차: 별도 Hermes 프로필과 민감하지 않은 테스트 저장소에서 먼저 모델 선택·도구 승인 거부·취소·재개를 확인합니다. 실제 업무로 넓히기 전 Hermes 사용량과 Claude 계정의 구독 허용량·추가 사용 설정을 함께 확인합니다.

살펴볼 점
  • 공식 문서가 명시하듯 전체 기능 동등성이나 운영 준비가 완료된 제품이 아니라 실험적 review build입니다. Claude Code 버전과 히스토리 재생 방식에 민감하고, 강제 tool choice·assistant prefill·원격 이미지 다운로드 등 일부 기능은 지원하지 않습니다.
  • 구독 사용량은 Claude Code 대화형 TUI와 다르게 소모될 수 있습니다. 문서의 측정값은 특정 Pro 계정·모델·시점의 결과이며 실제 청구 증빙이 아닙니다. 초과 과금을 원치 않으면 계정의 extra usage를 끄고 별도로 확인하세요.
