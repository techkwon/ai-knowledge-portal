포에듀 학교메신저: 교내 서버와 외부 연동을 나눠 보는 테스트판

학교 Windows 서버와 교직원 앱을 구분한 무료 테스트판. 교내 대화·자료실과 선택형 교외 중계·웹 계정 연동의 데이터 경계를 확인한다.

#학교메신저#자체 서버#Windows#테스트판

무엇을 할 수 있나요?

제작자 소개 페이지는 교내 서버와 교직원 앱을 별도로 설치하는 학교메신저를 소개한다. 대화·자료실·시간표 교체와 업무 위젯이 안내되어 있다. 기능 설명은 제작자의 안내이며 다른 메신저보다 우수하다는 성능 비교 결과가 아니다.

설치 안내는 Windows 0.2.10 학교 테스트판(2026-11-16)과 Windows 10·11 64비트 흐름을 명시한다. 기본 대화는 학교에서 발급한 계정을 사용하며 포에듀케이터 회원가입은 기본 대화에 필요하지 않다고 안내한다. 무료 학교 테스트판이라는 표시는 향후 정식판·모든 기능의 영구 무료 보장이 아니다.

기본 대화·학교 자료실은 학교 서버에 보관한다고 설명한다. 개인 메모·사진 등 PC 저장, 개인 할 일·일정의 웹 계정 동기화, 교외 접속의 전용 중계는 서로 다르다. 교외 접속은 학교 관리자의 허용과 계정 연결이 필요하며, 문서상 기능을 켠 뒤의 새 텍스트는 최대 3개월, 교외에서 새로 보낸 파일·사진의 암호화 사본은 7일 뒤 접근 차단·삭제한다. 학교가 받은 파일과 사용자가 복사한 사본까지 회수하는 기능은 아니다.

AI 안내문·품의 엑셀 도구는 계정 연결과 인터넷이 필요하다고 안내한다. 기본 메신저의 교내 저장 설명을 AI 도구까지 완전 로컬 처리한다는 뜻으로 확대하지 않는다.

살펴볼 점
  • 설치·로그인·호출·파일 전송·보안 테스트를 하지 않았다. 안내상 외부 보안 검토·대규모 부하 검증·서명된 업데이트 등은 정식 출시 준비 항목이며 Windows 테스트판은 정식 배포자 서명이 아직 없다고 명시한다. 학교 운영망에 바로 도입하라는 추천이 아니다.
  • 제작자 본문은 Mac 교직원 앱도 소개하지만 이번에 읽은 상세 설치·기능 흐름은 Windows 기준이다. Mac 기능 동등성·모바일 지원은 확인하지 않았다.
  • 무료 배포와 코드 수정·재배포 라이선스는 별개다. 공개 코드 라이선스나 모델 가중치 이용권을 확인하지 않았으며 오픈소스로 분류하지 않는다.
  • AI 제공업체·모델·API 요금·개인 구독 사용 가능 여부는 확인하지 않았다. 메신저 테스트판 무료 표시를 AI API 무료나 개인 구독 포함으로 해석하지 않는다.
  • 교직원용 설명이며 학생 가입 가능 연령·만 14세 미만 동의·학교 선정 절차 충족을 확인하지 않았다. 개인정보처리방침 페이지는 요약만 읽혔으므로 전체 위탁·국외 처리 조건이 검증되었다고 볼 수 없다.
