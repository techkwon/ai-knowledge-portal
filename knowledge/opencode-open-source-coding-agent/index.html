OpenCode: 여러 모델을 연결해 쓰는 오픈소스 코딩 에이전트와 Plan·Build 모드

터미널·데스크톱·IDE에서 쓰는 오픈소스 코딩 에이전트로, 수정 권한이 제한된 Plan과 전체 도구를 쓰는 Build를 오가며 다양한 공급사 모델을 연결할 수 있다

#OpenCode#코딩 에이전트#오픈소스#멀티 모델#서브에이전트

무엇을 할 수 있나요?

OpenCode 공식 사이트는 이 도구를 터미널, 데스크톱 앱, IDE 확장에서 쓰는 오픈소스 코딩 에이전트로 소개합니다. Models.dev를 통해 75개 이상의 LLM 공급사와 로컬 모델을 연결할 수 있고, GitHub Copilot이나 ChatGPT Plus/Pro 계정 로그인도 지원한다고 안내합니다.

공식 문서의 기본 주 에이전트는 두 가지입니다. Build는 모든 도구가 켜진 기본 개발 모드이고, Plan은 파일 수정과 bash 명령이 기본적으로 '확인 요청(ask)'으로 설정된 분석·계획 모드입니다. Tab 키로 전환할 수 있어 먼저 Plan으로 계획을 정리하고 Build로 구현하는 흐름을 만들기 쉽습니다.

하위 에이전트로 General(병렬 작업), Explore(읽기 전용 코드 탐색), Scout(외부 문서·의존성 조사)가 기본 제공되며, `opencode.json`이나 마크다운 파일로 에이전트별 모델·권한·프롬프트를 따로 지정할 수 있습니다. 예를 들어 검토 전용 에이전트는 편집 권한을 deny로 두는 식입니다.

OpenCode Go는 월 10달러 구독으로 오픈 모델 위주의 코딩 모델 묶음을 제공하는 별도 상품이며, 다른 에이전트에서도 쓸 수 있다고 공식 페이지가 안내합니다. 모델별 예상 요청 한도는 페이지의 표로 공개됩니다.

살펴볼 점
  • Go 요금제의 모델 목록·한도·기간 한정 무료 모델은 수시로 바뀝니다. 기간 한정 익명 모델은 데이터 처리 조건을 확인한 뒤 민감한 코드나 학생 정보에는 쓰지 마세요.
  • 같은 모델이라도 도구(하네스)에 따라 결과가 달라질 수 있다는 사용자 의견이 있지만 이는 검증된 수치가 아닙니다. 이 카드는 공식 사이트·문서 확인이며 설치·성능 테스트는 하지 않았습니다.
