Nod: n8n Labs의 별도 개인 에이전트 프리뷰

로컬 샌드박스·브라우저와 외부 모델을 연결하는 개인 작업 도구

#n8n#개인 에이전트#연구 프리뷰#권한 관리

무엇을 할 수 있나요?

Nod는 n8n 워크플로 플랫폼과 별개인 연구 프리뷰입니다. Mac·Windows용 데스크톱 앱과 자체 호스팅 경로를 소개하며 n8n 계정 없이도 사용할 수 있다고 안내합니다.

자체 브라우저와 작업 공간에서 연결된 앱·웹사이트를 다루고 예약 작업과 장기 기억을 제공합니다. 설치 한 곳에 소유자 한 명이며, 실행 컴퓨터가 잠들면 예약 작업도 멈춥니다.

앱 코드는 무료지만 선택한 모델 사용료는 별도입니다. 요청 범위 밖의 보내기·결제·게시·삭제 등에 승인 검사를 두지만 이 검사 자체도 모델 판단이어서 오류를 낼 수 있습니다.

공식 개인정보 문서는 사용 데이터 공유가 기본 켜짐, 대화 추적 공유는 기본 꺼짐이라고 명시합니다. 로컬 저장과 외부 전송을 구분해야 합니다.

살펴볼 점
  • 설치·가입·계정 연결·실행·예약·전송은 하지 않았습니다. 프리뷰 안전성이나 업무 성공률을 보증하지 않습니다.
  • Apache 2.0 코드에는 상업적 사용·수정·재배포 권한이 있으나 LICENSE·NOTICE 유지, 수정 표시 등 조건이 있습니다. 포함 폰트·로고·런타임과 외부 AI·연결 서비스 약관은 별도입니다.
  • 메시지·스크린샷·읽은 내용은 선택한 모델로, 앱 요청/결과는 기본 연결 서비스를 통해 전송될 수 있습니다. 사용 데이터와 선택적 대화 추적도 설정에서 별도 관리하세요. 가명처리는 완전 익명화가 아닙니다.
  • Nod 이용약관은 연결 계정과 결제수단의 정당한 권한 및 AI 행동 검토 책임을 사용자에게 둡니다. 연령·지역별 전체 서비스 조건은 확인하지 않았으므로 미성년자·학교 데이터 연결은 별도 검토가 필요합니다.
