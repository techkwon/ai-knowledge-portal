Hugging Face GUI 모델 관리

Hugging Face 모델 다운로드·분석·로딩과 리소스 모니터링을 GUI로 제공하는 커뮤니티 프로젝트

#Hugging Face#Streamlit#모델 관리

무엇을 할 수 있나요?

Hugging Face 공식 제품이 아니라 CLI 작업을 GUI로 다루려는 커뮤니티 구현입니다. Streamlit 웹 UI와 CustomTkinter 데스크톱 실행 경로를 제공합니다.

제작자 안내는 모델 ID 기반 다운로드, 설정 파일 분석, 여러 모델 로드·언로드와 CPU·GPU·메모리 모니터링을 설명합니다. 작은 모델부터 메모리 사용량을 확인하며 시험하세요.

의존성 설치 후 `uv run streamlit run app.py`로 웹 UI를 실행할 수 있습니다. 로드한 모델을 FastAPI로 제공하는 개발·테스트용 기능도 포함합니다.

살펴볼 점
  • FastAPI 기능은 운영 서비스용 보안 구성을 대신하지 않습니다. 인증·접근 범위를 별도로 검토하고 로컬 시험 서버를 인터넷에 그대로 노출하지 마세요.
  • GPU 메모리 부족 시 자동 CPU 전환이 구현되지 않았다고 안내됩니다. 모델별 라이선스·접근 권한과 메모리 요구량을 확인하세요. 설치·실행 검증이 아닌 제작자 자료 확인입니다.
