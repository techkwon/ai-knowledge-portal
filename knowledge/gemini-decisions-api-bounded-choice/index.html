Gemini Decisions API: 답변 생성 대신 선택지의 확률 반환하기

공유 멀티모달 입력에 여러 제한형 질문을 묶어 도구 선택·라우팅·검토 보조에 쓰는 API. 확신도와 실행 권한은 다릅니다.

#Google#Gemini Decision 1#결정 모델#확신도#권한 분리

무엇을 할 수 있나요?

Google 공식 발표는 gemini-decision-1 모델을 쓰는 별도 Decisions API를 소개합니다. 자유로운 답변을 토큰 단위로 생성하기보다 주어진 후보의 확률을 계산하며, 텍스트·이미지·오디오·영상·PDF를 공유 입력으로 사용할 수 있다고 설명합니다.

발표 기준 입력은 최대 256K 토큰이며 한 요청에 최대 1,000개 독립 질문을 묶습니다. noul은 예/아니오 조건, choice는 2~255개 후보 중 선택, score는 0부터 시작하는 순서형 평가 기준을 다룹니다. 각 답에는 0~1 확신도가 포함됩니다. 실제 SDK 필드·지원 범위는 최신 API 문서를 별도로 확인해야 합니다.

예를 들어 비민감 작업 설명 하나에 도구 선택·추가 검토 필요·작업 범위의 여러 질문을 함께 평가할 수 있습니다. 애매한 결과는 보류하거나 사람이 확인하도록 설계합니다. 모델이 높은 확신도를 내도 결제·게시·삭제 권한이나 사용자 승인이 생기는 것은 아닙니다. 실제 실행 전에는 허용 대상·입력·현재 상태를 별도로 검사해야 합니다.

발표 가격은 입력 100만 토큰당 0.10달러, 출력 토큰 과금은 0달러입니다. 공유 입력은 요청마다 한 번 계산하고 질문별 지시·기준 토큰은 각각 더해집니다. 무료 시험 경로를 안내하지만 계정별 한도·지원 지역·다른 서비스의 구독 포함 여부를 보장하지 않습니다. 지연·정확도·보정 성능은 제작자 발표이며 직접 비교 측정하지 않았습니다.

현재 Gemini API 추가 약관의 연령·데이터 관련 조항을 브라우저에서 확인했습니다. 사용자는 만 18세 이상이어야 하며, 18세 미만을 대상으로 하거나 이들이 접근할 가능성이 있는 API 클라이언트에 서비스를 사용하지 않도록 정합니다. 저가 결정 모델이라는 이유로 학생용 앱의 약관 예외가 되는 것은 아닙니다.

무료 서비스의 입력·출력은 제품과 머신러닝 기술 개선 및 인적 검토에 사용될 수 있습니다. Cloud Billing 활성화 여부에 따라 무료 할당량을 쓰더라도 데이터 이용 관점에서 유료 서비스로 취급되는 조건이 있습니다. 유료의 제품 개선 미사용과 로그·보안 목적의 일시 저장까지 전혀 없다는 주장은 다르므로 개인정보·기밀을 넣기 전 최신 계약과 설정을 확인해야 합니다.

살펴볼 점
  • 공식 발표와 Gemini API 추가 약관의 관련 조항을 확인한 정보입니다. API 호출·키 발급·결제·모델 성능·확신도 보정·보안성을 직접 테스트하지 않았습니다. SDK 전체와 기본 API 약관·모든 부록을 감사한 것은 아닙니다.
  • API 서비스 소개이지 모델 가중치·코드의 공개나 재배포 라이선스가 아닙니다. 서비스 자격·지원 지역·금지된 사용·입력 권리·제3자 콘텐츠 조건은 별도입니다. Gemini 앱·교육기관 계약과 API 조건을 동일시하지 않습니다.
  • 확신도는 권한 검사나 사실 검증을 대체하지 않습니다. 사용자별 대표 과제에서 오탐·누락·폴백을 평가하고 중요한 외부 작업의 승인 단계를 유지해야 합니다.
