Codex CLI 설치와 ChatGPT 로그인: 공식 경로 확인

공식 npm·Homebrew 설치 경로와 ChatGPT 구독 로그인·API 사용량 과금을 구분하는 시작 안내

#Codex CLI#OpenAI#구독 로그인#설치

무엇을 할 수 있나요?

공식 저장소는 npm install -g @openai/codex와 brew install --cask codex 등 설치 경로를 안내합니다. 공식 문서에서 운영체제와 요구사항을 확인하고 이미 설치된 실행 파일·버전·PATH를 먼저 점검하세요.

프로젝트 폴더에서 codex를 실행해 첫 로그인에 Sign in with ChatGPT를 선택할 수 있습니다. 공식 안내는 지원되는 ChatGPT 구독과 API 키 기반 사용량 과금 접근을 구분하므로 API 키가 반드시 필요하다고 설명하지 마세요.

Codex는 선택 디렉터리의 파일을 읽고 수정하거나 설치된 도구를 실행할 수 있습니다. 작은 테스트 프로젝트와 적절한 승인·권한 설정으로 시작하고 변경 내용을 확인하세요.

살펴볼 점
  • 재설치가 특정 오류의 해결책이라고 보장하지 않습니다. 출처를 확인하지 않은 curl 파이프 설치 스크립트를 맹목적으로 실행하지 마세요.
  • 개별 구독 플랜·조직 제한·로컬 패키지 관리자 상태는 확인해야 합니다. API 키 사용은 OpenAI Platform의 별도 과금입니다.
  • 인증 저장 파일은 비밀번호처럼 보호하고 공유하지 마세요. 이 작업에서는 설치·로그인·명령 실행을 하지 않았습니다.
