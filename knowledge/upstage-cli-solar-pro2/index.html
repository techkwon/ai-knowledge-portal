Upstage CLI

Upstage Solar Pro2 기반 에이전트형 터미널 UI — 코드 분석·페어 프로그래밍·자동화를 도구 30종과 MCP 서버 연동으로 지원

#Upstage#Solar Pro2#터미널#MCP#에이전트 하네스

무엇을 할 수 있나요?

Upstage의 Solar Pro2 모델을 기반으로 코드 분석, 페어 프로그래밍, 자동화 작업을 터미널 안에서 지원하는 에이전트형 TUI입니다.

30개의 내장 도구와 MCP 서버 연동, 평가용 하네스를 포함합니다.

macOS/Linux는 설치 스크립트, Windows는 릴리스 바이너리, 또는 Bun 1.3+ 환경에서 npm으로 설치할 수 있으며 `upstage chat`, `upstage ask` 명령으로 실행합니다.

살펴볼 점
  • Windows 설치 시 릴리스 페이지에서 플랫폼에 맞는 바이너리를 직접 선택해야 합니다.
  • Upstage API 키 발급 등 별도 계정·인증 설정이 필요할 수 있어 README의 설치 절차를 순서대로 따라야 합니다.
