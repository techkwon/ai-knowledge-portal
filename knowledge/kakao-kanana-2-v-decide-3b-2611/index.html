Kanana-2-v-decide: 문장 대신 선택지 확률을 내는 카카오 판단 모델

텍스트·JSON·대화·이미지 입력에서 선택형·예아니오·척도 판단의 확률을 반환한다. 일반 챗봇과 다르며 자체 라이선스의 API 재판매·SI·온디바이스 제공 조건을 확인해야 한다.

#Kakao#판단 모델#멀티모달#확률

무엇을 할 수 있나요?

카카오가 11월 6일 공개한 판단 모델이며 실제 파라미터는 비전 인코더를 포함해 3.67B다. 상태 입력과 질문·선택지를 임베딩한 뒤 유사도에 softmax를 적용해 답 분포를 구하며 자유로운 문장을 생성하지 않는다.

choice는 선택지, noul은 참일 확률, score는 2~10개 순서 있는 수준의 기대 인덱스와 확률을 반환한다. 텍스트·JSON·메시지 형식과 최대 10장 이미지·20,480토큰을 안내하며 동영상 입력은 지원하지 않는다.

문의 분류·도구 라우팅처럼 후보를 명시할 수 있는 작업을 검토할 수 있다. 확률은 제시한 선택지에 상대적이므로 선택지를 추가하거나 설명을 바꾸면 분포가 달라진다. 이를 현실의 절대 확률이나 오류 없는 판단으로 해석하지 않는다.

공식 예제는 transformers의 trust_remote_code=True와 CUDA·BF16을 사용한다. HTTP 서버는 기본 127.0.0.1이며 외부 노출 전 인증 키 설정을 요구한다. 기본 동작은 긴 상태의 앞뒤를 남기고 줄일 수 있어 엄격한 입력 제한과 이미지 방향 정규화도 확인한다.

살펴볼 점
  • 직접 설치·추론·지연시간·벤치마크 재현은 하지 않았다. 점수는 제작자가 선택한 비교 모델과 평가 조건에 따른 보고다.
  • 학생 평가·채용·민감한 의사결정을 자동 확정하는 용도로 바로 쓰지 말고 대표 입력의 실패 사례와 사람 검토 기준을 준비한다.
  • KananaOpenLicense는 MIT·Apache가 아닌 자체 조건이다. 제3자에게 API·클라우드 접근을 제공 또는 재판매하거나 SI·온프레미스·온디바이스로 제공하는 경우 별도 상업 라이선스가 필요하다고 명시한다. 해당하지 않는 자체 서비스 운영과 구분하고 전문을 확인한다.
  • 재배포 시 계약·Notice 제공, 수정 표시, Powered by Kanana 표시 등 조건이 있다. 다른 Kanana 버전의 라이선스를 이 버전에 자동 적용하지 않는다. 원격 코드는 실행 전 검토한다.
