Browser Use: CLI·Python·클라우드 선택 가이드

기존 코딩 에이전트에 브라우저를 연결하거나 Python 코드와 호스팅 API로 웹 작업을 자동화하는 도구

#브라우저 자동화#CLI#Python

무엇을 할 수 있나요?

CLI는 기존 에이전트에 브라우저 조작을 연결하고, Python 라이브러리는 사용자 코드에서 모델과 도구를 구성하며, Fully Hosted Cloud는 에이전트와 브라우저 운영까지 맡기는 방식입니다.

Python 라이브러리는 Python 3.11 이상을 요구하며 uv add browser-use로 프로젝트에 추가할 수 있습니다. README의 신규 프로젝트 예시는 Python 3.12를 사용합니다.

CLI와 Python 라이브러리 모두 로컬 또는 클라우드 브라우저를 선택할 수 있습니다. 로컬 브라우저와 로컬 모델을 함께 쓰는 경로도 별도로 안내합니다.

살펴볼 점
  • MIT 라이선스 라이브러리와 모델 추론·호스팅 비용은 별개입니다. 직접 모델 연결은 공급자 API 키, Browser Use 서비스는 해당 API 키가 필요하며 일반 구독 로그인과 같다고 가정하지 마세요.
  • 클라우드 프로필 동기화는 쿠키를 전송합니다. 로컬 스토리지·IndexedDB·확장 기능까지 복제되는 것은 아니며 일부 사이트는 재로그인이 필요합니다.
  • 로그인 세션과 화면에 개인정보가 포함될 수 있습니다. 처음에는 읽기 전용 과제로 검증하고 결제·게시·삭제는 별도 승인 단계로 분리하세요.
