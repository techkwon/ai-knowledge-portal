Self-Evolving Agent Harness: 모델 가중치는 고정하고 하니스만 진화시키는 연구

프롬프트·메모리·워크플로·실행 컴포넌트 같은 에이전트의 소프트웨어 하니스를 모델 가중치는 그대로 둔 채 피드백 기반으로 수정·채택하는 프레임워크를 이론적으로 분석한 66쪽 연구.

#에이전트 하니스#자기 개선#PAC 학습#검증

무엇을 할 수 있나요?

공식 arXiv 초록(2610.18813)에 따르면 이 논문은 "하니스 자기진화(harness self-evolution)"를 모델 가중치는 고정한 채 프롬프트·메모리·워크플로·실행 컴포넌트 같은 소프트웨어 스캐폴딩을 수정하는 것으로 정의하고, 승인된 수정이 실행 간 유지되는 피드백 기반 과정을 형식화합니다.

업데이트 대상(해석된 상태 변경 vs 도구·코드·저장소 수준 제어 로직·플러그인 조합 변경)과 수정 제안·승인 메커니즘을 분리하고, 진화적 최적화를 통한 탐색과 연속 PAC-학습 기반 신뢰성 분석을 다룹니다. 저자들은 기대 일반화 경계, 과거 회귀 예산에 조건화된 유지 경계, 신선한 독립 검증 데이터를 쓰는 고확률 승인 규칙을 제시합니다.

공식 코드·보충자료는 저장소(github.com/zgcagi/Harness-RSI)에서 계속 갱신된다고 명시되어 있습니다. 반복 업무 에이전트를 설계할 때 변경 제안과 승인(검증) 절차를 분리하고 별도 평가 데이터를 쓰는 참고 자료로 활용할 수 있습니다.

살펴볼 점

  • 기존 카드(procedural-graphs-self-evolving-agents, arXiv 2609.09153)와 주제(에이전트 자기 개선)는 비슷하지만 저자·방법론이 다른 별도 논문입니다. 혼동하지 않도록 유의해야 합니다.
