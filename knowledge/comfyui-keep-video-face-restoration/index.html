ComfyUI-KEEP: 프레임 간 얼굴 특징을 전달하는 영상 복원 노드

KEEP 알고리즘을 ComfyUI V3 노드로 쓰는 얼굴 복원 도구. 단일 이미지와 시퀀스 처리를 구분하며, 노드 코드와 가중치의 이용권이 다르다.

#ComfyUI#KEEP#얼굴복원#영상복원#비상업적

무엇을 할 수 있나요?

ComfyUI-KEEP는 Kalman-Inspired Feature Propagation 방식으로 영상의 시간축을 따라 얼굴 특징을 전달한다. 매 프레임을 서로 독립적으로 복원하는 것과 달리 이전 특징을 다음 프레임에 이용해 시퀀스 일관성을 유지하도록 설계됐다. 복원된 디테일은 원본에 실제 존재했던 사실을 증명하지 않는다.

구성은 Load KEEP Models, KEEP Single Image, KEEP Image Sequence의 세 V3 노드다. 모델 로더를 두 복원 경로에 연결하고, 영상이라면 순서가 유지된 이미지 시퀀스를 넣는다. 얼굴 패치와 배경에는 각각 별도의 UPSCALE_MODEL을 연결할 수 있다.

제작자 예제는 VideoHelperSuite로 영상을 읽고 다시 결합한다. 이는 예제의 선택 의존성이지 KEEP 노드 자체의 필수 의존성은 아니다. 긴 영상은 max_clip_length가 한 번에 처리할 프레임 수를 정하므로 메모리 상황에 맞춰 검토하고, 여러 얼굴이 있는 장면은 only_center_face 기본값이 중앙 얼굴만 대상으로 한다는 점을 확인해야 한다.

기본 체크포인트는 첫 실행 시 다운로드되고 해시를 검사하도록 문서화돼 있다. Asian 체크포인트는 상위 프로젝트에서 공개되지 않았으므로 사용 가능한 기본 모델로 가정하면 안 된다. 이 설명은 제작자 README와 라이선스 직접 검토에 기반하며 설치·모델 다운로드·복원 실행은 하지 않았다.

살펴볼 점
  • 노드 자체 코드는 Apache-2.0이지만 KEEP 알고리즘·가중치와 포함된 basicsr/facelib 코드 및 얼굴 검출/파싱 가중치는 S-Lab License 1.0의 비상업적 제한을 따른다. 전체 파이프라인을 상업용 자유 이용 가능으로 해석하면 안 되며 상업 이용은 권리자에게 별도 문의해야 한다.
  • 재배포 때 각 라이선스의 저작권·조건·면책 고지를 유지해야 한다. 사용자가 추가하는 업스케일 모델과 VideoHelperSuite의 라이선스는 별도 확인 대상이다.
  • 얼굴 복원은 디테일을 생성할 수 있다. 당사자 동의·영상 권리·개인정보를 검토하고, 증거·신원 확인에 원본처럼 사용하지 않아야 한다.
  • 직접 테스트하지 않았으며 영상 일관성·VRAM·속도를 보증하지 않는다. final_upscale_factor의 원본 크기 관련 README 문구가 섹션 간 일관되지 않아 정확한 배율 동작은 실행 검증 전 단정하지 않았다.
