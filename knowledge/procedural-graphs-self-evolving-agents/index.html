Procedural Graphs: 에이전트 실행 절차 그래프

행동의 순서와 조건을 그래프로 표현하고 검증 성능을 기준으로 수정하는 LLM 에이전트 연구

#절차 그래프#자기 개선#검증#도구 사용

무엇을 할 수 있나요?

논문은 절차 지식을 (절차, 관계, 절차) 삼중항으로 구성합니다. 사실을 저장하는 지식 그래프와 달리 무엇을 어떤 순서와 조건에서 수행할지를 표현합니다.

각 단계에서 현재 활성 노드를 찾고 주변 부분 그래프를 상황별 안내로 바꿔 다음 행동을 돕습니다. 안내가 행동을 강제로 결정하는 구조는 아닙니다.

개선기는 성공·실패 실행 기록을 대조해 그래프를 수정하고, 별도 검증 성능을 유지하거나 개선하는 수정만 채택합니다. 거절된 수정도 보관해 같은 시도를 반복하지 않도록 합니다.

반복 업무 에이전트를 설계할 때 단계·선행조건·분기 관계를 명시하고 별도 평가 과제를 마련하는 참고 자료로 활용할 수 있습니다.
