SoDam O-Brain: Claude Code용 로컬 기억·그래프

Claude Code의 확정된 대화 내용을 로컬 SQLite에 기록하고 검색·그래프로 관리하는 선택형 플러그인/웹 앱

#Claude Code#로컬 메모리#MCP#SQLite

무엇을 할 수 있나요?

Windows 10/11과 Node.js 26.7.x를 안내합니다. 웹 대시보드는 Claude Code 없이 사용 가능하고, 선택형 Claude Code 플러그인·MCP 연결은 자동 저장/되읽기와 7개 기억 도구를 제공합니다.

기억은 로컬 SQLite에 저장하며 FTS5·로컬 임베딩 검색, 2D/3D 그래프, 백업/내보내기를 지원한다고 제작자 README가 설명합니다. Codex용 포팅판은 별도 저장소이자 이미 등록된 별도 카드입니다.

제작자는 Apache-2.0을 안내합니다. 첫 설치 때 npm 패키지와 임베딩 모델을 다운로드하며 Claude Code 모델 서비스의 데이터 정책은 별개입니다.

살펴볼 점
  • 직접 설치·성능·보안 실측은 하지 않았습니다. 자동 추출 대상의 개인정보·비공개 업무 정보는 DB/백업/내보내기 및 다음 AI 문맥에 남을 수 있습니다.
  • 시크릿 자동 가림은 누락될 수 있습니다. MCP 저장 권한과 시작/종료 훅 실행 권한을 확인하고 민감하지 않은 자료로 먼저 검토하세요.
  • 기본 SDK 세션 수집은 꺼져 있지만 OBRAIN_CAPTURE_SDK=1은 수집 범위를 넓힙니다. '로컬 저장'을 Claude Code/모델로 전송되지 않음이라는 뜻으로 해석하지 마세요.
