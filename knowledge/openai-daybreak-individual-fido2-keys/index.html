OpenAI Daybreak 개인 접근: 10월 1일까지 물리 FIDO2 보안 키 요건

OpenAI의 보안 연구자용 Trusted Access for Cyber(Daybreak) 개인 계정은 물리 하드웨어 보안 키만 로그인 수단으로 둬야 한다. 공식 도움말 기준 요건과 확인 방법

#OpenAI#Daybreak#보안 키#FIDO2#계정 보안

무엇을 할 수 있나요?

OpenAI 도움말에 따르면 Daybreak는 OpenAI의 Trusted Access for Cyber 프로그램이며 Daybreak Blue·Red가 그 안의 접근 등급입니다. 승인된 방어 목적 보안 작업(자신이 소유·운영하거나 명시적으로 허가받은 시스템)에 쓰입니다.

개인 Trusted Access에는 자격 있는 유료 요금제, Advanced Account Security, 호환되는 물리 FIDO2 하드웨어 보안 키가 필요하고, 하드웨어 키만 등록된 로그인 수단이어야 합니다. 기존 개인 사용자는 2026년 10월 1일까지 이 요건을 충족해야 접근이 유지됩니다. 조직 단위 접근은 별도 온보딩 절차를 따릅니다.

기기나 비밀번호 관리자에 저장되는 소프트웨어·동기화 패스키는 인정되지 않습니다. OpenAI 계정에 등록된 다른 패스키는 화면 안내에 따라 제거해야 하지만, 기기나 비밀번호 관리자에서 무관한 패스키까지 지울 필요는 없습니다.

확인 방법: chatgpt.com/cyber에 해당 계정으로 로그인해 'Your eligibility'에서 요금제·계정 보안·보안 키·신원 확인 상태를 점검합니다. 키가 인식되지 않으면 오류 메시지·스크린샷·브라우저와 기기 정보를 준비해 지원팀에 문의하되, 복구 키나 자격증명은 보내지 않습니다.

살펴볼 점
  • 공식 도움말 안에서도 필요한 최소 키 개수가 '최소 1개'와 '1개로는 부족' 으로 엇갈리게 적혀 있습니다. 분실 대비로 2개를 준비하는 편이 안전하다는 것은 제안이며, 최종 기준은 eligibility 페이지 표시를 따르세요.
  • 마감일 이후 요건이 바뀔 수 있습니다. 이 카드는 2026-09-28 기준 공식 도움말 확인이며 실제 등록 과정을 검증하지 않았습니다.
