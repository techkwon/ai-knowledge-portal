Openjutsu: 오픈 가중치 기반 영상 인물·오브젝트 교체 도구

영상과 캐릭터 사진을 넣으면 카메라·컷·사운드트랙을 유지한 채 영상 속 인물을 교체하는 오픈소스 ComfyUI 기반 앱. MiniMax H3·SAM 3.1·Qwen3-VL을 자신의 GPU에서 구동

#ComfyUI#MiniMax H3#SAM 3.1#Qwen3-VL#영상 편집

무엇을 할 수 있나요?

Next.js 화면과 ComfyUI 워크플로를 결합한 영상 인물·오브젝트 교체 앱입니다. 영상과 캐릭터 사진으로 주요 인물·머리·옷을 바꾸거나 사물을 추가·제거할 수 있다고 README는 설명합니다. 원본 카메라 움직임·컷·사운드트랙을 유지하도록 구성됐지만 모든 생성 결과가 원본을 정확히 보존한다는 보증은 아닙니다.

영상은 MiniMax H3로 생성하고, 인물 추적은 SAM 3.1, 장면·인물 설명은 Qwen3-VL(8B INT8 기본, 4B FP8/Gemma 4 E2B INT8 선택 가능)을 사용합니다. 전부 오픈 가중치 모델이며 자신의 GPU에서 로컬로 구동합니다.

Simple(단일 인물 교체)·Advanced(최대 4명, 역할별 교체, 몽타주 지원)·Object swap(변경/제거/배경 교체) 세 모드를 제공하며, Fix faces(얼굴 복원)·Fix colours(색보정) 후처리 기능도 포함합니다.

실행 조건·참고 성능: NVIDIA GPU, ComfyUI 0.41.2 이상, Node.js 22.6 이상, Python 프록시와 다수의 커스텀 노드·모델이 필요합니다. 제작자 테스트 환경은 RTX 4060 Ti 16GB와 시스템 RAM 64GB이며 H3 INT8 모델을 RAM에서 스트리밍합니다. 이 환경에서 480p 6초 생성 약 6~13분, 얼굴 복원은 768p 17초·4청크 약 28분(모델 로딩 포함)을 보고했습니다. 일반 GPU의 최소 사양이나 실측 보장으로 해석하지 마세요.

살펴볼 점
  • 앱 코드는 MIT지만 모델 라이선스는 별개입니다. Fix faces의 InsightFace buffalo_l은 비상업적 연구용 전용이고, Bingsu/adetailer의 Ultralytics YOLO 가중치는 AGPL-3.0으로 안내됩니다. 상업적 이용 전 선택한 모델·기능의 조건을 개별 확인해야 합니다.
  • 거울·창문 반사는 아직 처리하지 못한다고 문서는 설명합니다. 반사에 원래 사람이 남고 그 사람의 머리·의상·체형이 교체 캐릭터에 다시 섞일 수 있어 반사가 없는 소스를 권장합니다.
  • 공식 Comfy Developer Platform 배포 경로는 저장소 문서에 안내되어 있으나 '아직 테스트되지 않음(Not tested yet)'이라고 명시되어 있습니다.
  • 직접 설치·실행·성능 재현은 하지 않았으며, 저장소 README에 기재된 설명과 수치를 확인한 것입니다.
  • 공유·터널 배포는 강한 인증과 HTTPS가 필요하며, 비밀번호를 공유한 사람은 같은 작업에 접근하는 단일 소유자 앱이라고 문서는 경고합니다. 얼굴·참조 영상의 이용 동의와 초상권·저작권을 확인하고 합성 결과를 실제 촬영처럼 오인시키지 않도록 사용하세요.
