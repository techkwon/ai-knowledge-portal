HarnessRouter: 에이전트 하네스 통합 라우터

Codex·Claude Code 등 서로 다른 에이전트 하네스를 하나의 API로 전환해 붙일 수 있는 자체 호스팅 인프라 계층

#에이전트 하네스#셀프호스팅#오픈소스#API

무엇을 할 수 있나요?

공식 GitHub README에 따르면 HarnessRouter는 Codex, Claude Code 등 기존 에이전트 하네스를 OpenAI Responses 호환 API 뒤에 세워 제품에서 플러그인처럼 바꿔 끼울 수 있게 하는 셀프호스팅 인프라입니다. 자체 정의한 Unified Harness Protocol(UHP)을 구현하며, 세션 유지·스트리밍·파일·취소·구조화된 실패 처리를 API 레벨에서 지원한다고 설명합니다.

Docker 한 줄 명령으로 커뮤니티 에디션을 자체 서버에 띄우고, 원하는 모델 제공자 API 키를 콘솔에 연결한 뒤 기본 제공 하네스로 작업을 실행하거나, Agent instructions·Tools·Skills를 조합해 커스텀 하네스를 만들 수 있습니다. 콘솔에서 검증한 하네스는 API 키를 발급해 제품 백엔드에서 metadata.harness_id로 호출하는 구조입니다.

공식 문서는 토큰·ID·해시 같은 긴 값을 프롬프트에 직접 넣지 말고 파일 첨부나 환경변수(vault: 참조 등)로 전달하라고 권고하며, 이렇게 전달된 값은 응답·스트림·추적 기록에서 자동 마스킹된다고 설명합니다.

살펴볼 점
  • 커뮤니티 에디션은 자체 인프라에 직접 배포·운영해야 하며, 기본 로그인 정보를 즉시 바꾸고 인스턴스를 외부에 노출하지 않도록 안내합니다. 매니지드 Cloud 버전은 별도 상용 서비스입니다.
  • 벤치마크·비용 비교 수치는 자체 공개 자료(harnessrouter.ai/benchmarks) 기준이며, 실제 도입 전 자신의 작업에서 재현 검증이 필요합니다. 설치·성능은 이번에 직접 실측하지 않았습니다.
