Xiaomi MiMo-V2.6 에이전트 강화학습 환경 데이터셋 공개

코드·보안·지식 작업·웹 개발·음악 작곡 5개 영역의 에이전트 RL 과제와 검증기를 묶은 Xiaomi MiMo 공식 Hugging Face 데이터셋(Apache-2.0)

#Xiaomi MiMo#강화학습#데이터셋#Hugging Face#에이전트 평가

무엇을 할 수 있나요?

Xiaomi MiMo 공식 Hugging Face 조직이 LLM 에이전트용 강화학습(RL) 훈련 환경 데이터셋 'MiMo-V2.6-RL-oss'를 Apache-2.0 라이선스로 공개했습니다.

데이터셋 카드에 따르면 5개 영역으로 나뉩니다: 코드(소프트웨어 엔지니어링, 실행 가능한 테스트로 검증), 사이버(취약점 재현, 규칙 검사), 일반(지식 작업, 루브릭 기반 채점), 비주얼(웹 개발, 시각 채점), 음악(기호 음악 작곡, 규칙 검사).

코드 영역 예시는 실제 오픈소스 이슈 형식의 문제 설명과 과제별 Docker 이미지·작업 경로 정보를 담고 있습니다. 과제 실행용 Docker 이미지(Docker Hub)와 훈련 코드(GitHub XiaomiMiMo/verl) 링크가 함께 제공됩니다.

활용 방향: 에이전트 RL 연구나 평가 환경을 설계할 때 영역별로 검증기(테스트·규칙·루브릭·시각 채점)를 어떻게 나눴는지 참고하는 자료로 쓸 수 있습니다.

살펴볼 점
  • 데이터 규모·품질이나 모델 성능 기여는 검증하지 않았습니다. 코드 과제는 외부 오픈소스 저장소에서 유래하므로 재사용 시 원 저장소 라이선스도 확인하세요.
  • 사이버(취약점 재현) 과제는 격리된 승인 환경에서만 다뤄야 합니다. 이 카드는 공식 데이터셋 카드 확인이며 실행 테스트가 아닙니다.
