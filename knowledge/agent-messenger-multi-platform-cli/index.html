Agent Messenger: 여러 메신저를 연결하는 CLI·SDK

Slack·Discord·Teams·LINE·KakaoTalk 등 메시징 플랫폼을 공통 CLI와 TypeScript SDK로 다루는 프로젝트로, 개인 세션 권한을 사용할 수 있어 보안 검토가 중요합니다.

#Agent Messenger#메신저 연동#CLI#권한 검토

무엇을 할 수 있나요?

공식 README는 플랫폼별 CLI, 구조화된 JSON 출력, TypeScript SDK와 에이전트 스킬을 제공합니다. 읽기·검색·메시지 전송 등 지원 기능은 플랫폼별 표와 문서를 확인해야 합니다.

일부 플랫폼은 데스크톱·브라우저에서 세션 인증 정보를 읽고 다른 플랫폼은 QR·휴대전화 코드·봇 토큰 등을 사용합니다. 개인 세션으로 작동하면 자신의 이름과 권한으로 메시지를 보낼 수 있다는 점이 핵심입니다.

연결하기 전에 필요한 플랫폼만 선택하고 인증 방식·인증 정보 저장·전송 권한을 검토하세요. 읽기 중심 작업과 실제 발송을 분리하고, 조직 계정에서는 정책과 담당자의 허가를 먼저 확인하세요.

살펴볼 점
  • 프로젝트가 제공하는 개인 세션 연동을 플랫폼의 공식 승인이나 조직 관리자 승인으로 오해하면 안 됩니다.
  • 공개된 c99c1af9 커밋의 KakaoTalk 저장 코드는 자격 정보를 JSON으로 직렬화해 파일에 쓰고 0600 권한을 설정합니다. Windows 권한 한계 TODO도 있습니다. 이는 해당 커밋 확인이며 최신 버전 보안 전체에 대한 감사가 아닙니다.
  • 세션 파일·디버그 로그·백업을 채팅이나 공개 저장소에 올리지 마세요. 설치·로그인·메시지 전송 테스트는 하지 않았습니다.
