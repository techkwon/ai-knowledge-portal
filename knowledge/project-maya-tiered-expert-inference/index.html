Project Maya: GPU·RAM·NVMe에 전문가를 나눠 두는 로컬 추론

대형 MoE 모델의 전문가 가중치를 계층적으로 배치하고 OpenAI·Anthropic 호환 API를 제공하는 추론 엔진

#로컬 LLM#MoE#오프로딩

무엇을 할 수 있나요?

공식 README는 GLM-5.3-Flash와 DeepSeek-V4.1-Flash-1017용 엔진을 안내합니다. 자주 쓰는 전문가를 GPU에, 나머지를 RAM과 NVMe 파일에 두고 접근하는 방식입니다.

채팅 UI와 OpenAI·Anthropic 호환 API를 제공하지만, 사용할 모델의 큰 저장 공간·RAM·GPU와 메모리 대역폭을 함께 검토해야 합니다. 낮은 VRAM으로 파일이 들어간다는 사실과 긴 문맥에서 빠른 응답은 같은 기준이 아닙니다.

기본 안내는 x86-64 Linux·NVIDIA·CUDA 환경이며 AMD와 Windows는 실험적 지원으로 구분합니다. 문서의 지원 목록을 Mac 지원 근거로 해석하지 않습니다.

살펴볼 점
  • 커뮤니티 영상의 저가 PC 가격·초당 토큰·긴 프롬프트 처리 수치를 보편 성능으로 옮기지 마세요. 모델·양자화·문맥·메모리 구성이 서로 다릅니다.
  • Maya 코드는 MIT이지만 선택 모델·파일의 조건은 별개입니다. 선택형 DFlash2 drafter에는 CC BY-NC-ND 4.0 비상업 제한이 명시됩니다. 원격 API에는 인증과 네트워크 제한을 적용하세요.
  • 공식 문서 확인 기준이며 설치·실행·성능을 직접 시험하지 않았습니다.
