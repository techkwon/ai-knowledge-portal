Orca 감독형 멀티에이전트 개발 스킬

PRD를 작업 의존성 그래프로 나누고 파일 소유권·계획 승인·독립 검증으로 병렬 개발을 관리하는 커뮤니티 Claude 스킬

#Orca#Claude Code#오케스트레이션#작업 분할

무엇을 할 수 있나요?

프로젝트 문서는 환경 조사, 계약 확정, 작업 DAG 설계, 병렬 구현, 통합, 점검 순서를 제시합니다. 작업별 파일 소유권을 정해 동시 수정 충돌을 줄이는 절차를 포함합니다.

PRD를 준비한 뒤 개발 계획을 먼저 검토하고 승인하는 방식입니다. 공유 타입과 의존성을 구현 전에 확정하고 워커의 완료 보고와 별도로 결과를 검증하도록 설계되어 있습니다.

Orca 실행, 오케스트레이션 활성화, 기존 커밋과 깨끗한 작업 트리가 사전 조건입니다. 설치는 저장소 안내에 따라 프로젝트 전용 또는 전역 Claude 스킬 경로를 선택합니다.

살펴볼 점
  • Orca 공식 제품 기능 자체가 아닌 커뮤니티 스킬입니다. 문서의 검증 환경은 macOS Orca 1.4.161이며 다른 버전의 명령 호환성을 보장하지 않습니다.
  • 오케스트레이션은 실험적 기능입니다. 에이전트 수에 따른 사용량 증가를 고려하고 작은 변경에는 단일 에이전트를 우선 검토하세요. 설치·실행 성능은 직접 검증하지 않았습니다.
