MagikaDocumentFromPixel: OCR 이전 이미지 흐림 점검

촬영 이미지를 선명·흐림·불확실로 분기하는 가벼운 선명도 게이트. 글자를 읽는 범용 OCR이 아니라 OCR·VLM 호출 전 품질 확인에 쓴다.

#이미지 품질#흐림 감지#OCR 전처리#오픈소스#PyTorch

무엇을 할 수 있나요?

Duy Tran Thanh(Brad Duy)의 MobileNetV3 기반 모델이다. RGB 영상에 라플라시안 엣지 정보를 더해 선명/흐림을 분류하고, 낮은 확신도에는 uncertain을 반환해 재촬영 또는 재검토로 보낼 수 있다. Google Magika의 파일 형식 식별이나 범용 OCR과는 별개다.

제작자 안내는 Python 3.10 이상, GitHub 코드·requirements, Hugging Face best.pt 체크포인트로 추론하는 경로를 제공한다. CPU 선처리 및 ONNX 변환을 설명하지만 이 환경에서 설치·실행하지 않았다.

제작자는 GoPro Large 시험 분할에서 F1 0.9803, 정확도 0.9806, CPU 단일 스케일 약 17ms/이미지, 모델 17MB를 보고한다. 이 수치는 자체 보고이며 실제 문서 사진 성능은 검증하지 않았다. 코드 라이선스는 저장소의 MIT 고지다.

살펴볼 점
  • GoPro 모션블러 위주 학습이라 초점 흐림·저조도·압축 손상·스캐너 왜곡에는 성능 보장이 없다. 현장 샘플로 임계값과 재촬영 기준을 검증하세요.
  • 제작자 벤치마크와 배포/모바일 변환 가능성은 독립 검증이 아니다. 사진에 민감정보가 있다면 외부 서비스 업로드 여부를 별도로 판단하세요.
  • 공식 제작자 자료 확인 기준이며 다운로드·설치·추론·성능 실측은 하지 않았습니다.
