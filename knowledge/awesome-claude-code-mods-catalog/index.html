Awesome Claude Code Mods: 2,600여 개 커뮤니티 확장 카탈로그

GitHub 공식 README 기준, Claude Code 2.1.287 이상에서 동작하는 커뮤니티 제작 mod(함수 훅)를 자동 스캔·검증해 분류한 카탈로그 저장소입니다.

#Claude Code#플러그인#오픈소스#확장

무엇을 할 수 있나요?

공식 README에 따르면 이 저장소는 Claude Code 2.1.287 이상에서 동작하는 mod(JavaScript/TypeScript 함수 훅으로 인터페이스나 동작을 바꾸는 플러그인)를 GitHub에서 자동으로 스캔해 모은 커뮤니티 카탈로그입니다. 2026년 10월 6일 기준 2,685개 mod가 등록되어 있으며, 각 mod가 읽기·쓰기·실행·네트워크 접근 중 무엇을 하는지 Claude의 검증기로 스캔한 결과를 함께 보여줍니다.

카탈로그는 용도별로 분류되어 있습니다: 사용량·비용 대시보드(cctop, token-ledger 등), 대기 중 미니게임, Git/PR/CI 연동, 메모리·컨텍스트 관리, 렌더링(mermaid·수식 등), 멀티 에이전트 워크플로우 등. mod 설치는 `claude --plugin-dir` 로컬 플러그인 방식이나 각 mod의 설치 안내를 따르면 됩니다.

저장소는 공식 Anthropic 디렉터리가 아니라 독립적인 커뮤니티 스캔임을 명시하며, 검증은 소스 코드를 실행하지 않고 정적으로 확인하는 수준이라 실제 런타임 안전성을 보장하지 않는다고 밝힙니다.

살펴볼 점
  • 공식 Anthropic 카탈로그가 아니라 독립 운영되는 커뮤니티 스캔 결과입니다. 소스 검증은 정적 분석 수준이므로 설치 전 각 mod의 소스와 접근 권한을 직접 확인해야 합니다.
  • mod 다수가 네트워크 호출이나 파일 읽기/쓰기 권한을 가지므로, 민감한 저장소나 데이터가 있는 환경에서는 권한 범위를 먼저 검토하세요.
