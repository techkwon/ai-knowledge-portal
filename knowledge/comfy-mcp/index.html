Comfy MCP

AI 에이전트에서 로컬 ComfyUI 또는 Comfy Cloud를 연결해 템플릿 탐색·워크플로 실행·결과 수집을 수행하는 공식 MCP

#MCP#워크플로 자동화

무엇을 할 수 있나요?

로컬 연결은 `comfy-mcp` stdio 서버가 자신의 ComfyUI 설치를 제어하고 실제 설치된 노드·모델을 조회합니다. Python 3.10 이상, comfy-cli 1.14.0 이상과 ComfyUI 워크스페이스가 필요하며 실행 도구에는 구동 중인 ComfyUI가 필요합니다.

클라우드 연결은 `https://cloud.comfy.org/mcp`를 사용합니다. 클라이언트의 OAuth 또는 API 키 지원을 확인하고 로컬 연결과 구분해 작업 위치를 지정하세요.

템플릿·모델·노드를 탐색한 뒤 적절한 기존 템플릿을 실행하고 완료를 기다려 결과를 수집하는 흐름입니다. 로컬에서는 워크플로 검증 후 실행하고, 클라우드 결과 다운로드에는 클라이언트의 파일·셸 접근이 필요할 수 있습니다.

살펴볼 점
  • 클라우드 MCP는 공개 베타로 API와 동작이 바뀔 수 있습니다. 탐색과 생성의 과금 조건은 다르며 문서는 클라우드 생성에 활성 구독이 필요하다고 안내합니다.
  • 로컬 실행도 파트너 모델을 사용하면 외부 처리와 크레딧 소비가 발생할 수 있습니다. 민감한 입력·인증키를 공유하지 말고 실행·업로드·공유 전에 비용과 공개 범위를 확인하세요.
  • 공식 문서를 확인한 상태이며 실제 연결·생성 테스트를 수행한 것은 아닙니다.
