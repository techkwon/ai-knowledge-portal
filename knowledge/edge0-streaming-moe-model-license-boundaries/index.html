Edge0: 스트리밍 MoE 추론과 코드·모델 이용조건 구별

구형 35B의 Mac 지원과 최신 145B·120B의 NVIDIA 배포 범위를 나눠 보는 로컬 추론 프레임워크

#Edge0#MoE#공개 가중치#라이선스

무엇을 할 수 있나요?

Edge0는 희소 MoE 모델을 소비자용 장비에서 실행하기 위한 추론 프레임워크입니다. edge0-infer가 모델 폴더에 맞는 엔진을 선택하고 CLI·로컬 서버·채팅 앱 경로를 제공합니다.

현재 공개 설명에서 145B·120B는 Qwen3.8-Flash-Next 계열의 latent MoE이며 edge0-strata 엔진을 이용합니다. 배포·빌드 대상은 Linux 또는 Windows의 NVIDIA GPU와 CUDA 13입니다.

이전 35B는 별도 네이티브 엔진으로 Apple Silicon의 Metal·CPU와 iOS·Android 등 플랫폼을 지원합니다. 최신 모델 성능표의 Apple M2 Ultra 행은 측정 결과이지 해당 모델의 macOS 릴리스 제공을 뜻하지 않습니다.

프레임워크 코드는 Apache-2.0이고 포함된 Strata 코드는 별도 MIT 조건을 유지합니다. 최신 모델의 Edge0 기여분에는 Edge0 Community Model License 1.0, Qwen 상위 재료에는 Qwen Community License 1.0을 각각 검토해야 합니다.

Edge0 모델 조건은 교육·연구·개인 사용·내부 조직 사용과 일반적인 생성 결과의 상업 사용을 허용하되, 모델 유료 배포·상업 추론/미세조정 서비스·독립 상업 코딩/오피스 비서에는 별도 서면 허가를 요구합니다. 이는 Qwen의 별도 허가 요구를 없애지 않습니다.

살펴볼 점
  • 모델·양자화·운영체제·엔진별 지원이 다릅니다. 큰 모델의 시험용 메모리 제한 수치를 최소 요구 사양으로 읽거나 모든 모델이 Mac에서 배포된 것으로 해석하지 마세요. 설치·모델 실행·벤치마크는 하지 않았습니다.
  • Qwen 조건은 Model as a Service 또는 AI Work Assistant 사업자의 상업 사용에 별도 허가를 요구하며 내부 사용 예외가 있습니다. 대규모 상업 제품에는 표시 요건도 있으므로 원문을 확인하세요. Edge0와 Qwen의 허가는 서로 대체되지 않습니다.
  • 모델 배포 범위 기록은 실제 학습/변환 원본 리비전의 독립 검증이나 별도 Qwen 상업 허가의 증거가 아니라고 명시합니다. 과거 유효한 허가와 새 지정 범위도 구별해야 합니다.
  • 재배포는 코드·모델 각각의 라이선스, 상위 라이선스, 저작권·출처 고지와 수정 기록을 보존해야 합니다. 생성 결과의 제3자 권리까지 보장하는 허가는 아닙니다. 개인정보 처리 안전성·아동 대상 서비스 적합성을 검증하지 않았습니다.
