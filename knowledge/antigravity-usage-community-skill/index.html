Antigravity Usage 쿼터 조회 스킬

Antigravity CLI의 사용량 정보를 에이전트 채팅과 터미널에서 읽기 쉽게 보여 주는 커뮤니티 스킬

#사용량#쿼터#Antigravity

무엇을 할 수 있나요?

Google 공식 기능 자체가 아닌 커뮤니티 확장입니다. 제작자 문서에 따르면 Antigravity CLI의 `agy` 사용량 조회 결과를 가공해 모델 그룹별 잔여 쿼터와 초기화 시각을 표시합니다.

지원 환경에 스킬을 등록한 뒤 `/usage`, `/quota` 또는 사용량을 묻는 자연어 요청을 이용하는 흐름입니다. 터미널 스크립트는 `--json`, `--raw`, `--tz` 옵션을 제공하고 기본 시간대는 KST입니다.

설치 스크립트는 글로벌 등록 외에 복사 모드와 워크스페이스 지정 옵션을 안내합니다. 기존 CLI 인증과 실제 환경에서의 호환성을 먼저 확인하세요.

살펴볼 점
  • 원격 설치 스크립트를 바로 실행하기보다 내려받아 변경 파일과 실행 내용을 검토하세요. 이 카드에서는 설치·실행하지 않았습니다.
  • 쿼터 표시는 조회 시점의 정보이며 계정별 요금제·사용 가능 모델을 보장하지 않습니다. 인증 정보와 원본 출력은 공개 저장소에 올리지 마세요.
