Claude Commerce Agents: 승인형 상거래 에이전트 예제

쇼핑 안내와 판매자 운영을 분리하고 쓰기 작업을 사람의 승인 뒤 적용하는 Anthropic 참조 구현

#Claude#승인 절차#참조 구현

무엇을 할 수 있나요?

쇼핑 에이전트와 판매자 에이전트를 Messages API, Claude Agent SDK, Managed Agents에서 실행하는 구조를 제공합니다. 소매·여행·통신·공연의 네 가지 데모가 포함됩니다.

데모는 Python 3.11 이상과 Node 22, API 키를 요구합니다. 쇼핑 체크아웃은 실제 결제 대신 호스트에 장바구니를 전달하며, 판매자 쓰기 작업은 승인 대기 변경으로 준비합니다.

도입 실험은 검색·상품 상세 또는 읽기 전용 지표부터 시작하세요. 자체 백엔드에 인증과 권한 검사를 연결하고 승인 화면을 별도로 검증하는 것이 좋습니다.

살펴볼 점
  • 예제 앱에는 인증이 없습니다. 실제 고객 데이터나 결제 시스템을 바로 연결하지 마세요.
  • 공식 README는 유지보수와 외부 기여를 받지 않는 참조 구현이라고 명시합니다. 운영용 완제품이나 안전 보증이 아닙니다.
