Claude 시스템 프롬프트 공개본: 웹·앱과 API의 동작 차이 읽기

Claude 웹·모바일에 주기적으로 갱신되는 시스템 프롬프트가 적용되며 API에는 적용되지 않는다는 Anthropic 공식 설명과 확인 범위

#Claude#시스템 프롬프트#Anthropic#API

무엇을 할 수 있나요?

Anthropic 공식 문서에 따르면 Claude 웹 인터페이스와 모바일 앱은 대화를 시작할 때 현재 날짜 같은 최신 정보를 제공하고, Markdown 코드 작성 등 일부 응답 행동을 유도하는 시스템 프롬프트를 사용합니다.

공개 페이지는 이 프롬프트를 모델별·날짜별로 확인할 수 있게 하며, Anthropic은 응답을 개선하기 위해 내용을 주기적으로 갱신한다고 설명합니다.

중요한 경계: 웹·모바일의 시스템 프롬프트 변경은 Claude API에 적용되지 않습니다. 같은 모델 이름을 보더라도 claude.ai와 API 결과가 다른 이유를 점검할 때 이 차이를 먼저 확인할 수 있습니다.

Claude 4.6 세대부터 각 모델 ID는 하나의 고정 스냅샷을 가리키므로 해당 모델에는 공개 항목이 하나만 제공됩니다. 재현 가능한 비교가 필요하면 모델 ID와 사용 표면(웹·앱·API)을 함께 기록하세요.

살펴볼 점
  • 공개본만으로 서비스 내부의 모든 정책·도구 설정을 설명할 수 있다고 가정하면 안 됩니다. 문서가 공개한 범위만 참고하세요.
  • 공개 시스템 프롬프트를 복사해 API에 넣는다고 웹·앱과 완전히 같은 동작이 재현되는 것은 아닙니다.
