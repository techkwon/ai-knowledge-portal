GPT-6 Sol·Luna: 비용 효율 중심 GPT-6 라인업 확장

OpenAI 공식 발표. 최상위 모델 GPT-6 Astra 아래에 더 저렴하고 빠른 Sol·Luna를 추가해 API 가격을 GPT-5.6 대비 절반으로 낮춘 모델 확장

#OpenAI#GPT-6#API 가격#모델 선택

무엇을 할 수 있나요?

OpenAI가 공식 블로그에서 GPT-6 Astra의 하위 라인업으로 GPT-6 Sol과 GPT-6 Luna를 발표했습니다. Astra와 같은 학습 방식을 저비용·고속 모델에 적용해 전문 업무·사실성·코딩·컴퓨터 사용·정합성 성능을 유지하면서 API 가격을 GPT-5.6 프로모션 가격 대비 50% 낮췄다고 설명합니다.

가격표 기준 GPT-6 Sol은 입력 100만 토큰당 4달러에서 2달러로, 출력은 20달러에서 10달러로 인하됐고, GPT-6 Luna는 입력 0.2달러에서 0.1달러, 출력 1.2달러에서 0.5달러로 인하됐습니다(가격은 발표 시점 기준이며 변동될 수 있습니다).

공식 발표는 최고 성능이 필요한 작업에는 여전히 Astra를 권장하고, Sol·Luna는 반복적이거나 예산 제약이 있는 업무를 더 저렴하게 처리하기 위한 용도로 소개합니다. AutomationBench 등 벤치마크 비교 수치도 함께 제시되어 있습니다.

살펴볼 점
  • 벤치마크 수치는 OpenAI가 자체 공개한 테스트 결과이므로, 실제 업무 적용 시에는 자신의 작업으로 별도 검증이 필요합니다.
  • 가격·성능은 출시 이후 변경될 수 있어 사용 전 공식 페이지에서 최신 수치를 재확인해야 합니다.
