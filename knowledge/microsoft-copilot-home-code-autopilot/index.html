Microsoft Copilot Home·Code·Autopilot: 대화, 앱 제작, 지속형 에이전트의 분화

Copilot을 대화·위임의 Home, 샌드박스 앱 제작 Code, 계속 작동하는 클라우드 에이전트 Autopilot으로 확장한 Microsoft의 2026년 공개 계획

#Microsoft Copilot#Copilot Code#Autopilot#Microsoft 365#에이전트

무엇을 할 수 있나요?

Microsoft는 새 Copilot을 Home, Code, Autopilot 세 축으로 재구성했습니다. Home은 Chat과 장시간 위임 작업인 Cowork를 한곳에 모으고 Word·Excel·PowerPoint 문서를 대화 옆에서 직접 만들고 편집하는 시작 화면입니다.

Code는 자연어로 앱, 추적기, 대시보드, 자동화와 워크플로를 만드는 기능입니다. GitHub Copilot 기반 기술을 쓰되 코드는 샌드박스에서 실행되고, 조직 테넌트 안에 안전하게 호스팅하는 Copilot Managed Runtime과 연결됩니다.

Autopilot은 이전 Scout의 새 이름으로, 목표와 역할을 받은 뒤 채널을 지켜보고 후속 요청·반복 업무를 계속 처리하는 클라우드 에이전트입니다. 자체 ID, 메모리, 컴퓨터, 작업공간을 가지며 Teams·Outlook 등에서 권한과 감사를 적용받습니다.

Home과 Code는 Frontier 프로그램부터 순차 배포되고 Autopilot은 비공개 미리보기를 확대합니다. Cowork·Code·Autopilot 같은 장시간 에이전트 기능은 사용량 기반 과금 대상이므로 기능 평가와 함께 비용 정책을 설계해야 합니다.

살펴볼 점
  • 발표 시점 기준 단계적 미리보기 계획입니다. 조직·요금제·지역에 따라 기능명, 배포 시점, 실제 사용 가능 범위가 달라질 수 있습니다.
  • 샌드박스·테넌트 호스팅이 자동으로 안전을 보장하지 않습니다. 플러그인 권한, 데이터 경계, 승인 단계, 감사 로그와 사용량 한도를 관리자가 검토해야 합니다.
