Hermes Agent Advanced Delegation: 서브에이전트에 모델/프로필 라우팅 추가하기

Hermes Agent 공식 플러그인으로, 기존 단일 delegation 모델 대신 작업별로 이름이 붙은 모델 라우트(model_map) 또는 프로필 라우트(profile_routes)를 골라 서브에이전트를 실행할 수 있게 하는 공식 확장

#Hermes Agent#서브에이전트#delegation#Nous Research#플러그인

무엇을 할 수 있나요?

핵심 원리: 기본 Hermes는 모든 서브에이전트를 하나의 delegation.model/provider로 실행하지만, 이 플러그인은 두 가지 라우팅 모드를 추가합니다. Model routes(model_map)는 작업이 fast/deep/local처럼 미리 정의한 이름 중 하나를 고르게 하고, Profile routes(profile_routes)는 서브에이전트를 다른 Hermes 프로필(고유 모델·자격증명·스킬·SOUL.md 포함)로 통째로 실행하게 합니다. 한 번에 한 모드만 활성화됩니다.

사용 절차: `hermes plugins install advanced-delegation`으로 설치(Hermes 0.22.5 이상 필요) 후 `hermes delegation config`로 모드를 고르고 라우트를 등록합니다. 대화 중에는 `/delegation model_map` 같은 명령으로 모드를 전환할 수 있으며, `--now`를 붙이면 현재 대화에 즉시 적용되지만 프롬프트 캐시가 한 번 끊깁니다.

활용: 간단한 조회/요약 작업은 저비용 모델로, 어려운 디버깅은 고성능 모델로 자동 분기하거나, 특정 서브작업만 별도 자격증명·스킬을 가진 프로필로 격리 실행하고 싶을 때 쓸 수 있습니다.

살펴볼 점
  • Profile routes는 나열된 프로필의 자격증명·크리덴셜 풀·SOUL.md·터미널 정책까지 서브에이전트가 그대로 쓰게 되므로, 키·터미널 접근을 믿고 맡길 프로필만 등록해야 한다고 공식 경고가 명시되어 있습니다.
  • Hermes 0.22.0~0.22.4는 설치 자체가 거부되고, 0.22.0 미만에서는 설치는 되지만 동작하지 않고 경고만 남깁니다.
  • 직접 설치·구성 실행은 하지 않았으며 공식 문서 내용만 확인한 것입니다.
