Claude로 Chrome·Safari·Android·Windows·Linux의 치명적 취약점 발견

Anthropic이 미공개 내부 연구 모델로 브라우저·OS의 5가지 실제 공격 체인(크롬 원격코드실행, 사파리 SOP 우회, 안드로이드 잠금화면 우회, 윈도우 원격 DoS, 리눅스 제로클릭 RCE)을 발견하고 조정된 취약점 공개(90일) 절차로 각 벤더에 신고·패치한 공식 사례

#Anthropic#Claude#취약점 연구#보안#CVE

무엇을 할 수 있나요?

핵심 내용: Anthropic은 공개하지 않은 내부 연구 모델로 수개월에 걸쳐 크롬 V8·Safari JavaScriptCore·Android 기기간 전송 프로토콜·Windows 커널 QUIC 구현·Linux 커널 네트워킹 스택에서 다단계 공격 체인 5건을 직접 작성했습니다. 모두 코디네이티드 취약점 공개(90일 패치 기한, 이후 45일 추가 유예) 절차를 따라 각 벤더(Google, Apple, Microsoft, 리눅스 커뮤니티)에 신고됐고, 크롬은 62개 CVE가 할당·패치(Chrome 156)됐으며 윈도우 취약점은 CVE-2026-33096, 리눅스 커널 취약점은 CVE-2026-98432로 각각 공개 패치됐습니다.

방법론 인사이트: 다수의 스캐닝 에이전트를 병렬로 돌리고 스캐너별로 추가로 찾아낸 취약점 수를 측정해 커버리지를 동적으로 추적하는 플랫폼을 구축했다고 설명합니다. 전략은 순수 커버리지 기반, 목표 기반(이 앱이 고객 데이터를 노출하는가), 위협모델 기반(문서화된 위협모델을 우회하는가) 등으로 나뉘며, 확인된 발견마다 자동 변종 분석을 추가로 수행합니다.

실무 교훈: 기존 취약점 백로그를 없애는 것만으로는 절반만 해결되며, 신규 취약점이 코드베이스에 유입되는 속도를 PR 시점에서 스캔해 낮추는 것이 나머지 절반이라는 운영 교훈을 제시합니다. 이를 위해 Claude Code 플러그인(보안 가이드)을 공개 저장소로 배포했습니다.

살펴볼 점
  • 이 내부 연구 모델은 공개 제품이 아니며, 기재된 다섯 사례는 모두 사전 보고·벤더 패치가 완료된 뒤 공개된 것으로, 재현 가능한 공격 코드는 포함되어 있지 않습니다.
  • 방어자용으로 Anthropic의 Cyber Verification Program(심사를 통과한 보안 전문가 대상 고급 사이버 역량 제공)이 확장 운영 중이라고 언급되나, 일반 사용자에게 바로 열려 있는 서비스는 아닙니다.
  • 직접 재현·실측하지 않았으며, 수치(CVE 개수, 패치 시점 등)는 Anthropic 공식 발표를 그대로 인용한 것입니다.
