Hermes Bot Mode

여러 개의 Hermes 프로필을 하나의 데스크톱 화면에서 마치 여러 봇 팀처럼 관리할 수 있게 해주는 플러그인

#Hermes Agent#멀티 프로필#에이전트 운영

무엇을 할 수 있나요?

기존 Hermes는 프로필 분리, Skill, Cron, 기억 기능이 있었지만 CLI와 설정 파일 중심이라 프로필 전환을 직접 해야 했습니다.

Bot Mode는 이 기능들을 하나의 데스크톱 화면에 통합해 여러 AI 프로필을 팀처럼 동시에 운영할 수 있게 해줍니다.
