T3 Code: 기존 코딩 에이전트를 모바일·웹에서 이어서 관리하기

컴퓨터에 설치·인증한 코딩 에이전트를 모바일·웹·데스크톱 인터페이스로 제어하는 control surface

#원격 개발#Codex#Claude Code

무엇을 할 수 있나요?

공식 README는 Claude Code·Codex·Cursor·Grok Build·OpenCode·Antigravity 등을 지원 대상으로 열거합니다. 호스트 컴퓨터의 제공자를 먼저 설치하고 인증해야 하며 별도의 모델 구독을 제공하는 앱은 아닙니다.

모바일·웹·Electron 데스크톱 인터페이스에서 호스트의 에이전트를 제어하는 구조입니다. 원격 작업 중에는 호스트 컴퓨터와 서버가 계속 실행되고 접근 가능해야 합니다.

T3 Connect, 사설 네트워크의 pairing, SSH 등 접속 방식이 나뉩니다. 계정 로그인만 저장했다고 호스트가 연결되는 것은 아니며 연결 방식과 권한 모드를 확인해야 합니다.

살펴볼 점
  • 초기 프로젝트로 버그 가능성을 명시합니다. 권한·파일 변경·커밋·푸시 범위를 검토하고 중요한 프로젝트는 백업하세요.
  • Pairing은 기기 접근을 승인하는 동작입니다. 연결 링크·토큰을 공개하지 말고 무인증 포트 포워딩으로 대체하지 마세요. 제공자별 약관·구독 조건도 따로 확인해야 합니다.
  • 공식 문서 확인 기준이며 설치·실행·성능을 직접 시험하지 않았습니다.
