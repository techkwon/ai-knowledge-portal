Mistral 학습 데이터 사용 거부 설정

Vibe와 Studio·API의 학습 데이터 설정을 각각 점검하는 공식 개인정보 보호 절차

#Mistral#Vibe#API#데이터 관리

무엇을 할 수 있나요?

Vibe 웹에서는 Admin 패널의 Manage > Vibe > Privacy에서 Allow your interactions to be used to train our models를 끕니다. 업로드 문서도 입력 데이터에 포함됩니다.

모바일에서는 Settings > Data & Account Controls에서 Enable data sharing을 해제합니다.

Studio·API는 Admin 패널의 Privacy > Anonymous improvement data를 별도로 끕니다. Vibe에서 거부해도 API 설정은 자동 변경되지 않습니다.

살펴볼 점
  • Vibe 일반 사용자와 Enterprise의 기본 설정은 다릅니다. Enterprise는 기본적으로 학습에서 제외되며 관리자 수준에서 설정을 관리합니다.
  • 학습 사용 거부를 데이터 삭제나 모든 보관 중단과 동일하게 해석하지 마세요. 민감한 자료는 조직 정책을 먼저 확인하세요.
