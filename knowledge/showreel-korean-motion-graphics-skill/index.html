showreel: 한글 모션그래픽 영상을 기획부터 QA까지 혼자 완성하는 Claude Code 스킬

콘셉트 후보 비교, 리서치, 나레이션·음악 생성, 코드 기반 렌더링, 비평·재작업, 음량/섬광 자동 검수까지 한 번의 요청으로 이어지는 영상 제작 파이프라인

#실무 가이드

무엇을 할 수 있나요?

공식 저장소 설명에 따르면 showreel은 "제품 출시 60초 홍보 영상 만들어줘" 같은 요청을 받으면 사용자만 알 수 있는 사실(주제, 꼭 들어갈 정보, 자료 위치)만 묻고, 분위기·길이·나레이션 여부 같은 창작 결정은 Claude가 콘셉트 후보 3개 이상을 채점해 직접 고른다고 설명합니다.

리서치 단계에서는 영상에 들어가는 모든 사실에 출처 URL과 신뢰도를 붙이고 날짜를 달력과 대조하며, 오디오(나레이션·음악·효과음)를 먼저 만든 뒤 그 타이밍에 맞춰 HTML/Canvas/WebGL/three.js로 장면을 코드로 렌더링한다고 설명합니다.

완성 전 매 초안마다 8가지 기준(템플릿 느낌 여부, 한글 활용, 리듬 등)으로 각 구간을 유지/수정/재작업으로 판정하는 비평 루프를 거치고, 최종본은 음량·섬광·정지 화면·발음(STT)까지 자동 점검한 보고서와 함께 전달된다고 명시합니다.

나레이션에는 ElevenLabs API 키가 필요하며(음악은 유료 플랜 필요), 요구 도구는 ffmpeg·Node 20+·Python 3.10+·Chrome이고 macOS에서 개발·검증됐다고 안내합니다.

살펴볼 점
  • 공식 문서는 "Claude는 오디오를 들을 수 없다"고 명시해 음량·발음 검수는 수치로만 확인되므로, 공개 전 실제로 들어보고 확인해야 한다고 권고합니다.
  • 한글 나레이션·타이포그래피 규칙 중심으로 개발됐으며 다른 언어는 별도의 스크립트·발음 규칙이 필요하다고 안내합니다. ElevenLabs 사용은 해당 서비스 요금제 약관을 따릅니다.
