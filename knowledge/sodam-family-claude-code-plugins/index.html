SoDam Family (소담 패밀리)

Claude Code를 더 안전하고 편리하게 쓰도록 돕는 7개 플러그인 묶음 — 위험 행동 차단, 사용설명서 점검, 반복 작업 자동화, 계획·검토 워크플로 등

#Claude Code#플러그인#안전 게이트#워크플로 자동화#한국어

무엇을 할 수 있나요?

SoDamHarness(위험 행동 자동 차단·백업 확인), SoDamContext(CLAUDE.md/AGENTS.md 점검·정비), SoDamLoop(반복 작업 자동화, 최대 8회·30분 제한), SoDamAgentic(계획-실행-검토), SoDamPrompt(초보자용 한국어 글쓰기 스킬), SoDamReverse(역공학 시도 차단), SoDamGraph(진행 상황 시각화) 7개 플러그인으로 구성됩니다.

각 플러그인은 개별 GitHub 저장소로 분리되어 있어 필요한 기능만 선택적으로 설치할 수 있습니다.

비개발자도 이해할 수 있도록 한국어 설명과 초심자용 개념 안내를 README에 포함하고 있습니다.

살펴볼 점
  • 라이선스·상업적 사용 조건은 저장소의 법률/저작권 안내 섹션을 직접 확인해야 합니다.
  • 각 하위 플러그인의 설치·실행 요구사항(Claude Code 버전 등)이 다를 수 있어 개별 저장소 문서를 함께 참고해야 합니다.
