PS5LM: 탈옥한 PS5에서 llama.cpp로 로컬 LLM 구동

탈옥한 PlayStation 5의 GPU에서 llama.cpp·Vulkan으로 GGUF 모델을 구동하고, 같은 네트워크의 기기에 OpenAI·Anthropic 호환 API를 제공하는 네이티브 홈브류 앱.

#llama.cpp#GGUF#PS5#Vulkan#로컬 LLM

무엇을 할 수 있나요?

현재 공식 GitHub README와 웹사이트에 따르면 PS5LM은 PS5의 RDNA 2 GPU에서 llama.cpp의 Vulkan 백엔드로 GGUF 모델을 실행하는 네이티브 앱입니다. 모델과 문맥에 약 11.4GB의 공유 메모리를 사용하며, 같은 네트워크의 브라우저나 코딩 도구에 OpenAI /v1/chat/completions 및 Anthropic /v1/messages 호환 API를 제공합니다.

개발자가 PS5 Slim에서 공개한 측정치는 Qwen 3.5 9B(Q4_K_M)에서 초당 55토큰, Qwen 3.8 27B(UD-Q2_K_XL)에서 약 20토큰입니다. 이는 특정 모델·양자화·문맥 설정의 개발자 측정값이며, 이 카드 작성자가 재현한 성능은 아닙니다. 앱의 모델 플래너로 파일과 문맥이 실제 메모리에 들어가는지 확인해야 합니다.

공식 설치 안내는 펌웨어 7.00~13.60의 탈옥된 PS5와 kstuff-lite·etaHEN·ShadowMountPlus를 요구합니다. 현재 앱은 PS5LM Plus의 네이티브 GPU 앱에서 발전했으며, 별도 title ID(PPSA99575)로 나란히 설치할 수 있다고 설명합니다. 이전 CPU 페이로드 문서의 메모리·지원 모델 사양과 혼합하지 않아야 합니다.

저장소 라이선스는 GPL-3.0-or-later이며 llama.cpp는 MIT 라이선스를 유지합니다. 공식 저장소는 Sony SDK 파일·키·펌웨어·모델 가중치를 포함하지 않는다고 명시합니다.

살펴볼 점
  • 2026-10-18에 확인한 현재 공식 네이티브 GPU 앱 문서 기준의 자료 정리이며, 직접 설치·실측하지 않았습니다. 성능은 모델·양자화·문맥 길이·기기 상태에 따라 달라집니다.
  • 일반 순정 PS5에서 바로 실행되는 앱이 아니라 탈옥·홈브류 환경이 필요합니다. 기기 지원·이용약관·콘솔 계정에 미치는 영향과 네트워크 API의 접근제어를 별도로 확인하세요. 외부 인터넷에 무방비로 노출하지 않는 구성이 필요합니다.
