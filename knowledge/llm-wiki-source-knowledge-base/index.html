#위키#문서 검색#출처 추적

무엇을 할 수 있나요?

PDF·Office 문서·웹 자료 등을 가져오면 원본 자료, 생성 위키, 구조 규칙을 나누어 관리합니다. 변경되지 않은 자료는 캐시를 이용해 중복 처리를 줄이도록 설계되어 있습니다.

원본 자료만 검색하는 Read Sources Only 모드와 생성 페이지의 출처 연결을 이용해 답변의 근거를 다시 확인할 수 있습니다. 생성 위키를 사실로 확정하기 전에 원문과 대조하세요.

프로젝트별 모델 설정, Chat과 Ingest의 별도 모델 선택, 선택적 벡터 검색과 로컬 MCP 연결을 제공합니다. 소량의 공개 문서로 가져오기·질의·검토 흐름부터 시험하는 것이 좋습니다.

살펴볼 점
  • 데스크톱 앱이라고 해서 모델 처리가 모두 기기 안에서 이뤄지는 것은 아닙니다. 선택한 모델·임베딩·문서 파서·웹 검색 제공자에 전송되는 범위와 비용을 확인하세요.
  • 개인정보나 학생 자료는 비식별화하고 파일·셸 접근 권한을 제한하세요. 제작자 문서만 확인했으며 설치와 답변 정확도 검증은 하지 않았습니다.
