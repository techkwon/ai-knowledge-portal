Record & Replay: Mac 작업 시연을 스킬로

Mac 화면 작업을 녹화해 재사용 스킬 초안을 만드는 기능. 재실행은 고정 매크로가 아닌 현재 도구·맥락에 따른 작업입니다.

#macOS#Computer Use#스킬

무엇을 할 수 있나요?

공식 문서는 macOS에서 Computer Use를 사용할 수 있고 활성화한 환경을 전제로 합니다. 데스크톱 앱의 Work 또는 Codex에서 Plugins의 Record a skill을 선택하고 녹화 권한을 승인한 뒤 작업을 시연하면 스킬 초안을 만듭니다.

재실행은 화면 좌표를 그대로 재생하는 매크로가 아닙니다. 스킬을 새 작업의 맥락으로 삼아 당시 사용 가능한 Computer Use, 브라우저와 플러그인으로 다시 수행하므로 화면·권한·도구 상태에 영향을 받습니다.

초보자 시작점: 비민감한 짧은 반복 작업을 고르고 입력값과 성공 기준을 말로 설명하며 시연한 뒤 생성된 스킬과 실행 결과를 직접 검수하세요.

살펴볼 점
  • 녹화에는 작업 창과 내용이 관찰될 수 있습니다. 비밀번호·개인정보·기밀 자료를 제외하고 화면 범위와 녹화 권한을 신중히 선택하세요.
  • macOS와 Computer Use 활성화가 선행 조건입니다. requirements.toml로 Codex를 관리하는 조직에서 computer_use=false로 설정하면 Record & Replay도 사용할 수 없습니다. 계정별 제공 여부를 확인하세요.
  • 외부 발송·파일 변경은 매번 검증하세요. 공식 문서만 확인했으며 녹화·설치·재실행 또는 성능을 독립 시험하지 않았습니다.
