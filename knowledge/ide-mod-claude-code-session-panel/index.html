ide-mod: Claude Code 세션·문서·알림·캐시를 한 패널에서

작업 상태와 확인 요청을 구분하고 문서 탐색·캐시 유지 비용을 함께 살피는 커뮤니티 플러그인

#Claude Code#문서#캐시

무엇을 할 수 있나요?

제작자 README는 Claude Code function-hooks 기반 패널로 에이전트 트리, 파일 탐색과 탭, 세션 문맥·캐시 적중·사용 한도 표시를 설명합니다. 공식 Anthropic 제품이 아닌 커뮤니티 확장입니다.

알림은 완료와 사용자 확인 필요를 구분하며, macOS의 “소리+읽기” 모드에서는 세션 이름을 읽어 어느 작업인지 알아보도록 설계됐다. 이름 변경 추종 개선은 v0.20.0 릴리스에 명시돼 있다.

v0.21.0 릴리스는 백그라운드 에이전트·명령·워크플로가 남아 있을 때 완료 소리를 미루도록 수정했다고 설명한다. 다만 계속 감시하는 작업과 요약 에이전트는 제외하며, 완료 알림을 놓친 작업은 6시간 후 종료로 간주한다. 소리 자체가 산출물 검증을 대신하지 않는다.

캐시 유지는 /cache로 상태를 보고 유지 시간을 조절합니다. README상 마지막 요청을 복제 호출해 만료 전에 캐시를 다시 읽는 방식이며, 작은 대화와 유지 시간에는 제한을 둡니다. 추가 호출이므로 무료 절약 기능으로 단정할 수 없습니다.

HWP·HWPX는 rhwp, PDF는 pdf.js 등 별도 엔진을 이용한다고 명시합니다. 대체 렌더러에서 보이는 모양과 실제 Hancom의 문서 호환성은 별도 확인 대상입니다.

라이선스 파일은 MIT로 사용·수정·상업 이용과 재배포를 허용하되 저작권·허가문 유지 및 무보증 조건을 둔다. 포함된 rhwp와 pdf.js에는 각각 MIT·Apache-2.0 조건이 별도로 적용된다.

살펴볼 점
  • 설치·실행·코드 전체 보안감사·문서 렌더링 검증은 하지 않았습니다. function-hooks는 early access API이며 제작자 테스트 버전은 2.1.290입니다.
  • 캐시 유지 호출·보드 요약도 사용량을 소모할 수 있습니다. API 공식 문서상 기본 캐시는 5분이며 1시간 TTL은 추가 비용입니다. API 가격과 구독 한도를 같은 것으로 보지 마세요.
  • 로컬 파일·요청 기록·다른 도구 세션을 읽는 기능과 인수인계 게시 기능이 있습니다. 금융·학생·계정 자료를 제외하고 공유 전 원문·비밀정보를 직접 확인하세요.
  • MIT는 플러그인 코드 허락이지 Claude 모델·구독·제3자 서비스 이용권이 아닙니다. 계정의 연령·지역·상업적 사용 가능 여부는 해당 서비스 약관을 별도 확인해야 합니다.
  • 완료 소리는 산출물·테스트·남은 작업의 검증을 대신하지 않습니다. 음성 읽기 설명은 macOS 기준이며 다른 OS의 동일 동작을 보장하지 않습니다.
