Apple LensVLM-9B: 압축된 텍스트 이미지에서 필요한 쪽만 펼쳐 읽는 VLM

긴 문서를 압축 이미지로 훑고 관련 페이지만 원본으로 확장하는 9B 비전 언어 모델로, 5x·10x·15x 압축 옵션과 Apple 모델 라이선스가 적용됩니다.

#Apple#LensVLM#VLM#긴 문맥#압축

무엇을 할 수 있나요?

Hugging Face 모델 카드는 LensVLM을 텍스트를 압축한 이미지로 훑어본 뒤 학습된 도구로 관련 있는 페이지만 압축 전 형태로 선택 확장하는 9B 비전 언어 모델이라고 설명합니다.

기반 모델은 Qwen3.5-9B 계열이고, 논문은 arXiv 2605.07019, 코드는 apple-aiml-research/ml-lensvlm 저장소에 있습니다. 데모 스크립트는 텍스트 파일과 질문을 받아 5x, 10x, 15x 압축을 고를 수 있습니다.

모델 파일은 Apple Machine Learning Research Model License를, 함께 제공되는 코드는 Apple Sample Code License를 따릅니다. 긴 문서 질의응답에서 문맥 비용을 줄이는 접근으로 참고할 만합니다.
