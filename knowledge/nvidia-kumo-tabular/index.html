NVIDIA Kumo Tabular: 표 데이터 사전학습 모델

분류·회귀 작업에 라벨된 예시를 맥락으로 주고 바로 추론하는 NVIDIA의 표 데이터 사전학습 모델 사용법

#Kumo Tabular#NVIDIA#structured-data-models#In-context learning

무엇을 할 수 있나요?

Hugging Face 공식 모델 카드는 Kumo Tabular를 분류·회귀용 사전학습 표 데이터 기반 모델로 소개합니다. 레이블이 있는 예시(context)를 함께 넣으면 추가 학습 없이 새 데이터의 클래스 확률을 바로 예측합니다.

사용은 공식 저장소 `structured-data-models`(pip install git+https://github.com/NVIDIA/structured-data-models.git)를 설치하고, `sdm.TableTensor.from_pandas`로 표를 텐서로 바꾼 뒤 `sdm.models.KumoTabular(task="classification")`에 context 행과 query 행을 넣는 방식입니다.

가중치 라이선스는 OpenMDW 1.1입니다. 소규모 정형 데이터셋에서 라벨링 예시만으로 빠르게 분류·회귀를 시험해보는 용도로 적합합니다.

살펴볼 점
  • 실제 설치·추론 테스트는 하지 않았습니다. GPU 메모리 요구량과 대규모 데이터에서의 실제 정확도는 공식 카드 외 별도 벤치마크로 확인하세요.
  • OpenMDW 1.1 라이선스 조건을 상업적 용도 적용 전 직접 확인하세요.
