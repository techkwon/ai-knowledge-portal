Workspace Studio 맞춤 트리거·단계·외부 연동·웹훅

Apps Script 맞춤 로직과 8개 외부 서비스, HTTP 웹훅을 Workspace Studio 흐름에 연결하는 Google 공식 기능과 관리자 통제 항목

#Google Workspace Studio#Apps Script#웹훅#외부 연동

무엇을 할 수 있나요?

Google은 Workspace Studio 흐름에 네 가지 확장 기능을 추가했습니다. 맞춤 트리거는 외부 앱 이벤트로 흐름을 시작하고, 맞춤 단계는 Apps Script 같은 사용자 로직을 실행하며, 웹훅은 외부 엔드포인트에 HTTP 요청을 보냅니다.

외부 연동은 베타로 Asana, Confluence, HubSpot, Jira, Mailchimp, QuickBooks, Salesforce, Slack을 지원합니다. Workspace와 외부 서비스 사이에서 데이터를 전달해 업무 흐름을 자동화하는 용도입니다.

관리자 설정은 기본적으로 꺼져 있습니다. 관리 콘솔에서 맞춤 단계, 외부 연동, 웹훅을 각각 허용하고 승인 요구 수준을 조정할 수 있으며, 일부 상위 에디션은 웹훅 URL 허용 목록을 설정할 수 있습니다.

교육 환경에서는 Education Fundamentals·Standard·Plus와 일부 교육 부가 기능에서 제공됩니다. 기능이 보이지 않으면 사용자 권한뿐 아니라 관리자 활성화와 Rapid/Scheduled Release 배포 시점을 함께 확인하세요.

살펴볼 점
  • 외부 연동 단계는 Gmail·Calendar 같은 Google 계정 데이터를 제3자 서비스와 공유할 수 있습니다. 학교에서는 승인 정책, 최소 권한, 데이터 처리 조건을 먼저 검토하세요.
  • 기능 제공 범위와 롤아웃 일정은 조직 에디션·릴리스 트랙에 따라 달라집니다. 공식 관리자 도움말의 최신 값을 확인하세요.
