Snorkl MCP: 학생 과제·응답을 Claude for Teachers에서 바로 조회·배정하기

Snorkl 교사 계정을 Claude for Teachers에 MCP로 연결해 수업·과제·학생 점수를 대화로 조회하고, 확인 후에만 새 과제를 배정할 수 있는 공식 플러그인

#실무 가이드#커뮤니티 인사이트

무엇을 할 수 있나요?

Snorkl 공식 도움말에 따르면 MCP(Model Context Protocol)로 Snorkl 교사 계정을 Claude for Teachers에 연결하면 내보내기·복사 없이 대화로 학급·과제·학생 진행도를 물어볼 수 있다고 안내합니다.

예시 질문으로 "분수 활동에서 학생들이 어디서 막혔는지 요약해줘", "처음 시도와 최고 시도 사이에 점수가 올랐는지 비교해줘" 등을 제시하며, 학생이 말한 설명 녹음 전사나 화이트보드 그림까지 조회할 수 있다고 설명합니다.

공식 FAQ는 AI가 데이터를 바꾸거나 지울 수는 없고, 새 과제를 배정할 때만 미리보기를 보여준 뒤 사용자 확인을 받고 실행한다고 명시합니다. 설치는 Claude for Teachers 데스크톱 앱의 설정 → 기능 → 플러그인에서 Snorkl을 검색해 설치하고 교사 계정으로 로그인하는 방식입니다.

Snorkl의 모든 교사 요금제에 MCP 접근이 포함되어 있다고 공식 문서가 밝히고 있습니다.

살펴볼 점
  • 학생 응답·녹음 전사·점수 등 민감한 교육 데이터가 AI 대화에 노출되므로(공식 문서는 원음 자체가 아닌 전사 텍스트 접근을 설명함), 학교·교육청의 학생 데이터 처리 정책과 동의 절차를 먼저 확인하는 것을 독립적으로 권고합니다.
  • Claude for Teachers 외 다른 AI 도구에서 쓰려면 Snorkl 지원팀에 별도로 MCP 서버 연결 정보를 요청해야 하며, 이 글은 공식 도움말 기준이고 실제 사용 테스트는 하지 않았습니다.
