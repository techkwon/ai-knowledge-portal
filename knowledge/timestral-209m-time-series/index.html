Timestral-209M: 수치 시계열의 확률 예측 모델

단변량·다변량 시계열과 공변량을 입력받아 미래 수치의 분위수 예측을 만드는 209M 모델

#시계열#Mistral#예측

무엇을 할 수 있나요?

공식 카드는 수치 시계열·공변량을 입력받아 여러 분위수의 확률 예측을 출력하는 모델로 설명합니다. 자연어 챗·번역이나 이미지·실시간 영상 생성 모델이 아닙니다.

공식 실행 저장소는 Python 3.10 이상·PyTorch 2.4 이상과 CPU 또는 GPU 추론을 안내합니다. 익명화된 수치나 공개 시계열로 예측과 실제값의 오차를 비교하는 실습의 출발점으로 활용할 수 있습니다.

코드의 Apache-2.0과 가중치의 Modified MIT는 별개입니다. 가중치 조건은 회사·고용주의 전월 전세계 연결 월매출 2,000만 달러 초과 시 별도 상업 라이선스 등을 안내하므로 원문을 확인해야 합니다.

살펴볼 점
  • 예측은 확률적 추정이며 실제 미래나 개인의 성과를 보장하지 않습니다. 데이터 누수·결측·평가 기간과 사용 목적을 먼저 정하세요.
  • 일반 MIT로 단순 표기하거나 호스팅이 무료라고 가정하지 마세요. 제공자 벤치마크와 실제 환경 처리량은 구별해야 합니다.
  • 공식 문서 확인 기준이며 설치·실행·성능을 직접 시험하지 않았습니다.
