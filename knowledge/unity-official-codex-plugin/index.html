Unity 공식 Codex 플러그인: 프로젝트 확인부터 검증까지

Unity 6 이상에서 엔진 전용 스킬을 사용하는 개발 흐름

#실무 가이드#커뮤니티 인사이트

무엇을 할 수 있나요?

Unity 공식 안내는 Unity 엔지니어가 작성한 31개 스킬과 Unity 6 이상 호환을 설명합니다. UI, 타일맵, 렌더링, 오디오, 물리와 현지화 등 작업별 지침을 제공합니다.

시작: 공식 안내에 연결된 플러그인 디렉터리와 문서에서 설치 절차를 확인합니다. 기존 프로젝트는 별도 브랜치나 복사본에서 열고 엔진 버전·사용 패키지·UI 시스템부터 확인하도록 요청합니다.

활용 예시: 메뉴를 만들어 달라는 요청 전에 UI Toolkit인지 uGUI인지 검사하게 합니다. 작업 후 빌드·테스트·로그와 실제 화면을 함께 확인합니다.

unity-cli 스킬은 에디터 설치, 프로젝트 생성·열기, 패키지 관리와 빌드·테스트·로그 확인을 지원합니다.

살펴볼 점
  • 공식 스킬이 모든 오류를 없애는 것은 아닙니다. 설치·성능 시험을 수행한 자료가 아니라 공식 문서 확인입니다.
  • 패키지 변경과 에디터 설치는 별도 승인·백업 절차를 두고, 외부 모델에 보낼 코드와 자산의 권한을 확인하세요.
