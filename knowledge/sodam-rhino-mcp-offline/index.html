SoDam Rhino Offline MCP: JSON 입력으로 3DM 건물 모델 생성

Rhino 설치·라이선스 없이 건물 위치·크기·종류를 적은 JSON에서 구성요소별 메시가 담긴 .3dm 파일을 만들고 재검수하는 Windows용 로컬 MCP 도구

#MCP#Rhino#3D 모델링#로컬 우선#커뮤니티 인사이트

무엇을 할 수 있나요?

SoDam Rhino Offline MCP는 건물의 위치·크기·종류 정보를 담은 JSON 설계 입력 파일에서 구성요소별 메시가 포함된 Rhino용 `.3dm` 파일을 생성하는 Windows 전용 로컬 도구입니다. 공식 README(한국어 사용 설명서, 2026-09-25 기준)는 Rhino 실행 파일이나 라이선스 없이 `rhino3dm` 라이브러리로 3DM을 직접 작성하며, 생성된 파일을 다시 읽어 치수를 검수하는 기능도 포함한다고 설명합니다.

MCP(Model Context Protocol)를 통해 Codex나 Claude Code 같은 AI 호스트가 로컬 프로그램의 도구를 호출하는 구조이며, 스킬은 AI에게 작업 절차를 안내하고 실제 파일 생성은 프로젝트의 MCP 서버가 수행합니다. Blender 연동을 통한 재질 렌더링과 기존 Blender 장면 가져오기 기능도 문서에 포함되어 있습니다.

README는 사진만으로 정확한 3D가 자동 완성되는 제품이 아니며 Rhino의 모든 기능을 복제하지도 않는다고 명시적으로 한계를 밝히고 있습니다. 독립 치수 평가와 테스트 현황도 문서에 별도로 정리되어 있습니다.

살펴볼 점
  • Windows 전용 로컬 도구로 설명되어 있으며, 이번 확인은 공식 README 본문을 직접 읽은 것이고 실제 설치·3DM 생성 테스트는 수행하지 않았습니다.
  • README 자체가 '사진 입력만으로 정확한 3D 자동 완성'이 아니라고 명시한 한계이며, Rhino 전체 기능을 대체하지 않는다는 점을 공식 문서가 강조하고 있습니다.
