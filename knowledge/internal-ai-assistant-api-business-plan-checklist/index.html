사내·학교 시스템에 AI 비서를 붙일 때: 개인 구독 대신 API·업무용 플랜을 검토하는 이유

여러 사람이 쓰는 내부 AI는 계정 공유와 API·업무용 계약을 구분해야 합니다. 학습 미사용·보관·외부 전송·기관 승인을 각각 점검하는 절차입니다.

#사내 AI 비서#API#데이터 학습#최소 권한#도구 승인

무엇을 할 수 있나요?

먼저 사용자를 나눕니다. 혼자 쓰는 개인 구독 앱과 동료·학생이 함께 쓰는 내부 서비스는 계약과 데이터 조건이 다릅니다. 여러 사람이 질문하는 서비스라면 모델 호출은 API나 업무용 플랜으로 설계하는 것이 출발점입니다.

데이터 조건을 확인합니다. OpenAI는 ChatGPT Business·Enterprise·Edu와 API 플랫폼의 입력·출력을 기본적으로 모델 학습에 쓰지 않는다고 밝히고, Anthropic도 Claude for Work와 API 같은 상업용 제품의 입력·출력을 기본적으로 학습에 쓰지 않는다고 안내합니다. 개인 요금제는 개인 설정에 따라 달라지므로 조직이 중앙에서 통제하기 어렵습니다.

데이터베이스는 직접 열어 주지 말고 필요한 조회만 하는 중간 API를 둡니다. 읽기 전용 계정, 삭제·수정 차단, 조회 범위 제한으로 시작하고, 쓰기 작업이 필요하면 사람이 확인하는 승인 단계를 둡니다. OpenAI 에이전트 안전 지침도 도구 승인을 켜 두고 외부 입력이 도구 호출을 직접 조종하지 못하게 구조화하라고 권합니다.

자주 묻는 질문 목록과 답변 근거 문서를 먼저 만들고, 실제 질문 표본으로 정확도·응답 시간·비용을 측정한 뒤 범위를 넓힙니다.

학습 미사용과 보관 없음은 다릅니다. OpenAI 공식 API 데이터 문서는 명시적 동의가 없으면 입력을 모델 학습에 쓰지 않더라도 악용 모니터링 로그와 기능별 애플리케이션 상태가 별도로 남을 수 있다고 설명합니다. 기본 악용 모니터링 로그는 원칙적으로 최대 30일이며 법률·안전상 예외가 있습니다.

conversations·files 같은 기능은 삭제 때까지 상태가 남을 수 있습니다. 모든 API 데이터가 24시간 뒤 사라진다고 일반화하지 말고 endpoint별 보관·삭제·만료 설정을 확인하세요. Zero Data Retention과 Modified Abuse Monitoring은 사전 승인과 기능별 제약이 있으므로 누구나 즉시 쓸 수 있는 공통 설정이 아닙니다.

도입 점검표에는 제품·플랜, 입력 데이터 종류, 저장 위치·기간, 외부 MCP/커넥터, 접근 권한, 삭제 절차와 기관 승인을 따로 둡니다. 외부 서비스로 보내는 정보는 그 서비스의 별도 보관 조건도 확인합니다.

살펴볼 점
  • 플랜별 데이터 보존 기간, 피드백 버튼 사용 시 저장 범위, 무보관 옵션 자격은 서비스마다 다릅니다. 도입 전 각 회사의 최신 약관과 기관 개인정보 지침을 확인하세요.
  • 학생 개인정보나 미성년자 대상 서비스는 별도 연령·보호 조건이 붙습니다. 관련 카드를 함께 확인하세요.
  • 이번 보강은 OpenAI의 기업 개인정보 안내와 API 데이터 문서 확인입니다. 기존 Anthropic 관련 설명이나 다른 공급자의 최신 약관을 모두 재검토한 것은 아니며 OpenAI 조건을 Aside·Claude·다른 서비스 전체에 적용하지 않습니다. 한국 학교의 사용 허용·국외 이전 적법성·기관 계약은 별도 확인 대상입니다.
  • 직접 API 호출·제품 설정·보안 감사·규정 준수 판정을 하지 않았습니다. 학습 미사용만으로 개인정보 문제가 모두 해결된다는 뜻도, 인터넷 연결 제품이 모두 금지된다는 뜻도 아닙니다.
