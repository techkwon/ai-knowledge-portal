GitHub Education 교사 인증과 Copilot Pro 혜택 확인

학교 이메일·재직 증빙·개인 계정 요건과 신청 심사를 확인하고 승인된 교사의 혜택을 구분하는 안내

#GitHub Education#교사 인증#Copilot Pro#신청 요건

무엇을 할 수 있나요?

공식 신청 안내는 교육자 재직, 검증 가능한 학교 발급 이메일, 소속 증빙과 개인 GitHub 계정을 요구합니다. Settings의 Education benefits에서 신청 절차를 확인합니다.

증빙 이미지에서 현재 소속과 재직 정보를 명확히 확인할 수 있도록 준비하세요. 승인은 GitHub 심사 결과에 따르며 정보가 불명확하면 보완 후 재신청 안내를 확인해야 합니다.

공식 교사 혜택 페이지는 인증된 교육자에게 Copilot Pro 무료 혜택을 안내합니다. 인증 승인과 실제 기능 활성화를 별도로 확인하세요.

살펴볼 점
  • 학교 유형·재직 증빙 등 자격 요건에 따라 심사가 달라집니다. 공식 거절 안내에는 비학위 수여 교육기관 소속도 사유로 언급되므로 초·중·고 교사에게 자동 승인된다고 보장하지 않습니다.
  • 개인 사례로 다른 신청자의 승인·거절 원인을 일반화하지 마세요. GitHub Copilot과 OpenAI Codex는 별도 제품입니다.
  • 신청·서류 업로드·계정 활성화는 이 작업에서 실행하지 않았습니다.
