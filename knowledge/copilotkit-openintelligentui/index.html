OpenIntelligentUI: 대화형 화면 생성 템플릿

질문에 텍스트·기본 구성요소·대화형 UI로 응답하는 개발자용 오픈소스 예제. 두 제공자의 API 키와 비용이 필요합니다.

#CopilotKit#생성 UI#API 키

무엇을 할 수 있나요?

공식 저장소는 질문에 따라 텍스트, 기본 A2UI 구성요소 또는 생성된 HTML·CSS·JavaScript UI를 고르는 채팅 인터페이스 예제를 설명합니다. Next.js 프런트엔드와 Python 백엔드로 구성되며 생성 UI는 격리된 iframe에 표시됩니다.

기본 자가 호스팅은 Node.js 22+, pnpm 9+, Python 3.12+, uv 및 OpenAI와 TypeSafe/Jev의 API 키가 필요합니다. 코드는 MIT이나 각 제공자 사용량 요금과 외부 콘텐츠 조건은 별도입니다. 문서는 브라우저에 입력한 키가 요청 시 앱 서버를 거쳐 공급자에게 전달된다고 설명합니다. 키를 저장하지 않는다는 설명과 외부 전송 여부는 별개입니다.

초보자 시작점: 직접 앱을 만들 계획이라면 공개 예시의 표·계산기처럼 UI 선택 패턴부터 살펴보고, 실제 키를 넣기 전 배포처 신뢰·예상 비용·생성 코드 권한을 검토하세요. 데모 수치나 지도는 검증된 실시간 정보가 아닙니다.

살펴볼 점
  • 생성된 iframe UI가 무해하거나 정확하다는 보장은 없습니다. 외부 네트워크·권한·출력 코드를 검토하고 신뢰할 수 있는 서버에만 키를 입력하세요.
  • 기본 설치의 익명 텔레메트리는 공식 문서에 옵트아웃 방법이 있습니다. 설치 전에 설정을 확인하고, 외부 이미지·지도·텍스트의 권리도 따로 확인하세요.
  • 공식 저장소 문서만 확인했으며 키 발급·설치·실행·보안 또는 성능을 독립 시험하지 않았습니다.
