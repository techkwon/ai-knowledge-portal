Google Drive·Docs 네이티브 Markdown(.md) 지원

Google Drive와 Docs에서 .md 파일을 변환 없이 바로 미리보기·편집·실시간 협업할 수 있게 된 공식 업데이트

#Google Workspace#Google Drive#Google Docs#Markdown

무엇을 할 수 있나요?

공식 안내: Google은 2026-10-05 Workspace 업데이트에서 .md·.markdown 파일을 Drive에 그대로 저장해 렌더링 미리보기하고, Docs에서 파일 형식을 바꾸지 않은 채 편집·실시간 공동작업할 수 있다고 발표했습니다. 10-26 개발자 블로그와 공식 X 계정은 이 기능을 다시 소개했습니다. 최초 안내는 10-05부터 최대 15일 점진 배포이며 모든 Workspace 고객과 개인 Google 계정이 대상이라고 명시합니다.

사용 절차: Markdown 파일을 Drive에 업로드한 뒤 미리보기에서 Markdown/Preview를 전환하거나, 파일을 두 번 클릭해 Docs의 Markdown Mode로 엽니다. 문서 제목 옆 .md 표시로 원래 파일 형식을 확인할 수 있습니다. 공동 편집·댓글·공유와 변경 이력을 활용하되 Docs 문서로 변환된 것으로 혼동하지 마세요.

활용과 제한: README·노트·AI 산출물을 Markdown 원본으로 협업할 때 유용합니다. 다만 Docs의 스마트 칩은 텍스트나 링크로 바뀌고, HTML 서식은 일반 텍스트가 되며, 글자색·하이라이트·텍스트 정렬은 제거된다고 공식 도움말은 설명합니다. 원본 형식 유지가 모든 Docs 서식의 보존을 뜻하지는 않습니다.

살펴볼 점
  • 공식 웹 안내를 확인한 것이며 iOS·Android 등 플랫폼별 세부 동작은 직접 테스트하지 않았습니다. 사용자 댓글만으로 특정 앱의 지원 여부를 확정하지 않습니다.
  • 이 절차는 파일을 Drive에 업로드해 다루는 기능이며 업로드 없는 로컬·오프라인 Markdown 뷰어를 뜻하지 않습니다. 민감한 파일은 조직의 클라우드 저장·공유 정책을 먼저 확인하세요.
  • 직접 업로드·편집·협업 테스트는 하지 않았습니다. 서식이 달라졌다면 공식 도움말은 파일의 버전 기록에서 원본 복원을 안내합니다.
