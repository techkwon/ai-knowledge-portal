Google Drive·Docs 네이티브 Markdown(.md) 지원

Google Drive와 Docs에서 .md 파일을 변환 없이 바로 미리보기·편집·실시간 협업할 수 있게 된 공식 업데이트

#Google Workspace#Google Drive#Google Docs#Markdown

무엇을 할 수 있나요?

핵심 내용: Google Workspace 공식 계정이 2026-10-26 발표한 바에 따르면 Google Drive와 Google Docs 전반에 네이티브 Markdown 지원이 적용되어, .md 파일을 다른 형식으로 변환하지 않고 Drive에서 바로 미리보기하거나 Docs에서 열어 편집하고 실시간으로 공동 작업할 수 있습니다.

활용: AI 도구나 코드 저장소에서 생성되는 README, 노트, 산출물이 대부분 .md 형식인 경우가 많은데, 기존에는 Google Docs 형식으로 변환해야 공유·협업이 편했던 과정을 생략하고 원본 Markdown 그대로 Drive/Docs 생태계에서 다룰 수 있게 되었습니다.

살펴볼 점
  • 발표 시점 기준 iOS 앱에서는 아직 지원되지 않는다는 사용자 댓글이 있었으나, 추후 롤아웃 범위가 바뀔 수 있어 실제 사용 전 각자 환경에서 재확인이 필요합니다.
  • 로컬 디스크에 있는 .md 파일을 업로드하지 않고 바로 포맷된 상태로 열어보는 기능까지 지원하는지는 이 발표만으로 확인되지 않습니다.
  • 직접 사용해 실측하지 않았으며 공식 발표 내용만 확인한 것입니다.
