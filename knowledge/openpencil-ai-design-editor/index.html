OpenPencil: Figma 파일을 여는 오픈소스 AI 디자인 에디터

.fig 파일을 직접 열고 저장할 수 있는 로컬 우선 오픈소스 디자인 에디터로, Claude Code·Cursor·Codex·Gemini CLI 등 코딩 에이전트가 MCP로 디자인 문서를 직접 편집할 수 있게 지원

#디자인 도구#Figma#MCP#오픈소스

무엇을 할 수 있나요?

공식 홈페이지에 따르면 OpenPencil은 .fig 파일을 페이지·컴포넌트·인스턴스·변수·오토레이아웃까지 편집 가능한 레이어로 직접 읽고 다시 .fig로 저장할 수 있는 로컬 우선(local-first) 디자인 에디터입니다. 계정이나 서버 연결 없이 디스크의 파일로 동작하며, MIT 라이선스로 에디터·렌더링 엔진·fig 코덱·CLI가 공개되어 있습니다.

"AI로 디자인하기" 기능은 자체 API 키로 어떤 공급자든 연결하거나, 이미 쓰고 있는 코딩 에이전트(Claude Code, Cursor, Windsurf, Codex, Gemini CLI, 그 외 모든 MCP 클라이언트)를 그대로 연결해 자연어로 캔버스를 편집하게 할 수 있다고 설명합니다.

공식 CLI(openpencil)는 24개 명령(쿼리, 린트, 내보내기, Figma 플러그인 코드 eval 실행 등)을 제공하고, MCP 서버는 122개의 도구를 stdio 또는 HTTP로 노출해 에이전트가 앱이 켜져 있지 않아도 파일을 직접 다루게 합니다. 디자인 결과는 Vue/React 컴포넌트, HTML+Tailwind, Storybook 스토리 등으로 변환해 내보낼 수 있습니다.

팀 협업·AI 호스팅·SSO 등을 포함한 "OpenPencil Cloud"는 초기 접근(Early access) 단계이며, 자체 호스팅(Self-hosted OpenPencil) 기능은 로드맵상 "다음" 단계로 아직 공개되지 않았습니다.

살펴볼 점
  • 이 카드는 공식 홈페이지 설명 기준 정리이며 실제 설치·파일 변환·에이전트 연동 테스트는 하지 않았습니다.
  • 에디터·CLI·fig 코덱 본체는 MIT지만, OpenPencil Cloud(팀 실시간 동기화, 호스팅 AI 등)는 별도 상용/초기 접근 서비스로 라이선스·요금 조건이 다를 수 있습니다. 실제 적용 전 로드맵과 라이선스 범위를 공식 사이트에서 재확인해야 합니다.
  • 디자인 파일을 외부 AI 공급자 API로 보내 편집을 요청하는 경우, 전달되는 디자인 내용(텍스트, 이미지 등)의 처리 정책을 사용하는 공급자 쪽에서 별도로 확인해야 합니다.
