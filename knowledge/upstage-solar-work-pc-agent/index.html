Upstage Solar Work: 폴더 기반 업무를 지원하는 데스크톱 에이전트

Upstage가 문서·반복 업무용으로 소개한 데스크톱 에이전트. 선택한 폴더에서 작업하고 삭제·외부 공유 등에 확인을 요청한다고 안내하며, HWPX·스캔 문서 읽기와 서비스 연동을 소개. 확인한 배포는 프리릴리스

#Upstage#Solar#데스크톱 에이전트#HWPX#문서 자동화

무엇을 할 수 있나요?

공식 소개에 따르면 선택한 폴더의 파일을 읽고 쓰며 문서·발표자료·보고서를 생성·수정하는 앱입니다. 배포 안내는 macOS Apple Silicon(M1 이상), Windows 10/11 x64(Git for Windows 필요), Linux x64이며 Intel Mac에는 웹 버전을 권합니다. 별도 웹·모바일 접점 app.solarwork.dev도 소개하지만 웹 버전이 데스크톱과 같은 로컬 폴더 접근·권한 범위를 갖는다고 확인한 것은 아닙니다.

제작사가 설명하는 동작 원칙: 읽기·정리·이름 변경·새 파일 생성은 자동으로 수행하고, 삭제·휴지통 비우기·외부 공개 공유·선택 범위 밖의 작업 등은 이유를 설명해 확인을 요청합니다. 이는 소개 페이지의 권한 설계 설명이며 독립적으로 검증한 보안 경계나 모든 버전의 확인 절차 보증은 아닙니다.

공식 페이지는 HWPX·스캔 문서·사진 영수증을 읽고 카카오·Gmail·Notion·Jira·Slack 등과 연동할 수 있다고 소개합니다. 조회는 자동, 발송·변경은 확인 후 진행한다는 설명입니다. HWPX 읽기 지원을 원본 HWP/HWPX 양식의 네이티브 작성·편집·레이아웃 보존이 검증된 것으로 해석하면 안 됩니다.

모델·비용: 로그인으로 Solar를 무료 사용량 안에서 이용하는 경로와 Upstage 콘솔 API 키 연결 경로, 다른 모델 선택을 안내합니다. API 키 사용을 무료·무제한 보장으로 해석하지 말고 실제 모델 요금·사용량·속도 제한을 별도 확인해야 합니다. 사내 설치형 기업 버전은 데이터·승인·감사·권한 관리 기능을 제공한다고 소개하지만 구체 운영 조건은 별도 확인 대상입니다.

GitHub 릴리스 목록에서 확인한 v0.1.0-rc.62는 Pre-release로 표시돼 있습니다. 공식 페이지는 SHA256SUMS로 받은 파일을 대조하는 절차를 안내합니다. 체크섬 일치는 파일 무결성 대조일 뿐 개발자 서명·공증·설치·보안성을 직접 검증했다는 뜻은 아닙니다.

살펴볼 점
  • 공식 페이지 기준 아직 정식 출시가 아닌 프리릴리스(-rc) 단계입니다. 기능과 동작이 추후 버전에서 바뀔 수 있습니다.
  • 메일·채팅 연동, 발표자료 생성 등 데모 화면의 구체적 내용(회사명·수치 등)은 페이지 자체에 '시뮬레이션'이라고 명시되어 있어 실제 결과물의 품질을 보장하는 것은 아닙니다.
  • 로컬에 대화·결과물을 저장하고 민감 파일·로그인 원문을 모델에 노출하지 않도록 설계했다는 것은 제작사의 설명입니다. 로컬 저장만으로 모델 호출·문서 인식·연동 과정의 외부 전송이 없다고 단정할 수 없으며, 실제 데이터 처리 위치·보존·접근 권한을 확인해야 합니다.
  • 직접 설치·실행·연동 테스트는 하지 않았으며, 공식 공개 페이지에 기재된 설명을 확인한 것입니다.
