Upstage Solar Work: 내 PC 파일에서 작업을 끝내는 에이전트 데스크톱 앱

Upstage가 공개한 데스크톱 AI 에이전트. 사용자가 고른 폴더 안에서 문서·보고서 작성, 반복 업무 자동화를 수행하며 파일 삭제나 외부 공유 시에만 확인을 요청. 한글(HWPX)·스캔 문서 인식 지원, 현재 프리릴리스(rc) 단계

#Upstage#Solar#데스크톱 에이전트#HWPX#문서 자동화

무엇을 할 수 있나요?

Upstage의 Solar Work는 사용자가 지정한 폴더 안에서 파일을 읽고 쓰며 문서·발표자료·보고서를 자연어 지시로 생성·수정하는 macOS/Windows/Linux 데스크톱 앱입니다. 웹·모바일(app.solarwork.dev)에서도 설치 없이 사용할 수 있습니다.

핵심 동작 원칙: 읽기·정리·새 파일 생성 같은 작업은 알아서 수행하고, 파일 삭제·휴지통 비우기·외부 공개 공유·다른 폴더/컴퓨터 설정 변경처럼 되돌리기 어렵거나 범위를 벗어나는 작업만 사전에 이유를 설명하고 확인을 요청합니다.

한글(HWPX) 문서, 스캔된 계약서, 사진으로 찍은 영수증을 그대로 읽어 처리할 수 있고, 카카오·Gmail·Notion·Jira·Slack 등 기존 서비스 계정을 연결해 대화 중 바로 조회·작업할 수 있습니다(가져오기는 자동, 발송·변경은 확인 후 진행).

로그인 후 Upstage 자체 Solar 모델을 무료 사용량 내에서 쓸 수 있고, Upstage 콘솔 API 키를 연결하면 한도 없이, GPT·Claude·Gemini 등 다른 모델도 선택해 사용할 수 있습니다. 사내 설치형(기업용) 버전은 서버·데이터를 내부에 두고 승인·감사 로그·권한 관리를 제공합니다.

현재 다운로드 가능한 버전은 프리릴리스(-rc) 단계이며, GitHub 릴리스 페이지에 SHA256SUMS로 받은 파일의 무결성을 검증하는 절차가 안내되어 있습니다.

살펴볼 점
  • 공식 페이지 기준 아직 정식 출시가 아닌 프리릴리스(-rc) 단계입니다. 기능과 동작이 추후 버전에서 바뀔 수 있습니다.
  • 메일·채팅 연동, 발표자료 생성 등 데모 화면의 구체적 내용(회사명·수치 등)은 페이지 자체에 '시뮬레이션'이라고 명시되어 있어 실제 결과물의 품질을 보장하는 것은 아닙니다.
  • 비밀번호·인증서 등 민감 파일은 애초에 보지 못하도록 설계되었다고 소개하나, 이는 제작사의 자체 설명이며 독립적인 보안 검증을 거친 것은 아닙니다.
  • 직접 설치·실행·연동 테스트는 하지 않았으며, 공식 공개 페이지에 기재된 설명을 확인한 것입니다.
