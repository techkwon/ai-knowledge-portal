Claude Duet: 미국 Pro·Max 대기명단형 능동 비서

연결한 앱을 살피고 메시지로 일을 위임받는 클라우드 에이전트의 연구 미리보기. 미국 Pro·Max 대기명단 조건부터 확인합니다.

#공식 발표#서비스 범위 확인#승인과 검수

무엇을 할 수 있나요?

공식 소개에 따르면 Claude Duet은 자체 클라우드 컴퓨터에서 연결된 앱을 사용하고, 아침 브리핑과 위임한 작업의 결과를 한 메시지 스레드로 전달하는 능동형 에이전트입니다. 기존 Claude의 메모리·스킬·연결 앱을 활용합니다.

현재 조건: 미국 Claude Pro·Max 구독자 대상 대기명단형 연구 미리보기입니다. Team·Enterprise는 아직 포함되지 않으며, iOS·Android 전용 앱과 claude.ai에서 제공한다고 안내합니다.

초보자 시작점: 지역·플랜·대기명단 조건부터 확인하고, 이용 권한이 생긴 경우 비민감 테스트 자료와 최소 범위의 연결 앱으로 브리핑·답장 초안부터 검토합니다. 메시지 발송·결제 같은 민감한 행동은 내용을 확인한 뒤 승인합니다.

살펴볼 점
  • 일반 공개나 한국 계정의 즉시 이용을 뜻하지 않습니다. 접근 가능 여부는 공식 대기명단과 계정 안내로 확인하세요.
  • Claude의 기존 플랜 사용 한도를 공유하며 백그라운드 확인도 사용량에 포함됩니다. 장기 작업은 일반 대화보다 많은 사용량을 쓸 수 있습니다.
  • 연구 미리보기라 대화·긴급도를 잘못 판단하거나 확인 사이에 도착한 항목을 놓칠 수 있습니다. 개인정보와 외부 발송 내용은 직접 검토하세요.
  • 공식 문서만 확인했으며 가입·설치·작업 수행·보안 또는 성능을 독립 시험하지 않았습니다.
