CogSend: Cloudflare에서 운영하는 소셜 예약 발행 도구

한 초안을 플랫폼별로 다듬어 Mastodon·Bluesky·LinkedIn·Threads·X에 발행하고, API·MCP로 에이전트와 연결하는 셀프 호스팅 도구입니다.

#CogSend#Cloudflare#예약 발행#MCP

무엇을 할 수 있나요?

개인 Cloudflare 계정의 Workers·D1·R2를 사용하고 한 관리자 계정과 자신의 플랫폼 인증 정보로 운영하는 구조입니다.

플랫폼별 문구 수정·스레드 분할·예약 변경·취소·재시도·발행 결과 통계를 지원합니다. 공식 README는 일시 실패를 최대 5회 재시도한다고 안내합니다.

API 키는 읽기 전용과 읽기·쓰기 권한을 구분할 수 있으며 MCP 클라이언트로 초안·예약·게시를 연결합니다. 자동 생성 초안과 실제 공개 발행의 승인 단계를 분리하는 용도로 활용할 수 있습니다.

살펴볼 점
  • 도구 자체 구독료가 없더라도 Cloudflare 무료 한도·R2 결제 수단·플랫폼 API 또는 연결 서비스 비용은 별도 확인해야 합니다.
  • LinkedIn·Threads·X는 OAuth 앱이나 Zernio 등의 연결 구성이 필요합니다. 모든 플랫폼이 로그인만으로 즉시 연결되는 것은 아닙니다.
  • 공개 발행 권한과 인증 정보를 다루므로 최소 권한·2단계 인증·백업을 설정하세요. 설치·게시 테스트는 하지 않았습니다.
