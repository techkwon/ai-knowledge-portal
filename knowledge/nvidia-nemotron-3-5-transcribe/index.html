NVIDIA Nemotron 3.5 Transcribe: 40개 언어 지능형 전사 모델

하나의 오픈 가중치 음성 LLM으로 40개 언어 전사, 31개 언어 번역, 최대 13개 언어 화자 구분을 자연어 지시만으로 수행하는 NVIDIA 공식 모델

#NVIDIA#Nemotron#음성 인식#다국어

무엇을 할 수 있나요?

NVIDIA Nemotron 3.5 Transcribe는 Nemotron 3.5 Lightning 30B-A3B 언어 백본에 음성 인코더와 화자 구분 구성요소를 결합한 음성 증강 언어모델(SALM)입니다. 모델 카드상 오디오 인코더를 포함한 전체 모델은 약 34B 파라미터, 활성 파라미터는 약 4.3B입니다. 공식 기본 배포 예시는 H100 80GB 한 장이며, 다른 GPU에서는 체크포인트 정밀도와 하드웨어 호환표를 확인해야 합니다.

기능: 최대 1시간 녹음의 40개 언어 전사, 영어와 지원표상 31개 언어 사이의 양방향 번역, 13개 언어의 화자별 전사와 요청 시 단어 단위 타임스탬프, 녹음 질의응답을 지원합니다. 전사 스타일은 발화 그대로·정리된 서면형·문맥 반영 등 자연어 지시로 바꿀 수 있습니다. 모든 40개 언어 사이의 임의 쌍방향 번역을 지원한다는 뜻은 아닙니다.

배포·라이선스: BF16·FP8·NVFP4 등 별도 체크포인트가 공개돼 있습니다. 적용 라이선스는 OpenMDW-1.1이며 모델 카드는 상업적·비상업적 이용이 가능하되 라이선스와 제3자 고지·조건을 준수해야 한다고 안내합니다. NVIDIA는 NIM에서 NVFP4+DFlash2를 RTX PRO 6000 Blackwell 단일 GPU로 구동할 때 최대 2,238초 오디오/초 처리량을 보고합니다. 이는 그 구성의 처리량이지 모든 환경의 지연시간이나 일반 GPU 성능을 보증하지 않습니다.

살펴볼 점
  • 오프라인(녹음 파일) 전용 모델로, 실시간 스트리밍/라이브 캡션에는 쓸 수 없다고 공식 모델 카드에 명시돼 있습니다.
  • 공식 벤치마크(Open ASR Leaderboard 등)에서 경쟁 모델 대비 우위를 주장하지만, 이는 NVIDIA 자체 평가 결과이며 모든 언어·환경에서 동일한 정확도를 보장하지는 않습니다.
  • 직접 설치·추론 테스트는 하지 않았으며, 모델 카드와 공식 발표문 확인에 한정합니다.
