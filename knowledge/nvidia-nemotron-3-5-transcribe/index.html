NVIDIA Nemotron 3.5 Transcribe: 40개 언어 지능형 전사 모델

하나의 오픈 가중치 음성 LLM으로 40개 언어 전사, 31개 언어 번역, 최대 13개 언어 화자 구분을 자연어 지시만으로 수행하는 NVIDIA 공식 모델

#NVIDIA#Nemotron#음성 인식#다국어

무엇을 할 수 있나요?

공식 발표(2026-10-28): NVIDIA가 Nemotron 3.5 Lightning 30B-A3B(하이브리드 Mamba-Transformer MoE) 기반의 음성 증강 언어모델(SALM) Nemotron 3.5 Transcribe(NVIDIA-Nemotron-3.5-Transcribe-30B-A4B)를 공개했습니다. 전체 30B 파라미터 중 활성 파라미터는 약 4.3B이며, 단일 GPU(Jetson AGX Thor부터 데이터센터 GPU까지)에서 구동 가능하다고 설명합니다.

기능: 최대 1시간 길이 녹음을 대상으로 40개 언어 전사(발화 그대로/정리된 서면형/문맥 반영/화자 구분/타임스탬프 포함 등 자연어 지시로 스타일 선택), 31개 언어 영어 양방향 번역, 최대 13개 언어 화자 구분(최대 8명), 녹음 내용에 대한 질의응답을 하나의 모델로 처리합니다. 재훈련 없이 지시문만으로 출력 스타일을 바꿀 수 있습니다.

모델 카드와 라이선스: Hugging Face(nvidia/NVIDIA-Nemotron-3.5-Transcribe-30B-A4B) 및 NGC에 BF16/FP8/NVFP4 가중치가 공개돼 있고 상업적 사용이 허용된다고 모델 카드에 명시돼 있습니다. NIM(NVFP4)로는 실시간 대비 최대 2,238배 처리 속도를 보고합니다.

살펴볼 점
  • 오프라인(녹음 파일) 전용 모델로, 실시간 스트리밍/라이브 캡션에는 쓸 수 없다고 공식 모델 카드에 명시돼 있습니다.
  • 공식 벤치마크(Open ASR Leaderboard 등)에서 경쟁 모델 대비 우위를 주장하지만, 이는 NVIDIA 자체 평가 결과이며 모든 언어·환경에서 동일한 정확도를 보장하지는 않습니다.
  • 직접 설치·추론 테스트는 하지 않았으며, 모델 카드와 공식 발표문 확인에 한정합니다.
