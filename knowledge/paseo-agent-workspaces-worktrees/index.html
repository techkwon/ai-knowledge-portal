Paseo: Claude Code·Codex를 작업공간별로 함께 관리하기

기존 코딩 CLI와 인증을 유지하면서 작업·세션·변경 내역을 묶고 worktree로 병렬 작업을 분리하는 개발 환경

#코딩 도구#오픈소스#병렬 작업

무엇을 할 수 있나요?

Paseo는 이미 설치하고 인증한 코딩 CLI를 실행하는 개발 환경입니다. Claude Code는 공식 claude CLI와 Agent SDK, Codex는 공식 codex CLI와 app-server 인터페이스로 연결한다고 문서가 설명합니다. 모델 자체를 배포하는 도구는 아닙니다.

프로젝트 안에 작업공간(workspace)이 있고, 각 작업공간에 여러 에이전트 세션과 터미널·변경 내역을 함께 둡니다. Local 모드는 기존 디렉터리를 사용하고 Worktree 모드는 작업별 Git 디렉터리와 브랜치를 분리합니다. 같은 작업공간의 세션끼리는 작업 파일을 공유합니다.

병렬 작업은 서로 독립적인 요구사항에 별도 worktree를 배정하는 방식으로 설계합니다. 각 변경 내역을 검토하고 테스트한 뒤 병합할 결과를 고릅니다. worktree를 나눠도 네트워크 포트는 같은 컴퓨터에서 공유하므로 개발 서버 포트는 구분해야 합니다.

데스크톱은 macOS·Windows·Linux를 지원한다고 안내하며, 모바일·웹·CLI 클라이언트는 실행 중인 에이전트와 작업공간을 가진 daemon에 연결합니다. 이는 임의의 기존 채팅 자동 동기화 보장이나 서로 다른 프로젝트 파일의 자동 병합을 뜻하지 않습니다.

Claude Code의 사용량은 기존 Claude 플랜 한도를 따르고, Codex는 ChatGPT 로그인 또는 API 키 방식의 기존 한도·과금을 따릅니다. Paseo의 오픈소스 코드 이용권과 모델/구독 서비스 이용권은 별개입니다.

살펴볼 점
  • 직접 설치·실행·연결·병렬 성능 테스트를 하지 않았습니다. 제품 문서의 기능 설명을 독립 요약했습니다.
  • Paseo 자체 코드는 Apache-2.0이며 제3자 구성요소는 각 라이선스를 따릅니다. 상업 이용·수정·배포 시에도 라이선스 사본, 수정 표시, 관련 저작권·NOTICE 등 조건을 지켜야 하며 상표 사용권이 자동 부여되지는 않습니다.
  • 모델 가중치나 Claude/OpenAI 서비스 권리는 이 코드 라이선스에 포함되지 않습니다. 각 제공자의 계정 자격·연령·지원 지역·요금·데이터 정책을 별도 확인하세요. 이 문서 검토로 모든 제공자의 제한을 확인한 것은 아닙니다.
  • 에이전트는 호스트의 파일·터미널에 접근할 수 있습니다. worktree는 파일 분리이지 보안 샌드박스가 아닙니다. 원격 접근 권한과 승인 정책, 비밀정보·학생자료를 다루는 범위를 먼저 제한하세요.
