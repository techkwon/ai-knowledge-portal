Hy-Nomas: 텍스트·카메라로 이어 만드는 비디오 세계

Tencent-Hunyuan이 공개한 세그먼트 기반 상호작용형 비디오 생성 모델과 추론 코드

#Tencent-Hunyuan#비디오 생성#카메라 제어#오픈 모델

무엇을 할 수 있나요?

텍스트 지시나 카메라 궤적으로 이전 문맥을 이어받아 다음 영상 구간을 생성합니다. 코드 저장소와 모델 가중치의 공식 배포처가 별도입니다.

표준 추론 예시는 8개 GPU 병렬 설정이고, RTX 4090 단일 GPU 예시는 별도 INT8 DiT·FP8 디코더·CPU 오프로드 구성을 사용합니다. Linux/CUDA 설치 또는 제작자 Docker 이미지와 모델 자산 다운로드가 필요합니다.

프로젝트 코드는 Apache-2.0으로 안내되지만 Qwen 등 제3자 모델/구성요소 조건은 별도 확인해야 합니다.

살펴볼 점
  • 직접 설치하거나 생성 속도·화질·VRAM 사용량을 실측하지 않았습니다. 24 FPS는 출력 영상 설정이지 실시간 생성 성능이 아닙니다.
  • 온라인 데모의 프롬프트 처리·보존 정책은 별도 확인해야 합니다. 단일 GPU 추론을 전체 웹 데모나 학습 요구사항으로 일반화하지 마세요.
