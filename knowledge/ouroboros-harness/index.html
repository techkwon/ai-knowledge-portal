Ouroboros 에이전트 하네스

소크라테스식 대화(질문을 반복해 던지는 인터뷰 방식)로 요구사항을 구체화한 뒤 반복 루프를 도는 AI 에이전트 하네스

#에이전트 하네스#반복 루프#요구사항 정제#MCP#설계 단계#Claude Code#Codex

무엇을 할 수 있나요?

사용자에게 이것저것 되묻는 소크라테스식 인터뷰 과정을 거친 뒤, 정리된 목표를 바탕으로 자동 반복 루프를 실행하는 에이전트 하네스입니다.

실제로 이 하네스와 AI 브라우저(Aside)를 함께 사용해 짧은 시간에 게임을 완성한 해커톤 사례가 공유되었습니다.

초기 설계 단계에서 주로 활용하도록 설계된 MCP로 소개됨.

설치 후 기존 도구(Codex, Claude Code)와 충돌이 발생한 사례가 보고되어 설치 시 환경 점검이 필요함.

살펴볼 점
  • 한국어 README 기준으로 세부 동작은 저장소 최신 버전에서 재확인 필요
  • 다른 MCP·CLI 도구와 동시 설치 시 충돌 가능성이 보고됨
