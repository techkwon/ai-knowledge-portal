NVIDIA Dory1.0-4B: 반복 깊이를 조절하는 소형 추론 LLM

같은 4B 가중치의 recurrent block을 반복해 추론 연산량을 조절하는 영어 텍스트 LLM. 모델 카드와 논문에서 코딩·에이전트 벤치마크를 공개했으며 실제 지연·메모리·한국어 성능은 별도 검증이 필요하다.

#NVIDIA#Nemotron Labs#Dory#latent recurrence#추론 모델#오픈 웨이트

무엇을 할 수 있나요?

Dory는 음성 인식이나 임베딩 모델이 아니라 텍스트를 입력받아 텍스트를 생성하는 범용 reasoning LLM이다. normalized-GPT 기반으로 sliding-window/full attention을 혼합하며 최대 256K 문맥과 영어 지원을 명시한다.

하나의 checkpoint에서 recurrent block의 반복 횟수를 바꾼다. 2 loops를 출발점으로 권장하며 1 loop는 토큰당 연산을 줄이고 4 loops는 일부 작업의 정확도에 더 많은 연산을 쓴다. 재학습이나 다른 모델 교체 없이 조절한다.

NVIDIA 논문에서 BF16의 SWE-bench Verified pass@1은 1/2/4 loops에 50.3/59.5/61.8이었다. 동일 프로토콜을 사용한 연구진 자체 평가이며 실제 사용자 프로젝트의 버그 해결률이 아니다.

효과는 작업별로 다르다. GPQA는 2 loops 72.41에서 4 loops 72.16으로 소폭 낮아지고 AA-Omniscience accuracy는 거의 변하지 않았다. 반복을 늘리면 모든 지식·정확도가 올라간다는 주장은 피한다.

기본 캐시 설정은 per_loop라 loop 수에 따라 KV 캐시가 늘어난다. last_loop는 recurrent attention layer당 캐시 하나로 유지하는 별도 옵션이며, 논문의 4-loop 비교에서 점수 변화는 -2.12~+0.42점이었다.

모델 카드의 BF16 경로는 vLLM의 Dory 지원 PR 기반 안내이며 NVIDIA GPU·Linux 통합을 설명한다. Apple Silicon 예제는 별도 양자화 GGUF와 Dory 지원 llama.cpp 소스 경로이므로 이 BF16 가중치를 Mac에서 바로 쓴다는 뜻이 아니다.

localhost의 OpenAI-compatible API는 직접 구동하는 서버 예시다. OpenAI SDK를 쓴다고 OpenAI 유료 API가 필수인 것은 아니며, 호스팅 서비스로 바꾸면 해당 서비스의 키·요금·약관·전송 조건이 별도로 적용된다.

메인 모델 카드의 governing terms는 OpenMDW-1.1이며 링크된 실제 전문에서 사용·수정·배포 권한과 고지 보존 의무를 확인했다. 다만 explainability 서브카드의 다른 라이선스 링크와 충돌이 있어 배포 전 라이선스 재확인이 필요하다.

살펴볼 점
  • 원문만 확인했다. 설치·가중치 다운로드·추론·모델 API 호출·속도 재현을 실행하지 않았다. 연구 벤치마크를 수업·학교·업무 효과로 확대하지 않는다.
  • 영어 지원 모델이다. 한국어 정확도·학생 대상 적합성·교실 효과는 확인되지 않았다. 256K는 최대 문맥 사양이지 모든 장치에서 그 길이로 작동하거나 필요한 메모리가 충분하다는 보장이 아니다.
  • 4 loops의 생성 토큰 감소 1.3~2.5배를 같은 비율의 속도·가격 개선으로 해석하지 않는다. 논문의 layer-application 근사 연산량은 1 loop 대비 1.07~2.04배였고 실지연은 하드웨어·동시성·도구에 좌우된다.
  • 양자화 최대 2.44배 속도는 DGX Spark, batch 1, ISL 128/OSL 1024에서 NVFP4 대 BF16의 제한된 측정이다. BF16/GGUF·Mac·일반 PC로 일반화하지 않는다. self-speculation 속도도 도구 실행·초기 대기 등을 제외한 측정이다.
  • 모델 카드에는 일부 benchmark 반복 조건과 실제 표의 명칭이 어긋나는 부분이 있다. 논문별 프로토콜·캐시·정밀도·harness를 함께 보며 외부 공식 리더보드와 동일 수치라고 주장하지 않는다.
  • 메인 카드의 OpenMDW-1.1과 explainability.md의 NVIDIA Open Model License 표기가 다르며 모델 저장소의 별도 LICENSE 파일은 확인하지 못했다. 상업적 배포나 재배포 전 제공자에게 적용 약관을 재확인한다.
  • 연결된 privacy.md와 safety.md가 404여서 개인정보 보호·안전성 평가 원문은 확인하지 못했다. 로컬 서버 예제가 있다는 사실만으로 개인정보 누출 방지나 무전송을 보장하지 않는다. 실제 외부 전송은 선택한 endpoint·연결 클라이언트·도구·로그 구성에 달리며 이 검증에서는 네트워크 동작을 시험하지 않았다.
  • explainability.md는 prompt injection·jailbreak와 에이전트 실행 위험을 명시한다. 모델의 도구 호출을 실제 실행 권한과 분리하고 민감정보·학생 원문을 입력하지 않는 등 별도 통제가 필요하다.
