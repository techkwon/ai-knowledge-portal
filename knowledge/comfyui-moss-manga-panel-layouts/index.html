ComfyUI MOSS 만화 노드: 196개 도안에서 2~6컷 구성하기

MOSS-Image에 보낼 만화 컷 배치·인물·장면·대사를 ComfyUI에서 구성하는 커스텀 노드. 기존 MOSS 모델과 별개인 제작 보조 UI이며 생성 결과의 컷 수·문자·인물 일관성을 보장하지 않는다.

#ComfyUI#MOSS-Image#만화#레이아웃#MIT

무엇을 할 수 있나요?

제작자 README는 미리보기에서 2~6컷 배치를 선택하고, 공통 인물·각 컷의 장면·화자·대사를 입력해 MOSS 프롬프트를 만드는 흐름을 설명한다. 레이아웃마다 워크플로를 받거나 좌표 JSON을 손으로 작성하는 작업을 줄이는 보조 노드다.

배치 데이터와 MOSS 생성 미리보기 196개를 동봉한다. 자동 검사로 유사 중복 후보를 제거한 수치이며 모든 도안을 사람이 정확성·차별성 검수했다는 뜻은 아니다. 목록 열람에는 외부 서비스 연결이 필요 없다는 제작자 설명과 모델 설치·다운로드는 구별해야 한다.

컷 수를 바꾸면 전용 컷 노드와 연결이 늘거나 줄고, 줄였던 입력은 다시 복원할 수 있다고 안내한다. 공통 인물은 2명이며 한 컷은 최대 2명·2발언이다. 인물 외형·장면은 영어, 대사는 렌더링할 언어로 넣고 별도 번역 LLM은 사용하지 않는다.

노드 UI와 라벨은 일본어이며 README에 주요 라벨의 영어 대조표를 제공한다. 한국어 UI 지원을 확인한 것은 아니며 인물 외형·장면은 영어, 대사는 표시하려는 언어로 입력하는 안내를 따른다.

Python 3.10 이상과 MOSS-Image를 네이티브 지원하는 ComfyUI가 필요하다. 제작자 확인 환경은 ComfyUI v0.42.0·Python 3.13이며, 필요한 moss_image·EmptyFlux2LatentImage 기능이 없는 구버전은 사용할 수 없다.

모델 가중치는 포함하거나 자동 다운로드하지 않는다. 동봉 예시는 MOSS SFT int8, Qwen3.5 9B int8 텍스트 인코더, FLUX.2 VAE를 별도로 지정한다. 모델명·하위 폴더가 다르면 로더 선택도 바꿔야 한다.

이 저장소의 독자 코드·배치 데이터·동봉 미리보기는 MIT로 배포한다고 명시하며 실제 LICENSE를 확인했다. MOSS 모델·ComfyUI·기타 제3자 구성요소에는 각각의 배포 조건이 적용된다.

살펴볼 점
  • 미리보기 이미지를 복사하는 방식이 아니라 좌표와 설명으로 생성 모델을 유도한다. 컷의 모양·비율·개수, 인물 혼선과 글자 오류를 보장해 막지 못하며 생성 후 문자·테두리를 덧씌워 보수하지 않는다.
  • 제작자가 밝힌 원 데이터 생성 환경은 Windows·RTX 3060 12GB다. 다른 GPU·OS의 실제 생성이나 최소 VRAM을 검증한 수치가 아니며 이 카드에서도 설치·실행·196개 도안의 시각 검수는 하지 않았다.
  • 인물·대사·보류된 컷은 일반 ComfyUI 워크플로에 저장한다. 즐겨찾기는 브라우저 로컬 저장소에 있어 다른 브라우저로 자동 이전되지 않고 사이트 데이터를 지우면 사라진다.
  • MIT를 전체 모델·학습자료·생성물의 권리 보증으로 확대하지 않는다. 실제 인물·학생 자료와 타인의 캐릭터·대사에는 개인정보·초상권·저작권을 별도로 확인한다.
