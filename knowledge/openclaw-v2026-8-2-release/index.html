OpenClaw v2026.8.2 업데이트

세션/작업 Dock UI 개편, Linux 데스크톱 컴패니언, 새 테마, 크론·하트비트 스케줄링 개선을 담은 OpenClaw 정식 릴리스

#OpenClaw#에이전트 하네스#릴리스#스케줄링

무엇을 할 수 있나요?

세션·작업을 한눈에 보는 Dock 뷰 UI가 추가되고, x86-64 Linux용 데스크톱 컴패니언(.deb/AppImage)이 새로 지원됩니다.

CRT, Manuscript, Rosé, Miami 등 새 테마와 음성 출력 개선, 업데이트·롤백 안전성 강화, 보안 마스킹 확장이 포함되었습니다.

크론(cron)·하트비트(heartbeat) 방식 예약 작업 기능이 개선되어 반복 자동화 시나리오에 활용하기 좋아졌습니다.

살펴볼 점
  • 정식 배포 채널(GitHub Releases)에서 받은 빌드인지 확인 후 설치하는 것이 안전합니다.
  • 이전 버전에서 다중 에이전트가 설정된 상태로 업데이트할 경우 설정 마이그레이션이 실패하는 사례가 보고되었으니, 문제가 발생하면 공식 setup 절차로 복구하는 것이 좋습니다.
