Hydrogen-1.0: GLM-5.3 기반 과학 연구 보조 언어모델

Deep Principle이 GLM-5.3을 후학습한 753B 과학 연구 보조 모델. BF16 가중치의 MIT 본문은 확인됐지만, 파일 접근 동의와 추가 권리 문서의 미확인 범위를 구분해야 한다.

#Deep Principle#GLM-5.3#과학 연구#오픈 가중치

무엇을 할 수 있나요?

모델카드는 GLM-5.3 기반 과학 문제 해결·연구 보조 모델로 소개한다. 저장소 메타데이터는 753B 파라미터와 BF16 배포본을 표시하며, 컨텍스트 1M·최대 출력 128K 토큰을 안내한다. 실제 사용 가능한 길이는 추론 프레임워크·서비스 설정·런타임 자원에 따라 달라진다.

기술 블로그는 화학·재료·생명과학 지식과 연구 시나리오·실험 기록·발견 과정을 이용한 SFT·RL을 설명한다. 과학 계산·반응망 탐색·NMR 분석·실험 설계 시연은 외부 도구와 특정 연구 환경을 결합한 제작사 사례이며, 전체 학습 데이터셋과 레시피는 공개하지 않는다.

모델카드는 SGLang의 8 GPU 환경에서 테스트했다고 명시하고 generation_config.json의 종료 토큰 설정을 유지하라고 안내한다. BF16 외 NVFP4·MXFP4는 별도 저장소이며, 각각 NVIDIA Blackwell(B200/B300)과 AMD Instinct(MI350X/MI355X)를 대상으로 소개한다. 이는 배포 대상 안내이지 모든 대체 실행 방식의 불가능성을 증명한 것은 아니다.

사용 예제의 OpenAI 호환 클라이언트는 이미 실행 중인 호환 서비스 호출을 전제한다. 예제만으로 가중치가 내려받아지거나 로드되는 것이 아니며, Hugging Face의 무료 호스팅 API가 제공된다는 뜻도 아니다.

살펴볼 점
  • 직접 설치·다운로드·추론·API 호출·과학 실험 재현은 하지 않았다. 성능과 시연은 제작사 자체 보고이며, 과학적 검토·독립 계산·실험을 대신하지 않는다. 건강·안전 등 중요한 판단의 근거로 단독 사용하지 않는다.
  • BF16 가중치는 모델카드가 MIT로 명시하고 실제 LICENSE의 MIT 본문도 확인했다. 재배포 시 Deep Principle·Z.AI의 저작권 및 허가 고지를 보존해야 한다. 이를 프로젝트 전체·별도 양자화본·학습자료·모든 의존성에 일괄 적용하지 않는다.
  • 독자 코드·문서는 Apache-2.0, 제3자 파일은 각각의 조건이라는 설명은 모델카드 기준이다. LICENSING.md·LICENSE-APACHE-2.0·NOTICE는 조회 시 401로 세부 내용을 확인하지 못해, 파일별 예외·추가 고지까지 권리 검토가 끝난 상태가 아니다.
  • 저장소 파일 목록은 Hugging Face 정보 공유 동의를 거치는 접근 절차를 표시한다. 무조건 로그인 없이 내려받는다고 안내하지 않으며, 여기서는 로그인·연락정보 공유 동의·가중치 다운로드를 하지 않았다.
  • 753B BF16 배포본의 자원 요구는 일반 개인 기기에 바로 권장할 수준으로 검증되지 않았다. 8 GPU는 제작사의 테스트 구성이지 보편적인 최소·유일 구성이라는 뜻은 아니며, 실제 메모리·오프로딩·긴 문맥 비용을 별도로 산정해야 한다.
