Hydrogen-1.0: GLM-5.3 기반 과학 연구 보조 언어모델

Deep Principle이 GLM-5.3을 파인튜닝해 공개한 753B 파라미터 과학 문제 해결·연구 보조 모델, MIT 라이선스로 가중치 공개

#Deep Principle#GLM-5.3#과학 연구#오픈 가중치

무엇을 할 수 있나요?

공식 모델 카드: Deep Principle이 Z.AI의 GLM-5.3을 기반으로 만든 과학 문제 해결·연구 보조 모델입니다. 텍스트 대화로 과학적 질문에 답하고 수식 전개를 설명하며 열린 연구 문제에 대한 답변을 구조화하도록 설계됐습니다. 컨텍스트 길이 1M 토큰, 최대 출력 128K 토큰이며 BF16(비양자화) 가중치 753B 파라미터를 공개 저장소에서 받을 수 있고, NVIDIA Blackwell용 NVFP4·AMD Instinct용 MXFP4 양자화 버전도 별도 저장소로 제공됩니다.

기술 블로그는 과학 계산, 반응망 탐색, NMR 구조 분석, 실험 설계 예시를 소개하지만 이들은 외부 도구·특정 연구 환경과 결합한 시연이며 출력은 과학적 검토가 필요하다고 명시합니다. 학습 데이터는 도메인 지식·연구 시나리오·실험 기록·발견 과정 등으로 구성됐다고 개요만 공개하고 전체 데이터셋과 학습 레시피는 공개하지 않습니다.

SGLang으로 8GPU 환경에서 테스트됐고 `generation_config.json`의 종료 토큰 설정을 유지해야 응답이 올바르게 끝난다고 안내합니다. 평가는 과학 객관식 문제와 열린 연구 문제 중심이며, 모델 답변이 독립적인 과학적 검증을 대체하지 않는다고 명시합니다.

살펴볼 점
  • 제작사 자체 모델 카드 기준이며 독립 재현 평가나 직접 실행 테스트는 하지 않았습니다.
  • 753B 파라미터 비양자화 모델로 실행에 다중 GPU와 상당한 메모리가 필요합니다. NVFP4/MXFP4 양자화 버전은 각각 Blackwell/MI350X 계열 하드웨어가 필요합니다.
  • 모델 카드는 출력이 검증된 실험 결과나 건강·안전 등 중요한 의사결정의 근거가 될 수 없다고 명시합니다. 학습 데이터·레시피 전체가 공개되지 않아 편향이나 한계를 완전히 검증하기 어렵습니다.
  • 모델 가중치는 MIT 라이선스이나 기반 모델(GLM-5.3)과 독자적으로 작성된 코드/문서의 라이선스가 구분되어 있어 재배포 시 각각 확인이 필요합니다.
