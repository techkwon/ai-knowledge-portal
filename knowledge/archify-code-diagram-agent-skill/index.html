Archify: 코드베이스를 탐색 가능한 다이어그램으로 만드는 에이전트 스킬

코드베이스나 자연어 설명을 아키텍처·워크플로·시퀀스·데이터 흐름 다이어그램으로 변환해 탐색 가능한 형태로 보여주는 에이전트 스킬

#Claude Code#Codex#다이어그램#실무 가이드

무엇을 할 수 있나요?

Archify는 Cursor, Claude Code, Codex CLI, OpenCode 같은 에이전트 코딩 도구 위에서 동작하는 스킬로, 저장소가 없어도 자연어 설명만으로 시작할 수 있습니다. 코드베이스를 분석하거나 시스템을 말로 설명하면 구성 요소와 연결 관계를 직접 탐색할 수 있는 다이어그램을 생성합니다.

아키텍처, 워크플로, 시퀀스, 데이터 흐름, 생명주기 등 다섯 가지 다이어그램 유형을 지원하며, 에이전트가 구조화된 JSON을 작성하면 Node.js 렌더러가 이를 HTML/SVG로 변환하는 방식입니다. 생성된 JSON을 수정하며 대화로 결과를 다듬을 수 있고, 노드를 검색해 앞뒤 연결 관계나 두 요소 사이의 경로를 따라가며 단계별 설명·발표 모드로 시스템 동작을 보여줄 수 있습니다.

변경 전후 다이어그램을 비교해 추가·삭제·수정된 요소와 연결 경로 변화를 표시하는 기능도 있고, 요청 시 노드에 특정 Git 커밋의 소스 파일과 코드 위치를 연결해 설명의 근거를 확인할 수 있습니다. 결과는 단일 HTML 파일로 생성되며 PNG/SVG/WebM과 소셜 공유용 이미지로 내보낼 수 있습니다.

살펴볼 점
  • `npx skills add tt-a1i/archify -g`로 설치하는 MIT 라이선스 프로젝트입니다. 이 항목은 공식 소개 글을 확인한 것이며 실제 설치·사용 테스트는 하지 않았습니다.
  • 생성 과정에서 데이터 구조·배치·간격을 자체 검사해 오류를 반환한다고 소개하지만, 대규모 코드베이스에서의 정확도나 처리 속도는 별도로 검증되지 않았습니다.
