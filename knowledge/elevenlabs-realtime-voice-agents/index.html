Eleven Realtime: 음성 인식부터 응답까지 묶은 실시간 대화 에이전트

Mini·Max 모델이 음성 인식, 대화 차례, LLM, 음성 출력을 함께 관리한다. 기존 Eleven v4 TTS나 이미지·영상 API와 다른 대화 기능으로, 연결 시간·토큰 비용과 대화 보관 설정을 함께 살펴야 한다.

#ElevenLabs#Eleven Realtime#음성 에이전트#Speech to Speech#실시간 대화#개인정보

무엇을 할 수 있나요?

새로운 기능: 공식 2026년 10월 19일 변경 이력에 등장한 대화 모델군이다. 텍스트를 읽는 TTS나 음색만 바꾸는 Voice Changer가 아니라 음성 인식·대화 차례·LLM·음성 출력을 하나의 대화 설정으로 관리한다.

모델 선택: v1 Mini는 빠르고 자연스러운 대화, v1 Max는 복잡한 지시와 여러 단계의 도구 호출에 초점을 둔다. 프롬프트·목소리·도구·지식베이스·끼어들기 설정은 유지할 수 있다.

제공 방식: ElevenAgents의 Realtime 모드와 OpenAI 호환 Realtime API로 제공된다. 공식 제품 페이지는 90개 이상 언어를 안내한다. 작업공간별 단계적 배포이므로 모든 계정에 즉시 보인다고 단정하지 않는다.

개발 연결: OpenAI Realtime과 같은 WebSocket 이벤트를 사용한다. 브라우저에 장기 API 키를 넣는 대신 백엔드에서 단기 시크릿을 발급하는 방식이며 WebSocket 오디오는 PCM16 24kHz 입력·재생을 따로 연결해야 한다.

요금: 2026년 11월 5일 확인한 Realtime API 가격은 두 모델 모두 연결 오디오 분당 0.08달러에 토큰 비용이 더해진다. 100만 토큰 기준 Mini는 입력 0.20달러·출력 6달러, Max는 입력 1.80달러·출력 9달러이다. 세금과 한도 초과 조건을 별도 확인한다. ElevenAgents 요금은 표준 분당 요금에 모델 토큰 요금을 더하는 방식이다.

개인정보: Agents 문서는 대화 데이터 기본 보관을 2년으로 안내한다. 보관 기간 변경과 Zero Retention Mode는 별도 설정이며 Realtime에서 ZRM은 미국·EU의 Max만 지원한다. Mini까지 무보관이라고 일반화하지 않는다.

이용 조건: 일반 약관은 무료 이용을 비상업 목적으로 제한하고 유료 이용은 정책 준수 하에 상업적 사용을 허용한다. 일반 약관상 18세 또는 거주지 성년 미만 이용은 금지되어 있어 교육용 튜터라는 홍보만으로 학생 직접 이용을 허용된 것으로 판단하지 않는다.

살펴볼 점
  • 실제 API 호출·계정 로그인·음성 전송·대화 실행은 하지 않았다. 한국어 인식·자연스러움·응답 지연·도구 호출 성공률은 미시험이다.
  • 공식 벤치마크와 지연 수치는 공급자 공개 조건의 결과이며 실제 한국어 수업·상담 환경 성능 보장이 아니다. 독립 벤치마크 원자료 검증은 하지 않았다.
  • Custom LLM·Amazon Bedrock 사용, 관리 설정을 덮어쓰는 워크플로, Custom 모드 에이전트와의 전환에는 제약이 있다. 기존 에이전트에 무조건 그대로 적용할 수 있는 교체품이 아니다.
  • 무보관은 기본값이 아니다. 보관 설정, 학습 이용 거부, 녹음 고지·동의, 외부 도구·웹훅의 저장, 기업 계약·데이터 이전 조건을 별도 확인해야 한다.
  • 공개자료 소개는 학생 직접 사용 또는 개인정보 포함 음성 수집에 대한 승인이나 법적 적합성 판정이 아니다.
