Flint: 로컬 코딩용 MoE 모델

Recursive의 코딩 모델. BF16 원본과 Mac용 경량 런타임의 저장공간·메모리 조건을 나눠 확인합니다.

#로컬 모델#MoE#Mac

무엇을 할 수 있나요?

Recursive의 공식 자료는 Flint를 전체 39.8B, 토큰당 약 2.5B 활성화하는 코딩용 MoE 모델로 소개하고 가중치에 Apache 2.0을 표기합니다. 소개 글의 최대 512K 문맥 주장과 현재 Hugging Face BF16 카드의 입력·출력 합계 262,144토큰 구성은 구별해야 합니다.

BF16 모델 카드는 약 80GB 다운로드와 서버급 GPU 추론 경로를 안내합니다. 별도 경량 양자화 rec 런타임의 지원 Mac 조건은 M4 Pro, M5 Pro 또는 M5 Max, 통합 메모리 최소 48GB와 여유 저장공간 약 30GB입니다. 이 조건을 BF16 모델 요구와 혼동하지 마세요.

초보자 시작점: 사용할 런타임의 공식 장비·저장공간 조건을 먼저 대조하고, 권한이 있는 작은 공개 코드에서 함수 설명이나 테스트 초안을 받아 사람이 검토하는 방식으로 범위를 좁히세요.

살펴볼 점
  • 512K 소개 문구를 모든 체크포인트의 확정 문맥으로 쓰지 마세요. 긴 문맥과 양자화 방식에 따라 실제 동작은 달라질 수 있습니다.
  • 속도 및 벤치마크 우위는 제작사 발표이며 독립 성능 시험이나 특정 기기에서의 보장이 아닙니다. 생성 코드와 도구 실행은 권한 제한과 테스트가 필요합니다.
  • 가중치 라이선스와 별도 호스팅 서비스 조건은 다릅니다. 공식 문서만 확인했으며 다운로드·설치·실행·성능을 독립 시험하지 않았습니다.
