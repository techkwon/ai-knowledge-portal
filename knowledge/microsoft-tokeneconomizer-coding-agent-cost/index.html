TokenEconomizer: 코딩 에이전트 비용을 저절로 줄여주는 경험 기반 플러그인

UC버클리·Microsoft Research 공동 연구로, 반복 작업한 저장소에서의 경험을 학습해 마이크로스킬 주입·미사용 도구 정리·반복 실패 개입으로 코딩 에이전트 비용을 줄이는 플러그인

#Claude Code#Codex#비용 관리#Microsoft Research

무엇을 할 수 있나요?

공식 논문/README: TokenEconomizer는 Claude Code, Codex, GitHub Copilot CLI, Pi용 플러그인(opencode는 실험 지원)으로, SWE-Bench 5개 에이전트-모델 조합에서 평균 비용을 18.4~30.9% 낮추고 30개 저장소×조합 전부에서 비용이 줄었으며, 5개 조합 중 4개에서 Pass@1(정답률)도 올랐다고 보고합니다.

세 가지 메커니즘: (1) 마이크로스킬 - 반복되는 빌드 명령·환경변수 등 저장소별 사실을 3회 이상 세션에서 확인되면 다음 세션 시작 시 주입하고, 이후 세션이 반박하면 제거합니다. (2) 도구 가지치기 - 일정 기간 쓰이지 않은 도구 정의를 다음 세션 설정에서 빼서 매 요청마다 전송되는 도구 목록 토큰을 줄입니다(설정으로 복원 가능). (3) 실패 루프 개입 - 같은 실패를 반복하는 턴을 판정 모델이 감지하면 다른 접근을 시도하도록 짧은 안내를 주입(턴당 최대 1회), 그래도 막히면 직접 멈추지 않고 사용자에게 멈추는 법을 안내합니다.

모델 호출(사실 제안자, 판정 모델)은 사용자 자신의 에이전트·로그인을 통해 실행되고 비용이 리포트에 포함되며, 학습 데이터는 로컬(~/.tokeneconomizer)에만 저장된다고 명시합니다.

살펴볼 점
  • 수치는 연구팀이 자체 SWE-Bench/Web-Bench 환경에서 측정한 결과이며, 모든 저장소·작업에서 동일한 절감률을 보장하지 않습니다.
  • 플러그인 작동 실패 시 세션이 설치되지 않은 것처럼 계속 진행된다고 설명하지만, 직접 설치·동작 테스트는 하지 않았습니다.
  • Apache 2.0 라이선스로 공개돼 있으나 실제 저장소에 적용했을 때의 체감 절감폭은 사용 패턴에 따라 달라질 수 있습니다.
