Meta Muse Code: 터미널·CI용 공식 코딩 에이전트

Meta가 공개한 터미널/CI 전용 코딩 에이전트로, Muse Spark 모델을 기반으로 계획·수정·명령 실행을 승인 절차와 OS 샌드박스 안에서 수행

#Meta#CLI#CI#샌드박스

무엇을 할 수 있나요?

Muse Code는 Meta의 Muse Spark 모델을 기반으로 만들어진 터미널·CI용 코딩 에이전트입니다. 프로젝트 안에서 실행하면 작업을 계획하고, 코드를 수정하고, 명령을 실행하는데, 첫 실행부터 승인 절차와 OS 샌드박스가 켜져 있습니다. `curl -fsSL https://dev.meta.ai/install.sh | sh` 한 줄 설치로 `muse` 바이너리가 설치되며, 대화형(`muse`)과 헤드리스(`muse exec "<prompt>"`) 두 가지 실행 방식을 지원합니다.

macOS·Linux·Windows를 하나의 코드베이스로 지원하지만 Windows에서는 PowerShell 사용, 샌드박스 초기화 시 UAC 승인 프롬프트, 음성 입력 미지원, 세션 메시징 미지원 등 몇 가지 제약이 있습니다. 독립적인 실행 세션끼리 인수인계·리뷰 요청·상태 업데이트를 주고받는 '세션 메시징' 기능은 macOS·Linux에서만 지원됩니다.

CLI 외에도 자체 프로그램에서 세션을 제어할 수 있는 버전 관리된 프로토콜(`muse serve`, `muse schema`)과 이를 감싼 TypeScript SDK(`@muse-code/sdk`)를 제공해 커스텀 통합이 가능합니다.

2026년 11월 11일 공식 제품 페이지에서 월 구독 플랜 Everyday 5달러, High 15달러, Power 50달러, Maximum 200달러를 확인했습니다. 같은 페이지의 모델 표는 muse-spark-1.3-contributor 및 1.2-contributor를 제품 개선에 사용되는 경로로, contributor가 없는 해당 모델을 제품 개선에 사용되지 않는 경로로 구분합니다. 가격뿐 아니라 선택 모델의 데이터 이용 구분도 함께 확인하는 것이 좋습니다.

살펴볼 점
  • 이 항목은 Meta 공식 문서 확인 단계이며 실제 설치·사용 테스트는 하지 않았습니다. 워크플로우(병렬·단계적 에이전트 조율) 기능은 설치된 빌드와 롤아웃 여부에 따라 제공되지 않을 수 있다고 공식 문서에 명시돼 있습니다.
  • 기존 문서의 기본 모델 안내와 현재 제품 페이지의 모델 목록은 구분해야 합니다. 브라우저 로그인 또는 API 키(META_API_KEY) 인증, 비대화형 CI의 인증·과금 조건은 해당 버전의 공식 문서에서 별도로 확인하세요.
  • 이번 보강은 공식 제품 페이지의 플랜·모델 표 확인입니다. 전체 이용약관·데이터 처리 계약, 계정별 청구·세금·지역·기능 제공 범위는 검증하지 않았고 구독·설치·가입은 하지 않았습니다.
