LLM Configurator Hardware Analyzer

GPU·VRAM·시스템 메모리를 기준으로 실행 가능한 로컬 LLM과 예상 속도·전력 비용·Ollama 설치 명령을 안내하는 브라우저 도구

#VRAM#GPU#모델 선택#Ollama#Apple Silicon

무엇을 할 수 있나요?

GPU를 직접 고르거나 브라우저 자동 감지를 사용하고 VRAM·시스템 RAM을 입력하면 모델을 실행 적합도에 따라 분류합니다.

모델별 예상 VRAM 사용량, 초당 토큰 수, 전력 비용과 복사 가능한 Ollama 설치 명령을 함께 보여줍니다.

Apple Silicon은 전용 VRAM 대신 통합 메모리 총량을 입력해 비교할 수 있으며 로그인 없이 브라우저에서 사용할 수 있습니다.

살펴볼 점
  • 속도와 전력 비용은 추정치이므로 실제 성능은 모델 양자화, 컨텍스트 길이, 냉각과 다른 앱의 메모리 사용량에 따라 달라질 수 있습니다.
  • 브라우저 자동 감지 결과와 모델 요구량은 실행 전 공식 모델 문서로 한 번 더 확인하세요.
