Claude와 Theorem의 바이너리 수준 형식 검증: 증명 범위와 공개 자료

Anthropic은 Claude로 123개 OSS 라이브러리의 239개 퍼징 진입점에 대한 제한적 증명을 작성했다고 보고했다. Theorem은 그중 공개 증명과 오픈소스 등록 절차를 제공한다. 보안 전체를 보증하는 결과는 아니다.

#형식 검증#Rocq#OSS-Fuzz#RISC-V#Claude

무엇을 할 수 있나요?

Anthropic/Theorem의 자체 보고는 123개 라이브러리·239개 진입점이다. 공개 저장소의 증명은 25개 라이브러리·60개 진입점이며 전체 결과를 그대로 공개한 것은 아니다.

기존 퍼징 테스트를 명세로 삼아 컴파일된 정적 RISC-V 바이너리의 특정 무충돌 성질을 Rocq로 확인한다. 입력 크기·메모리·단일 스레드·Linux 모델 등 가정이 붙는다.

Theorem의 OSS Verify는 적격 오픈소스 핵심 유지관리자가 빌드·퍼징 대상 정보를 PR로 제출하는 별도 프로그램이다. 프로젝트 선정과 빌드 포팅이 필요하다.

살펴볼 점
  • 연구팀의 자체 보고 수치이며 여기서 증명을 재현하지 않았다.
  • 특정 명세·진입점의 증명이지 전체 라이브러리의 버그 부재나 실환경 보안 보증이 아니다.
  • 비공개 코드의 가격·자료 처리 조건과 지역 범위는 확인되지 않았다.
