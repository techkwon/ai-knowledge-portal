모델자료 확인

Youtu-Parsing-Omni: 문서·이미지·오디오·영상을 하나의 JSON 스키마로 파싱하는 5B 모델

Tencent Youtu Lab이 공개한 5B 규모 멀티모달 파싱 모델로, 문서·차트·도형·오디오·영상을 한 종류의 구조화 JSON(OmniSchema)으로 출력하며 OmniDocBench 등에서 소형 모델 중 상위권 결과를 공식 발표함

#실무 가이드

무엇을 할 수 있나요?

Hugging Face 공식 모델 카드에 따르면 Youtu-Parsing-Omni는 문서 페이지·자연 이미지·차트·흐름도·도형·오디오·영상 중 하나를 입력받아, 레이아웃·텍스트·표·수식·좌표(perception)와 캡션·요약(cognition)을 함께 담은 단일 JSON으로 출력하는 5B 파라미터 모델입니다.

공식 발표 수치로 OmniDocBench v1.6에서 Overall 96.96점(공개 비교 모델 중 1위권), OmniParsingBench 평균 75.08점(공개 가중치 모델 중 1위, Gemini-3-Pro 다음)이라고 밝히고 있으며, 화학식 인식(ChemOCR)과 악보 인식(PDMX-Synth)에서도 전문 모델과 경쟁력 있는 결과를 보고합니다.

vLLM 플러그인과 Transformers 추론 코드, 과제별 프롬프트(JSON), 추론 예제 스크립트를 함께 공개했으며, OpenAI 호환 API 서버로 로컬 서빙이 가능하다고 설명합니다. 가중치는 Hugging Face와 ModelScope에서 받을 수 있습니다.

살펴볼 점
  • 공식 수치는 모델 제작사(Tencent)가 자체 발표한 벤치마크 결과이며, 독립 재현·실측은 하지 않았습니다.
  • Hugging Face 메타데이터는 license: other(license_name: youtu-parsing)로 표기되어 있고, 공식 LICENSE 파일은 Apache 2.0이 아닌 Tencent 자체 약관입니다. 이 약관은 "Youtu-Parsing IS NOT INTENDED FOR USE WITHIN THE EUROPEAN UNION"이라는 지역 제한 조항을 명시하고, 재배포 시 원 라이선스·고지 보존 의무를 두고 있어 사용 전 조건을 직접 확인해야 합니다.
  • 공식 README는 Hugging Face Hub에서 모델을 받을 때 `trust_remote_code=True`로 로드되어 체크포인트에 포함된 Python 코드가 그대로 실행된다고 밝히고 있으며, Hub id로 받을 경우 `--revision <commit-hash>`로 특정 커밋을 고정해 받으라고 권고합니다. 사용 전 해당 코드 검토가 필요합니다.
  • vLLM 서빙과 Transformers 추론은 서로 다른 transformers 버전을 요구해 별도 파이썬 환경이 필요하고, GPU와 ffmpeg 등 설치 요건이 있어 비개발자가 바로 쓰기는 어렵습니다.
