Cinematique: 영상 문법 프롬프트 라이브러리

카메라·렌즈·조명·구도를 기준으로 이미지와 영상 생성용 프롬프트를 구성하는 공개 참고 자료

#구도#조명#카메라#영상 문법

무엇을 할 수 있나요?

제작자 사이트는 150개 이상의 영화·사진 기법과 복사해 활용할 수 있는 프롬프트 템플릿을 무료로 제공합니다. 카테고리·난도·분위기 기준으로 기법을 탐색하도록 안내합니다.

원하는 카메라 시점이나 조명 기법을 고른 뒤 템플릿의 [Subject]를 자신의 장면으로 바꾸고 사용하는 생성 도구에 입력하는 방식입니다.

같은 피사체로 시점·조명 조건 하나씩을 바꿔 결과를 비교하면 시각적 의도를 구체적으로 전달하는 연습에 활용할 수 있습니다.

살펴볼 점
  • 특정 생성 모델의 공식 프롬프트 규격이 아니라 독립 제작자의 참고 라이브러리입니다. 도구별 지시 해석과 결과는 다를 수 있습니다.
  • 카메라명·해상도 표현이 실제 촬영 장비나 출력 해상도를 보장하지 않습니다. 예시 이미지의 재배포 권한과 도구 약관은 별도로 확인하세요.
