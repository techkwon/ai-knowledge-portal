edu-legal-mcp: 교사가 만든 학습용 앱에 이용약관·개인정보처리방침·체크리스트를 생성하는 MCP

교사 개발자의 웹앱 코드를 분석해 이용약관/개인정보처리방침과 하단 팝업, 에듀집·학교용 필수기준 체크리스트(HWPX)를 생성하는 로컬 전용 MCP 서버

#MCP#교육 AI#HWPX#개인정보처리방침#교사 개발자

무엇을 할 수 있나요?

핵심 기능: `analyze_app`이 프로젝트 코드를 정규식 기반으로 분석해 입력 항목, 브라우저 저장, 외부 AI 연동(OpenAI·Gemini·Claude 등), Firebase/Supabase 사용, 로그인 기능, 프레임워크·스타일 등을 근거(파일:줄)와 함께 찾아내고, `write_legal_docs`가 이용약관·개인정보처리방침을 마크다운과 한글 HWPX로 생성합니다. 확인되지 않은 항목은 추측 없이 `[확인 필요]` 질문으로 남겨 교사가 직접 답하게 합니다.

체크리스트: `generate_checklists`가 에듀집 필수기준 체크리스트와 학교용 필수기준 체크리스트를 제작자 설명상 원본 HWPX의 표 구조·병합·용지 설정을 보존하여 생성합니다. 선택기준처럼 학교가 심의할 영역은 체크하지 않고 "교사 답변"란만 채워 심의가 끝난 것처럼 가장하지 않도록 설계되어 있습니다.

안전장치: 공식 README에 따르면 외부로 데이터를 전송하지 않고 로컬 stdio로만 동작하며, 쓰기 범위를 프로젝트 폴더 내부(`legal-docs/`, `legal/`, `index.html`)로 제한하고 폴더 밖을 가리키는 심볼릭 링크나 경로를 거부합니다. `[확인 필요]`가 남은 문서나 "시연용/검토용" 같은 임시 표시가 있으면 앱에 설치되지 않습니다.

설치: `pip install -e .`(Python 3.10+)로 설치 후 Claude Desktop/Cursor/Claude Code의 MCP 설정 파일에 등록합니다. 작은 Python 서버로, Claude Code는 `claude mcp add edu-legal -- python -m edu_legal_mcp.server` 한 줄로 추가할 수 있습니다.

공식 README의 확인 입력에는 retention(보유 기간), consent_method(만 14세 미만 보호자 동의 방식), ai_retention(외부 AI 보관·학습 정책), ai_transfer_type(처리위탁/제3자 제공), api_key_in_server(서버 환경변수 보관), server_location, withdrawal_method가 있다. 이 값들은 도구가 법적 정답을 보증하는 자동 판정이 아니라 운영자가 실제 앱과 정책으로 확인해야 하는 정보다.

README는 학교용 선택기준의 학교 확인란을 비워 두며 학교 심의를 끝낸 것처럼 채우지 않는다고 설명한다. 또한 도구는 배포·게시·제출을 하지 않는다고 명시한다. 문서 생성 성공을 학교 도입 승인이나 보안 인증으로 보지 않는다.

코드에서 개인정보 입력이 보이지 않아도 IP·오류 기록·익명 로그인·외부 AI·Storage 업로드 등의 신호를 별도로 검토하도록 설명한다. 정규식 탐지는 누락·오탐이 있어 코드 직접 재확인이 필요하다.

살펴볼 점
  • 공식 README가 명시: "이 도구가 만드는 문서는 법률 자문이 아니며" 학교·교육청 안내와 학교운영위원회 심의 절차를 대체하지 않습니다.
  • `analyze_app`은 정규식 패턴 매칭 보조 도구로, 놓치거나 잘못 탐지하는 경우가 있어 AI가 코드를 직접 재확인하고 교사에게 확인한 뒤 문서를 확정해야 한다고 공식 문서가 강조합니다.
  • 개인 개발자(Ingyu87)가 만든 비교적 신생·소규모 저장소로, 유지보수 지속성이나 폭넓은 사용 사례는 아직 검증되지 않았습니다. 체크리스트 서식은 특정 한국 교육 행정 양식(에듀집, 학교용)에 특화되어 있어 해당 맥락 밖에서는 적용성이 제한적입니다.
  • 공식 README만 읽었으며 코드 감사·설치·MCP 호출·HWPX 렌더링·테스트를 하지 않았다.
  • README의 로컬 stdio·외부 전송 없음 설명은 이 MCP 자체의 설계 설명이다. 연결하는 AI 클라이언트나 분석 대상 앱의 데이터 전송까지 로컬임을 보장하지 않는다.
  • 법률 자문·학교/교육청 안내·학교운영위원회 심의를 대체하지 않는다. 양식 권리는 원 작성 기관에 있으며 코드·모델·양식 재배포 권한을 한꺼번에 허용한다고 보지 않는다. 라이선스 전문은 검토하지 않았다.
  • 개인 AI 구독과 API 비용·학생 이용 연령 조건은 사용하는 서비스마다 별도 검토해야 한다. 문서 입력 항목에 동의 방식이 있다는 사실만으로 아동 대상 서비스를 적법하게 운영할 수 있는 것은 아니다.
  • 원본 서식 구조 보존은 제작자의 설명이다. 실제 Hancom에서 생성 HWPX를 열어 배치·줄바꿈·겹침을 확인한 것이 아니므로 제출 전 원래 앱의 시각 검토가 필요하다.
