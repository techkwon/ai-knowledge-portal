A.I.G(AI-Infra-Guard): AI 인프라·MCP·스킬·에이전트를 점검하는 오픈소스 레드팀 플랫폼

Tencent Zhuque Lab이 Apache 2.0으로 공개한 AI 보안 자가 점검 도구로, AI 구성요소 CVE 스캔, MCP 서버·에이전트 스킬 검사, 에이전트 점검, 탈옥 평가, OpenClaw 설정 점검을 Docker 웹 UI·API·CLI로 제공합니다.

#AI 보안#레드팀#MCP 스캔#스킬 스캔#OpenClaw

무엇을 할 수 있나요?

README는 A.I.G를 AI 보안 위험을 스스로 점검하는 레드팀 플랫폼으로 소개하며, AI 인프라 취약점 스캔, MCP 서버와 에이전트 스킬 검사, 에이전트 점검, 탈옥 평가, OpenClaw 보안 점검(ClawScan)을 묶어 제공합니다.

2026-09-17 v4.6.2 기준 변경 기록에는 40개 이상 AI 구성요소에 대한 CVE 규칙 155개 추가, 스킬 스캔 오탐 감소, 에이전트 통제 상실 벤치마크 추가가 적혀 있습니다. 이전 릴리스에는 모델 바꿔치기·백도어 위험을 보는 LLM API 감사 기능도 포함되어 있습니다.

설치는 저장소를 복제한 뒤 Docker Compose로 띄우고 `http://localhost:8088` 웹 화면에 접속하는 방식이며, API 문서와 skill-scan·mcp-scan·agent-scan CLI도 제공합니다.

살펴볼 점
  • README가 자체 인증 기능이 없어 공개 네트워크에 배포하면 안 된다고 명시합니다. 내부망이나 로컬에서만 실행하세요.
  • 점검 대상은 본인이 권한을 가진 시스템으로 한정하세요. 스캔 결과는 출발점이며 오탐·미탐 여부를 직접 확인해야 합니다.
