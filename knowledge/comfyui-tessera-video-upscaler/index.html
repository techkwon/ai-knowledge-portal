ComfyUI-Tessera: MiniMax H3 기반 타일 스트리밍 영상 업스케일러

타일·시간 청크와 스트리밍 VAE로 긴 영상의 메모리 부담을 줄이려는 ComfyUI 업스케일 노드팩. MiniMax H3 기반이므로 한국의 기본 모델 라이선스 제외 조건을 먼저 확인해야 한다.

#ComfyUI#MiniMax H3#영상 업스케일#오픈소스

무엇을 할 수 있나요?

제작자 README는 MiniMax H3 기반 영상 업스케일을 2K/4K/8K 타일·청크 처리로 구성한다고 설명한다. 스트리밍 VAE는 전체 해상도 픽셀 클립을 한 번에 메모리에 올리지 않도록 설계됐다. 단일 소비자 GPU·임의 길이 지원은 제작자의 설계 설명이며, 모든 환경에서 메모리 초과가 없다는 보증은 아니다.

Streamed Encode는 시간창별 플레이트·가이드를 만들고, Refine은 타일 조건·시간 청크·주요 피사체 타일·빈 타일 샘플링 스킵을 처리한다. Tile Plan은 실행 전 타일 격자·비용을 살피는 드라이런이며, high_vram/low_vram 설정으로 타일·시간창 예산을 조정한다.

flat_skip은 하늘·연기처럼 특징이 적은 타일에 원본 플레이트를 유지하는 규칙으로 소개된다. 결과물 전체의 환각·시간 일관성 보증으로 확대하지 않는다. 디코드 실패 시 tessera_rescue_*.latent를 이용하는 복구 설계도 안내하지만, 실제 저장 공간·파일 확보·버전 호환은 별도 확인이 필요하다.

살펴볼 점
  • README와 관련 모델 문서 확인 수준이며, 직접 설치·영상 업스케일·메모리·복구 시험은 하지 않았다. 처리 속도와 결과 품질은 GPU·VRAM·입력 길이·해상도·타일 설정에 따라 달라진다.
  • 노드 코드의 MIT와 핵심 모델의 허가는 별개다. MiniMax H3 Community License는 대한민국을 기본 적용 제외 지역으로 명시한다. 한국에서 로컬 가중치를 사용하려면 별도 정식 허가 여부를 확인해야 하며, 비상업 수업·연구도 이 지역 조건의 자동 예외로 안내하지 않는다.
  • LoRA와 인코더·VAE 등 자산별 조건도 따로 확인한다. Alissonerdx의 라이선스 안내는 Character Swap·Motion Transfer 등 특정 파일에만 적용되므로, 같은 저장소의 LMS detail LoRA에도 그 허가가 자동 적용된다고 볼 수 없다. LMS의 구체적 권리 조건은 이번 검토에서 확정하지 않았다.
  • 생성 기반 재묘사이므로 사라진 원본 세부를 정확하게 복원한다는 보장이 아니다. 원본 영상의 이용권·인물 동의도 별도로 확보한다.
