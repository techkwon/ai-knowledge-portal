Excel MCP Server: 허용 폴더를 제한한 워크북 자동화

Microsoft Excel 설치 없이 openpyxl 기반으로 워크북을 읽고 편집하는 MCP 서버

#Excel#MCP#스프레드시트

무엇을 할 수 있나요?

공식 저장소는 Windows·macOS·Linux에서 셀·수식·표·차트·피벗 등 Excel 파일 작업을 지원하고, Microsoft Excel이 필요하지 않다고 설명합니다. uv 기반 stdio와 Streamable HTTP 연결을 안내합니다.

--allow-dir로 접근 가능한 워크북 폴더를 한정하고 읽기 전용 설정부터 시작하면, 에이전트가 다루는 파일의 범위를 검토하기 쉽습니다. stdio에서 허용 폴더를 지정하지 않으면 임의의 절대 경로 워크북에 접근할 수 있습니다.

내장 수식 계산 기능과 매크로 보존을 안내하지만 Excel의 모든 동작을 동일하게 재현한다는 보장은 아닙니다. VBA 쓰기는 별도 선택이며 서버는 매크로를 실행하지 않는다고 설명합니다. 코드는 MIT입니다.

살펴볼 점
  • 원본 사본에서 테스트하고 수식·피벗·차트·서식 보존을 실제 대상 앱에서 확인하세요. 특히 복잡한 통합문서는 결과 검수가 필요합니다.
  • HTTP 서비스를 외부에 열 때는 인증·TLS·네트워크 제한이 필요합니다. 모델 제공자나 MCP 클라이언트로 전달되는 데이터 범위도 따로 확인하세요.
  • 공식 문서 확인 기준이며 설치·실행·성능을 직접 시험하지 않았습니다.
