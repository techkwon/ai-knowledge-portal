Pele: Mermaid 텍스트를 SVG로 렌더링하기

Mermaid 구문을 SVG로 바꾸고 CSS 변수로 다이어그램의 색과 글꼴을 맞추는 공개 렌더러

#Mermaid#SVG#다이어그램

무엇을 할 수 있나요?

공식 저장소는 Mermaid 12.1.0의 다이어그램 구문을 대상으로 하는 동기식 SVG 렌더러로 설명하며, runtime 의존성이 없고 MIT 라이선스라고 명시합니다.

render()로 SVG 문자열을 얻거나 브라우저에서 mount()로 붙이는 방식을 제공합니다. AI가 작성한 구조도·순서도 텍스트를 문서와 수업 자료의 시각 요소로 옮기는 단계에 활용할 수 있습니다.

CSS 변수로 색·글꼴을 맞추고, 다이어그램 종류별 등록이나 지연 로딩으로 번들 구성을 선택할 수 있습니다. 문법 호환과 배치·시각적 동일성은 서로 다른 기준입니다.

살펴볼 점
  • 원하는 대상 앱의 Mermaid 버전과 출력 차이를 확인하고 좁은 화면·긴 한글 라벨·색 대비를 직접 검수하세요.
  • 신뢰할 수 없는 다이어그램에는 공식 보안 안내의 링크·스타일·출력 크기 제한을 적용하세요. 제공자 호환 테스트를 사용자 문서 전체의 무오류 보장으로 해석하지 않습니다.
  • 공식 문서 확인 기준이며 설치·실행·성능을 직접 시험하지 않았습니다.
