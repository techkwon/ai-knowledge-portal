Claude Fable 5.2: 장기 코딩·설계 작업과 데이터 보관 조건

공식 공개된 기술 작업용 모델의 접근 경로·API 가격·안전 모니터링 조건을 함께 확인한다.

#Claude#Fable 5.2#코딩#데이터 보관

무엇을 할 수 있나요?

Anthropic은 2026년 11월 9일 Claude Fable 5.2를 공개했다. 공식 제품 페이지는 대규모 코드베이스, 장기 에이전트 작업, 3D·모션·하드웨어 설계 등을 주요 용도로 소개한다. 이는 제작사의 기능 설명이며 이 카드가 모델의 실제 성능 우위나 무감독 작업의 안전성을 독립 검증했다는 뜻은 아니다.

공식 안내상 Pro·Max·Ultra·Team·Enterprise에서 이용할 수 있고 Claude Platform 및 지원 클라우드 경로로도 제공된다. API 모델 ID는 claude-fable-5-2이며 표준 가격은 입력 100만 토큰당 8달러, 출력 40달러, 캐시 읽기 0.20달러다. Fast mode의 입력·출력 가격은 각각 16·80달러로 별도이므로 구독료와 API 비용, 표준·빠른 모드를 구분한다.

코딩 작업에 적용할 때는 프로젝트 권한과 목표를 먼저 좁히고 작은 결과물부터 검토한다. 예를 들어 한 페이지 인터랙션을 만들도록 한 뒤 화면·입력 동작·오류 처리·모바일 표시를 별도로 검사할 수 있다. 정적 캡처만으로 애니메이션이나 게임 조작 품질을 평가하지 않고, 다른 모델과 비교할 때도 도구 실행 권한·추론 강도·반복 횟수를 맞춘다. 이 절차는 검토용 제안이며 실행한 벤치마크가 아니다.

Fable 계열은 기본적으로 안전 모니터링을 위한 30일 데이터 보관을 요구한다. 공식 페이지는 적격 고객의 별도 예외 및 ZDR 경로도 설명하지만 모든 개인 계정에 적용되는 예외로 확대해서는 안 된다. 사이버·생물 분야 질의는 안전장치로 덜 강한 모델에 자동 전환될 수 있다.

API 등 상업용 서비스 약관은 허용 범위에서 입력 권리 유지·출력 소유를 규정하고 고객 콘텐츠로 모델을 학습하지 않는다고 명시하지만, 서비스 지식재산권 자체를 이전하지 않는다. 출력의 정확성과 적합성은 이용자가 검토해야 한다. 개인용 Claude.ai에는 별도 소비자 약관이 적용되므로 API 조건을 개인 구독 전체에 그대로 대입하지 않는다.

살펴볼 점
  • 직접 테스트하지 않았음. 모델 호출·설치·가입·유료 액션을 수행하지 않았다.
  • 제작사 제품 본문과 상업용 약관을 읽었으며 소비자 약관·전체 Usage Policy·시스템 카드까지 검토하지는 않았다. 개인용 이용권한의 포괄적 판단은 하지 않는다.
  • 금융·의료 성과나 사이버·생물학 성능 수치는 검증·재현하지 않아 이 카드에서 추천 근거로 쓰지 않는다.
  • 출력 소유 조항은 제3자 권리 비침해 보장이나 모델 가중치 재배포 허가가 아니다.
  • 리셋권 지급·주간 한도 초기화 범위는 개인별 공식 도움말 검증을 하지 않아 포함하지 않는다.
