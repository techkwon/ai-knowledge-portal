Unreal Engine Skills: Claude Code에서 에디터를 제어하는 MCP

Epic Games가 공개한 스킬·훅으로 Unreal Editor의 오브젝트·블루프린트·에셋·테스트 도구를 연결하는 프로젝트

#Unreal Engine#MCP#게임 개발

무엇을 할 수 있나요?

Unreal Editor의 ModelContextProtocol과 AllToolsets 플러그인이 활성화되고 MCP 서버가 실행되어야 도구를 사용할 수 있습니다. 플러그인 설치만으로 에디터 실행·연결이 확인되는 것은 아닙니다.

공식 안내는 에디터에서 ModelContextProtocol.GenerateClientConfig ClaudeCode로 현재 포트에 맞는 설정을 생성하도록 설명하며 정적 .mcp.json을 동봉하지 않는다고 명시합니다.

액터·블루프린트·머티리얼·시퀀서·테스트 등 편집 기능을 제공합니다. Windows에서 SessionStart 훅에는 Git Bash나 WSL처럼 PATH에 bash가 있는 환경이 필요합니다.

살펴볼 점
  • 도구는 실제 프로젝트를 수정·이동·삭제할 수 있고 임의 Python 실행도 포함합니다. 작업 사본과 버전 관리 백업에서 권한을 최소화하세요.
  • localhost 자체가 신뢰 경계는 아닙니다. 포트를 외부에 노출하거나 승인 절차를 끈 채 신뢰할 수 없는 입력을 처리하지 마세요. 엔진과 플러그인의 사용 조건은 별도 확인하세요.
  • 공식 문서 확인 기준이며 설치·실행·성능을 직접 시험하지 않았습니다.
