AIMovieStorage: 로컬 AI 영상 제작 워크벤치 (Windows, 베타)

GitHub 공식 저장소. 캐릭터·3D 블로킹·프롬프트 작성을 한 프로젝트에서 관리하며 로컬 이미지·영상·음악 생성과 SeedVR2 업스케일링을 지원하는 Windows 데스크톱 도구

#영상 제작#로컬 생성#Windows#오픈소스

무엇을 할 수 있나요?

공식 GitHub README에 따르면 AIMovieStorage는 Windows 데스크톱에서 동작하는 AI 영상 제작 워크벤치로, 시나리오 분해부터 캐릭터·장소 설정, 3D 블로킹, AI 기반 프롬프트 작성, 로컬 또는 외부 생성, 업스케일링까지 하나의 프로젝트 흐름으로 관리합니다.

ComfyUI 없이 자체 워커로 이미지(Qwen-Image, Z-Image Turbo, Krea 2 Turbo), 영상(MiniMax-H3, Wan 2.2, LTX 2.5), 음악(MiniMax-Music3, ACE-Step) 등 로컬 모델을 설치·관리할 수 있고, SeedVR2로 이미지를 2K~8K까지 업스케일링할 수 있습니다.

Claude·OpenAI API를 연결해 대본 분해, 레퍼런스 분석, 카드별 프롬프트 작성을 지원하며, 캐릭터 레퍼런스와 태그를 재사용해 여러 컷에서 동일한 캐릭터 정체성을 유지하는 기능도 제공합니다.

살펴볼 점
  • README에 명시된 대로 베타 단계이며 로컬 생성과 모델별 프롬프트 기능은 아직 검증 중이므로 결과 확인과 백업이 필요합니다.
  • Windows 전용 데스크톱 앱이며, 일부 모델은 Hugging Face 토큰이나 접근 승인이 필요하고 각 모델의 라이선스 조건이 다릅니다.
  • 직접 설치·실행해 테스트한 것은 아니며 공식 README 내용을 확인한 상태입니다.
