P-H3-Image: H3를 8단계 이미지 생성·편집으로 전환한 모델

영상용 MiniMax H3를 정지 이미지 생성·다중 이미지 편집에 맞게 바꾼 Pruna의 공개 가중치 모델. ComfyUI 양자화 워크플로를 제공하지만 한국은 기본 라이선스 적용 제외지역이다.

#Pruna#P-H3-Image#ComfyUI#이미지 생성#이미지 편집#공개 가중치#라이선스 제한

무엇을 할 수 있나요?

무엇인가: H3 영상 모델의 백본·텍스트 인코더·확산 스케줄·디코더를 이미지용으로 바꿨다. 기존 H3 영상 가속·연장·음성 정제 카드와 달리 최종 결과가 정지 이미지이며, 다중 참조 이미지 편집도 제공한다. 별도 연결 논문은 읽은 발표·모델카드에서 확인하지 못했으며 기술 설명과 공개 워크플로를 근거로 한다.

출력과 입력: 모델카드는 8스텝·CFG/negative prompt 없이 8MP 이미지 생성을 설명한다. 기본 정사각형은2912×2912, 편집은4/8MP 권장. 최대8장(편집 대상1장+참조7장) 입력으로 안내한다. 블로그의9장 설명과 불일치하여8장을 보수적으로 표기했다.

실제 워크플로: 공개 JSON의 이미지 조건화, 업샘플러, 8단계 시그마, VAE 디코딩, SaveImage 경로를 읽었다. ComfyUI 자체 노드 사용이지만 모델카드는 최신 master/nightly가 필요하고 안정판·데스크톱·클라우드는 다음 릴리스 반영 예정이라고 안내한다.

필수 자원: ComfyUI4비트의 모델·텍스트 인코더·VAE 기본 묶음은 약20GB 다운로드, 8MP 피크VRAM 약21GB라는 제작사 수치다. 업샘플러는 별도6.7/9.7/19.3GB이고 기본 권장bf16 업샘플러 자체도 약21GB 피크를 안내한다. 따라서 전체 다운로드가20GB라는 뜻은 아니다. INT8 커널 조건은 NVIDIA Ampere 이상 또는 AMD RDNA3/4다. Mac mini 지원을 확인한 자료가 아니다.

속도와 요금: 제작사는 B200 bf16 4MP2.6초·8MP5.8초, L40S48GB4비트2048×2048에서6.3초를 제시한다. 업샘플러 L40Sbf16 약7초는 별도 작업이므로 이를 전체 체감 생성시간으로 단정하지 않는다. 자체 실행의 GPU·전기·호스팅 비용은 별도이며 고정 API/플레이그라운드 요금은 이번 자료에서 확인하지 못했다.

Diffusers와 ComfyUI를 혼동하지 말 것: Diffusers bf16 모델카드는 업샘플러 포함 약101GB VRAM(제외83GB)을 안내한다. ComfyUI 양자화의21GB 수치를 Diffusers 기본 파이프라인 요구량으로 옮기면 안 된다.

권리: 실제 LICENSE는 MiniMax H3 Community License다. 한국·미국·영국·EU는 기본 허용지역 밖이며 별도 MiniMax 허가가 필요하다. Apache2.0는 Qwen 기반 특정 구성요소에만 적용된다.

살펴볼 점
  • 직접 설치·추론·벤치마크하지 않았다. 모든 속도·VRAM·품질 수치는 제작사 문서상 조건부 주장이다. 모델카드와 블로그 사이 입력 수 및 모델 크기 설명의 차이는 해소되지 않았다.
  • 한국은 비상업·연구 목적이라고 자동 예외가 되지 않으며 LICENSE V.4는 Outputs의 지역 외 이용도 제한한다. 공개 가중치를 무제한 오픈소스로 표현하지 않는다.
  • 실제 LICENSE III.3의 Powered by MiniMax H3는 권장사항이다. 상업 UI MiniMax H3 표시는 IV.2의 의무이며, 연매출2천만달러 초과 상업 제품·서비스에는 별도 서면허가가 필요하다. 블로그의 일괄 의무 설명보다 실제 조문을 우선한다.
  • 손·작은 배경 인물·촘촘한 글자·코드 표현은 불안정하고4비트는 세부나 구도가 달라질 수 있다.
  • 타인의 얼굴·캐릭터·사진 사용 권리를 확보해야 한다. 외부 Spaces/API에 학생 사진이나 비공개 원본을 업로드하지 말고 보관·학습·지역 허가 조건을 먼저 확인한다.
